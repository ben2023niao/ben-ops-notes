# 配置管理

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202304141557-DevOps%20%E4%B8%8E%20SRE%2B%E9%AB%98%E6%95%88%E8%BF%90%E7%BB%B4%2B%E7%9F%A5%E8%AF%86%E7%AC%94%E8%AE%B0-%E9%85%8D%E7%BD%AE%E7%AE%A1%E7%90%86.md)

## 介绍

用户维护服务和应用在不同环境下的具体配置。

### 提示

在 Spug 之外使用配置中心的配置信息，取请参考 [API文档](https://spug.cc/docs/config-api)

## 小提示

- 当需要一次性录入大量配置时可以使用 `文本模式` 或 `JSON模式`。
- 当使用 `文本模式` 或 `JSON模式` 创建应用的配置时默认会创建为 `私有` 配置。
