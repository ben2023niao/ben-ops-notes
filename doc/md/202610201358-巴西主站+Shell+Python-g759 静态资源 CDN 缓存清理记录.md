# g759 静态资源 CDN 缓存清理记录

> 来源文件：`~/Projects/work/game/pgserver/master/docs/history/2026-10-20-1358-【运维】g759静态资源CDN缓存清理记录.md`

> 整理日期：2026-10-20 13:58｜日期依据：文件名日期

时间：2026-10-20 13:58（北京）｜2026-10-20 02:58（巴西圣保罗）
需求：「把 g759 的缓存清理一下，参考之前的前端缓存清理操作来」
对象：`g759-static.*` → Cloudflare Worker `summer-wave-c94f` → GCS `newgg2-dbqp-gcs-g759-static`

## 一、做法：按厂家缓存版本号，不做整 zone 刷新

2026-10-17 之后 Worker 已经支持按厂家设置缓存版本（`CACHE_VERSION`），
缓存键是 `https://<prefix>.internal-static-pool/<ver>/<path>`。
给某个厂家加/改版本号并重新部署 Worker，该厂家的边缘缓存整体失效，其它厂家完全不受影响；
比整 zone `purge_everything` 影响面小得多。

本次改动：

```js
const CACHE_VERSION = {
    "pp-static": "v2",
    "g759-static": "v1",   // 2026-10-20：g759 首次启用版本键
};
```

之前 g759 不在这个表里（缓存键不带版本），现在键里多了 `/v1`，
所有旧缓存条目自然失效，等于一次干净的 g759 整体刷新。

## 二、执行

```bash
# 1) 备份线上 Worker（部署脚本会自动存一份）
#    /root/dbqp-cf-backups/summer-wave-c94f.js

# 2) 部署
python3 /opt/dbqp-scripts/cf_worker_deploy.py \
  --script summer-wave-c94f \
  --file /root/worker-g759-v1.js \
  --backup-dir /root/dbqp-cf-backups \
  --token-file /root/dbqp-cf-workers.env
```

结果：`deploy: http=200 success=True`。

### 顺带修掉的问题

宝塔上的 `/opt/dbqp-scripts/cf_worker_deploy.py` 还是 9 月 10 日的旧版，
不会识别 ES Module，第一次上传报
`Uncaught SyntaxError: Unexpected token 'export'`（线上 Worker 未受影响）。
已用仓库里的新版覆盖，旧版备份为 `cf_worker_deploy.py.bak-20261020`。

## 三、验证

1. 线上 Worker 源码已包含 `"g759-static": "v1"`（从 CF API 重新拉取确认）。
2. g759 资源实测（宝塔巴西出口，浏览器 UA）：

   | 路径 | 第 1 次 | 第 2 次 |
   | --- | --- | --- |
   | `/dbqp-gcs-g759-static/games/slofortunetiger/health.json` | `cf-cache-status: MISS` + 200 | `HIT` + 200 |
   | `/games/slofortunetiger/health.json` | `MISS` + 200 | `HIT` + 200 |

   首次 MISS 说明旧缓存已被绕过、重新回源；第二次 HIT 说明缓存重建正常。
3. 其它厂家缓存键未变（pp 仍是 `v2`，其余厂家仍不带版本），不会被这次部署清掉。

## 四、回滚

```bash
python3 /opt/dbqp-scripts/cf_worker_deploy.py \
  --script summer-wave-c94f \
  --file /root/dbqp-cf-backups/summer-wave-c94f.js \
  --token-file /root/dbqp-cf-workers.env
```

备份文件是**本次部署前**的线上版本（`CACHE_VERSION` 只有 pp-static）。

## 五、以后怎么刷

```text
g759 需要再刷一次：把 "g759-static": "v1" 改成 "v2"，重新部署 Worker。
其它厂家同理；改完只影响该厂家，不用整 zone 刷新。
```
