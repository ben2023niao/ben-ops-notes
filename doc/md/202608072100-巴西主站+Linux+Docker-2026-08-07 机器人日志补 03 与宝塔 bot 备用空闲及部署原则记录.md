## 一、排查结论

```text
01/02：日志维护定时器 dbqp-log-maintenance.timer enabled+active，今日仍在运行（小时轮转 + S3 归档）。
03：缺少整套日志维护栈（/usr/local/bin/dbqp_game_log_archive.py、/etc/dbqp-game-log-s3.env、
    /etc/dbqp-logrotate/*、systemd service/timer），日志从不轮转（只有 pg.log，无 .gz）。
日志查看代码（日志排查/action.py）SERVERS 已含 p3（203.0.113.1），问题仅在 03 无轮转产物。
```

## 二、修复

```text
1. 03 部署日志维护栈（从 01 复制，凭据 root 600 不落日志）：
   - /usr/local/bin/dbqp_game_log_archive.py
   - /etc/dbqp-game-log-s3.env
   - /etc/dbqp-logrotate/pgserver、pgserver-hourly、docker-json-existing
   - /etc/systemd/system/dbqp-log-maintenance.service、dbqp-log-maintenance.timer
   - systemctl enable --now dbqp-log-maintenance.timer；强制轮转生成 8 个厂家 .gz。
2. 宝塔 bot 重建为备用空闲实例：
   - 从停止容器导出环境到 /opt/benbot-runtime.env（root 600）；
   - run_standby_bot.sh 身份变量支持覆盖；宝塔以 CONTAINER_NAME=dbqp-ben-bot idle 运行；
   - 身份标识：宝塔备用实例（空闲）/ dbqp-saopaulo-game-results-data-bt / 35.247.205.6 / 203.0.113.1。
3. 文档更新：机器人架构图、交接总览（活动实例=备用机、宝塔=备用空闲、部署原则=备用 nginx 服务器）。
```
