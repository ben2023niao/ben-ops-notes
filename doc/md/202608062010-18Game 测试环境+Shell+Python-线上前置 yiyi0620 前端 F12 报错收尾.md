## 3. 现象和根因

用户截图中的主要异常分两类：

1. API 请求失败或 404
   前置 Nginx 曾把 `/api/v1/...` 代理到 `admin.youdianse.com`，实测该域名对应路径返回 404；线上可用前端 API 入口为 `www.youdianse.com`，同类接口返回 200。

2. 静态资源 403
   H5/PC 前端页面中的部分 `/images/...`、根路径静态图被代理到了错误源或缺少兼容映射。H5 历史缺图 `email.png`、`pwd.png`、`sms.png`、`game-controller-icon.png` 在此前补资源文档中已记录为“源码引用但 `public/images` 中不存在”，本轮前置服务器和本地仓库均未找到真实文件。

补充观察：

- `business.svg` 在本轮页面 bundle 反查中未发现当前首页真实引用；线上 CloudFront 和前置 S3 对该路径也返回 403，判断不是当前首页主要报错路径。
- 本机 in-app Browser 插件不可用，无法直接接管当前 Chrome DevTools；本轮使用 HTTP 状态、Content-Type、页面静态引用和接口抽样替代验证。
