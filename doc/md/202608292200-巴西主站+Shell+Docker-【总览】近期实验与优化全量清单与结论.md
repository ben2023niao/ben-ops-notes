## 三、关键结论

1. **静态**：CF CDN（A 组）优于直连 S3（B 组）：点继续→加载出 7.6s vs 8.2s，
   点击图标→完整加载 12.3s vs 12.6s；
2. **动态**：Argo 3 套生效后，我方点击图标→完整加载均值 12.3s，竞品 14.2s，
   快约 1.9s；画布出现前优势明显（1.2-2.3s vs 2.1-4.7s）；
3. **点继续→加载出**（同基准）与竞品持平（7.6s vs 7.6-7.9s）；
4. 剩余差距与优化点见《Argo三套域优化空间与费用测算》文档。
