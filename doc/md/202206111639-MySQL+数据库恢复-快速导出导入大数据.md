一、导出数据

1、mysqldump

2、重命名压缩

3、scp传输

```
scp msn.sql.zip [邮箱已脱敏]:/root/
```

二、导入数据

1、解压

```
unzip msn.sql.zip
```

2、连接数据库

```
mysql -umsn_block -p password
mysql -umsn_mall -p  password
```

3、设置参数

```
#设置参数
set autocommit=0;
use msn_block;
START TRANSACTION;
#导入数据库
source /root/msn.sql;
#提交事务
COMMIT;
```
