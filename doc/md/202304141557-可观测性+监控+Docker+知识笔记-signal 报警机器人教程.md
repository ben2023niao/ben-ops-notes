# signal 报警机器人教程

```bash
mkdir -p $HOME/.local/share/signal-cli

docker run -d \
--name signal-api \
--restart=always \
-p 8080:8080 \
-v $HOME/.local/share/signal-cli:/home/.local/share/signal-cli \
-e 'MODE=native' bbernhard/signal-cli-rest-api
```

在浏览器中打开 <http://localhost:8080/v1/qrcodelink?device_name=signal-api>

然后在手机上打开 Signal，转到*“设置”>“已链接的设备”并使用**+*按钮扫描二维码绑定上去
