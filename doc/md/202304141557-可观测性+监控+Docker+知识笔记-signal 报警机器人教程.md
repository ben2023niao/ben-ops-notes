# signal 报警机器人教程

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202304141557-%E5%8F%AF%E8%A7%82%E6%B5%8B%E6%80%A7%2B%E7%9B%91%E6%8E%A7%2BDocker%2B%E7%9F%A5%E8%AF%86%E7%AC%94%E8%AE%B0-signal%20%E6%8A%A5%E8%AD%A6%E6%9C%BA%E5%99%A8%E4%BA%BA%E6%95%99%E7%A8%8B.md)

```bash
mkdir -p $HOME/.local/share/signal-cli

docker run -d \
--name signal-api \
--restart=always \
-p 8080:8080 \
-v $HOME/.local/share/signal-cli:/home/.local/share/signal-cli \
-e 'MODE=native' bbernhard/signal-cli-rest-api
```

在浏览器中打开 <http://localhost:8080/v1/qrcodelink?device_name=signal-api>

然后在手机上打开 Signal，转到*“设置”>“已链接的设备”并使用**+*按钮扫描二维码绑定上去
