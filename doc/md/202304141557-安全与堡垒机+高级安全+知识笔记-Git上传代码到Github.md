# Git上传代码到Github

```
我们新建了一个 Git 工程，需要将其上传到 github，按照如下操作步骤：

创建工作空间：

mkdir workspace
cd workspace
初始化仓库：

git init
添加文件：

git add -A ./
提交到缓冲区：

git commit -m "message"
提交到远程：

git remote add origin https://github.com/LibevTcpProj.git
origin 这个相当于是个别名，你可以自己随便写也可以写成当前文件夹的名。

开始上传：

git push -u origin master
更新代码
首先添加修改：

git add .
提交修改：

git commit -m "message"
推送：

git push -u origin master
还记的这个别名吗，origin 这个别名就是你用第一种方法首次向 GITHUB 提交代码你用的别名。
```
