# Git上传代码到Github

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202304141557-%E5%AE%89%E5%85%A8%E4%B8%8E%E5%A0%A1%E5%9E%92%E6%9C%BA%2B%E9%AB%98%E7%BA%A7%E5%AE%89%E5%85%A8%2B%E7%9F%A5%E8%AF%86%E7%AC%94%E8%AE%B0-Git%E4%B8%8A%E4%BC%A0%E4%BB%A3%E7%A0%81%E5%88%B0Github.md)

```
我们新建了一个 Git 工程，需要将其上传到 github，按照如下操作步骤：

创建工作空间：

mkdir workspace
cd workspace
初始化仓库：

git init
添加文件：

git add -A ./
提交到缓冲区：

git commit -m "message"
提交到远程：

git remote add origin https://github.com/LibevTcpProj.git
origin 这个相当于是个别名，你可以自己随便写也可以写成当前文件夹的名。

开始上传：

git push -u origin master
更新代码
首先添加修改：

git add .
提交修改：

git commit -m "message"
推送：

git push -u origin master
还记的这个别名吗，origin 这个别名就是你用第一种方法首次向 GITHUB 提交代码你用的别名。
```
