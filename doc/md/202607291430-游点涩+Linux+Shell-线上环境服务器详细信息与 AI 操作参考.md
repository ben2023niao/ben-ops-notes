## 用途

这份文档给 AI、运维和发布人员在操作线上环境前阅读，用来确认每台服务器的连接方式、认证材料、部署内容、运行进程、关键路径和风险边界。

本页只记录“需要用哪个账号和哪个密钥文件连接”，不记录密码、token、私钥内容、证书私钥、Git 凭据或 Telegram `chat_id`。

## 操作前必读

1. 当前仓库 `main` 分支对应游点涩线上环境，执行前必须确认不要误用测试环境配置。
2. 所有服务器操作优先只读核对，再决定是否修改。
3. 需要发布、重启、改 Nginx、改 crontab、改密钥文件、改 Docker 配置前，先说明影响范围和回滚方式。
4. 不要在终端、文档、提交或 Telegram 中输出任何密码、token、私钥内容、证书私钥、Git 凭据。
5. 线上后端服务器的 Telegram 运行密钥在 `/opt/docker-youdianse-php/cicd-web/runtime/secrets.env`，只允许程序读取后发送通知，不允许打印内容。
