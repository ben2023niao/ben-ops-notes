## 一、背景

Argo 实际开通 3 套：`xqv9m8.icu`、`vendor_a-cdn-2026.icu`、`cdn-tokyo-bizops.icu`
（t6qv8m / q7m9v8 Argo 订阅失败，待面板重试后加回）。

用户要求：

1. `game_hosts` 仅保留 3 套 Argo 根域；
2. 静态资源域名分两组对比：
   - A 组：CF 黄云 CDN 静态域（`pg-static.xqv9m8.icu` 等）；
   - B 组：直连 S3（GCS 桶 `bizops-gcs-*-sa.storage.googleapis.com`）；
3. 每组发布后与竞品对比，口径统一：点游戏→画布→点继续→加载出游戏，
   主指标=点继续→加载出。

## 二、配置与发布

```text
A 组：f7da0931  game_hosts=3 套 Argo 根域 + static_hosts=CF CDN 静态域
B 组：f850ef8d  game_hosts 不变 + static_hosts=直连 S3 桶
最终：86f2840f 恢复 A 组（结论更优）为线上配置
均发布 platform-api 3/3 成功
```

## 三、对比结果（备用机，Fortune Tiger，各 3 轮）

### 点继续 → 加载出游戏（同基准主指标）

```text
A 组(CF CDN)：我方 7.5/7.8/7.7（均值 7.6s）｜竞品 7.4/8.2/7.2（均值 7.6s）→ 持平
B 组(直连S3)：我方 7.3/9.3/7.9（均值 8.2s）｜竞品 8.6/7.4/7.7（均值 7.9s）→ 我方慢 0.3s
```

### 点击图标 → 完整加载

```text
A 组：我方均值 12.3s｜竞品 14.2s（快 1.9s；画布 1.2-2.3s vs 2.1-4.7s）
B 组：我方均值 12.6s｜竞品 14.6s（快 2.0s；画布 0.7-2.3s vs 2.1-5.1s）
```

## 四、结论

1. 静态 A 组（CF CDN）略优于 B 组（直连 S3）：点继续→加载出 7.6s vs 8.2s，
   点击图标→完整加载 12.3s vs 12.6s；
2. 与竞品比：点继续→加载出两边持平（7.6s vs 7.6-7.9s）；
   点击图标→完整加载我方快约 2s（画布出现前优势，CF CDN 静态 + Argo）；
3. 最终线上配置：game_hosts=3 套 Argo 根域 + static_hosts=A 组 CF CDN（86f2840f）。
