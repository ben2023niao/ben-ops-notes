## Nginx 配置

配置文件：

```text
/etc/nginx/conf.d/youdianse-test-record-domains.conf
```

当前是 HTTP 回源/反代配置：

```text
test-h5.* -> 38.92.8.34:3003
test-pc.* -> 38.92.8.34:3004
/(api|channel|customer) -> 38.92.8.34:8088
test-h5-s3.hbabaxb.cn -> AWS S3 H5 静态桶
test-pc-s3.hbabaxb.cn -> AWS S3 PC 静态桶
test-img.* /uploads/ 带 token/t -> CloudFront uploads
test-img.* /uploads/ 缺 token/t -> 固定占位图
```

域名配置明细：

| 域名 | 新 Nginx 规则 | 上游 |
| --- | --- | --- |
| `test-h5.hbabaxb.cn` | H5 页面；API 路径分流到后端 | 页面 `38.92.8.34:3003`，API `38.92.8.34:8088` |
| `test-h5.hbazuua.cn` | H5 页面；API 路径分流到后端 | 页面 `38.92.8.34:3003`，API `38.92.8.34:8088` |
| `test-pc.hbabaxb.cn` | PC 页面；API 路径分流到后端 | 页面 `38.92.8.34:3004`，API `38.92.8.34:8088` |
| `test-pc.hbazuua.cn` | PC 页面；API 路径分流到后端 | 页面 `38.92.8.34:3004`，API `38.92.8.34:8088` |
| `test-h5-s3.hbabaxb.cn` | H5 静态资源代理 | AWS S3 H5 静态桶 |
| `test-pc-s3.hbabaxb.cn` | PC 静态资源代理 | AWS S3 PC 静态桶 |
| `test-img.hbabaxb.cn` | `/uploads/` 必须带 `token/t`；裸链固定图 | CloudFront uploads / 固定图 |
| `test-img.hbazuua.cn` | `/uploads/` 必须带 `token/t`；裸链固定图 | CloudFront uploads / 固定图 |

HTTPS 说明：

```text
当前新服务器未配置 443 证书。
域名由 EdgeOne/CDN 接入，HTTPS 在 EdgeOne/CDN 终止，回源到 162.211.181.13:80。
不要把 EdgeOne/CDN 回源协议设置为 HTTPS，除非后续给新服务器补 443 证书。
```
