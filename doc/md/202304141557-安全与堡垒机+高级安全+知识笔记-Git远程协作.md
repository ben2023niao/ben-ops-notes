# Git远程协作

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202304141557-%E5%AE%89%E5%85%A8%E4%B8%8E%E5%A0%A1%E5%9E%92%E6%9C%BA%2B%E9%AB%98%E7%BA%A7%E5%AE%89%E5%85%A8%2B%E7%9F%A5%E8%AF%86%E7%AC%94%E8%AE%B0-Git%E8%BF%9C%E7%A8%8B%E5%8D%8F%E4%BD%9C.md)

```
Github
github 是一个代码托管的服务提供商，也是一个巨大的开源社区。他可以为个人或者企业提供代码托管，也可以在上面找到很多的开源项目的代码。

Git远程协作命令
更新远程仓库：

git clone url
获取远程仓库的更新：

git fetch
更新完后把指针移到最新：

git merge origin/master
提交本地到远程，首先 pull，然后 push，pull 其实就是 fetch 和 merge 的两个操作：

git pull
git push
如果执行上步，test.txt 有冲突，则修改 test.txt 文件，然后：

git add test.txt
git commit
git push
创建一个 tag：

git tag -a v0 -m"tag for v0"
也可以只更新某一个分支：

git pull origin feacher
只推送本地的 master 分支：

git push origin master
删除本地分支：

git branch -d feacher
删除远程服务器分支：

git push --delete origin feacher
```
