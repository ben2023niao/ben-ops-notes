**安装运行 glances 监控**

```bash
yum -y install epel-release ; yum install -y jq screen glances python2-bottle.noarch使用-R 创建虚拟终端：
screen -R glances
创建好虚拟终端后运行程序
glances -w
这个时候，我们按Ctrl+a，再按d，即可保持这个screen到后台并回到主终端
```
