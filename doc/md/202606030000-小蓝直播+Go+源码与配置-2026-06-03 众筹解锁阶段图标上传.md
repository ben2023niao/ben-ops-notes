# 2026-06-03 众筹解锁阶段图标上传

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202606030000-%E5%B0%8F%E8%93%9D%E7%9B%B4%E6%92%AD%2BGo%2B%E6%BA%90%E7%A0%81%E4%B8%8E%E9%85%8D%E7%BD%AE-2026-06-03%20%E4%BC%97%E7%AD%B9%E8%A7%A3%E9%94%81%E9%98%B6%E6%AE%B5%E5%9B%BE%E6%A0%87%E4%B8%8A%E4%BC%A0.md)

> 整理日期：2026-06-03 00:00｜日期依据：文件名日期

## 背景

后台“众筹解锁阶段”配置仍要求运营手动输入图标 URL，不符合当前后台资源管理方式。

## 变更

- 众筹阶段表单移除图标 URL 输入框，改为图标预览 + 上传按钮。
- 上传走后台通用图片上传 `POST /api/v1/admin/upload`，使用 `scene=crowdfund_icon`。
- 新增上传 scene 存储目录 `media/crowdfund`，上传成功后自动把返回 `url` 写入阶段 `icon_url`。
- OpenAPI / contracts 同步补充 `crowdfund_icon` scene 和 `icon_url` 字段说明。

## 验证

- `pnpm --filter @kickoff/admin typecheck`
- `go test ./services/go-app/internal/service/admin ./services/go-app/internal/http/adminapi`
- `npm run check:openapi && npm run check:contract`
