## 二、为什么内网主机不需要隧道

Beszel 的 agent 是**主动向外连接 Hub**（不是 Hub 连 agent）：

```
agent 日志：WebSocket connected host=52.79.252.255:8090
```

也就是说：

- 内网主机只要能访问 Hub 的公网地址（`52.79.252.255:8090`，出方向），就能被监控
- **不需要**开放任何入方向端口，**不需要**改安全组，**不需要**在 VPC 里放探测点
- 现有的 24 台监控对象里，内网地址的机器都是这么接进来的

> 因此之前设想的「在 203.0.113.1 放 blackbox + SSH 反向隧道」在当前监控体系下没有必要。

**接入方式（拿到凭据后）**：在目标机执行

```bash
docker run -d --name beszel-agent --restart unless-stopped \
  -e LISTEN=61208 \
  -e 敏感凭据：[已脱敏] token> \
  -e HUB_URL=http://52.79.252.255:8090 \
  -e KEY="ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAII+xVa2O3blyab23CN5RnMD8uY6xLDCbIV+zTPw+PtB0" \
  -p 61208:61208 \
  henrygd/beszel-agent
```

（`TOKEN` 在 Beszel 里新增系统时生成；实际部署时由运维填）
