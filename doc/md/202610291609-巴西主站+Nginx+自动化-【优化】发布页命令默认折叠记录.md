# 【优化】发布页命令默认折叠记录

> 来源文件：`~/Projects/work/game/pgserver/master/docs/history/2026-10-29-1609-【优化】发布页命令默认折叠记录.md`

> 整理日期：2026-10-29 16:09｜日期依据：文件名日期

更新时间：2026-10-29 16:09（Asia/Manila）

状态：发布页全部命令区已改为默认折叠，展开/收起验证通过。

## 一、开始前基线

```text
本地 ops master：558af670
本地领先 origin/master：5 个提交
工作区：干净
```

## 二、需求

发布页命令较长，默认全部展开会让页面难扫。要求：

- 命令区默认折叠；
- 点击后展开；
- 再次点击可收起；
- 保留复制按钮；
- 动态生成的发布命令仍可用。

## 三、实现

新增 `setupCollapsibleCodes()`：

- 扫描页面所有 `.code` 命令容器；
- 自动包装为 `<details class="cmd-details">`；
- 默认不设置 `open`；
- 摘要显示“展开命令 / 收起命令”；
- 原命令 `pre` 和复制按钮保持在容器内。

样式新增 `.cmd-details`：

- 标题可点击；
- 关闭状态只显示折叠标题；
- 展开后显示完整命令；
- 打印和复制逻辑保持原有行为。

## 四、验证

```text
HTML 解析：通过
Chrome 实际渲染：通过
命令区总数：14
已包装 details：14
初始展开数量：0
点击巴西 01“展开命令”：显示完整命令和复制按钮
再次点击“收起命令”：恢复折叠
```

动态生成命令不影响折叠，因为包装只移动 `.code` 容器，不替换 `pre`。

## 五、变更范围

本轮只修改发布页和文档，未修改服务器、容器、Nginx、DNS、CDN 或业务数据。
