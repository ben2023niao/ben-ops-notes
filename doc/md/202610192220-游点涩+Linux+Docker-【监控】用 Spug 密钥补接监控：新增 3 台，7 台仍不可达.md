## 一、密钥处理

- zip 内为 `spug公私钥/id_rsa` + `id_rsa.pub`（目录名 GBK 编码，需用 `ditto` 解压）
- 私钥原文件为 **CRLF 换行且缺末尾换行**，导致 `ssh-keygen` 报 `invalid format`；转换 CRLF→LF 并补换行后正常
- 公钥指纹：`SHA256:z2NQHKo2a8ujuR74v0izJHdlq/sChmvpup009nEO3vE`（与 Spug 全局私钥、以及定时任务机登录后端用的是同一把）
