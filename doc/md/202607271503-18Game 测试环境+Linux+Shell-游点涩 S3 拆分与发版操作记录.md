## 4. 2026-07-27 主要操作

### 4.1 测试资源迁移到新加坡

- 确认测试 H5/PC 静态资源和测试业务 uploads 需要从广州链路迁移到腾讯新加坡 COS。
- 建立/确认新加坡 COS 桶：
  - `18game-nuxt-static-test-h5-sg-1450169938`
  - `18game-nuxt-static-test-pc-sg-1450169938`
  - `18game-storage-dev-uploads-sg-1450169938`
- 将新加坡 COS 桶设置为私有。
- 验证 COS 原始域名公网直连返回 `403`，符合“不公开，只能 CDN/EdgeOne 访问”的要求。
- 配置 COS CORS，允许测试 H5/PC 站点跨域读取前端静态资源。

### 4.2 EdgeOne/CDN 与备案域名

- 按备案域名替换要求，围绕 `hbabaxb.cn` 配置测试资源访问域名。
- 初始阶段使用 `test-s3.hbabaxb.cn` 作为测试前端静态资源与部分测试资源的 CDN 域名。
- 配置 EdgeOne 源站为腾讯新加坡 COS，并修正为 S3-compatible 私有源站。
- 补齐私有回源参数：`SignatureVersion=v4`、`Region=ap-singapore`、virtual-hosted addressing。
- 验证 `test-s3.hbabaxb.cn` HTTPS 可访问，抽样资源返回 `200`。
- 同对象 COS 原始域名保持 `403`。

### 4.3 线上后端 S3 首次同步

- 确认线上后端 `.env.prod` 当前仍使用 AWS S3：
  - AWS 区域：`ap-northeast-3`
  - AWS Bucket：`18game-prod`
  - 当前展示域名：AWS CloudFront
- 新建线上腾讯新加坡私有桶：`18game-storage-prod-uploads-sg-1450169938`。
- 创建 `main-s3.hbabaxb.cn` EdgeOne 域名，源站为腾讯新加坡 COS 私有桶。
- 通知 Gname 增加 `main-s3` CNAME：
  - `main-s3.hbabaxb.cn` -> `main-s3.hbabaxb.cn.eo.dnse4.com`
- 使用线上后端服务器上的 `rclone copy` 做 AWS `18game-prod` 到腾讯新加坡 COS 的首次同步。
- 本次明确不修改线上后端 `.env.prod`，线上展示仍继续走现有 AWS CloudFront。

## 5. 2026-07-28 主要操作

### 5.1 排查测试 H5/PC 静态资源异常

- 现象：测试 H5/PC 页面静态资源加载异常，浏览器 F12 出现 404/CORS。
- 排查结论：
  - 页面前端 `_nuxt` 资源仍引用旧地址或共享 `test-s3` 域名。
  - 广州旧桶清理后，部分旧路径资源不可用。
  - 后端接口返回的 AWS/CloudFront 图片资源是后端 uploads，不属于本次前端构建资源问题。
- 处理方向：
  - 前端构建资源不再依赖“桶到桶异步同步”。
  - H5/PC 发版时直接双推 AWS 前端桶和腾讯新加坡前端桶。
  - H5/PC 分别使用独立 CDN 域名，避免共用 `test-s3`。

### 5.3 拆分测试 H5/PC 前端 CDN 域名

最终确认：

| 用途 | 访问域名 | EdgeOne CNAME | 源站 |
| --- | --- | --- | --- |
| H5 前端 S3/CDN | `test-h5-s3.hbabaxb.cn` | `test-h5-s3.hbabaxb.cn.eo.dnse4.com` | `18game-nuxt-static-test-h5-sg-1450169938.cos.ap-singapore.myqcloud.com` |
| PC 前端 S3/CDN | `test-pc-s3.hbabaxb.cn` | `test-pc-s3.hbabaxb.cn.eo.dnse4.com` | `18game-nuxt-static-test-pc-sg-1450169938.cos.ap-singapore.myqcloud.com` |

Gname 解析要求：

| 主机记录 | 类型 | 记录值 | 用途 |
| --- | --- | --- | --- |
| `test-h5-s3` | CNAME | `test-h5-s3.hbabaxb.cn.eo.dnse4.com` | 测试 H5 前端静态资源 |
| `test-pc-s3` | CNAME | `test-pc-s3.hbabaxb.cn.eo.dnse4.com` | 测试 PC 前端静态资源 |
| `_dnsauth.test-h5-s3` | CNAME | `test-h5-s3.hbabaxb.cn.eoacme2.com` | EdgeOne 免费证书 DNS 验证 |
| `_dnsauth.test-pc-s3` | CNAME | `test-pc-s3.hbabaxb.cn.eoacme2.com` | EdgeOne 免费证书 DNS 验证 |

处理过程：

1. 创建 `test-h5-s3.hbabaxb.cn`、`test-pc-s3.hbabaxb.cn` EdgeOne 加速域名。
2. 配置源站到对应腾讯新加坡 COS 私有桶。
3. 配置私有回源参数，使用 S3-compatible 源站和 `ap-singapore`。
4. 主 CNAME 生效后，HTTPS 免费证书文件验证失败。
5. 通知 Gname 补充 `_dnsauth` 证书验证 CNAME。
6. `_dnsauth` 解析生效后，EdgeOne 免费证书验证通过。
7. 发现已签发证书未自动挂载到域名，改为使用证书 ID 显式绑定。
8. 本地和服务器侧验证两个域名 HTTPS `ssl=0` 后，再继续发版。
