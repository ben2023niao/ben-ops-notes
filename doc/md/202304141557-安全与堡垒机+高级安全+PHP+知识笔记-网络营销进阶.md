## 网页速度

如何提高网页速度

1. 控制网页大小
2. 代码瘦身(除去空白区域，除去注释，除去换行，把 css 和 js 代码改为外部文件或使用工具压缩 js 代码)
3. 尽量使用静态页面(没有后台数据库，不含程序和不可交互的网页)

网页代码少了，搜索引擎抓取的速度也会快一些。符合 W3C 相关的国际标准的代码，搜索引擎是非常喜欢抓取的，所以我们写代码要规范。

## 静态页面

1. 完全静态化：CMS 系统一般自带可以配置的
2. 伪静态：页面其实还是动态的，就是 URL 的改写，如把 XXX.php?id=5 改写为 XXX5.html，需要配置网站的服务器来实现，不会提高网页的打开速度，但是有利于搜索引擎的抓取

## 404页面

使用 Google 网站管理员工具，能直接帮你检索出你网站上的 404 错误。

## Ajax技术原理

用户向服务器发送请求，服务器回复数据，客户端只更新需要更新的局部数据，不需要刷新整个页面。

## 搜索技术

1. 全球资源搜索：Google，baidu
2. 局部资源搜索：站内网页搜索，购物网站商品搜索。站内网页搜索的实现：

	1. 利用 Google 实现站内搜索：

	`http://www.google.com/cse/`
	2. 自己创建数据库写程序实现。

## 网站地图

网站地图又叫站点地图，它就是一个页面，上面放置了网站上所有页面的链接。作用：

- 方便用户快速了解网站结构及内容，导航清晰
- 方便搜索引擎爬虫抓取内容

实现思路：

- 从用户使用角度，整理出网站结构
- 添加相应链接，尽量不用图，而使用文字，因为搜索引擎没办法抓取图片

商品图片局部放大技术：左边放一张原图，右边放一张放大后的图片，然后判断鼠标移动的位置，显示大图中相应的位置。
