## 修改内容

- 将生产环境 `XIAOLAN_NAV_SECRET` 与测试环境保持一致。
- 修复外部导航接口返回 `403 密钥无效` 的问题。
- 新增与标准 Spug 模板格式一致的生产发布脚本，包含通知、Git 信息、健康检查和 Docker 状态。
- 停止 Git 跟踪生产 `.env.prod`，避免敏感配置进入仓库。

## 验证结果

- `/api/nav/promote`：HTTP 200，认证通过。
- `/api/nav/stats`：HTTP 200，认证通过。
- Web 与 Admin 容器运行正常。

## Spug 使用

普通发布：

```sh
RUN_MIGRATIONS=0 sh scripts/spug-prod-template.sh
```

包含数据库 migration 的发布：

```sh
RUN_MIGRATIONS=1 sh scripts/spug-prod-template.sh
```

生产密钥仅保存在服务器 `/opt/ghome/.env.prod`，不得提交到 Git。
