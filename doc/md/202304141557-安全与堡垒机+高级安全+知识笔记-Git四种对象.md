# Git四种对象

**[Git](https://haicoder.net/git/git-tutorial.html)** 使用 40 个 16 进制字符的 SHA-1 Hash 来唯一标识对象，Git 中有四种对象，分别为 blob、tree、commit 和 tag。

git 四种对象：

1. blob：表示文本文件或二进制文件。
2. tree：表示是目录。
3. commit：代表着一次历史提交。
4. tag：指向一个固定的历史提交。

它们四种对象的关系为，一个 tag 指向一个 commit，一个 commit 指向一个 tree，tree 里面也可以包含其他 tree 的项和 blob。
