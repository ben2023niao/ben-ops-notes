## 任务边界

用户要求：

```text
使用谷歌云 API 开一下端口，浏览器打不开。
外网面板地址 http://192.0.2.8:30264/dbe2aa30（账号密码由用户提供，不入库/不入群）。
按标准工作流：workbench、逐步群通知、完成后验证、汇总文档发群、最后合并提交本地代码。
```

## 症状

```text
浏览器无法打开 http://192.0.2.8:30264/dbe2aa30（连接超时）。
```

## 排查过程（只读）

```text
1. 云防火墙：GCP 规则 bt-30264 已存在且启用（INGRESS、tcp/30264、192.0.2.3/0、priority 1000）——无需新增。
2. 宿主机：UFW 已放行 30264/tcp；nft 规则有 accept（历史计数 380 包）；iptables ufw-user-input ACCEPT 30264。
3. 面板监听：BT-Panel 监听 192.0.2.3:30264，入口路径 admin_path.pl=/dbe2aa30。
4. 关键异常：
   - ss 显示 30264 Recv-Q=101 超过 Send-Q(backlog)=100，accept 队列溢出；
   - 存在 [BT-Panel] <defunct> 僵尸进程（pid 421285，自 7-24）；
   - 本机 curl 192.0.2.1:30264 也超时（SYN 被丢弃）——说明问题在宿主机/面板进程，不在云防火墙。
5. 对照：80/443（nginx）本机正常，说明 nginx 与业务链路无碍。
```

## 修复

```text
/etc/init.d/bt restart（重启 BT-Panel / BT-Task）
结果：
  - 30264 重新监听，Recv-Q=0（accept 队列清空）；
  - 面板服务可响应，旧 [BT-Panel] 僵尸进程消失；
  - nginx（80/443）、业务容器、其它端口未做任何改动。
```

## 验证

```text
用户确认：浏览器可打开面板并成功登录宝塔（2026-08-07 19:3x）。
技术验证：30264 外网可达、面板正常监听、nginx/业务不受影响。
说明：curl 裸请求 /dbe2aa30 返回面板默认 404（无浏览器头/会话），浏览器访问正常，以用户实际登录为准。
```

## 结论

```text
GCP 防火墙原本已放行 30264，不需要新增云规则；
真正原因是宝塔面板进程卡死（accept 队列溢出 + 僵尸进程），重启面板服务后恢复。
```
