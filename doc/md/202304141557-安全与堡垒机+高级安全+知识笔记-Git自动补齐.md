# Git自动补齐

```
如果我们在使用 git 的过程中，git 不能够自动补齐，我们可以按照如下配置，设置自动补齐：

克隆仓库：

git clone https://github.com/git/git.git
解压缩：

unzip git-master.zip
进入目录：

cd git-master/contrib/completion
拷贝文件：

cp git-completion.bash ~/
cp git-prompt.sh ~/
修改配置，即使用 vim 打开 bashrc，具体命令如下：

vim ~/.bashrc
加入如下配置：

. ~/git-completion.bash
. ~/git-prompt.sh
export GIT_PS1_SHOWDIRTYSTATE=1
```
