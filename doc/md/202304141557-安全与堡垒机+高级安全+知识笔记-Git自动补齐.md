# Git自动补齐

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202304141557-%E5%AE%89%E5%85%A8%E4%B8%8E%E5%A0%A1%E5%9E%92%E6%9C%BA%2B%E9%AB%98%E7%BA%A7%E5%AE%89%E5%85%A8%2B%E7%9F%A5%E8%AF%86%E7%AC%94%E8%AE%B0-Git%E8%87%AA%E5%8A%A8%E8%A1%A5%E9%BD%90.md)

```
如果我们在使用 git 的过程中，git 不能够自动补齐，我们可以按照如下配置，设置自动补齐：

克隆仓库：

git clone https://github.com/git/git.git
解压缩：

unzip git-master.zip
进入目录：

cd git-master/contrib/completion
拷贝文件：

cp git-completion.bash ~/
cp git-prompt.sh ~/
修改配置，即使用 vim 打开 bashrc，具体命令如下：

vim ~/.bashrc
加入如下配置：

. ~/git-completion.bash
. ~/git-prompt.sh
export GIT_PS1_SHOWDIRTYSTATE=1
```
