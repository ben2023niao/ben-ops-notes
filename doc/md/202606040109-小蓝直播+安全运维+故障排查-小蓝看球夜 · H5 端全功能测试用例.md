## 0. 测试前置：后台入口与数据准备

H5 端无自助数据初始化能力，**用例执行前需先登录运营后台造数据**（赛事、竞猜盘口、直播间、运营 banner 等），并自行注册/准备前台测试账号。

| 项 | 值 |
|---|---|
| 后台入口 | https://admin-dev.54-151-131-132.sslip.io/ |
| 后台账号 | `kickoff_admin` |
| 后台密码 | `Admin1234!` |
| 接口文档 | https://admin-dev.54-151-131-132.sslip.io/docs/（权威契约，含 OpenAPI；用例预期结果以此为准） |

数据准备清单（按需在后台创建/配置）：

- **赛事 / 赛程**：覆盖 未开赛 / 进行中 / 已结束 / 延期 / 取消 / 加时 / 点球 各状态，供赛程、首页倒计时、竞猜关联使用。
- **竞猜盘口**：覆盖 未开始 / 进行中 / 待开奖 / 已开奖，配置选项与赔率，供投注、派彩、退款用例。
- **直播间**：至少 1 个在播房间 + 1 个离线房间，配置线路/清晰度，供拉流成功/失败用例。
- **运营 banner**：配置 1 / 6 个两种数量，验证轮播与边界。
- **前台账号**：自行注册若干前台账号（游客态、已登录态、冻结态、首充<14 天账号），用于权限 gate、提现风控等用例。
- **钱包数据**：通过充值/后台调账准备「余额充足 / 余额不足 / 可提现>0」等场景。

> 注意：后台为 dev 环境，造数据后注意清理；资金类用例（充值/提现/投注）优先使用专用测试账号，避免污染。
