## 3. 目录边界

### allowedWritePaths

本次允许 Agent 写入：

```yaml
allowedWritePaths:
  - docs/prd/**
  - packages/contracts/**
```

### readOnlyPaths

本次允许 Agent 读取但默认不能写入：

```yaml
readOnlyPaths:
  - apps/**
  - services/**
  - docs/architecture/**
```

### forbiddenPaths

本次明确禁止修改：

```yaml
forbiddenPaths:
  - .env
  - secrets/**
  - production-data/**
```

### requestedWritePaths

如果 Agent 需要跨边界写入，必须先说明：

```yaml
requestedWritePaths:
  - packages/contracts/**
reason: ""
requiresReview:
  - contract-owner
  - backend-owner
```
