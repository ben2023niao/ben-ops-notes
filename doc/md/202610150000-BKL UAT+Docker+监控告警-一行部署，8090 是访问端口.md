Beszel 监控 - 安装配置
更新时间：2026-10-15
===========================================================

整体就两块：一台"服务端"装监控中心，每台"客户端"装 agent 上报数据。

===========================================================
【服务端】监控中心 Hub（只装一台）
===========================================================

docker run -d --name beszel --restart unless-stopped -p 8090:8090 -v /opt/beszel/beszel_data:/beszel_data henrygd/beszel

===========================================================
【客户端】被监控机器 Agent（每台都装）
===========================================================

docker run -d --name beszel-agent --restart unless-stopped --network host -v /opt/beszel-agent:/var/lib/beszel-agent -v /var/run/docker.sock:/var/run/docker.sock:ro -e KEY="xxxx" -e 敏感凭据：[已脱敏] -e HUB_URL="http://xxxx:8090" henrygd/beszel-agent

===========================================================
【报警】通知到 Telegram（在服务端配置）
===========================================================

telegram://<机器人token>@telegram?chats=<群ID>

===========================================================
【常用命令】
===========================================================

docker logs beszel / docker logs beszel-agent          # 看日志
docker restart beszel / docker restart beszel-agent    # 重启
docker pull henrygd/beszel && docker rm -f beszel      # 升级服务端（客户端同理）

===========================================================
【注意】
===========================================================

1. 监控中心建议只在内网开放，或者加访问控制，不要直接暴露公网
2. 用域名访问时，Hub 的站点地址要填对外域名
3. 官方文档：https://beszel.dev/zh/guide/getting-started
