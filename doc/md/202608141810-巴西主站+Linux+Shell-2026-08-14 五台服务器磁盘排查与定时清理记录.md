## 三、定时清理

```text
新增 docker/scripts/disk_cleanup.sh（仓库，安全清理）：
  - docker builder prune -f + docker image prune -af（在用镜像不受影响）
  - journalctl --vacuum-time=5d --vacuum-size=500M
  - /www/wwwlogs 中 >200M 访问日志截断

  - 宝塔模式（某业务公司_DISK_CLEAN_BAOTA=1）：回收站 3 天前 + /root/bizops-static-import 14 天前暂存

  - 后端 01/02/03：systemd timer 每天 04:00（后端无 cron）
  - 宝塔/备用机：cron 每天 04:00
验证：三台后端 timer active；宝塔/备用机 cron 在位；磁盘 01=32%、02=32%、03=33%、宝塔=46%、备用机=19%。
```
