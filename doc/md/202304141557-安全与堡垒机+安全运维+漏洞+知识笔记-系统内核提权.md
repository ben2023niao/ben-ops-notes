# 系统内核提权

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202304141557-%E5%AE%89%E5%85%A8%E4%B8%8E%E5%A0%A1%E5%9E%92%E6%9C%BA%2B%E5%AE%89%E5%85%A8%E8%BF%90%E7%BB%B4%2B%E6%BC%8F%E6%B4%9E%2B%E7%9F%A5%E8%AF%86%E7%AC%94%E8%AE%B0-%E7%B3%BB%E7%BB%9F%E5%86%85%E6%A0%B8%E6%8F%90%E6%9D%83.md)

> 提示：内核漏洞提权有风险，有可能会崩溃系统。

内核漏洞是我们几乎最先想到的提权方法。通杀的内核漏洞是十分少见的，因而我们应该先对系统相关的信息进行收集，收集方法参考第一小节**基础信息收集**即可。

大多内核漏洞通过内核版本能很快查到
