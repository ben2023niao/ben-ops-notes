# Git服务器搭建

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202304141557-%E5%AE%89%E5%85%A8%E4%B8%8E%E5%A0%A1%E5%9E%92%E6%9C%BA%2B%E9%AB%98%E7%BA%A7%E5%AE%89%E5%85%A8%2B%E7%9F%A5%E8%AF%86%E7%AC%94%E8%AE%B0-Git%E6%9C%8D%E5%8A%A1%E5%99%A8%E6%90%AD%E5%BB%BA.md)

我们可以使用 SSH 搭建 Git 服务器，具体操作如下：

1. 服务器和客户端分别安装 **[git](https://haicoder.net/git/git-tutorial.html)**
2. 服务器上安装 ssh 服务
3. 在客户机上安装 ssh 客户端

具体操作如下：

1. 选择 Ubuntu 作为 git 服务器
2. 安装 git：

`apt-get install git`
3. 安装 ssh 服务(一般系统都安装了)：

`apt-get install openssh-server`
