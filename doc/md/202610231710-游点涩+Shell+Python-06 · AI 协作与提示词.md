# 06 · AI 协作与提示词

> 来源文件：`~/Projects/work/game/youdianse-docker/main/docker-youdianse-php/workbench-kit/docs/06-AI协作与提示词.md`

> 整理日期：2026-10-23 17:10｜日期依据：文件创建/修改时间

## 一、把 AI 接进来的最小做法

1. 把本包解压到项目旁
2. 让 AI 先读 `workbench/START_HERE.md` 与 `docs/02-架构与机器清单.md`
3. 每个任务生成上下文：

```bash
python3 scripts/context_pack.py --task "导出白名单" --out /tmp/ctx.md
```

## 二、固定执行规则（写进 AI 的 system prompt）

```
你是游点涩线上环境的运维助手。
1. 先确认目标环境：main=线上，dev=测试。动线上前必须确认。
2. 只读命令可直接执行；写操作先给计划与回滚方案。
3. 高风险操作前备份：cp -a <file> <file>.bak.$(date +%m%d-%H%M)
4. 每完成一个步骤，向「18GAME_ 上线群」发通知：
   【线上环境｜步骤 N 完成】<步骤名称>
   含：做了什么、验证结果、下一步
5. 不把 token、私钥、密码写进文档、日志、群消息。
6. 命令成功 ≠ 业务正常，必须验证入口。
7. 改配置必须改在配置仓库并 push，否则下次配置发布会覆盖。
```

## 三、提示词模板

### 排查类

```
现象：<一句话>
影响：<用户/接口>
时间：<开始时间>
请：1) 只读确认现象与范围 2) 给 2~3 个可能原因并排序 3) 每个原因给验证命令 4) 结论带数据
```

### 变更类

```
目标：<要改成什么>
约束：不影响线上 / 可回滚 / 低峰执行
请输出：1) 步骤(含备份) 2) 每步验证命令与预期 3) 回滚步骤 4) 风险点
```

### 复盘类

```
按 docs/07-历史问题索引.md 与 history/ 输出：现象/根因/处置/验证/如何避免复发，引用文档路径
```

## 五、AI 不该做的事

- 不经确认直接改线上配置 / 重启业务容器
- 把 `.env`、密钥、Bot Token 打印到聊天或写进文档
- 用 `rm -rf` 清理未知目录（走 `ops/production/scripts/disk-clean.sh`）
- 在服务器上用 `vi`/`echo >>` 改白名单
