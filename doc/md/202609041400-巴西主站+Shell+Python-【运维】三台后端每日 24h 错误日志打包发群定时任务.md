## 一、需求

```text
每天下午 3 点（Asia/Manila）把每台后端 24 小时内错误日志按厂家分类打包发群；
若 24h 内无错误则不发送。脚本用 Python 实现。
```

## 二、实现

```text
脚本：docker/scripts/daily_error_log_pack.py（Python）
  - 扫描 /opt/pgserver/logs/bizops-*-release-* 下 24h 内 *.log/*.gz
  - 抽取 ERROR/Exception/Traceback/Timeout/rcode1110/接口超时/
    SQL Error/sp_upsert/尚未开放/Suspicious IP 等
  - 按厂家分目录：PG/vendor_a/PP/PPK/vendor_c/PANDA/G759/PLATFORM-API
  - summary.txt 列出各厂家行数；无错误 -> NO_ERROR_SKIP 不发群
  - tar.gz 发飞机群（caption 带各厂家计数）
部署：
  /opt/bizops-scripts/daily_error_log_pack.py（3 台）
  /opt/benbot-runtime.env（从宝塔下发，root-only 600，3 台）
cron（后端 UTC，15:00 马尼拉 = 07:00 UTC）：
  0 7 * * * PATH=... /usr/bin/python3 /opt/bizops-scripts/daily_error_log_pack.py
            >> /var/log/bizops_daily_error_pack.log 2>&1
01/02 已安装 cron 包并启用（03 原有）。
```

## 三、验证

```text
1) 三台 crontab 均有上述条目；
2) 01 dry-run：24h 命中 696 行、63 文件，厂家分布
   G759 114/PANDA 16/PG 72/PLATFORM-API 196/vendor_c 3/PP 68/PPK 24/vendor_a 203；
3) 空窗口 dry-run：NO_ERROR_SKIP（不发群）。
```
