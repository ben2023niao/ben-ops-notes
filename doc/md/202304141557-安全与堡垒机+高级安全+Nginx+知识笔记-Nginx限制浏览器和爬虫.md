# Nginx限制浏览器和爬虫

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202304141557-%E5%AE%89%E5%85%A8%E4%B8%8E%E5%A0%A1%E5%9E%92%E6%9C%BA%2B%E9%AB%98%E7%BA%A7%E5%AE%89%E5%85%A8%2BNginx%2B%E7%9F%A5%E8%AF%86%E7%AC%94%E8%AE%B0-Nginx%E9%99%90%E5%88%B6%E6%B5%8F%E8%A7%88%E5%99%A8%E5%92%8C%E7%88%AC%E8%99%AB.md)

## Nginx限制爬虫

修改 nginx.conf，禁止网络爬虫的 ua，返回 403，具体配置如下：

```nginx
server{
 listen 80;
 server_name 203.0.113.1;
 # 添加如下内容即可防止爬虫
 if ($http_user_agent ~* "qihoobot|Baiduspider|Googlebot|Googlebot-Mobile|Googlebot-Image|Mediapartners-Google|Adsbot-Google|Feedfetcher-Google|Yahoo! Slurp|Yahoo! Slurp China|YoudaoBot|Sosospider|Sogou spider|Sogou web spider|MSNBot|ia_archiver|Tomato Bot")
 {
 return 403;
 }
}
```

## Nginx限制浏览器访问

限制浏览器访问：

```
if ($http_user_agent ~* "Firefox|MSIE")
{
 return 403;
}
```
