# 5、历史命令

显示当前用户的历史命令记录

```
history
cat ~/.bash_history

# 查看其他用户的历史命令文件
cat /home/user/.bash_history
```

history显示**内存和~/.bash_history中的所有内容**；
内存中的内容并没有立刻写入~/.bash_history，只有当当前shell关闭时才会将内存内容写入shell
