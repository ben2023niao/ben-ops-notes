## 需求

- 需求 ID：LIVE-101
- 范围：允许修改 H5/Web 代码，C 端直播间接入后端 `/live/room/{id}/play-url` 返回的 ZegoCloud Web SDK 拉流参数。

## 变更

- `apps/web` 新增 `@kickoff/live` 工作区依赖，复用项目内 ZEGO SDK 隔离层。
- 将 H5 `PlayUrl` / `PlayTokenRefresh` 类型切到 `zego_app_id`、`zego_server`、`zego_room_id`、`zego_stream_id`、`zego_user_id`、`zego_token`、`expires_at_ms`。
- 新增 `useLiveZegoPlayer`：
  - 调用 `GET /api/v1/live/room/{id}/play-url` 获取 ZEGO 拉流参数。
  - 登录 ZEGO 房间并 `startPlayingStream`，输出 `MediaStream`。
  - 登录用户过期前调用 `POST /api/v1/live/room/{id}/refresh-token` 续期。
  - 游客因续期接口需要登录，过期前重新获取 play-url 并重连。
- 删除旧的 `useLivePlayUrl` HLS/FLV token 播放逻辑。
- 扩展 `NXPlayer` / `NXPlayerCore` 支持外部 `MediaStream`，直播桌面、移动剧场、横屏沉浸页统一接入 ZEGO 媒体流。
