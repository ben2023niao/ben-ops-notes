## B2【代码已修，待 dev 通道启用】充值 — 后端改契约，前端本轮对齐

### 根因变化
后端没有把字段改回旧契约，而是**更新了契约源**（`packages/contracts/openapi/v1.yaml` + `docs/api/openapi.yaml`，见 `2026-05-26-web-contract-feedback-recheck.md`）：

```
RechargeInitRequest.required = [rmb_amount, channel, pay_type, agree_terms]
  rmb_amount  : string, 10.00-50000.00
  channel     : enum [shark]
  pay_type    : enum [alipay, wechat, union, usdt, dyhbPay, digitalRmb]
  agree_terms : boolean
```

前端代码仍发旧字段 → 被拒。属正常红方待办：契约已更新，前端按新契约对齐（非写转换器迁就错误返回）。

### 复验取证（修复前）
- 浏览器走「member → 充值 → 立即支付」，请求体 `{"amount_rmb":"100.00","channel":"wechat"}` → HTTP 400
- 响应：`参数 channel 取值必须是 [shark] 之一; 参数 rmb_amount 必填; 参数 pay_type 必填; 参数 agree_terms 必填`
- 证据：`.playwright-mcp/screenshot/verify-recharge-fail-B2.png`

| 文件 | 改动 |
