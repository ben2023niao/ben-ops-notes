## 一、需求

```text
用户：
  1. 三个域名都设置到期自动续费：m4q7z1.shop / k8x2v9.shop / p3w9n5.shop
  2. m4q7z1.shop、k8x2v9.shop 是游戏域名；p3w9n5.shop 是商户域名，参考 CF 的商户域名 hk-socket.com
  3. 把这 3 个域名写进香港 01/02 的配置并生效
本轮按要求不发送飞机群通知。
```

## 二、三个域名的注册与续费（需要注册商侧操作）

```text
RDAP 查询（rdap.gmoregistry.net，.shop 注册局已停用 whois）：
  注册商：GNAME.COM PTE. LTD.
  注册时间：2026-09-29
  到期时间：2027-09-29（三个域名一致）
  域名状态：clientTransferProhibited（正常，禁止转移）

⚠️ 自动续费我这边做不了：当前的腾讯云密钥只有 EdgeOne（TEO）权限，
   而域名的续费在注册商 GNAME 侧，腾讯云控制台管不到。
   需要在 GNAME（gname.com）后台操作：我的域名 -> 域名管理 -> 选择域名 -> 开启「自动续费」。
   说明：.shop 是按年计费（1 年一个周期），所以能开的是「到期自动续费（1 年）」；
   如果 GNAME 支持按月分期扣款，在同一个续费设置里选周期即可。
   把 GNAME 的账号或 API 凭据给我，我可以代做。
```

## 三、p3w9n5.shop 商户域名接入（参考 CF 的 hk-socket.com）

```text
对照 CF 的 hk-socket.com 现网配置：
  DNS：hk-socket.com + socket.hk-socket.com 橙云 A -> 192.0.2.37（无 Worker、无缓存规则）
  nginx：server_name hk-socket.com socket.hk-socket.com -> platform-api（9090）
  platform-api 的 api_hosts = socket.hk-socket.com

本轮按同一口径落地（EdgeOne 渠道）：
1) nginx（standby 192.0.2.37）
   新增 server 块：server_name p3w9n5.shop socket.p3w9n5.shop -> bizops_hk_standby_platform_api，
   带 /healthz 探针；备份 *.bak-20261002-p3w9n5；nginx -t + reload 通过。
   直连验证（Host 头）：p3w9n5.shop / socket.p3w9n5.shop / hk-socket.com / socket.hk-socket.com
   的 /healthz 全部 200（新旧域名并存，旧的 CF 渠道未受影响）。

2) EdgeOne（zone-3vm7chzbxkcb，站点已 active + plan-basic）
   用 edgeone_apply.py 的 merchant 模式：2 个加速域名（p3w9n5.shop 根域 + socket.p3w9n5.shop），
   源站 192.0.2.37:80 HTTP；规则 3 条（merchant-nocache 不缓存 + 2 条回源 Host 重写）；
   启用 2 条 CNAME；触发免费证书申请。
```

## 四、香港 01/02 写入三个域名

```text
目标机器：prod-01（192.0.2.16）/ prod-02（192.0.2.17）
文件：/data/server-runtime/conf/domains/*.json
改动（共 68 条 host + 1 处 api_hosts）：
  · static_hosts / game_hosts：每个前缀同时列出两个游戏域名（原来只有 k8x2v9）
        ["pg-static.m4q7z1.shop", "pg-static.k8x2v9.shop"] 等
        顺序：m4q7z1 在前（已在服务），k8x2v9 在后（正在上线）
  · api_hosts（pg.json）：["socket.p3w9n5.shop", "socket.hk-socket.com"]
        新商户域名在前，旧的 CF 渠道保留为第二条
  · vendor_a.json 的 game_hosts（vendor_a-games.hkcloudplay06/07.com）保持原样：EdgeOne 无对应域名，
    在 CF 上也是 404 的历史遗留项

校验：10 个文件 JSON 全部通过；m4q7z1 / k8x2v9 各出现在 8 个文件，p3w9n5 出现在 pg.json
生效：conf/domains 以 bind mount 挂到容器 /app/config/domains，platform-api 每次请求读文件，
      热更新，**不需要重启容器**；已用 docker exec 读容器内 pg.json 确认三处 host 列表都是新值
```
