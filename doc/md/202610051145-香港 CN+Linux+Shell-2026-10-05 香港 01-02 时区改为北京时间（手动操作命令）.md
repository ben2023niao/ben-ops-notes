# 2026-10-05 香港 01/02 时区改为北京时间（手动操作命令）

> 公开版脱敏说明：公司、平台、节点、账号、地址和业务对象均已替换为示例标识；替换后的名称仅用于公开复盘。

> 来源文件：`~/Projects/ops/private-notes/cn/docker/doc/2026-10-05-1145-【运维】香港0102时区改为北京时间手动操作命令.md`

> 整理日期：2026-10-05 11:45｜日期依据：文件名日期

## 一、现状（改动前实测，两台一致）

```text
主机：date -> 2026-10-05 03:41 UTC +0000
      timedatectl -> Time zone: UTC (UTC, +0000)
      /etc/timezone = UTC ；/etc/localtime -> /usr/share/zoneinfo/Etc/UTC
容器（例：game-service-pg-prod）：date -> 03:41 UTC +0000
      容器内 /etc/localtime -> /usr/share/zoneinfo/Etc/UTC，且没有 TZ 环境变量
      => 容器时区来自镜像，**改主机时区不会自动改容器**
定时任务：只有 bizops-container-watch（每分钟）、bizops-result-perms（每 2 分钟），无 crontab、
          无「每天几点」类任务 => 改时区不影响触发节奏（分钟级任务与时间点无关）
```

## 二、主机时区改北京时间（**两台各执行一次**）

```bash
# 1) 改时区（Ubuntu 自带 timedatectl，会同时更新 /etc/timezone 与 /etc/localtime）
timedatectl set-timezone Asia/Shanghai

# 2) 验证（应显示 Asia/Shanghai / CST +0800，且时间与北京一致）
timedatectl
date "+%Y-%m-%d %H:%M:%S %Z %z"

# 3) 确认文件
cat /etc/timezone
readlink -f /etc/localtime
```

```text
预期输出：
  Time zone: Asia/Shanghai (CST, +0800)
  2026-10-05 11:45:00 CST +0800
  Asia/Shanghai
  /usr/share/zoneinfo/Asia/Shanghai
```

若机器没有 systemd/timedatectl（本机有，备用写法）：

```bash
ln -sf /usr/share/zoneinfo/Asia/Shanghai /etc/localtime
echo "Asia/Shanghai" > /etc/timezone
date "+%Y-%m-%d %H:%M:%S %Z %z"
```

改完后受影响的日志：主机 journal/syslog、容器监控日志 `/var/log/bizops-hk-restart-watch.log`
（日志前缀时间会变北京时间；告警正文本来就是「北京 / 香港」双时间）。

## 三、容器时区（可选，需要单独处理）

```text
说明：容器不会跟随主机时区。当前容器日志（如 vendor_b/vendor_d 的 Sanic 日志）都是 UTC 时间。
两种做法：
```

### 方式 A：不重启容器，让后续日志变北京时间（临时，重建容器后失效）

```bash
# 对每个容器执行（把容器内 /etc/localtime 覆盖成北京时区）
for c in $(docker ps --format '{{.Names}}'); do
  docker cp /usr/share/zoneinfo/Asia/Shanghai "$c":/etc/localtime
done

# 验证：应显示 CST +0800
docker exec game-service-pg-prod date "+%Y-%m-%d %H:%M:%S %Z %z"
docker exec game-service-vendor_b-prod date "+%Y-%m-%d %H:%M:%S %Z %z"
```

### 方式 B：永久生效（改 start.sh + 按发版流程重建容器）

```bash
# 1) 备份并给 start.sh 的 docker 参数加上 TZ（保留原有参数不变）
cp -a /data/server-runtime/start.sh /data/server-runtime/start.sh.bak-20261005-tz
python3 - <<'PY'
p = "/data/server-runtime/start.sh"
s = open(p).read()
if "TZ=Asia/Shanghai" not in s:
    s = s.replace("--restart=always \\", "--restart=always -e TZ=Asia/Shanghai \\", 1)
    open(p, "w").write(s)
print("OK" if "TZ=Asia/Shanghai" in open(p).read() else "FAILED——请手工检查 start.sh")
PY
grep -n "restart=always" /data/server-runtime/start.sh

# 2) 重建容器才生效（示例：pg；其它厂家同理，用当前 tag）
cd /data/server-runtime && ./start.sh pg 20261003-ben
docker exec game-service-pg-prod date "+%Y-%m-%d %H:%M:%S %Z %z"
```

```text
⚠️ 方式 B 会重建容器（= 业务容器重启）。香港当前 9 个厂家容器 uptime 1 天多、刚稳定，
   建议放到发版窗口一起做；只想让日志好看，用方式 A 或只改主机时区即可。
```

## 四、回滚

```bash
# 主机时区回滚
timedatectl set-timezone UTC && date

# 容器（方式 B）回滚
mv /data/server-runtime/start.sh.bak-20261005-tz /data/server-runtime/start.sh
```
