## 公共注意事项

- Go 主程序通常位于 `/www/wwwroot/<项目>/main`，监听 9086；日志 `/www/wwwlogs/go/<项目>.log`。
- 配置：`/www/wwwroot/<项目>/config/config.toml`（image_url / MySQL / Redis）。
- PHP 站点若含 `/upload` 路径，需加伪静态 `location /upload { root /www/wwwroot/<项目>/; }`。
- 证书：宝塔 acme_v2 签发 Let's Encrypt，路径 `vhost/letsencrypt/<域名>/`。
