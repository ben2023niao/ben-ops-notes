参照线上改造（`master/docker/doc/2026-08-28-2200-【架构改造】巴西静态GCS圣保罗桶公开地址直出记录.md`）：


## 执行内容

### 1. 香港 S3 公开读（dbqp-h5-hk-517506432530，ap-east-1）

```text
- PublicAccessBlock：BlockPublicPolicy 由 true 改为 false（ACL 相关仍阻止）；
- bucket policy 保留原 15 条 CloudFront OAC 语句（兜底），新增 12 条 PublicRead 语句：
  Principal=*，Action=s3:GetObject，Resource=arn:aws:s3:::dbqp-h5-hk-517506432530/<前缀>/*
  前缀：pg-static、pg3-static、pg4-static、pg5-static、pp-static、ppk-static、
        panda-static、playson-static、g759-static、tada-statics、tada-statics1、tada-statics2；
- CORS 已有（GET/HEAD，origin *），无需变更。
```

### 2. domains 配置（static_hosts -> S3 公开地址）

```text
7 个 JSON（pg/pp/popok/panda/playson/g759/jili）的 static_hosts 全部改为：
https://dbqp-h5-hk-517506432530.s3.ap-east-1.amazonaws.com/<前缀>

pg.json：默认 pg-static + 分组 pg3/pg4/pg5；
pp.json：pp-static；popok.json：ppk-static；panda.json：panda-static；
playson.json：playson-static；g759.json：g759-static；
jili.json：默认 tada-statics、v1 tada-statics1、v2 tada-statics2。

game_hosts（动态域名）保持不变；CloudFront CNAME 域名保留在 DNS 中作为兜底。
```

### 3. 文档更新

```text
docker/conf/README.md、docker/README.md：静态链路改为直接 S3 公开地址。
```
