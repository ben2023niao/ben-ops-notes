```text

实现：宝塔服务器出故障时，机器人跑到备用流量入口服务器也能正常工作全部功能。
按标准工作流：workbench、逐步群通知、完成后验证、汇总文档发群、最后合并提交本地代码。
```

## 1. 公网 IP 确认（VERIFIED）

```text

结论：公网 IP 已固定。
```

## 2. 迁移内容（宝塔 -> 备用机，内网传输）

```text
仓库：/opt/pgserver（1.53GB，含 .git）rsync 到备用机同路径。
镜像：bizops-ben-bot:latest（3.57GB）docker save -> ssh -> docker load。
运行时环境：宝塔容器 env 直传备用机 /opt/benbot-runtime.env（root 600，未落日志/仓库/群）。
数据目录：data/upload、data/scripts、known_chat_ids.json 随仓库同步。
SSH 密钥：/root/.ssh/id_ed25519 -> 备用机仓库 线上服务器信息/192.0.2.8_id_ed25519（root 600）。
gcloud 凭据：三个 SQLite 库 sqlite3 .backup + 配置文件 rsync 到备用机 /root/.config/gcloud。
```

## 3. 备用机部署

```text
容器：bizops-ben-bot-standby（镜像 bizops-ben-bot:latest，restart unless-stopped）
挂载：/opt/pgserver、data/upload、data/scripts、/www/wwwroot、/www/server、/www/wwwlogs、/root/.config/gcloud
脚本：docker/ben-bot/run_standby_bot.sh（idle=待命不轮询 / poll=接管轮询，二选一）
待命模式：不轮询，避免与宝塔 bot 双轮询冲突（同 token 双轮询会 409）。
```
