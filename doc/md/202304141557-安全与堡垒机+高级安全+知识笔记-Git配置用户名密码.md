# Git配置用户名密码

因为 **[Git](https://haicoder.net/git/git-tutorial.html)** 是分布式版本控制系统，所以，每个机器都必须自报家门：你的名字和 Email 地址。

注意 git config 命令的 --global 参数，用了这个参数，表示你这台机器上所有的 Git 仓库都会使用这个配置，当然也可以对某个仓库指定不同的用户名和 Email 地址。

Git 配置用户名和密码的具体命令如下：

```
git config --global user.name "Your Name"
git config --global user.email "[邮箱已脱敏]"
```
