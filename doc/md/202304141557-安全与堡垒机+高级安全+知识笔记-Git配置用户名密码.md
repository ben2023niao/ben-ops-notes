# Git配置用户名密码

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202304141557-%E5%AE%89%E5%85%A8%E4%B8%8E%E5%A0%A1%E5%9E%92%E6%9C%BA%2B%E9%AB%98%E7%BA%A7%E5%AE%89%E5%85%A8%2B%E7%9F%A5%E8%AF%86%E7%AC%94%E8%AE%B0-Git%E9%85%8D%E7%BD%AE%E7%94%A8%E6%88%B7%E5%90%8D%E5%AF%86%E7%A0%81.md)

因为 **[Git](https://haicoder.net/git/git-tutorial.html)** 是分布式版本控制系统，所以，每个机器都必须自报家门：你的名字和 Email 地址。

注意 git config 命令的 --global 参数，用了这个参数，表示你这台机器上所有的 Git 仓库都会使用这个配置，当然也可以对某个仓库指定不同的用户名和 Email 地址。

Git 配置用户名和密码的具体命令如下：

```
git config --global user.name "Your Name"
git config --global user.email "[邮箱已脱敏]"
```
