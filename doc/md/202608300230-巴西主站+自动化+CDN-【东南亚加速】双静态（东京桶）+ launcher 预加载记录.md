## 一、问题

马尼拉/亚洲打开游戏 ~20s+（巴西本地快）。F12 瀑布定位：

```text
优化前（马尼拉，PG 126）：
入口 3.7s → 画布 12.8s → 继续 15.9s → 完整加载 23.9s
慢点：pg4-static.xqv9m8.icu（CF亚洲边缘→巴西源→圣保罗桶）单资源 1-3s
竞品静态走亚洲 CDN（game-logo ~320ms）
```

## 二、方案与实施

### 1. 双静态配置（platform-api）

`static_hosts` = [3 个巴西 CF CDN 域, 东京桶直连 URL]：

```text
pg-static.xqv9m8.icu / vendor_a-cdn-2026.icu / cdn-tokyo-bizops.icu
+ bizops-gcs-pg-static.storage.googleapis.com（东京）
launcher 测速选优：巴西→CF CDN 域，亚洲→东京桶
```

提交：`21720063`（已 push），发布 3/3。

### 2. 东京桶同步

```text
/opt/rsync_asia.sh：12 厂商 rsync → 东京桶
/opt/patch_webp_ct_asia.py：并发 PATCH Content-Type:image/webp（28188 对象，155s，0 失败）
```

### 3. launcher 包体预加载（P0-3）

```text
platform-api/conf/launcher.txt：跳转前 fetch 游戏 HTML（同源），
解析 script/link，预加载静态域/桶上前 10 个资源（preload link）
提交：79cc071e（已 push），发布 3/3
```

## 三、马尼拉实测

```text
优化后：入口 3.5s → 画布 9.7s → 继续 13.0s → 完整加载 21.0s（原 23.9s）
or=bizops-gcs-pg4-static.storage.googleapis.com（东京桶已选中）
单资源延迟：50ms（curl）vs 原 1-3s
```

## 四、剩余瓶颈

```text
游戏引擎顺序加载 241 个资源（vendor 行为）：浏览器瀑布单资源 0.5-0.7s
（同资源 curl 仅 50ms → 主要是引擎串行/连接队列，非网络）
需要：vendor 引擎并行加载/分包，或服务端全量资源清单预加载
```

## 五、回滚

```text
static_hosts 回退：改回纯 CF CDN 域（21720063 前）；launcher 回退：79cc071e 前
东京桶内容与 -sa 桶一致（webp），不影响巴西
```
