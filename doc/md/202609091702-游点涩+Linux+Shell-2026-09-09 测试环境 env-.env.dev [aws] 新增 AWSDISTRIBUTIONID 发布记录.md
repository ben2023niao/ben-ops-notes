## 背景

后端反馈：测试环境 `[aws]` 需新增 `AWS_DISTRIBUTION_ID`。

过程：

```text
配置已由 Kermit 通过 GitLab 合入配置仓库 dev 分支（4191785 -> 25260d6），
但 live 一直未生效。
```

未生效根因：

```text
live /opt HEAD=c6fcd30，且 env/.env.dev 存在 spj2/trtc 等仅服务器本地维护段；
整文件 git merge 会覆盖本地运行配置，因此需要“备份 + 仅增量合入目标 key + no-build 发布”。
```

本次只处理测试环境，不触碰正式环境；`AWS_DISTRIBUTION_ID` 明文不写入文档/Git/通知。

## 操作记录

### 1. 现状核对

```text
远端：origin/dev=25260d6，env/.env.dev [aws] 已含 AWS_DISTRIBUTION_ID（值匹配需求）
本地：worktree clean；merge origin/dev 后本地基线 9d60d5e
live：15.152.247.196 /opt HEAD=c6fcd30；AWS_DISTRIBUTION_ID 不存在；存在本地维护段
```

### 2. live 增量合入

```bash
cd /opt/docker-youdianse-php
git fetch origin dev
mkdir -p cicd-web/runtime/env-backups
cp -p env/.env.dev "cicd-web/runtime/env-backups/.env.dev.before_aws_distribution_id_$(date +%Y%m%d_%H%M%S).bak"
```

备份完成后，从 `origin/dev:env/.env.dev` 提取目标行，只在 `[aws]` 段增量写入；保留：

```text
AWS_DOMAIN_ENCRYPT_KEY（前次任务）
[cdn.tencent.spj2-apk.showfifa.com]
[trtc]
7 处 host=203.0.113.1
```

### 3. 发布

```bash
docker compose --env-file .ops-build.env --profile cron config
docker compose --env-file .ops-build.env --profile cron up -d --force-recreate --no-build web nginx cron
```

### 4. 验证结果

```text
宿主机 env：AWS_DISTRIBUTION_ID=1，值与 origin/dev 一致；AWS_DOMAIN_ENCRYPT_KEY=1；host=203.0.113.1 x7；spj2=1；trtc=1
web 容器：/var/www/html/youdianse-php/.env 含 AWS_DISTRIBUTION_ID -> OK
cron 容器：/var/www/html/youdianse-php/.env 含 AWS_DISTRIBUTION_ID -> OK
容器：youdianse-dev-php-web / nginx / cron 均 Up
HTTP：admin / cicd / h5 均 200
```
