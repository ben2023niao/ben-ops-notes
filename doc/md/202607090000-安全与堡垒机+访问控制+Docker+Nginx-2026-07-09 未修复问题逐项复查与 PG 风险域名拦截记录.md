## 本轮新修复项

### PG 风险旧动态域名仍可访问

复查时发现：

```text
platform-api/conf/domains/pg.json 已不再主动分发：
pg-games.t6qv8m.icu
pg-games.6qv8m.icu

但宝塔活跃 Nginx 仍可通过默认站点接住旧 Host。
公网旧 URL 仍返回 200：
https://pg-games.t6qv8m.icu/65/index.html
https://pg-games.6qv8m.icu/65/index.html
```

风险：

```text
即使新 launcher 不再分发这些域名，旧缓存 URL、手工链接或未来域名同步仍可能再次命中。
PG 客户端在这类 host 下可能继续把 verify host 误拼为：
pg-games.t6qv8api.icu
pg-games.6qv8api.icu
```

本轮运维修复：

```text
1. 修改宝塔域名同步脚本：
   docker/线上服务器信息/baota/scheduled-tasks/sanitized/sync_all_game_domains_to_baota.py

2. 新增 PG_RISKY_GAME_ROOT_DOMAINS：
   t6qv8m.icu
   6qv8m.icu

3. PG provider 的 game_hosts / pg3 game_hosts / api.* 反代 server_name 均过滤这两个 root。
   静态域名不动，因为本次风险在 PG 动态入口派生 verify/API host。

4. 同步脚本到宝塔：
   /www/server/panel/script/sync_all_game_domains_to_baota.py

5. 执行：
   python3 /www/server/panel/script/sync_all_game_domains_to_baota.py --baota

6. 自动备份：
   /root/all_game_domain_sync_backup_20260709_190603

7. 修改共享 Nginx 反代：
   docker/线上服务器信息/baota/nginx/panel-vhost-nginx/common/all-games-proxy.conf

8. 对以下旧 PG 风险动态/API host 直接返回 410：
   pg-games.t6qv8m.icu
   pg-games.6qv8m.icu
   api.t6qv8m.icu
   api.6qv8m.icu

9. Nginx 语法测试并 reload：
   /www/server/nginx/sbin/nginx -t
   /www/server/nginx/sbin/nginx -s reload
```

验证：

```text
https://pg-games.t6qv8m.icu/65/index.html -> 410
https://pg-games.6qv8m.icu/65/index.html  -> 410
https://api.t6qv8m.icu/web-api/auth/session/v2/verifyOperatorPlayerSession -> 410
https://api.6qv8m.icu/web-api/auth/session/v2/verifyOperatorPlayerSession  -> 410
https://api.t6qv8m.icu/api/report/timing -> 410

正常域名不受影响：
https://pg-games.xqv9m8.icu/65/index.html -> 200
https://api.xqv9m8.icu/web-api/auth/session/v2/verifyOperatorPlayerSession -> 405
```

说明：

```text
405 是 GET 访问 verify 接口的预期响应，说明正常 api.xqv9m8.icu 仍可到后端。
真实游戏 POST 带参数时继续走 PG verify 逻辑。
```
