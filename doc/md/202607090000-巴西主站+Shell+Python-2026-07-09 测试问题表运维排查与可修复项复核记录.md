### vendor_a 摇钱树 /cnt/

对应表项：

```text
4 vendor_a 摇钱树：vendor_a-games.cdn-manila-bizops.cyou/cnt/ 404
```

本轮复核：

```text
https://vendor_a-statics1.cdn-tokyo-bizops.icu/cnt/ -> 200
https://vendor_a-statics1.cdn-manila-bizops.cyou/cnt/ -> 200
https://vendor_a-games.cdn-manila-bizops.cyou/cnt/ -> 404
```

判断：

```text
vendor_a-statics1.* 是静态入口，当前 /cnt/ 正常。
vendor_a-games.* 是动态接口/落地链路，不应直接当静态目录打开。

如果真实游戏入口仍把摇钱树发到 vendor_a-games/cnt/，需要继续看 launcher 生成结果。
如果只是手工直接访问 vendor_a-games/cnt/，这个 404 不代表游戏故障。
```

历史交接文档也记录：

```text
vendor_a 摇钱树 pass。
```

结论：

```text
运维静态入口当前 OK。
```

### Playson 大厅显示有误

对应表项：

```text
2 Playson 大厅：电子游艺页面 Playson/API Playson 显示有误
```

历史背景：

```text
Playson 未开放游戏需要从大厅列表访问策略验证。
docker/scripts/patch_ind_h5_entry_static.py 支持过滤 vendor_cbronline 的 gameConfig。
机器人浏览器巡检侧已经内置本地白名单过滤。
```

本轮复核：

```text
公网 https://ind-h5.bizopsplus999.com/vendor_cbronline/ 当前仍能抓到 50 个 gameConfig id。
白名单应保留 33 个。

当前宝塔 /www/wwwroot 下没有 ind-h5.bizopsplus999.com/vendor_cbronline 入口源文件。
历史文档也确认 ind-h5 真实入口源不在当前宝塔。
```

能做的运维动作：

```text
python3 docker/scripts/patch_ind_h5_entry_static.py \
  --source-url https://ind-h5.bizopsplus999.com/vendor_cbronline/ \
  --only-page vendor_cbronline \
  --output-file /tmp/vendor_cbronline.filtered.index.html
```

限制：

```text
只能生成过滤后的 index.html。
需要管理 ind-h5.bizopsplus999.com 真实静态源的人把文件覆盖到 vendor_cbronline/index.html。
当前这台宝塔不能直接修公网大厅源。
```

结论：

```text
机器人巡检已过滤，公网大厅若仍显示 50 个，需要入口源站负责人覆盖过滤后的入口页。
```
