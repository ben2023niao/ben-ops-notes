## 追加：指定配置 git id 发布支持（2026-09-10）

### 背景

为了让 ben-bot 新增按钮「测试环境-游点涩-配置-发版」可以选择历史配置 git id 发布，CICD 在原有“跟随 main HEAD”基础上增加按 ref 发布能力。

### 代码改动（dev=4664fca）

```text
cicd-web/config_repo.py
  - sync_config_repo(logger, force, ref=None)
  - ref 为空：保持原逻辑跟随配置仓库分支（main）
  - ref 非空：fetch 后 git checkout --force <ref>（失败则 fetch origin <ref> + FETCH_HEAD）
  - 写入 runtime/config-repo.last_commit 与 runtime/config-repo.last_ref
  - ref 发布为一次性：不写入分支缓存，后续自动更新仍回到 main

cicd-web/core.py
  - sync_runtime_config_no_build(..., config_ref=None)
  - 日志输出“配置仓库版本：<commit>，ref=<ref>（env/白名单已同步）”

cicd-web/cli.py
  - sync-config-repo --ref <git id>
  - sync-config --force --ref <git id>（指定 ref 自动 force）
  - --json 输出增加 config_ref
```

### 验证结果

```text
1. live 同步（15.152.247.196）：
   sync-config-repo --ref <commit> → 检出成功，last_commit/last_ref 一致
   sync-config --force --ref <commit> → web/nginx/cron no-build 重建成功
   复查：env/nginx/php/日志配置全部 ok

2. 权限与入口：
   env/.env.dev = 644
   alb_white.txt / alb_white_secret.txt = 600
   admin 登录页 200、cicd 200、h5 version.json 200

3. 机器人按钮：
   新增「🧪 测试环境-游点涩-配置-发版」，运维可见；
   列出配置仓库 main 最近提交，选择 git id 后调用上述 --ref 流程；
   完成/失败通知 18game运维 与 18GAME_ 上线群（正式環境）。
```

### 说明

- 指定 ref 发布属于一次性操作；配置仓库 main 有新提交时，自动更新仍会同步到 main HEAD。
- 配置内容不在群通知、工作台或文档中展开。
