# 2026-06-02 大白鲨充值 DeviceId 修复

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202606020000-%E5%B0%8F%E8%93%9D%E7%9B%B4%E6%92%AD%2BShell%2BGo-2026-06-02%20%E5%A4%A7%E7%99%BD%E9%B2%A8%E5%85%85%E5%80%BC%20DeviceId%20%E4%BF%AE%E5%A4%8D.md)

> 整理日期：2026-06-02 00:00｜日期依据：文件名日期

## 背景

前端调用 `POST /api/v1/wallet/recharge/init` 时已传 `X-Device-Fingerprint`，但大白鲨返回：

```text
ToPayRequest.Info.DeviceId validation failed
```

排查发现后端 `WalletHandler.InitRecharge` 只把 `User-Agent` 传入钱包 service，未读取 `X-Device-Fingerprint`。

## 变更

- `WalletHandler.InitRecharge` 读取 `X-Device-Fingerprint` 作为支付上游 `info.deviceId`。
- 缺失 `X-Device-Fingerprint` 时直接返回参数错误，不使用 `User-Agent` 兜底。
- `wallet.Service.InitRecharge` 拆分 `deviceID` 和 `userAgent`：
  - `info.deviceId` 使用 `deviceID`
  - `info.deviceType` 继续通过 `userAgent` 判断 ios/android/pc
- 新增 handler 边界测试覆盖 header 优先级和 UA fallback。

## 验证

```bash
go test ./internal/http/public ./internal/service/wallet ./internal/infra/payment/shark
```

结果：通过。
