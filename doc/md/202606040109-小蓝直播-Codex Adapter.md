# Codex Adapter

> 来源文件：`~/Projects/work/game/xiaolan-watches/dev/docs/agents/adapters/codex.md`

> 整理日期：2026-06-04 01:09｜日期依据：文件创建/修改时间

Codex Adapter 用于把 乌托邦 Core 映射到 Codex 风格的仓库工作方式。

## 入口文件

```text
AGENTS.md
```

`AGENTS.md` 仍然保留，但它不再代表 乌托邦 Core 只服务 Codex。它只是 Codex 的默认入口，同时引用 Core 规则和项目 Overlay。

## 使用方式

1. Codex 进入仓库后先读取 `AGENTS.md`。
2. 再读取任务相关 PRD、OpenAPI、QA、架构和团队成员任务 Brief。
3. 多文件任务按小步实现、验证、记录日志。
4. 合入前运行 `npm run check` 和项目要求的额外命令。

## Codex 特有建议

1. 对复杂任务先写计划，再分切片实现。
2. 使用 Agent 日志记录读取资料、修改文件、验证命令和红蓝对抗。
3. UI 或前端交互变更完成前，启动对应 app，并运行 `UI_VISUAL_BASE_URL=<local-url> npm run verify:ui-runtime`。
4. 不要把 Codex 的执行习惯写成所有 Agent 的默认规则。

## 不允许

1. 只因为 Codex 能直接改文件，就越过 `allowedWritePaths`。
2. 只因为 Codex 能跑命令，就用冒烟测试替代完整验收。
3. 把 Codex 专属目录或指令写进 Core。
