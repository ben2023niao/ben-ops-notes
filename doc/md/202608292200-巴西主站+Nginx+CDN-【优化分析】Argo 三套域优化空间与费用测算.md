## 一、3 套 Argo 域还能做的优化

### CF 侧

| 优化项 | 说明 | 套餐 | 状态/建议 |
|---|---|---|---|
| Cache Rules | 静态域 HTML 也 Cache Everything + 长 TTL（默认只缓存静态扩展名） | Free 10 条 | 待开：`http.host ends with "-static."` → Cache Everything，Edge TTL 1d |
| Tiered Cache | 上层缓存（就近节点命中） | Pro 自带 | 确认 3 套已开（Pro 默认开启） |
| Brotli 压缩 | 文本资源更小 | Pro | 建议开启 |
| Early Hints（103） | 游戏页提前预连静态域/verify | 待确认套餐 | 需验证套餐后开 |
| Argo / HTTP3 / 0-RTT | 已开 | - | 保持 |
| 边缘缓存 /shared/ | 已做（宝塔 nginx 边缘缓存） | - | 保持 |

### 我方侧

1. **nginx 源站缓存**：静态域 location 加 `proxy_cache`（内存/磁盘），
   进一步减少 GCS 回源（CF 未命中时兜底）；
2. **缓存头**：hash 静态资源 immutable 1 年已做；游戏 HTML 可短缓存（已 1h）；
3. **launcher**：P0-1 测速优化已做；P0-2 launcher 模板边缘缓存可继续；
4. **preconnect**：游戏页对 `pg-games.* / <vendor>-static.* / verify.*` 提前连接
   （受厂商页面限制，可尝试 CF 响应头规则/Workers）；
5. **前端**：大厅封面图 WebP + 懒加载（5.5MB → ~1MB）、APP 弹窗可跳过；
6. **接口压缩**：nginx gzip 已开，可加 Brotli（Pro 生效）。

## 二、静态资源使用 3 套 Argo 域的费用与收益

### 费用

```text
固定费：3 套 Pro + Argo 已开通 = $75/月（Pro $60 + Argo $15）
静态走这 3 套域：固定费不增加（zone 已含 Argo）
流量费：Argo 每 zone 免费 1GB/月，超出 $0.10/GB（按走 Argo 优化路径的流量计）
静态资源带 immutable 长缓存头，CF 边缘命中率高，回源/Argo 流量极少
→ 预计每月 Argo 流量费 ≈ $0-几美元（视缓存命中率）
若扩到 5 套：+2×$25 = +$50/月（共 $125/月）
若 22 套全开：+19×$25 = +$475/月（共 $550/月）
```

### 收益（实测对比，备用机 3 轮）

```text
A 组（CF CDN，3 套 Argo 域）：点继续→加载出 7.6s；点击图标→完整加载 12.3s
B 组（直连 S3）：点继续→加载出 8.2s；点击图标→完整加载 12.6s
→ 静态走 3 套 Argo 域比直连 S3：点继续→加载出快约 0.6s，
  点击图标→完整加载快约 0.3s；缓存命中后二次加载收益更大
```

### 结论

静态使用 3 套 Argo 域**不增加固定费用**（已在 3 套 zone 的 Argo 订阅内），
流量费可忽略（高缓存命中）；收益约 0.3-0.6s/次加载。
已作为最终配置（A 组）上线。

## 三、与竞品最新对比（本日复测）

```text
点继续→加载出：我方 7.3/8.4/7.3（均值 7.7s）vs 竞品 8.1/7.3/7.1（均值 7.5s）→ 持平（竞品快 0.2s）
点击图标→完整加载：我方 11.5/13.9/12.8（均值 12.7s）vs 竞品 16.2/12.3/14.8（均值 14.4s）→ 我方快 1.7s
画布出现：我方 1.2-2.5s vs 竞品 2.0-5.1s → 我方明显快
```

差距定位：**点继续之后到加载出**两边打平（竞品略快 0.2s，正常波动）；
我方优势仍在画布出现前（CF CDN 静态 + Argo）。
后续要再拉开，重点在「点继续→加载出」段的资源加载（游戏包体/渲染启动），
方向：游戏静态资源 Brotli/更小包体、Cache Rules 全缓存、preconnect 到静态域。
