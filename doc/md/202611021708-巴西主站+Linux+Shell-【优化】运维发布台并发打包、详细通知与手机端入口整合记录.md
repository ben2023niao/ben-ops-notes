## 一、结论

运维发布台已支持按厂家选择并按 2/3/4 路并发打包，默认 3 路。每个厂家仍调用
03 原有单厂家 `build.sh`，但使用独立临时 runtime；全部成功后才一次性合并到
正式巴西/香港 runtime，避免并发任务互相覆盖域名、配置和元数据。

每个厂家完成后单独发送格式化群通知，包含完成序号、北京时间、版本、批次、
镜像、源码、入口、专属配置、共享配置和日志路径。

页面只保留一份源码：

```text
deliverables/bizops-ops-console/web/运维发布页.html
```

仓库根目录最外层 `运维发布页.html` 和脱敏生成脚本已删除。新增 `运维.html`
作为 VSCode 快捷登录入口。

## 三、并发打包实现

### 3.1 页面操作

- 8 个厂家可独立勾选；
- 并发数可选 2、3、4，默认 3；
- 实时展示每批分组，例如 4 并发时为：

```text
第 1 批：api / pg / vendor_a / ppk
第 2 批：pp / vendor_c / vendor_d / g759
```

- “开始并发打包”按钮显示当前厂家数和并发数；
- 未填写正确 `share.so` MD5 时按钮禁用；
- 打包状态按“排队 / 打包中 / 完成 / 失败 / 未选”显示；
- 每完成一个厂家立即更新页面并发送详细群通知；
- 任一厂家失败后停止后续批次，不合并正式 runtime。

### 3.2 隔离策略

并发调用示例：

```bash
RUNTIME_DIR=/tmp/bizops-build-<tag>/.runtime-<vendor>/br \
RUNTIME_HK_DIR=/tmp/bizops-build-<tag>/.runtime-<vendor>/hk \
  sh build.sh <vendor> <tag>
```

由于原 `build.sh` 已支持覆盖 `RUNTIME_DIR` 和 `RUNTIME_HK_DIR`，无需修改
03 业务仓库脚本即可安全并发。每个任务只写自己的临时目录；批次全部成功后再
合并：

- 选中的 `configs-<vendor>.py`；
- vendor_a 的 `configs-vendor_b.py`；
- 巴西 / 香港 `domains`；
- 巴西 `server_configs`、`version.json`；
- 公共 `xxxxxx.mmdb`、`share.so`；
- 香港独立 `server_configs` / `version.json` 前后 SHA256 保持不变。

### 3.3 自动校验

打包命令在启动前和完成后自动校验：

- 版本号字符安全；
- 开发 `share.so` MD5 格式及实际文件一致；
- 所选厂家镜像存在；
- 巴西 / 香港域名目录与源码一致；
- 香港域名不进入巴西，巴西域名不进入香港；
- 两边 `configs-*.py` 一致；
- 香港独立元数据未被修改；
- 巴西 `server_configs` / `version.json` 与 Git 源一致；
- 输出 `DOMAIN_SYNC=OK`、`CONFIG_SYNC=OK`、`BUILD_COMPLETE=n/n`。

原手工“粘贴输出检查”步骤已移除，页面根据实时执行结果自动完成步骤。

## 四、厂家通知格式

以 vendor_a 为例：

```text
【镜像打包】vendor_a 完成（3/8）
北京：2026-11-02 17:05:25
版本：20261102-ben
批次：api pg vendor_a ppk · 本批 4 个厂家
镜像：192.0.2.1:5000/game-service-vendor_a:20261102-ben
源码：vendor_a/
入口：vendor_a.py
专属配置：
• 巴西 / 香港：vendor_a/configs.py → configs-vendor_a.py
• 巴西 / 香港：vendor_a/configs_vendor_b.py → configs-vendor_b.py
共享配置：domains / domains-hk、server_configs、version.json、
xxxxxx.mmdb、share.so
日志：/tmp/bizops-build-20261102-ben/vendor_a.log
状态：镜像已构建并推送；全部厂家完成后统一合并 runtime 并自动校验
```

通知由后端识别 `BUILD_VENDOR_DONE=<vendor>` 后发送，避免并发日志互相覆盖。

## 五、页面与手机端

- 保留命令默认折叠，收起状态右侧仍可直接点击“执行”；
- 执行后在当前命令下方展开 SSE 实时输出；
- 手机端厂家选择为两列大触控卡片；
- 2/3/4 并发按钮在手机端等宽排列；
- 批次计划、开始按钮和当前进度纵向展示；
- 操作审计折叠时缩成右下角小胶囊，不再遮挡整行；
- 巴西 / 香港服务器状态保持两列展示；
- 只有一个页面源码，避免内外两份 HTML 漂移。
