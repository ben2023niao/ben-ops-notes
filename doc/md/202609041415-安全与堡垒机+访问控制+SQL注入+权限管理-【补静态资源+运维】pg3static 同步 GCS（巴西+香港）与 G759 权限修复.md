## 一、背景

```text
开发把 PG3 前端代码目录由 pg3 改名为 pg3static（client master b7d5a20）；
需要重新同步到 GCS（巴西 live / 香港 asia / backup），并刷新 CDN 缓存。
中途收到 G759 数据集报错：只读连接 SQLITE_READONLY。
```

## 二、pg3static 同步

```text
1) 工具 git_static_gcs_sync.py：
   - STATIC_MAP 增加 pg3static -> pg3-static
   - 支持目录改名场景：diff 同时包含旧目录(pg3)+新目录(pg3static)，
     且 -M 识别纯重命名（7304 R100 不重传），只同步 1038 个真实新增；
   - fetch 后 update-ref HEAD 指向远端 master（修复工具 HEAD 不更新问题）；
2) 初次 git archive 懒拉取触发宝塔磁盘告警（下载 20GB+）-> 中断清理，
   改用 sparse clone（pg3static 8342 文件 / 679MB）；
3) gcloud storage rsync 三路：
   - 巴西 live：gs://dbqp-gcs-pg3-static-sa
   - 香港 asia：gs://dbqp-gcs-pg3-static
   - backup：gs://dbqp-game-statics-gcs/pg3-static
4) 样本校验：1981965_20260826/index.html 三路 md5 均 e44e32f0…；
5) CF 22 zone purge_everything（缓存刷新）；
6) 公网抽测 pg3-static 新资源：三域 MISS→HIT，内容 md5 一致。
```

## 三、G759 数据集权限修复

```text
报错：建立 G759 只读连接失败 [6910]: attempt to write a readonly database
根因：/opt/game_results_datas/g759 目录/文件 root:root 644/755，
      容器 appuser(uid1000) 无法写 -shm/-wal
修复：目录 777、文件 a+rwX（3 台后端），对齐 panda/pg 目录权限；
验证：容器可写、dbqp-g759 重启后 0 readonly 错误、Up。
```
