## 1. 简短版（推荐先发这个）

```text
【通用 Workbench 模板已发群】

这套东西是给项目配一个“AI 能接手的工作台”，解决：
· 换会话就失忆
· 服务器/域名/端口靠猜
· 做完没文档、没验证、没提交
· AI 乱改、密码进仓库

用法（3 步）：
1. 解压后进目录
2. python3 scripts/install.py /path/to/项目 --name "项目名" --with-vscode
3. python3 workbench/scripts/check.py .

先看这 4 篇：
· docs/01-设计思路.md
· docs/03-快速导入.md
· docs/05-VSCode插件与配置.md
· docs/06-Token与AI接入.md

不需要一次全上。先把 AGENTS.md、机器矩阵、ACTIVE_TASKS、doc/日期-事项 用起来。
各项目按自己的技术栈改模块索引和验证命令，骨架别动。
```

## 2. 详细版

```text
【Workbench Kit v1.0.0 · 通用 AI 工作台】

目的：
让任何项目都能被 AI 持续接手，而不是每个会话重新讲一遍背景。

包含：
· AGENTS.md 执行规则
· workbench/ 事实、任务、交接、模板
· 安装器 / 检查器 / 上下文打包 / Telegram 通知
· VS Code 推荐插件与配置
· 设计思路、Token 接入、团队落地文档

导入：
python3 scripts/install.py /path/to/项目 \
  --name "项目名" --slug project-name --with-vscode

检查：
python3 workbench/scripts/check.py .

生成 AI 上下文：
python3 workbench/scripts/context_pack.py --project . --task TASK-001

建议顺序：
1. 先读 docs/01-设计思路.md
2. 按 docs/03-快速导入.md 填 5 个文件
3. 按 docs/05 配 VS Code
4. 按 docs/06 接 AI / Telegram / GitLab Token
5. 用一个真实小任务试点

注意：
· 不要把 token、密码、私钥写进仓库
· 已有 AGENTS.md 不会被覆盖，模板在 workbench/AGENTS.template.md
· 各项目只改事实和模块，不要改“验证后再提交”“高风险先批准”这些骨架
```

## 3. 发完后的跟进

```text
大家先不用一次改完。
每个项目先做三件事：
1. 填机器/域名/端口
2. 登记当前任务
3. 用 AI 跑一个真实小任务，按 context → plan → result 走一遍

跑完把问题发群里：
· 哪一步多余
· 哪个文件看不懂
· 哪个检查失败
· 还缺什么模板

我按反馈出 v1.1，不一次加太多。
```

## 4. 开发者改造提示

```text
开发项目重点改这 4 个文件：
· workbench/PROJECT_INDEX.md      模块、目录、接口
· workbench/PROJECT_RUNTIME_CHAINS.md  本地/测试/生产链路
· workbench/projects/<slug>/CURRENT_STATE.md  当前版本、依赖、已知问题
· AGENTS.md                       测试、构建、发布、回滚命令

最小验证命令建议：
make test
make lint
curl -f http://203.0.113.1:8080/health
```

## 5. 运维项目改造提示

```text
运维项目重点改这 4 个文件：
· workbench/MACHINE_ACCESS_MATRIX.md  机器、网段、账号名
· workbench/PROJECT_RUNTIME_CHAINS.md  域名、反代、端口、证书
· workbench/NOTIFICATION_TARGETS.md    群、chat_id、通知场景
· workbench/AUDIT_CONFLICTS.md         事实冲突与待核验

高风险清单至少包含：
重启生产、改 DNS、改证书、改防火墙、改数据库、改权限、删除资源。
```
