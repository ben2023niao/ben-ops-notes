```text

```


## 问题 2：PG3 静态资源跨域

截图报错资源：

```text
https://pg3-static.xqv9m8.icu/1849515/shared/984721902a/index.json
```

页面 Origin：

```text
https://pg-games.m7v8k3.cyou
```

处理前先执行只读复核：

```text
截图 URL 本机连续 3 轮 OPTIONS + GET：6/6 成功
PG3 22 个静态域名 OPTIONS + GET：44/44 成功
巴西后台 01 连续 5 轮 OPTIONS + GET：10/10 成功
巴西后台 02 连续 5 轮 OPTIONS + GET：10/10 成功
所有响应均为 HTTP 200，Access-Control-Allow-Origin: *
```

22 个静态域名与 GCS live 直连对象内容一致：

```text
bytes=14797
sha256=7322d24cbf0186a2df3d7fb9d8ebc60bd769355b4721e0eb10f56cf2cd5e701d
```

虽然处理时现网已恢复，为避免 bucket CORS 元数据漂移和 CDN 边缘残留旧响应，仍执行了幂等修复。

### GCS CORS 重写

对以下 bucket 重写并回读 CORS：

```text
gs://bizops-gcs-pg3-static
gs://bizops-game-statics-gcs
```

结果：

```text
set 成功：2/2
get 成功：2/2
回读与目标配置完全匹配：2/2
```

配置允许：

```text
origin: *
methods: GET, HEAD, OPTIONS
maxAgeSeconds: 3600
response headers: Content-Type, Content-Length, Range, Content-Range,
                  Accept-Ranges, ETag, Cache-Control
```

### Cloud CDN 精确刷新

使用 URL Map `bizops-static-gcs-map`，针对 PG3 的 22 个 `static_hosts`只刷新截图报错路径：

```text
/1849515/shared/984721902a/index.json
```

没有使用 `/*`，不清空其它 PG3 游戏资源缓存。

结果：

```text
目标 host：22
operation 提交成功：22
DONE：22
失败：0
未完成：0
```
