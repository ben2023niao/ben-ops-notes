**1.确保docker正常运行**

**2.搜索ssr镜像**

```
docker search shadowsocks
```

**3.拉取镜像**

```bash
docker pull oddrationale/docker-shadowsocks
```

**4.运行应用，并设置端口映射，密码**

```bash
docker run -d -p 65535:65535 oddrationale/docker-shadowsocks -s 203.0.113.1 -p 65535 -k ben2022niao -m aes-256-cfb
```

解释：
-d 是后台运行
-p 端口映射
-m 加密方式
-k 登录密码
