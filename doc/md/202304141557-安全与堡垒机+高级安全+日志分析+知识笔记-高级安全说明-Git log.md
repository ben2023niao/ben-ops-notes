# Git log

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202304141557-%E5%AE%89%E5%85%A8%E4%B8%8E%E5%A0%A1%E5%9E%92%E6%9C%BA%2B%E9%AB%98%E7%BA%A7%E5%AE%89%E5%85%A8%2B%E6%97%A5%E5%BF%97%E5%88%86%E6%9E%90%2B%E7%9F%A5%E8%AF%86%E7%AC%94%E8%AE%B0-%E9%AB%98%E7%BA%A7%E5%AE%89%E5%85%A8%E8%AF%B4%E6%98%8E-Git%20log.md)

```
在 Git 中，我们要查看提交的日志，可以使用 git log 命令。

Git log案例
定制 log 显示的样式：

git log --oneline --decorate --graph --all
使用 git show 查看当前分支最新的提交：

git show 91efc48
git show master
git show HEAD
git show master^1
git show --oneline master^1
git show --stat master^1
查看 log 信息：

git log
输出每一个差异之间的统计：

git log --stat
输出工作区与暂存区的差异：

git diff
修改工作区文件：

echo "DD" >> master.txt
查看差异：

git diff
提交修改：

git add master.txt
再次查看差异：

git diff
查看暂存区与历史提交的差异：

git diff --cached
查看某一版本的具体文件的差异：

git diff HEAD~2 -- master.txt
```
