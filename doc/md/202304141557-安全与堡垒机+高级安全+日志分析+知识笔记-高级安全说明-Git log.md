# Git log

```
在 Git 中，我们要查看提交的日志，可以使用 git log 命令。

Git log案例
定制 log 显示的样式：

git log --oneline --decorate --graph --all
使用 git show 查看当前分支最新的提交：

git show 91efc48
git show master
git show HEAD
git show master^1
git show --oneline master^1
git show --stat master^1
查看 log 信息：

git log
输出每一个差异之间的统计：

git log --stat
输出工作区与暂存区的差异：

git diff
修改工作区文件：

echo "DD" >> master.txt
查看差异：

git diff
提交修改：

git add master.txt
再次查看差异：

git diff
查看暂存区与历史提交的差异：

git diff --cached
查看某一版本的具体文件的差异：

git diff HEAD~2 -- master.txt
```
