```text
执行步骤：
1. 对每个 zone 用 API 开启 Polish：
   PUT /zones/{zone_id}/settings/polish，body：{"value":"lossy"}
   （如希望无损质量优先可改 lossless；游戏素材推荐 lossy，体积更小、肉眼差异小）
2. 对每个 zone 开启 WebP：
   PUT /zones/{zone_id}/settings/webp，body：{"value":"on"}
3. 逐个 GET 验证：
   GET /zones/{zone_id}/settings/polish 和 /settings/webp
4. 开启后为 3 个 zone 各执行一次全站缓存清理：
   POST /zones/{zone_id}/purge_cache，body：{"purge_everything":true}
   让图片优化立即生效（如果担心全站清理，可改为只清图片路径或等缓存自然过期，TTL 1天）
5. 不要动 DNS、SSL/TLS、Page Rule、Cache Rule、其他任何设置

输出：zone 名 | Polish | WebP | 缓存清理结果
```

说明：Polish 只对经 CF 缓存且为图片的请求生效；静态子域已开 Cache Everything，满足条件。
