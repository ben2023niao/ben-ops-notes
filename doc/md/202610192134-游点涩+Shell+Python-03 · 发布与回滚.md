# 03 · 发布与回滚

## 一、后端发布（CICD）

```
打开：http://16.209.16.108:18090
流程：选分支(main) → 选 git id → 选是否带 cron → 输入发布密码 → 执行
```

发布会自动：同步配置仓库 → 构建镜像 → 重建 web/nginx/cron → 同步 app-local 文件 → **校验容器内 sha256**，不一致直接判失败。

### 发布后必看

```bash
docker ps --format '{{.Names}} {{.Image}} {{.Status}}' | grep youdianse
python3 cicd-web.py check-app-local          # 白名单一致性，应 PASS
sudo tail -100 /opt/docker-youdianse-php/runtime/app-logs/error-$(date +%F).log
curl -s -o /dev/null -w '%{http_code}\n' http://203.0.113.1:8088/
```

### 已知坑

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 发布后新游戏回调被拒 | 容器内 alb_white 是旧副本 | `check-app-local`；见历史文档《alb_white 白名单缺失》 |
| 发布窗口 502 | php-fpm 未就绪 | 预期短暂，1~2 分钟 |
| 健康检查 WARNING（Redis/Mongo closed） | .env 解析问题 | 见历史文档《健康检查 WARNING 假警》 |

## 二、前端发布（H5/PC）

```bash
pnpm run build:ci      # 测试环境由前端触发，运维收集报错
```

已知问题：`corepack` 拉 pnpm 版本不兼容、`preinstall` 未进镜像 → 模板改为「先 COPY 全量源码再 install」。

## 三、配置发布（env / nginx / php.ini / 白名单）

```
配置仓库：/opt/docker-youdianse-php/config-repo/
发布时会 reset --hard origin/main 后写入运行位置
```

**规则**：`env/.env.prod`、`alb_white*.txt` 只在配置仓库改；服务器上禁止 `vi` / `echo >>`。

## 四、回滚

```bash
# 镜像：选上一个 git id 重新发布
# 配置：都有 .bak.<时间戳>
cd /opt/docker-youdianse-php
sudo ls env/.env.prod.bak.* docker-compose.yml.bak.*
sudo cp -a env/.env.prod.bak.<时间> env/.env.prod
sudo docker compose up -d --force-recreate --no-build web nginx cron

# Beszel 回滚
docker rm -f beszel && docker rename beszel-old-1019 beszel && docker start beszel
```

## 五、发布前检查清单

- [ ] 分支正确（main=线上 / dev=测试）
- [ ] `git status` 干净
- [ ] 配置改动已提交并 push 到 config 仓库
- [ ] 备份要改的文件
- [ ] 群里知会发布窗口
- [ ] 发布后：接口 200、错误日志无新增、监控正常、`check-app-local` PASS
