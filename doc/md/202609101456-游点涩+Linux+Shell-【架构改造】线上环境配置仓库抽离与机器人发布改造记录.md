## 可手动操作运维手册

### 1. 修改线上配置（唯一入口）

```text
1. 打开 https://18game.18git.com/root/docker-youdianse-php-config-main
2. 只修改 main 分支：
   - env/.env.prod
   - app-local-files/alb_white.txt
   - app-local-files/alb_white_secret.txt
3. 提交后不会自动发布；需要机器人/运维显式触发（见下）。
```

### 2. 机器人/运维发布（在线上后端 16.209.16.108）

```bash
cd /opt/docker-youdianse-php

# 只同步配置仓库到 /opt 运行路径（不重建容器，用于核对）
sudo bash -c 'set -a; . cicd-web/runtime/secrets.env; set +a; \
  cicd-web/runtime/venv/bin/python cicd-web.py sync-config-repo'

# 按配置仓库 main 最新提交发布（no-build 重建并同步白名单进容器）
sudo bash -c 'set -a; . cicd-web/runtime/secrets.env; set +a; \
  cicd-web/runtime/venv/bin/python cicd-web.py sync-config --force'

# 按指定配置 git id 发布（机器人按钮使用；历史配置可回放）
sudo bash -c 'set -a; . cicd-web/runtime/secrets.env; set +a; \
  cicd-web/runtime/venv/bin/python cicd-web.py sync-config --force --ref <配置 git id>'
```

### 3. 发布后验证

```bash
cd /opt/docker-youdianse-php
sudo cat cicd-web/runtime/config-repo.last_commit
sudo cat cicd-web/runtime/config-repo.last_ref
sudo sha256sum env/.env.prod
sudo docker exec youdianse-main-php-web sha256sum /var/www/html/youdianse-php/.env
sudo docker exec youdianse-main-php-cron sha256sum /var/www/html/youdianse-php/.env
sudo docker ps --filter name=youdianse-main-php --format '{{.Names}} | {{.Status}} | {{.Image}}'
curl -s -o /dev/null -w 'admin=%{http_code}\n' http://203.0.113.1:8088/admin1866/login
curl -s -o /dev/null -w 'cicd=%{http_code}\n' http://203.0.113.1:18090
```

### 4. 回滚

```bash
# 方式一：按历史配置 git id 发布回放
cd /opt/docker-youdianse-php
sudo bash -c 'set -a; . cicd-web/runtime/secrets.env; set +a; \
  cicd-web/runtime/venv/bin/python cicd-web.py sync-config --force --ref <历史配置 git id>'

# 方式二：恢复 env 备份文件后重建（备份位于 env/.env.prod.bak.*）
# 方式三：如镜像需回退，按 CICD 正常发布流程指定业务 git id 发布
```

## 遗留事项

```text

   cicd-web.py sync-config --force --ref <配置 git id>

2. 服务器运维仓库工作区仍有历史本地改动，auto-update 会跳过自动 pull；配置发布不受影响。

   runtime/secrets.env（当前只迁移了运维群 TG_CHAT_IDS）。
```
