# 线上环境文档分类命名规范

> 来源文件：`~/Projects/work/game/youdianse-docker/main/docker-youdianse-php/docs/2026-07-29-1000-【运维记录】线上环境文档分类命名规范.md`

> 整理日期：2026-07-29 10:00｜日期依据：文件名日期

文档日期：2026-07-29 10:00
环境：游点涩线上环境（main 分支）
分类：运维记录

## 命名格式

线上环境文档统一使用下面格式：

```text
YYYY-MM-DD-HHMM-【分类】线上环境标题.md
YYYY-MM-DD-HHMM-【分类1+分类2】线上环境标题.md
```

目录索引文件可以继续使用 `README.md`，但正文开头必须标记 `文档日期`、`环境`、`分类`。新增操作类文档还必须标记 `标签`。

## 操作文档归档要求

每次线上操作都要落一份文档到 `docs/`，文件名按“日期 + 小时分钟 + 分类 + 线上环境 + 标题”命名。

`HHMM` 使用 24 小时制，例如 `1510` 表示 15:10。这样同一天的文档按文件名排序时，最新记录会排在更下面。

如果文档同时属于服务器资料、事故记录、快照说明等场景，可以在 `ops/production/` 保留同名文档或索引入口；但 `docs/` 必须有一份可被后续 AI 和运维直接检索到的操作记录或操作笔记。

操作类文档头部推荐格式：

```text
文档日期：YYYY-MM-DD HH:MM
环境：游点涩线上环境（main 分支）
分类：数据维护
标签：线上环境、后端、配置文件、平台名、手动维护
```

正文至少写清楚：

1. 需求背景和操作目标。
2. 到哪台服务器操作。
3. 每一步执行什么命令。
4. 每条命令是什么意思。
5. 怎么备份。
6. 怎么验证。
7. 怎么回滚。
8. 哪些敏感内容不能输出、不能提交。

## 常用分类

| 分类 | 使用场景 |
| --- | --- |
| 运维记录 | 服务器清单、巡检、交接、索引、提示词、普通操作记录 |
| 问题排查 | 现象分析、根因定位、只读排查过程 |
| 修复Bug | 线上缺陷修复、权限修复、接口异常修复 |
| 网络调整 | 域名、Nginx、反向代理、CORS、CDN、白名单等网络侧变更 |
| 架构改造 | 目录结构、持久化、服务拆分、基础设施搭建等结构性改造 |
| 优化 | 参数调优、日志轮转、容量治理、性能和稳定性优化 |
| 补静态资源 | 游戏或客户端静态资源补档、同步、验证记录 |
| 数据维护 | 数据包、结果集、备份、迁移和人工维护记录 |
| 配置维护 | `.env`、白名单、平台密钥、业务开关等配置文件维护；可与 `数据维护` 合并为 `数据维护+配置维护` |

## 环境标记

生产文档必须在文件名或正文开头明确包含 `线上环境`，正文头部统一写：

```text
环境：游点涩线上环境（main 分支）
```

操作类文档还要补一行标签，方便检索：

```text
标签：线上环境、后端、配置文件、平台名、手动维护
```

测试环境文档不要放在 `ops/production/`，应放到 `ops/test/`，并明确写测试环境，避免正式环境操作时误用。

2026-07-29-1015-【修复Bug+网络调整】线上环境PG四大神兽静态资源CORS修复记录.md
