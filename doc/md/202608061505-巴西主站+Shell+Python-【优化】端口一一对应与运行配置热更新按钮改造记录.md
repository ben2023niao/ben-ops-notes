### 3.2 运行配置热更新脚本

新增文件：

- `docker/scripts/hot_update_runtime_config.py`

能力：

- 白名单仅允许更新：
  - `version.json`
  - `server_configs`
- 根据所选 Git 版本执行 `git show <revision>:<file>` 抽取文件。
- `version.json` 会做 JSON 解析校验。
- 计算本地文件 SHA256。
- 默认目标后台：
  - `203.0.113.1:01`
  - `203.0.113.1:02`
- 默认目标容器：
  - `dbqp-pg-release-01/02`
  - `dbqp-tada-release-01/02`
  - `dbqp-pp-release-01/02`
  - `dbqp-popok-release-01/02`
  - `dbqp-playson-release-01/02`
  - `dbqp-panda-release-01/02`
  - `dbqp-platform-api-release-01/02`
- 正式执行时流程：
  1. 验证目标容器运行中。
  2. scp 文件到后端临时目录。
  3. `docker cp` 到每个运行容器的 `/app/<filename>`。
  4. 容器内 `sha256sum` 校验。
  5. `test -f /app/<filename>` 校验存在。
- 不重打镜像、不重启业务容器。
- dry-run 不连接后端，只验证 Git 文件、SHA256 与目标容器清单，便于本地安全校验。

注意：正式执行依赖运行环境提供 `PGSERVER_DEPLOY_PASS`，不写入仓库、不输出密钥。
