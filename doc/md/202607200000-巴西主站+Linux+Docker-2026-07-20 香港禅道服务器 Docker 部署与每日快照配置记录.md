## Docker 与禅道

Docker：Ubuntu `docker.io 29.1.3`，服务 `enabled + active`。

官方文档：<https://www.zentao.net/book/zentaopmshelp/405.html>

部署参数：

```text
container: zentao
image: hub.zentao.net/app/zentao:18.5
image digest: sha256:eec1c80743662b1f9dc216f000d33eb6928e6fc9ddeb12dd9967805d73fd0007
restart policy: always
host port: 80 -> container 80
network: zentaonet / 192.0.2.21/24
container IP: 192.0.2.22
volume: /data/zentao -> /data
MYSQL_INTERNAL: true
```

验收状态：

- 容器 `running`。
- `RestartCount=0`。
- 公网 `/` 返回 302 到 `install.php`。
- 本机跟随跳转返回 HTTP 200。
- `/data/zentao` 已产生持久化数据。
- 宿主机未映射 MySQL 3306。

内置浏览器当时没有可连接标签页，因此未代替用户点击首次安装向导，也未通过非官方方式改数据库。下一步由管理员打开 Web 地址设置管理员账号和密码；完成后再补做登录页、管理员登录和基础功能验收。

## Beszel 监控

```text
container: beszel-agent
image: henrygd/beszel-agent
network: host
restart policy: unless-stopped
hub: http://192.0.2.15:8090/
listen env: 45876
docker socket: read-only
data volume: beszel_agent_data
```

Agent 使用 TOKEN/WebSocket 主动连接模式，日志已确认 `WebSocket connected`，容器状态 `running`、重启次数 0。该模式不要求本机实际监听 45876，但仍按要求创建 GCP 规则 `bizops-hk-allow-beszel-agent-zentao`，只允许 Hub `192.0.2.15/32` 访问 TCP 45876。

TOKEN、KEY 和其他认证值不写入仓库或通知。
