## 背景

开发已优化 Cloudflare Worker，每个静态厂家/前缀都有独立的：

```js
version
forceNoCache
```

开发会直接手工修改线上 Worker，`ben` 分支也会维护 Worker 源码，因此线上、ben 分支和
运维仓库可能同时存在差异。

顶层只保留当前线上版本；所有历史版本移入 `history/`。

## 每厂家版本维护规则

每个静态前缀可独立维护。按厂家清理时需要更新该厂家全部相关前缀：

```text
PG：pg-static、pg3-static、pg4-static、pg5-static、pg6-static、pg7-static
vendor_a：vendor_a-statics、vendor_a-statics1 至 vendor_a-statics5
PP：pp-static
PPK：ppk-static
vendor_c：vendor_c-static
PANDA：vendor_d-static
G759：g759-static
```

`version` 变化只影响对应前缀的边缘缓存；`forceNoCache=true` 会要求浏览器重新协商，
适合更新窗口。不要为了单个厂家全局替换版本号。

## 后续操作

1. 先拉取 Cloudflare 线上源码。
2. 使用 `scripts/cf_worker_backup.py` 备份。
3. 比较线上、ben 分支、仓库当前版本。
4. 修改目标厂家/前缀的独立 `version`。
5. 发布后从巴西目标区域验证真实文件。

详细规范：
