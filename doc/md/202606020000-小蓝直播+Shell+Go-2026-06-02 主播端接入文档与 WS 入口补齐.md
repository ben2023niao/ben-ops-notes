# 2026-06-02 主播端接入文档与 WS 入口补齐

> 来源文件：`~/Projects/work/game/xiaolan-watches/dev/docs/agents/logs/2026-06-02-streamer-integration-docs-and-ws.md`

> 整理日期：2026-06-02 00:00｜日期依据：文件名日期

## 背景

前一版只给 C 端补了 `/ws/v1/client` 统一入口和 C 端接入说明。前端还需要主播端独立说明，且主播端应使用主播 JWT 的独立 WS 入口，不能混用 C 端 `/ws/v1/client`。

## 变更

- 新增主播端 WS：`GET /ws/v1/streamer?敏感凭据：[已脱敏]
- 主播端 WS 只接受 `streamer` subject 的 JWT。
- 主播端可通过 `client.subscribe` 订阅：
  - `room:{room_id}`
  - `match:{match_id}`
- 主播端不允许订阅 `user:*`，不接钱包个人频道。
- 新增 `docs/api/streamer-integration.html`。
- docs 首页新增「主播端接入指南」入口。
- WS 协议页、当前实现文档、OpenAPI/conventions 同步 `/ws/v1/streamer`。
