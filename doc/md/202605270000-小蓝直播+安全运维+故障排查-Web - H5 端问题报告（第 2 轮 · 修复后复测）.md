## 三、P1 详情

### N-01 赛程页时区错误：日期分组 + 时刻整体早 8 小时（P1）

- **现象**：同一场赛事在首页与赛程页时间不一致。
  - 英格兰 vs 挪威（`start_at_ms=1779847644000` = UTC 05-27 02:07 = 本地 05-27 **10:07**）：首页显示「05-27 10:07」（正确），赛程页显示「05-27 02:07」（早 8h）。
  - 美国 vs 加拿大（UTC 05-27 16:00 = 本地 05-28 00:00）：`schedule/days` 接口按本地日期归到 `2026-05-28`，赛程页却归到「05-27」组、时刻显示「16:00」（应为 05-28 00:00）。
  - 决赛 西班牙 vs 塞尔维亚（UTC 05-29 16:00 = 本地 05-30 00:00）：接口归 `2026-05-30`，赛程页归「05-29」组、显示「16:00」。
- **根因**：
  - `app/utils/adapters.ts:53` `toMatchVM`：HomeMatch 分支用 `new Date(m.start_at_ms).toISOString()` 生成 **UTC** ISO 字符串作 `kickoffAt`。
  - `app/pages/schedule.vue:26,56` 用 `kickoffAt.slice(0,10)` 取日期分组——拿到的是 UTC 日期，且**忽略了接口返回的本地 `date` 分组字段**。
  - `app/components/match/MatchScheduleRow.vue:23` `kickoffAt.slice(11,16)` 取时刻——拿到的是 UTC 时刻。
- **对比**：首页用本地格式化（正确），赛程页用 UTC slice（错误），两端不一致。
- **影响**：TC-SCH-001（日期分组）、TC-SCH-004（24h HH:mm）全部时间/日期错误；PC 与 H5 同样受影响。
- **建议**：`kickoffAt` 直接用本地化格式（`toLocaleString` / 指定 `Asia/Shanghai`）或保留时间戳由组件按本地渲染；日期分组优先用接口 `date` 字段，不要从 UTC ISO 切片。

## 四、P2 详情

- **N-02 充值上界无拦截**：充值弹窗输入 50001，无 inline 报错、「立即支付」按钮可点（仅下界 10 有拦截）。后端 `recharge/breakdown` 会返回「单次充值不能高于 50000 RMB」兜底，但前端应与下界一致地 inline 拦截。
- **N-03 预设金额硬编码**：充值弹窗预设 50/100/200/500/1000/2000 为前端写死；`GET /config/system` 返回 `recharge_amount_options=[6,30,100,300,500,2000]`。前端未消费后端配置（注：后端这组配置本身也可疑，见 api 报告）。
- **N-04 投注「余额不足」按钮无反应**：余额 0 时投注弹窗确认按钮文案变为「余额不足」（非 disabled），但点击无任何反应——既不弹充值也不禁用。对比同场景打赏弹窗能正确弹充值。TC-PRED-010 期望「弹充值弹窗、不扣款」。当前不扣款 ✅，但未弹充值；建议复用打赏的弹充值逻辑。
- **W-13 竞猜列表无投注入口**：`PredictActivityCard` 选项无 @click/emit，纯展示；投注只能从首页热门竞猜或直播间发起，TC-PRED-004「列表点选项弹投注」不达。
- **W-14 跳过凭证图**：带 `redirect`（如点「我的」跳 `/auth?redirect=/member`）注册成功后直跳目标页，跳过「选端→凭证图」，用户错过保存账号机会（TC-AUTH-021）。
- **W-15 客服链接**：`/member` 专属客服指向 `https://xiaolankanyeqiu.netlify.app/#telegram`（原型站锚点），非 PRD 约定的 Telegram `@kickoff_vip`。
- **W-11 dev 模拟按钮**：`/recharge/qr` 页「支付中/充值成功/充值失败」三个手动按钮疑似调试用，生产应隐藏。
- **W-10 USDT 缺失**：充值仅微信/支付宝/银联/数币 4 种；用例期望含 USDT，但 `CLAUDE.md` 标 USDT 为 v1 范围外（ADR-0010 暂缓）→ 用例与范围冲突，以谁为准需产品确认。
- **C-01 充值赠送广告**：直播间顶部展示「新人首充翻倍 · 充 100 送 200」广告 creative；`CLAUDE.md` v1 范围外清单标注「充值赠送活动（充 100 送 200）」为原型错误展示、无对应业务条目。此处是后台运营 ad slot 配置的数据，建议下线该 creative 或与产品确认。
