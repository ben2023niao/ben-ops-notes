## 实现内容

### `weekend_duty.json`

- 新增 `groups`（一组/二组）、`team_lead`、`big_small_weeks`（大小周映射）、`big_week`（大周周六/周日组）、`small_week`（小周周日组轮换）、`by_date`（8 月逐日排班）、`rest_by_date`（本周调休）、`weekday_rotation`（工作日两组轮换）。

### `duty_status.py`

- 周末值班按“大小周 + 分组”解析：大周周六一组、周日二组；小周仅周日一组。
- 工作日面板显示大小周、本周末值班预告、本周调休。
- 周末面板显示 `星期（大周/小周）· 值班组`。
- 出勤统计：已休假按 `rest_by_date` 已发生调休统计；剩余休假 = 本月值班天数 - 已休假；人员标注所属组。

### `duty_schedule.py`

- 排班/日历/详情/月度统计同步大小周与分组；payload 输出 `week_kinds`、`rest_by_date`、逐日 `group`。
