# HTTP请求方式

## HTTP请求方式教程

HTTP1.0 定义了三种请求方法： GET, POST 和 HEAD方法。

HTTP1.1 新增了五种请求方法：OPTIONS, PUT, DELETE, TRACE 和 CONNECT 方法。

## HTTP请求方式

| 请求方式 | 描述 |

| --- | --- |

| GET | 请求指定的页面信息，并返回实体主体。 |

| HEAD | 类似于 GET请求，只不过返回的响应中没有具体的内容，用于获取报文头。 |

| POST | 向指定资源提交数据进行处理请求（例如提交表单，或者上传文件）。数据包含在请求体中。POST 请求可能会导致新的资源的建立或已有资源的修改。 |

| PUT | 从客户端向服务器传送的数据取代指定的文档内容。 |

| DELETE | 请求服务器删除指定的页面。 |

| CONNECT | HTTP/1.1协议中预留给能够将连接改为管道方式的代理服务器。 |

| OPTIONS | 允许客户端查看服务器的性能。 |

| TRACE | 回显服务器收到的请求，主要用于测试或诊断。 |

## HTTP请求方式详解

HTTP请求方法名称是区分大小写的，当某个请求所针对的资源不支持对应的请求方法的时候，服务器应当返回 **状态码405**（Mothod Not Allowed）；当服务器不认识或者不支持对应的请求方法时，应返回状态码 501（Not Implemented）。

HTTP服务器至少应该实现 GET 和 HEAD/POST 方法，其他方法都是可选的，此外除上述方法，特定的 HTTP 服务器支持扩展自定义的方法。

### HTTP请求方式说明

#### HTTP GET

HTTP 的 GET 请求方式用于向特定的资源发出请求。注意：GET 方法不应当被用于产生 “副作用” 的操作中。

#### HTTP HEAD

HTTP 的 HEAD 请求用于向服务器获取 GET 请求相一致的响应，只不过响应体将不会被返回。这一方法可以再不必传输整个响应内容的情况下，就可以获取包含在响应小消息头中的元信息。

#### HTTP POST

HTTP 的 POST 请求用于向指定资源提交数据进行处理请求（例如提交表单或者上传文件），数据被包含在请求体中。POST请求可能会导致新的资源的建立和/或已有资源的修改。

#### HTTP PUT

HTTP 的 PUT 请求用于向指定资源位置上传其最新内容。

#### HTTP DELETE

HTTP 的 DELETE 请求用于请求服务器删除 Request-URL 所标识的资源。

#### HTTP CONNECT

HTTP/1.1 协议中预留给能够将连接改为管道方式的代理服务器。

#### HTTP OPTIONS

HTTP OPTIONS 请求用于返回服务器针对特定资源所支持的 HTTP 请求方法，也可以利用向 web 服务器发送‘*’的请求来测试服务器的功能性。

#### HTTP TRACE

HTTP TRACE请求用于回显服务器收到的请求，主要用于测试或诊断。

## HTTP请求方式总结

HTTP1.0 定义了三种请求方法： GET, POST 和 HEAD方法。

HTTP1.1 新增了五种请求方法：OPTIONS, PUT, DELETE, TRACE 和 CONNECT 方法。
