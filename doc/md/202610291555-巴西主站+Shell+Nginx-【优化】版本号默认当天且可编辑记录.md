# 【优化】版本号默认当天且可编辑记录

## 二、需求

版本号：

- 不再自动生成和只读；
- 默认值为当天 `YYYYMMDD-ben`；
- 用户可以手工编辑；
- 用户修改后，页面重绘或修改版本日期不能覆盖；
- 后续命令必须实时使用用户输入。

## 三、实现

页面修改：

```text
版本号（默认今天，可编辑）
```

逻辑：

1. 初始化时将版本号设为当天 `YYYYMMDD-ben`。
2. `effTag()` 优先读取 `verTag` 输入值。
3. 输入值非空时直接使用，不再从版本日期重新生成。
4. `render()` 不再给 `verTag.value` 赋值。
5. 输入版本号时触发 render，打包、镜像检查和群提示实时更新。
6. 版本日期仍可修改，但只影响日期字段，不覆盖手工版本号。

## 四、验证

```text
默认值：20261029-ben
输入：20261029-custom
顶部版本标签：20261029-custom
打包命令：build.sh all 20261029-custom
镜像检查命令：grep 20261029-custom
把日期改为 2026-10-30：版本号仍保持 20261029-custom
```

Chrome 实际渲染和交互验证通过。
