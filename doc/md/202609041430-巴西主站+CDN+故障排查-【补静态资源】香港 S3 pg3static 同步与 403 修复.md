## 一、问题

```text
pg3-static.hkcloudplay03.com/2081892/2081892/history/index.json 返回 403
（Ben(C++) 反馈“不行啊，403”）。
```

## 二、根因

```text
香港 hkcloudplay* 静态链路 = AWS S3 + CloudFront（非 GCS）。
此前只同步了 GCS（巴西 live/asia），香港 S3 桶未更新 ->
CloudFront 找不到新对象返回 403。
```

## 三、修复

```text
1) 重建 pg3static 源并确认 2081892/2081892/history/index.json 存在；
2) 香港入口机 192.0.2.14 执行：
   AWS_PROFILE=bizops-hk /usr/local/bin/bizops-sync-gcs-to-s3 pg3-static
   （源 GCS asia -> s3://bizops-h5-hk-517506432530/pg3-static/）
   sync_complete：source 8364 = destination(adjusted) 8364；
3) CloudFront pg3-static（E1MELSI31IM0FQ）全量 invalidation
   （I2CI89IWXDE49RU02W8UBVU027，Completed）。
```
