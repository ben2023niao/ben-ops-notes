## 线上前置模拟目标关系

这台机器的定位不是直接替代正式线上 H5/PC，而是在正式线上发布前，跑线上代码和线上配置做最后一次前端排雷。

建议目标链路：

```text
用户 / 内部验收浏览器
├─ H5 页面: main-h5.备案域名
│  -> DNSPod CNAME
│  -> EdgeOne/CDN 页面加速域名
│  -> 源站 43.241.16.84
│  -> Nginx
│  -> H5 线上代码容器，例如 3003
├─ PC 页面: main-pc.备案域名
│  -> DNSPod CNAME
│  -> EdgeOne/CDN 页面加速域名
│  -> 源站 43.241.16.84
│  -> Nginx
│  -> PC 线上代码容器，例如 3004
├─ H5 前端静态资源: main-h5-s3.备案域名
│  -> DNSPod CNAME
│  -> EdgeOne/CDN 静态资源域名
│  -> 腾讯 COS H5 前端静态资源桶
├─ PC 前端静态资源: main-pc-s3.备案域名
│  -> DNSPod CNAME
│  -> EdgeOne/CDN 静态资源域名
│  -> 腾讯 COS PC 前端静态资源桶
└─ 后端 uploads: main-img.备案域名
   -> DNSPod CNAME
   -> EdgeOne/CDN 图片资源域名
   -> 线上 uploads 源链路或线上 Nginx 代理链路
```

注意：用户聊天里线上 PC 页面写过 `test-pc.备案域名`，结合命名规则判断应统一为 `main-pc.备案域名`，避免线上与测试混用 `test-*` 前缀。
