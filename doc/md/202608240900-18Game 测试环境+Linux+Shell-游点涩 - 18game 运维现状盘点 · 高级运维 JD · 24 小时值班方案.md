## 七、近期问题复盘（为什么要 24h 值班 + 高级运维）

### 7.1 SDK 域名批量链路风险验证（2026-08-20，E4 安全事件）
- 10 个 SDK 域名（安卓 5 + iOS 5）在注册商 Gname 被批量改 DNS（NS→Cloudflare 指向第三方短剧站），导致多款游戏登录/注册失败、支付回调受影响；
- 处置：逐款解包 APK 核验 baseUrl、恢复解析到平台 AWS CloudFront/网关、加固网关 nginx（worker_connections 4096 + keepalive）、更新 pay.callback 域名并重建容器；
- 启示：需要 7×24 盯防 + DNS 变更审计 + 注册商加固 + 备用通道。

### 7.2 CPU 持续高位（2026-08-20，容量瓶颈）
- 晚间 QPS 约 280，4 核后端 load 5-6、idle 1.5%，连续 CPU 99% 告警；
- 处置：**扩容 4C/7.5G → 16C/30G**，PHP-FPM 调优（max_children 64、opcache 256M、memory_limit 256M），全量巡检验证；
- 启示：容量规划要按 QPS/接口成本测算，扩容后仍需调优，需要懂 PHP-FPM/OpCache 的运维。

### 7.3 Redis 连接端口耗尽偶发 500（2026-08-21）
- 高 QPS 下容器 ephemeral 端口被打满（2.8 万 TIME_WAIT），约 50% 请求 500；
- 处置：compose 加 sysctls（端口范围翻倍 + tcp_tw_reuse）+ 应用侧连接复用建议；
- 启示：需要懂 TCP/内核参数/连接池的深度运维，且要能独立复盘定位。

### 7.4 其他近期问题
- 正式包打入测试 SDK 域名导致登录失败（发布/打包链路校验）；
- 大数据上报缺数据/重复（logbus2 链路改造：去重+防丢失）；
- 发布会话丢失/分叉（CICD 加固）；
- 测试环境配置缓存被 3.6MB 脏数据撑爆（Redis 大 key 治理）；
- 自动发布构建失败（GitHub 429 → 镜像源切换）；
- 磁盘/日志告警治理。

## 十二、可优化点清单（真实，供会议讨论）

1. **高可用**：线上后端/网关单台 → 增加备机或容器编排（docker swarm/k8s 可选，按成本评估）；
2. **DNS 安全**：注册商加固（开启域名锁/双因素）、DNS 变更审计告警、备用权威 DNS；
3. **监控补强**：接入 Prometheus/Grafana（可选）、接口/支付成功率拨测、证书到期提前告警；
4. **值班工具**：值班看板 + 告警转群 + 一键 SOP 按钮；
