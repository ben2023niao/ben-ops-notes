## 部署内容

```text
Docker：29.7.2（docker-ce 官方源，docker daemon 正常，hello 容器验证通过）。
Nginx：1.30.4（nginx.org 源，含 http_ssl/http_v2/http_v3，支持配置中的 quic/http2）。
复制自宝塔（内网 rsync）：
  - 证书：/www/server/panel/vhost/cert（78 个域名目录，fullchain.pem + privkey.pem）
  - nginx 引用目录：common / extension / well-known / tcp / rewrite / proxy.conf
  - 活跃站点配置 45 个 -> /etc/nginx/conf.d/
    （动态：pg/tada/pp/ppk/playson/panda games + socket；静态：各 static 站点；
     排除 btwaf/lua/php/fastcgi/ssl.<root> 等宝塔面板专属配置）
  - 前端静态资源 12 个目录（26GB）-> /www/wwwroot/
主配置：/etc/nginx/nginx.conf（user www，include conf.d/*.conf，保持宝塔目录引用路径）。
```

```text
  1. Cloudflare 动态域名 A 记录从 35.247.205.6 改为 34.151.249.53
     （* -games.<root> / api.<root> / socket.xtmpz.com 等所有橙云记录）。

  3. 如宝塔短暂不可用，先手工改 Cloudflare 记录；恢复后切回。
  4. 证书续签仍在宝塔；备用机证书为复制副本，长期运行需定期 rsync 刷新。
```
