# Agent Adapter 目录

> 来源文件：`~/Projects/work/game/xiaolan-watches/dev/docs/agents/adapters/README.md`

> 整理日期：2026-06-04 01:09｜日期依据：文件创建/修改时间

本目录说明不同 AI 工具如何接入 乌托邦。

乌托邦 的核心判断是：

```text
Core 工具无关，Adapter 工具相关。
```

Core 定义事实源、契约、门禁和完成标准。Adapter 负责把这些规则翻译成某个工具习惯的入口文件、命令、子 Agent、hooks 或工作流。

## 当前适配器

| Adapter | 入口 | 模板目录 | 状态 |
| --- | --- | --- | --- |
| Codex | `AGENTS.md` | `framework/adapters/codex/` | 可用 |
| Claude Code | `CLAUDE.md`、`.claude/**` | `framework/adapters/claude-code/` | 可用 |

## 适配器边界

1. Adapter 可以改变“怎么调用”，不能改变“什么才算完成”。
2. Adapter 可以提供快捷命令，不能绕过 `npm run check`、验收矩阵和 Agent 日志。
3. Adapter 可以建议 hooks，但不能把危险自动化作为默认必开。
4. Adapter 文件默认走 advisory review，避免框架升级覆盖项目本地 AI 配置。

## 新增适配器要求

新增 Cursor、GitHub Copilot、通用 CLI Agent 等适配器时，必须补：

1. `docs/agents/adapters/<adapter>.md`
2. `framework/adapters/<adapter>/README.md`
3. 入口模板或命令模板。
4. `scripts/validate-agent-adapters.py` 支持。
5. PRD、验收证据和 Agent 日志。
