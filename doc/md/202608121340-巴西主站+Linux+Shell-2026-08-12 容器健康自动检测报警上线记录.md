## 任务

```text
自动检测访问不了要报警；各厂家容器状态也要报警；
容器异常、重启、恢复都要报警；监控尽量详细。
```

## 实现

```text
新增 docker/scripts/container_health_monitor.py：
  - 检查 3 台后端 7 个业务容器（pg/vendor_a/pp/popok/vendor_c/vendor_d/platform-api）+ beszel-agent 共 24 个；
  - 事件报警：
    * 容器异常：running -> 非 running（exited/restarting/dead/missing 等）
    * 容器重启：RestartCount 增加
    * 容器恢复：非 running -> running
    * 容器缺失：期望容器不存在
    * 后端不可达：SSH 查询失败
  - 状态文件 /var/tmp/bizops-container-health.json 防重复报警；支持 --dry-run 测试。
部署：备用机 cron 每 2 分钟运行（与入口监控并列），凭据取自 /opt/benbot-runtime.env。
```

## 排障记录

```text
首轮基线误报“后端查询失败”：docker ps --format 不支持 {{.RestartCount}} 字段导致远端命令失败；
已改用 docker inspect 获取 RestartCount 并保留 stderr，修复后基线 OK，并自动发出后端恢复通知闭环。
```
