## 一、口径修正

用户指出此前对比口径不统一：水印「点继续→可玩」实际显示的是
「点击图标→完整加载」（click_to_loaded_ms），两边起点不同，不具可比性。

修正：两边统一执行「点游戏 → 画布 → 点继续 → 加载出游戏」，
主指标为 **点继续→加载出游戏（continue_to_loaded_ms）**：

- `game_click_to_loaded_compare.py`：新增 `continue_to_loaded_ms`
  （点继续时刻 → wait_stable 网络稳定）；
- `label_game_videos.py`：水印分阶段改为「画布 X.Xs｜点继续→加载出 Y.Ys」，
  并单独标注「★ 点继续→加载出游戏」与「★ 点击图标→完整加载」两个口径。

## 二、结果（3 轮，备用机，Fortune Tiger）

### 点继续 → 加载出游戏（同基准）

```text
我方：8.6s / 7.3s / 8.6s，均值 8.2s
竞品：7.7s / 8.4s / 7.2s，均值 7.8s
→ 基本持平，竞品略快 0.4s
```

### 点击图标 → 完整加载（含画布前阶段）

```text
我方：12.8s / 12.8s / 13.3s，均值 12.9s；画布 1.2-2.5s
竞品：14.6s / 17.2s / 12.4s，均值 14.7s；画布 2.1-5.8s
→ 我方快约 1.8s
```

## 三、结论

1. 同基准「点继续→加载出」两边基本打平（竞品略快 0.4s，属正常波动）；
2. 我方优势集中在画布出现前（点游戏→画布 1.2-2.5s vs 竞品 2.1-5.8s，
   CF CDN 静态 + Argo 生效），整体「点击图标→完整加载」我方快约 1.8s；
3. 6 条带水印视频已发群（水印含两个口径）。
