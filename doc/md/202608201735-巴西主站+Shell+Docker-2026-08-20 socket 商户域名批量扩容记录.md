## 背景

```text
socket.xtmpz.com 是 platform-api/socket 独立反代站点（nginx -> socket_backend -> 9090）。
此前商户 API 仅此一个域名，单点故障风险高（2026-08-20 该域名 Cloudflare 回源异常，公网全 404）。
用户要求：把目前全部 22 个根域都加 socket.<root> 二级域名（参考 socket.xtmpz.com），批量生成商户域名，消除单点故障。
```

## 处理

```text
1. 根域清单（22 个）：
   xqv9m8.icu / t6qv8m.icu / p8m7xv.cyou / m7v8k3.cyou / q7m9v8.icu / m6xv8q.cyou /
   qv9m8.icu / 6qv8m.icu / 8m7xv.cyou / 7v8k3.cyou / 7m9v8.icu / 6xv8q.cyou /
   vendor_a-cf-2026.cyou / vendor_a-host-game.icu / vendor_a-cf-game.cyou / vendor_a-cdn-2026.icu /
   vendor_a-cdn-game.icu / vendor_a-host-2026.icu / cdn-tokyo-bizops.icu / cdn-tokyo-bizops.cyou /
   cdn-manila-bizops.icu / cdn-manila-bizops.cyou
2. Cloudflare 核对：22 个根域均已配置 *.<root> 通配 A 记录（橙云 proxied 回源宝塔 192.0.2.8），
   socket.<root> DNS 解析已通，无需新增 DNS 记录。
3. 宝塔：socket.xtmpz.com.conf server_name 由单域名扩容为 23 个（socket.xtmpz.com + 22 个 socket.<root>），
   nginx -t 通过并 reload；原文件备份 socket.xtmpz.com.conf.bak-20260820。
4. 备用机：/etc/nginx/conf.d/socket.xtmpz.com.conf 同样扩容并 reload（配置与证书目录均已同步）。
5. 监控扩展（docker/scripts/entry_health_monitor.py）：
   - 原 13 项入口/静态游戏页检查保留；
   - 新增 socket.xtmpz.com 4 个关键 API 探测（Register/Login/QueryBalance/GameLogs，
     200/400/401/403 视为链路正常，404/5xx/超时报警）；
   - 新增 22 个 socket.<root> Register 探测；
   - 总检查数 39 项，备用机 cron（每 2 分钟）已同步部署。
5. socket.xtmpz.com 废弃（用户确认）：从宝塔/备用机 socket 站点 server_name 移除
   （备份 .bak-20260820-retire），监控移除该域名 4 项探测；商户域名统一为 22 个 socket.<root>。
```

## 验证

```text
1. 宝塔 nginx reload 后公网复测：22 个 socket.<root>/services/v2/User/Register 全部 400
   （"missing params p" 业务校验，链路正常）；socket.xtmpz.com 仍 404（Cloudflare 回源异常，非本侧）。
2. 备用机直连（192.0.2.13 + Host）4 个抽样全部 400，配置一致。
3. 监控 dry-run + 备用机真实运行：22 个新域名 OK，socket.xtmpz.com 4 项按预期报警；
   cron 已使用新脚本（26 个 SOCKET 检查项）。
4. 证书：socket 站点沿用 *.xtmpz.com 泛证书；Cloudflare 边缘证书对外，回源链路实测正常。
5. socket.xtmpz.com 移除后复测：监控全绿（OK 无报警），22 个商户域名公网 Register 全部 400。
```

## 结论

```text
商户 API 域名由 1 个（socket.xtmpz.com）扩展为 22 个 socket.<root>（socket.xtmpz.com 已废弃），单点故障风险消除；
任一域名失效可通过入口监控第一时间报警。
```
