# Git推送免密码

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202304141557-%E5%AE%89%E5%85%A8%E4%B8%8E%E5%A0%A1%E5%9E%92%E6%9C%BA%2B%E9%AB%98%E7%BA%A7%E5%AE%89%E5%85%A8%2B%E7%9F%A5%E8%AF%86%E7%AC%94%E8%AE%B0-Git%E6%8E%A8%E9%80%81%E5%85%8D%E5%AF%86%E7%A0%81.md)

在使用 **[Git](https://haicoder.net/git/git-tutorial.html)** 中，默认使用 push 时，是需要密码的，我们可以按照如下设置，使 git 推送免密码：

1. 生成 key：

`ssh-keygen -t rsa -C "[邮箱已脱敏]"`
2. 查看 key 内容：

`cat ~/.ssh/id_rsa.pub`
3. 把上面的内容添加到 github 的 SSH Keys 的 key 里面。
