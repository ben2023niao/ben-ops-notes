# Git推送免密码

在使用 **[Git](https://haicoder.net/git/git-tutorial.html)** 中，默认使用 push 时，是需要密码的，我们可以按照如下设置，使 git 推送免密码：

1. 生成 key：

`ssh-keygen -t rsa -C "[邮箱已脱敏]"`
2. 查看 key 内容：

`cat ~/.ssh/id_rsa.pub`
3. 把上面的内容添加到 github 的 SSH Keys 的 key 里面。
