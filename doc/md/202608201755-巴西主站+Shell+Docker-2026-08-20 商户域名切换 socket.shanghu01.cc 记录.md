# 2026-08-20 商户域名切换 socket.shanghu01.cc 记录

> 来源文件：`~/Projects/work/game/pgserver/master/docs/history/2026-08-20-1755-【架构改造】商户域名切换socket.shanghu01.cc记录.md`

> 整理日期：2026-08-20 17:55｜日期依据：文件名日期

时间：2026-08-20 17:55（Asia/Manila）
项目：DBQP / PGServer master
范围：撤销 22 个 socket.<root> 游戏根域商户域名，切换为独立商户域名 socket.shanghu01.cc
执行人：Codex（本地工作区 + 宝塔 + 备用 nginx + Cloudflare API）

## 背景

```text
此前按“参考 socket.xtmpz.com”把 22 个游戏根域全部加 socket.<root> 作为商户 API 域名。
用户确认：游戏域名不应混入商户体系，改用独立购买的域名 shanghu01.cc 承载商户域名。
```

## 处理

```text
1. 撤销 22 个 socket.<root>：
   - 宝塔 /www/server/panel/vhost/nginx/socket.xtmpz.com.conf server_name 恢复为
     “socket.shanghu01.cc” 单一域名（备份 .bak-20260820-socket-revert），nginx reload 通过；
   - 备用机 /etc/nginx/conf.d/socket.xtmpz.com.conf 同样恢复并 reload；
   - Cloudflare 侧无需删除：22 个 socket.<root> 走的是各根域 *.<root> 通配记录（历史既有），
     未新增持久记录，撤销 nginx server_name 后即不再对外提供商户服务。
2. 新增独立商户域名 socket.shanghu01.cc：
   - shanghu01.cc 已接入本 Cloudflare 账户（zone active，NS bjorn/romina）；
   - Cloudflare 新增 A 记录 socket -> 35.247.205.6（橙云 proxied，TTL auto）；
   - DNS 生效后解析到 Cloudflare 边缘（104.21.8.178 / 172.67.157.204）。
3. 监控切换（docker/scripts/entry_health_monitor.py）：
   - 移除 22 个 socket.<root> Register 探测；
   - 保留 socket.shanghu01.cc 4 个关键接口探测（Register/Login/QueryBalance/GameLogs，
     200/400/401/403 视为链路正常）；
   - 总检查数由 35 收敛为 17 项，备用机 cron 已同步。
```

## 验证

```text
1. 公网 https://socket.shanghu01.cc/services/v2/User/Register、/Login 均 400
   （“missing params p” 业务校验，链路正常）；
2. 备用机直连（Host: socket.shanghu01.cc）Register 400，配置一致；
3. 监控端到端：备用机运行新脚本，socket.shanghu01.cc 4 项探测由 down 转 ok 并发出恢复通知，
   说明域名切换与监控切换同时生效；
4. 宝塔/备用机 nginx -t 全部通过。
```

## 结论

```text
商户 API 域名与游戏域名彻底分离：商户统一使用独立域名 socket.shanghu01.cc，
22 个游戏根域 socket.<root> 已全部撤销，不再承担商户入口职责。
```
