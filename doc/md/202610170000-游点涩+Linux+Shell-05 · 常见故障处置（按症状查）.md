# 05 · 常见故障处置（按症状查）

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202610170000-%E6%B8%B8%E7%82%B9%E6%B6%A9%2BLinux%2BShell-05%20%C2%B7%20%E5%B8%B8%E8%A7%81%E6%95%85%E9%9A%9C%E5%A4%84%E7%BD%AE%EF%BC%88%E6%8C%89%E7%97%87%E7%8A%B6%E6%9F%A5%EF%BC%89.md)

> 整理日期：2026-10-17 00:00｜日期依据：正文日期

## 症状：后端带宽/入流量突然很高

先判断是不是授权安全测试：看网关 `load`、444 数量、来源是否集中。若 `php-web` 入高、出低 → 是后端从 Mongo 读数据。

```bash
sudo docker stats --no-stream
sudo nsenter -t $(sudo docker inspect --format '{{.State.Pid}}' youdianse-main-php-web) -n ss -tin | grep 27017
```

历史案例：2026-10-17 主库读放大 222~299 倍；`/api/v1/modules/home` 平均 251.5KB/次，占 82.5%。

## 症状：新接入游戏登录/回调失败

```bash
sudo grep -a check_host_sign_failed /opt/docker-youdianse-php/runtime/app-logs/error-$(date +%F).log | tail -5
```

- `host_not_in_whitelist` → 主机不在 `alb_white.txt`
- `decrypt_host_sign_empty` → `alb_white_secret.txt` 缺平台密钥

处置：确认配置仓库 `config-repo/app-local-files/` 里有该平台，再跑 `python3 cicd-web.py check-app-local`（应 PASS）。

历史案例：2026-10-18 容器内是 9-23 旧副本（37 行），8.9 万条回调被拒。

## 症状：Redis 慢 / 接口偶发卡顿

```bash
sudo docker exec -i youdianse-main-php-web php -r '
$r=new Redis();$r->connect("203.0.113.1",6379);
print_r($r->slowlog("get",10));'
```

- 慢日志全是 `KEYS` → 业务在用前缀删除（登录踢下线 `[敏感内容已脱敏] SCAN
- 连接数暴涨 → 每次调用新建连接，需要连接复用

历史案例：KEYS 每 129 秒阻塞 0.5 秒，102/126 次来自登录踢下线。

## 症状：磁盘告警

```bash
df -h /; du -xh --max-depth=1 / | sort -rh | head -8; docker system df
sudo bash ops/production/scripts/disk-clean.sh
```

历史案例：GitLab 容器 json 日志单文件 123.3GB；后端/网关/前端构建缓存累计 24GB。

## 症状：内存告警

```bash
free -m; awk '/HugePages_Total/{print}' /proc/meminfo
ps -eo pmem,rss,comm --sort=-rss | head
```

若 `HugePages_Total` 大且 `HugePages_Free` 也大 → 大页被闲置占用：

```bash
sysctl -w vm.nr_hugepages=0
echo 'vm.nr_hugepages = 0' > /etc/sysctl.d/99-youdianse-disable-hugepages.conf
```

历史案例：定时任务机预留 1067 个大页（2GB），可用内存仅 267MB，回收后回到 2.4GB。

## 症状：发布后 502 / 容器起不来

```bash
docker ps -a --format '{{.Names}} {{.Status}}'
sudo docker logs --tail 50 youdianse-main-php-web
sudo docker exec youdianse-main-php-nginx tail -50 /var/log/nginx/error.log
```

发布窗口内的 502 多为 php-fpm 未就绪，等 1~2 分钟；持续 502 查镜像/启动命令/环境变量。

## 症状：被刷量 / CC 授权安全测试

```bash
ssh ubuntu@16.208.38.88 'uptime; sudo ss -tn state established | wc -l'
sudo tail -50 /opt/telegram/18game_devops/devops/scripts/cc_guard/state/guard.log
```

依赖 CC 守卫自动封禁；人工确认后可加 `static_block_ips.txt` / `static_block_prefixes.txt`。

## 症状：定时任务不执行 / 队列堆积

```bash
ssh ubuntu@16.208.32.40 'sudo docker ps | grep spug'
sudo docker logs --tail 50 youdianse-main-php-cron
```
