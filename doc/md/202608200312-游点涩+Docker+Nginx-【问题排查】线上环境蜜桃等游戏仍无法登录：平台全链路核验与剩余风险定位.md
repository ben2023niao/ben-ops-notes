# 【问题排查】线上环境蜜桃等游戏仍无法登录：平台全链路核验与剩余风险定位

## 背景

网关 nginx 连接打满修复后（`docs/2026-08-20-0259`），部分游戏恢复；但用户反馈
蜜桃、欲女梦工厂、淫欲斗罗等游戏仍无法登录（“网络连接失败”）。
本记录为平台侧全链路核验与剩余风险定位。

## 平台侧全链路核验（全部健康）

```text
1. 后端登录接口：08-20 全天 sdk/Login 响应 23782 条全部 status:"y"（0 业务错误）
2. 后端 /api：近 1 小时无 4xx/5xx（仅少量 499，客户端断开）
3. 网关（16.208.38.88）：近 15 分钟 20.2 万请求，200 为主，无 5xx、无 worker_connections 错误
4. CORS：Access-Control-Allow-Origin:*（全开放，非白名单问题）
5. 疑似故障游戏域名（bjyinhegame/spj2web/sdchjy/jingdun119）：
   网关近 30 分钟 34182 请求（200=33431）；后端 3782 请求（200=3779）
   其中 /api/sdk/Login/quickAccount 182 次 POST 全部 200
结论：平台后端+网关+宝塔链路完全正常，游戏调用平台登录均可成功。
```

## 剩余风险定位

```text
1. 老 SDK 域名失效（最可能）：
   api.18h.game / sdk.18h.game —— DNS 无解析记录（NXDOMAIN）
   api.youdianse.com / api.youdianse-main.xyz —— 解析到宝塔（正常）
   若蜜桃/欲女梦工厂/淫欲斗罗的老版本 SDK 配置 18h.game API 域名，
   则域名解析失败 → “网络连接失败”，平台侧完全感知不到请求。
2. 游戏侧 CDN/网络：联运游戏由厂商自行运维，登录页/选服/支付走游戏自身 CDN；
   平台官网正常、部分游戏正常，怀疑特定游戏 CDN 节点/域名问题。
3. 非平台问题已排除：IP 黑名单（已清空仍复现）、CORS、后端代码、网关连接。
```

## 需要游戏侧配合确认

```text
1. 蜜桃 / 欲女梦工厂 / 淫欲斗罗 的实际游戏域名（登录页地址）；
2. 游戏 SDK 配置的 API base URL（抓包/开发工具里失败的请求 URL）。
拿到后即可：查该域名 DNS/CDN、平台侧流量、给出针对性修复。
若确认老 SDK 指向 api.18h.game / sdk.18h.game：
  方案A：补 DNS 记录指向宝塔/网关并签发证书（老包恢复，无需改包）；
  方案B：推动游戏更新 SDK（推荐）。
```
