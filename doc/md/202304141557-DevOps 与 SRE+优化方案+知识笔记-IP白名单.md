# IP白名单

## 获取公众号授权失败，错误代码：40164，错误信息：IP-XXX.XXX.XXX.XXX不再白名单之内

![文档配图](../media/a876e628eaba596fa3.jpg)![文档配图](../media/4962773dbac603e76e.png)

## 解决方式：

### 把微擎提示的IP复制下来，登录微信公众号后台，左边找到基本设置，点击IP白名单的查看，输入刚刚复制的IP，点击确认修改就行了。
