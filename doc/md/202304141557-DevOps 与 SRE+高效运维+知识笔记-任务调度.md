# 任务调度

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202304141557-DevOps%20%E4%B8%8E%20SRE%2B%E9%AB%98%E6%95%88%E8%BF%90%E7%BB%B4%2B%E7%9F%A5%E8%AF%86%E7%AC%94%E8%AE%B0-%E4%BB%BB%E5%8A%A1%E8%B0%83%E5%BA%A6.md)

## 介绍

方便的维护一些周期性的任务，例如：在一个下单交易的应用里，超时未支付的订单需要被关闭掉，就可以通过任务调度模块添加一个调度任务来每隔 1 分钟调用一次应用的某接口来让应用检查那些超期未支付的订单。

> 执行历史仅保留每个任务最近 50 条记录，多余的记录将会被自动删除。
