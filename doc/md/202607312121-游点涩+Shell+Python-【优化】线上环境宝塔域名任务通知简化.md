# 【优化】线上环境宝塔域名任务通知简化

## 背景

宝塔服务器 `new.youdianse.com` 自动添加域名任务完成后，原 Telegram 成功通知会把全部域名直接放进群文本，消息过长，不利于快速识别本次实际变化。

## 改动

修改脚本：

```text
ops/production/scripts/baota-add-new-youdianse-domains.py
宝塔线上路径：/www/server/youdianse-ops/baota-add-new-youdianse-domains.py
```

成功通知调整为：

```text
宝塔域名任务完成
主机：<hostname>
站点：https://new.youdianse.com
本次变动（N 个）：
1. https://example-a.com
2. https://example-b.com
Nginx 新增：N 个
site.db 新增：N 个
已存在跳过：N 个
完整域名：见附件 YYYY-MM-DD-HHMMSS-domains.txt（共 N 个）
备份：<backup_dir>
```

同时设置 Telegram `disable_web_page_preview=true`，避免多个可点击域名生成网页预览刷屏。

完整域名信息写入 txt 附件，文件名示例：

```text
2026-07-31-212038-domains.txt
```

附件包含：

```text
本次变动
Nginx 新增
site.db 新增
已存在跳过
全部域名
队列归档 / dry-run 信息（如适用）
```

## 部署

已在宝塔服务器部署：

```text
主机：ip-172-31-26-125
脚本：/www/server/youdianse-ops/baota-add-new-youdianse-domains.py
旧脚本备份：
/www/backup/youdianse-baota/script-backups/baota-add-new-youdianse-domains.py.20260731-212012.bak
/www/backup/youdianse-baota/script-backups/baota-add-new-youdianse-domains.py.20260731-212925.bak
```
