# 12、防火墙

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202304141557-%E5%AE%89%E5%85%A8%E4%B8%8E%E5%A0%A1%E5%9E%92%E6%9C%BA%2B%E5%AE%89%E5%85%A8%E8%BF%90%E7%BB%B4%2B%E7%9F%A5%E8%AF%86%E7%AC%94%E8%AE%B0-12%E3%80%81%E9%98%B2%E7%81%AB%E5%A2%99.md)

```bash
iptables -L 查看防火墙配置

查看防火墙状态：
systemctl status firewalld
service iptables status
暂时关闭防火墙:
systemctl stop firewalld
service iptables stop
永久关闭防火墙：
systemctl disable firewalld
chkconfig iptables off
重启防火墙：
systemctl enable firewalld
service iptables restart
```
