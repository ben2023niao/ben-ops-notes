## 后续使用方式

新会话或新 AI 接手线上任务时，先按下面顺序读取：

```text
1. workbench/START_HERE.md
2. workbench/CURRENT_TASK.md
3. workbench/CURRENT_STATE.md
4. workbench/MACHINE_ACCESS_MATRIX.md
5. workbench/PROJECT_RUNTIME_CHAINS.md
6. workbench/DECISIONS.md
7. AGENTS.md
8. 只读取本次任务相关历史文档
```

每次线上任务完成后，至少更新：

```text
workbench/CURRENT_TASK.md
workbench/CURRENT_STATE.md
docs/YYYY-MM-DD-HHMM-【分类】线上环境标题.md
```

如果任务产生新决策、待办或冲突，再同步更新：

```text
workbench/DECISIONS.md
workbench/ACTIVE_TASKS.md
workbench/AUDIT_CONFLICTS.md
```
