## 用途

这份文档给 AI、运维和发布人员在操作测试环境前阅读，用来确认测试服务器的连接方式、部署内容、运行容器、关键路径、发布入口和风险边界。

本页只记录“需要用哪个账号连接”和“哪些路径需要核对”，不记录密码、token、私钥内容、证书私钥、Git 凭据或 Telegram `chat_id`。

## 操作前必读

1. 当前仓库 `dev` 分支对应游点涩测试环境，执行前必须确认不要误用线上环境配置。
2. 所有服务器操作优先只读核对，再决定是否修改。
3. 需要发布、重启、改 Nginx、改 crontab、改密钥文件、改 Docker 配置前，先说明影响范围和回滚方式。
4. 不要在终端、文档、提交或 Telegram 中输出任何密码、token、私钥内容、证书私钥、Git 凭据。
5. 测试服务器的 Telegram 运行密钥在 `/opt/docker-youdianse-php/cicd-web/runtime/secrets.env`，只允许程序读取后发送通知，不允许打印内容。
6. 本仓库 `AGENTS.md` 要求每完成一个步骤都发送 `【测试环境｜步骤 N 完成】` Telegram 通知；如果无法发送，必须向当前用户说明失败原因并保留重试记录。

### 测试环境 root crontab 重点

测试环境业务定时任务不在本仓库维护；业务调度入口是外部可视化系统。

```text
测试定时任务：https://cron.youdianse-test.xyz
```

测试服务器常见本地调度包括：

```text
cicd-web-auto-update.py：同步运维仓库配置
youdianse-server-health-alert.py：每 5 分钟健康告警
youdianse-health-hourly-summary.py：每小时健康汇总
youdianse-app-log-hourly-rotate.py：每小时 PHP 错误日志轮转
```

具体 crontab 以服务器实时只读核对结果为准。

## AI 操作建议

发布或排障前，AI 应按这个顺序读取资料：

1. `AGENTS.md`：确认测试环境 Telegram 逐步通知规则。
2. `README.md`：确认测试环境发布主流程、固定信息和运维入口。
3. `ops/test/README.md`：确认测试环境文档分类入口。
4. `ops/test/2026-07-29-1755-【运维记录】测试环境服务器详细信息与AI操作参考.md`：确认测试环境连接账号、部署内容、容器、端口和关键路径。
5. 涉及健康监控或日志轮转时，再读 `ops/test/2026-06-23-0116-【优化】测试环境健康监控与告警说明.md` 和相关安装脚本。
6. 涉及 H5 域名分流时，再读 `README.md` 的“宝塔域名分流配置”章节。

若当前服务器状态和本文不一致，以实时只读核对结果为准，并在操作结束后补充本文或测试环境索引。
