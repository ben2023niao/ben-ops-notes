## 游戏侧定位

```text
1. 两个游戏均为“蜜桃游戏”发行（同 CloudFront 包源 d391me9s8n5j5s.cloudfront.net）
2. 欲女梦工厂 APK 内认证域名：https://auth.for-girl.com
   （Cloudflare DNS，AWS ap-east-1 NLB，属游戏方/第三方，非平台域名）
3. 游戏登录链路：平台登录成功（平台侧已通过） -> 游戏方认证服务器校验/绑定
4. 判断：失败发生在游戏方认证环节——
   a) 平台账号未在游戏后端注册/绑定；
   b) 游戏后端校验平台 token 时使用了失效回调域名（如 api.18h.game / sdk.18h.game）；
   c) gp5219 为测试账号（is_test=1），若游戏正式环境拒绝测试号也会登录失败。
```
