## 介绍

管理应用的运行环境，一般包含开发环境、测试环境和生产环境，应用发布和配置管理需要用它来区分不同的环境。

创建环境时设置的 `唯一标识符` 用于配置中心提供的开放 API 调用，详情参考 [API文档](https://spug.cc/docs/config-api)
