## 背景

用户反馈 iOS 星界大战使用 18G827354 / Aa123456. 一开始登录不行，隔 20 分钟可以，
要求比对成功与失败使用的 SDK 域名。

## 账号登录记录

```text
18G827354（user_id 827354）：
  02:44-04:17 多次 /api/sdk/system/info、sdkDomains 全部 200
  04:18:44 /api/sdk/Login/account status:"y"（成功）
  04:20:28 /api/sdk/Login/account status:"y"（成功）
  失败时段（04:12-04:18）：该客户端从未向生产后端发起 Login/account
```

## 域名比对

### 现在（成功）

```text
链路：h5.18h.game/api（CloudFront -> 网关 16.208.38.88 -> 宝塔 -> 后端）
证据：后端日志 XFF 链 = 客户端IP + CloudFront 边缘IP（3.172.x / 15.158.x）+ 203.0.113.1（网关）
```

### 之前（失败）

```text
生产 /api/sdk/system/sdkDomains 下发 SDK 域名：["https://h5.game-app543.com"]
实测 https://h5.game-app543.com/api：
  HTTP 302 -> https://blocked.sbmd.cicc.gov.ph/?url=...（菲律宾政府网站访问策略验证页）
  跟随重定向 -> 403
结论：失败时 SDK 使用 sdkDomains 下发的 h5.game-app543.com，被区域访问策略验证页 302 拦截，
登录请求未到达生产后端；约 20 分钟后客户端改走未访问策略验证的 h5.18h.game 成功。
```

## 结论与建议

```text
1. 非平台后端问题；是 sdkDomains 下发了被访问策略验证的域名 h5.game-app543.com。
2. 建议将 sdkDomains 返回的生产 SDK API 域名改为：
   https://h5.18h.game 或 https://sdk.youdianse.com（03:56 已接通、未访问策略验证）。
3. 排查 h5.game-app543.com 被访问策略验证原因/是否换域名，并检查其它游戏包/H5 是否也引用该域名。
```
