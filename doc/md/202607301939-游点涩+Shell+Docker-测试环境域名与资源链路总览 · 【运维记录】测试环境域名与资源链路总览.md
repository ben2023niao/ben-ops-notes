```text

无效图片响应：HTTP 200 + 默认占位图
```

后端 env 配置目标：

```ini
[cdn.tencent._default]
path_prefix=/uploads/
ttl=2592000
[敏感内容已脱敏]
time_param=t
key=<仅本地 VSCode 与测试服务器 env 保管，不写入文档和 Git>
key_file=

[cdn.tencent.test-img]
domains=test-img.hbabaxb.cn,test-img.hbazuua.cn
```

维护规则：

```text
后续新增同规则图片域名：只追加 domains
```
