# 自建cdn下二级域名访问报错排查

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202304141557-%E6%95%85%E9%9A%9C%E6%8E%92%E6%9F%A5%2B%E9%97%AE%E9%A2%98%E6%8E%92%E6%9F%A5%2B%E7%9F%A5%E8%AF%86%E7%AC%94%E8%AE%B0-%E8%87%AA%E5%BB%BAcdn%E4%B8%8B%E4%BA%8C%E7%BA%A7%E5%9F%9F%E5%90%8D%E8%AE%BF%E9%97%AE%E6%8A%A5%E9%94%99%E6%8E%92%E6%9F%A5.md)

反馈人  shownu

问题描述
在使用自建CDN情况下
a.com 下访问业务一切正常
[www.a.com](http://www.a.com) 访问业务就出现token不通问题

原因
自建cdn的XFF配置和源服务器XFF不一致导致用户请求数据转发过程中丢失二级域名信息

处理方法
让基础平台那边保持CDN服务器 和我们 源服务器 XFF 配置一致
