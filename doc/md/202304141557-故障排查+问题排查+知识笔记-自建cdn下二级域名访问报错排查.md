# 自建cdn下二级域名访问报错排查

反馈人  shownu

问题描述
在使用自建CDN情况下
a.com 下访问业务一切正常
[www.a.com](http://www.a.com) 访问业务就出现token不通问题

原因
自建cdn的XFF配置和源服务器XFF不一致导致用户请求数据转发过程中丢失二级域名信息

处理方法
让基础平台那边保持CDN服务器 和我们 源服务器 XFF 配置一致
