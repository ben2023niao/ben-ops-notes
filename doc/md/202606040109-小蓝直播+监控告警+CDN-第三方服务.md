# 第三方服务

> 来源文件：`~/Projects/work/game/xiaolan-watches/dev/docs/project/third-party.md`

> 整理日期：2026-06-04 01:09｜日期依据：文件创建/修改时间

本文件记录当前项目选择的第三方服务。具体选择以 `project.config.json.thirdParty` 为准。

| 类型 | 配置项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 视频/语音 | `video` | `unselected` | ZEGO、Agora、Twilio 或自研 |
| 支付 | `payment` | `unselected` | Stripe、PayPal、IAP 或本地支付 |
| 短信 | `sms` | `unselected` | OTP、通知、风控 |
| 存储/CDN | `storage` | `local` | 本地、S3、OSS、R2、CDN |

## 接入规则

1. 第三方密钥只能通过环境变量注入。
2. SDK 初始化必须封装在服务适配层，不能散落在页面组件。
3. 回调接口必须有签名校验、幂等和审计日志。
4. 费用相关服务必须有失败补偿和告警设计。
5. 未配置第三方时，功能只能显示“未配置”或进入受控测试模式，不能伪装成真实完成。
