## 背景

用户反馈欲女梦工厂登录报错，并明确排除 api.18h.game / sdk.18h.game
（老域名未打包进安卓/苹果包）。平台全链路此前已核验健康。

## APK 核验

```text
包名：com.mn.crazy.rich.life（Unity/il2cpp 应用）
版本：V1.0.2-pro（构建 2026-08-14）
来源：https://d391me9s8n5j5s.cloudfront.net//20260814/6a7f2065bb5760.73622859-1.0.2-pro.apk
APK 内发现的业务域名：
  https://auth.for-girl.com          —— 游戏认证服务器（AWS ap-east-1 NLB：girl-prod-auth-nlb...elb.ap-east-1.amazonaws.com）
  https://h5.youdianse-main.xyz/game/detail/618 —— 平台 H5 游戏详情
APK 内未发现 api.18h.game / sdk.18h.game
```

## 可达性核验（本机 + 后端服务器）

```text
auth.for-girl.com      DNS -> AWS NLB 43.199.96.71；HTTPS 200（0.25-0.30s）
auth.for-girl.com /   返回加密 JSON（API 网关形态，各路径均 200）
h5.youdianse-main.xyz  HTTPS 200
平台登录接口           08-20 全天 status:"y"（无业务失败）
网关/后端              近 30 分钟无 5xx、无 worker_connections 错误
```

## 结论

```text
1. 已排除：老域名死记录（App 未打包）、平台侧故障、网关连接打满、CORS。
2. App 端依赖（auth.for-girl.com、h5.youdianse-main.xyz）从平台侧可达且健康。
3. 剩余可能：
   a) 报错设备/区域到 auth.for-girl.com（香港 AWS）网络不通（区域/ISP 问题）；
   b) 游戏 auth 服务器（for-girl.com 后端）回调平台校验 token 时使用旧域名
      （api.18h.game / sdk.18h.game）导致服务端验证失败；
   c) 业务级错误（账号/验证码/版本）需要报错原文。
```
