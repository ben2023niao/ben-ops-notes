# 【运维】取消 ff789p3 每 30 分钟探测定时任务记录

> 来源文件：`~/Projects/work/game/pgserver/master/docs/history/2026-08-29-0330-【运维】取消ff789p3定时探测任务记录.md`

> 整理日期：2026-08-29 03:30｜日期依据：文件名日期

时间：2026-08-29 03:30（Asia/Manila）
项目：DBQP / PGServer master
执行人：Codex（本地工作区 + 备用机 34.151.249.53）

## 一、背景

备用机挂载的 ff789p3 探测 cron（每 30 分钟）持续发送
「游戏还没开放 / 今日完整对比测试已完成」提醒，群内噪音大，用户要求取消。

## 二、定位

备用机 `dbqp-saopaulo-nginx-standby-01 / 34.151.249.53` crontab 第 7 行：

```text
*/30 * * * * flock -xn /tmp/ff789_watch.lock -c /opt/pgserver/docker/scripts/ff789_games_watch.sh >> /tmp/ff789_watch_cron.log 2>&1
```

宝塔 crontab 无此任务。

## 三、执行与验证

1. 备份 crontab：`/tmp/standby-crontab.bak-20260828-1921`；
2. 移除该行并重载 crontab；
3. 验证：`crontab -l | grep -c ff789_games_watch` = 0；
4. 清理锁文件 `/tmp/ff789_watch.lock`；无运行中的探测进程；
5. 最近一次运行 2026-08-28 19:00 UTC，之后不再触发。

## 四、说明

- 脚本 `docker/scripts/ff789_games_watch.sh`、`probe_ff789_open.py` 保留在仓库，
  需要时可重新挂 cron 恢复；
- 若竞品/站点开放状态仍需感知，可用手动跑 `probe_ff789_open.py` 或
  改为低频（如每日一次）任务，避免群噪音。
