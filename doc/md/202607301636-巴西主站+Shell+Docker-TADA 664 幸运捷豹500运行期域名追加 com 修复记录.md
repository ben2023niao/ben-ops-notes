## 问题现象

测试反馈：

```text
环境/游戏厂牌：TADA 游戏巴西线上版本
游戏：664 - 幸运捷豹500
问题等级：P2
问题描述：无法进入游戏
```

截图中的失败请求：

```text
https://tada-games.p8m7xy.cyou.com/j500/req
Referer: https://tada-statics2.t6qy8m.icu/
```

问题特征：

```text
动态域名被拼成 .cyou.com。
浏览器侧请求未能到达正确 TADA 后端。
游戏加载后提示 Desconectado / MSG 999.2。
```

## 参考历史文档

```text
docker/doc/2026-07-16-【修复Bug】TADA幸运鹦鹉lm斜杠对象漏同步修复记录.md
```

历史结论：

```text
TADA2 部分游戏实际入口使用 /<game>/，不是 /<game>/index.html。
GCS backend bucket 不会自动把 /<game>/ 映射到 /<game>/index.html。
运行阶段游戏代码会把正确的 .cyou/.icu 后端域名再追加 .com。
需要同时修复尾斜杠对象和运行期 URL。
```

## 修复内容

在 `/www/wwwroot/tada-statics2/lj500/index.html` 的 `<head>` 早期加入补丁：

```text

```

```text

XMLHttpRequest.prototype.open
```

规范化规则：

```text
tada-games.p8m7xy.cyou.com -> tada-games.p8m7xv.cyou
tada-games.t6qy8m.icu.com  -> tada-games.t6qv8m.icu
tada-statics2.t6qy8m.icu   -> tada-statics2.t6qv8m.icu
https://tada-games.<host>.cyou.com -> https://tada-games.<host>.cyou
https://tada-games.<host>.icu.com  -> https://tada-games.<host>.icu
```
