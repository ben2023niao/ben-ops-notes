# 2026-06-03 后台广告上传与前端广告接口说明

> 来源文件：`~/Projects/work/game/xiaolan-watches/dev/docs/agents/logs/2026-06-03-admin-ad-upload-and-contract.md`

> 整理日期：2026-06-03 00:00｜日期依据：文件名日期

## 背景

后台广告位的“管理素材 / 新建素材”不符合运营语义，且图片仍要求手动填写 URL。广告跳转类型中还保留了已下线的竞猜选项。

## 变更

- 后台广告管理文案改为“管理广告 / 新建广告 / 编辑广告 / 删除广告”。
- 广告图片改为通过 `POST /api/v1/admin/upload` 上传，使用 `scene=banner`，上传成功后把返回 `url` 保存到广告 `image_url`。
- 广告跳转类型移除 `predict`，前端下拉、admin DTO 校验、OpenAPI 契约同步改为 `none/external/route/match`。
- OpenAPI 补充 C 端读取方式：C 端按 `GET /api/v1/ads/slots/{slot_code}/creatives` 获取广告列表，直接使用 `items[].image_url` 展示图片。

## 验证

- `pnpm --filter @kickoff/admin typecheck`
- `go test ./services/go-app/internal/service/admin ./services/go-app/internal/http/adminapi`
