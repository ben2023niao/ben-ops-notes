# 异地备份

> 原文：[异地备份](https://xn--6o0a585a.gitbook.io/devops/shu-ju-ku/yi-di-bei-fen.html)

> 来源：GitBook 网页 HTML｜页面时间：2022-06-11 16:40｜日期依据：GitBook 页面更新时间

remote_backup.sh

```
#！bin/bash
#用于数据库异地备份

basefile=/mnt/data/mysql/
ip=203.0.113.1

date
echo "becoming remote_backup"
echo "---start backup-------"
rsync -avz /mnt/data/mysql/* root@203.0.113.1:/home/data/mysql/
echo "backup complete"
exit $?
```
