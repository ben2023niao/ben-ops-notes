# Git重写提交记录

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202304141557-%E5%AE%89%E5%85%A8%E4%B8%8E%E5%A0%A1%E5%9E%92%E6%9C%BA%2B%E9%AB%98%E7%BA%A7%E5%AE%89%E5%85%A8%2B%E7%9F%A5%E8%AF%86%E7%AC%94%E8%AE%B0-Git%E9%87%8D%E5%86%99%E6%8F%90%E4%BA%A4%E8%AE%B0%E5%BD%95.md)

```
在 Git 中，我们要重写或者修改提交的历史记录，可以使用 amend 命令，如下：

git commit --amend
touch "aaaa" >> master.txt
git add master.txt
git commit -m "confit rebase"
git rebase master
```
