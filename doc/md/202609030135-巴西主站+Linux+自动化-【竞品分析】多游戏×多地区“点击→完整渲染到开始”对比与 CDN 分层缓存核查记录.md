```text
查询：Cloudflare API 逐个 zone GET /zones/{id}/cache/tiered_cache_smart_topology_enable

范围：账号全部 42 个 zone（含 CDN 池 20 + 其他业务域）

开启 ON（3 个）：
  xqv9m8.icu（Pro，8-31 05:14 UTC 开）—— platform-api 单 Argo 域名，当前唯一承载
  cdn-tokyo-dbqp.icu（Pro，8-31 开）
  m6xv8q.cyou（Free，8-29 开）
其余 39 个 OFF（含 Pro：q7m9v8.icu / t6qv8m.icu(已下架) / tada-cdn-2026.icu）

结论：Ben(C++) 问“Tiered Cache 开没开” -> 当前实际承载域名 xqv9m8.icu = ON；
```
