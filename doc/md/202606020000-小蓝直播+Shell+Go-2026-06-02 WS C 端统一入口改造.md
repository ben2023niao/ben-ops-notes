# 2026-06-02 WS C 端统一入口改造

> 来源文件：`~/Projects/work/game/xiaolan-watches/dev/docs/agents/logs/2026-06-02-ws-client-unified-entry.md`

> 整理日期：2026-06-02 00:00｜日期依据：文件名日期

## 背景

C 端原先按业务拆成 `/ws/v1/live/{room_id}`、`/ws/v1/wallet`、`/ws/v1/match/{match_id}` 多条连接。上线前调整为一个 C 端统一入口，降低 H5/Web 接入复杂度，并收敛鉴权与订阅规则。

## 变更

- 新增 `GET /ws/v1/client?敏感凭据：[已脱敏]
- 登录 C 端用户自动订阅 `user:{user_id}`，用于钱包和个人通知。
- 客户端只能通过 `client.subscribe` / `client.unsubscribe` 订阅公开频道：
  - `room:{room_id}`
  - `match:{match_id}`
- 禁止客户端手动订阅 `user:*`，避免越权。
- 旧 C 端 WS 保留兼容并在文档标记 Deprecated：
  - `/ws/v1/live/{room_id}`
  - `/ws/v1/wallet`
  - `/ws/v1/match/{match_id}`
- 后台房间监控 WS 继续保持独立 Admin 鉴权入口。

## 前端接入口径

新版 H5/Web 只连：

```text
wss://api-dev.54-151-131-132.sslip.io/ws/v1/client?敏感凭据：[已脱敏]
```

进入直播间后发送：

```json
{
  "type": "client.subscribe",
  "data": {
    "channels": ["room:{room_id}"]
  }
}
```
