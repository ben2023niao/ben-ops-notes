# Kickoff C 端直播间接入指南

> 来源文件：`~/Projects/work/game/xiaolan-watches/dev/docs/api/c-end-integration.html`

> 整理日期：2026-06-01 00:00｜日期依据：正文日期

给前端开发的最小可用文档。看完这一份,直播间页面所有功能(视频 + 弹幕 + 打赏特效 + 投票 + 众筹)都能接通。

## ① 架构总览 — 两条独立链路

C 端直播间页面要起两个连接,完全独立:

```
┌─────────────────────────────────────────────────────────────────┐
│ 链路 ①:🎥 音视频流(走 ZegoCloud,不经我们后端)                │
│                                                                  │
│   主播浏览器(SDK)─── WebRTC ───► ☁️ Zego 云 ─── WebRTC ───► 你 │
│   startPublishingStream                       startPlayingStream │
│                                                                  │
│   你只需要:GET /play-url 拿 6 个参数 → ZegoExpressEngine 拉流  │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ 链路 ②:💬 业务事件(我们自有 WebSocket)                        │
│                                                                  │
│   你 ◄── WebSocket /ws/v1/client ── 我们后端 Hub                │
│                                                                  │
│   推送内容(server → client):                                   │
│     · 弹幕(别人发的)                                           │
│     · 打赏特效(别人送的)                                       │
│     · 投票实时票数变化                                           │
│     · 众筹累计 / 阶段达成                                        │
│                                                                  │
│   弹幕发送 + 打赏 + 投票 投票本身走 HTTP POST,不走 WS          │
└─────────────────────────────────────────────────────────────────┘
```

**常见误解清掉**

❌ `flv_url` / `hls_url` / `m3u8` — 已废弃,SRS 自建时代的产物,现在没有

❌ 用 WS 推视频 — WS 只推业务事件,视频流走 WebRTC(Zego SDK 自己处理)

❌ 主播用 OBS 推流 — 不需要,主播端也用 Zego SDK 推

## ③ 完整 C 端代码(直接抄)

下面是一个完整的 C 端直播间组件的最小实现。包含:进房 → 视频出图 → 订阅业务事件 → 发弹幕 → 送礼 → 投票。

### 3.1 安装依赖

```
pnpm add zego-express-engine-webrtc
```

### 3.2 完整组件代码

```
// LiveRoom.tsx / LiveRoom.vue 的核心逻辑
import { ZegoExpressEngine } from 'zego-express-engine-webrtc';

const API = 'https://api-dev.54-151-131-132.sslip.io/api/v1';
const WS  = 'wss://api-dev.54-151-131-132.sslip.io/ws/v1/client';

async function enterLiveRoom(roomId, accessToken /* 用户 JWT,未登录传 null */) {

  // ===== 链路 ①:拉视频流 =====
  // 1. 拿 Zego 接入参数
  const playRes = await fetch(`${API}/live/room/${roomId}/play-url`, {
    headers: accessToken ? { Authorization: `Bearer ${accessToken}` } : {}
  }).then(r => r.json());
  if (playRes.code !== 0) throw new Error(playRes.message);
  const p = playRes.data;

  // 2. 初始化 Zego SDK + 登录房间 + 拉流
  const engine = new ZegoExpressEngine(p.zego_app_id, p.zego_server);
  await engine.loginRoom(p.zego_room_id, p.zego_token, {
    userID: p.zego_user_id,
    userName: p.zego_user_id,
  });
  const remoteStream = await engine.startPlayingStream(p.zego_stream_id);
  document.getElementById('video').srcObject = remoteStream; // 视频出图

  // 3. token 即将过期回调(可选,Zego SDK 自动提醒)
  engine.on('tokenWillExpire', async () => {
    const refreshed = await fetch(`${API}/live/room/${roomId}/refresh-token`, {
      method: 'POST',
      headers: { Authorization: `Bearer ${accessToken}` }
    }).then(r => r.json());
    engine.renewToken(p.zego_room_id, refreshed.data.zego_token);
  });

  // ===== 链路 ②:订阅业务事件(WS) =====
  const ws = new WebSocket(WS +
    (accessToken ? `?敏感凭据：[已脱敏] : ''));

  ws.onopen = () => {
    ws.send(JSON.stringify({
      type: 'client.subscribe',
      data: { channels: [`room:${roomId}`] }
    }));
  };
  ws.onmessage = (e) => {
    const env = JSON.parse(e.data);
    switch (env.type) {
      // 别人发的弹幕 — 飞到弹幕层
      case 'live.danmaku.received':
        addDanmaku(env.data); // { nickname, content, color, sent_ts }
        break;

      // 别人送的打赏 — 播特效
      case 'live.tip.combo':
        playTipEffect(env.data); // { nickname, combo_count, diamond_amount }
        break;

      // 房间在线人数(30s 一次)
      case 'live.viewer.count.updated':
        setViewerCount(env.data.viewer_count);
        break;

      // === LIVE-102 投票 ===
      case 'live.vote.started':
        renderVoteCard(env.data); // 完整 vote 详情含 options[]
        break;
      case 'live.vote.tick':
        // 用 votes_count 直接覆盖,不要 +1(后端可能合并)
        updateVoteOption(env.data.vote_id, env.data.option_id, env.data.votes_count);
        setVoteTotal(env.data.total_votes);
        break;
      case 'live.vote.ended':
        // winner_option_id 为 null = 平票或无人投
        showVoteResult(env.data);
        break;

      // === LIVE-102 众筹解锁 ===
      case 'live.crowdfund.progress':
        updateCrowdfundBar(env.data.cumulative_diamond, env.data.next_stage);
        break;
      case 'live.crowdfund.stage_unlocked':
        showStageUnlockedToast(env.data.stage); // "🎉 主播唱歌 已解锁!"
        break;

      // 房间关播 — 沿用原有关播兜底逻辑
      case 'room.status.ended':
        showEndedOverlay();
        break;
    }
  };

  // 返回清理函数,组件销毁时调
  return async () => {
    ws.close();
    engine.stopPlayingStream(p.zego_stream_id);
    await engine.logoutRoom(p.zego_room_id);
  };
}

// ===== 用户操作 — 都走 HTTP,不走 WS =====

async function sendDanmaku(roomId, content, token) {
  return fetch(`${API}/live/room/${roomId}/danmaku`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${token}` },
    body: JSON.stringify({ content })
  }).then(r => r.json());
}

async function sendTip(roomId, giftId, giftName, diamondAmount, quantity, token) {
  return fetch(`${API}/live/room/${roomId}/tip`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Idempotency-Key': crypto.randomUUID(), // 资金接口要幂等键
      Authorization: `Bearer ${token}`
    },
    body: JSON.stringify({ gift_id: giftId, gift_name: giftName, diamond_amount: diamondAmount, quantity })
  }).then(r => r.json());
}

async function castVote(roomId, voteId, optionId, token) {
  // 一人限一票,重复 cast 后端幂等返回 is_new=false + 旧票据,不会改投
  const r = await fetch(`${API}/live/room/${roomId}/votes/${voteId}/cast`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${token}` },
    body: JSON.stringify({ option_id: optionId })
  }).then(r => r.json());
  if (r.data.is_new) toast('投票成功');
  else toast('您已投过 ' + r.data.my_vote_option_id);
}

// 进房间时拉一次"当前是否有 ongoing 投票"
async function checkActiveVote(roomId) {
  const r = await fetch(`${API}/live/room/${roomId}/votes/active`).then(r => r.json());
  if (r.code === 0) renderVoteCard(r.data);
  else if (r.code === 10004) hideVoteCard(); // 404 = 没有 ongoing,正常
}
```

**就这么多。**视频靠 Zego SDK,业务事件靠 WS,用户操作靠 HTTP。三套独立,各管各的。
## ④ WS 事件清单(直播间频道)

| type | 触发 | data 关键字段 | 前端要做什么 |
| --- | --- | --- | --- |
| `live.danmaku.received` | 有人发弹幕 | nickname, content, color, sent_ts | 飞过弹幕层 |
| `live.tip.combo` | 有人送礼 | nickname, combo_count, diamond_amount | 播打赏特效 |
| `live.viewer.count.updated` | 在线人数变化(30s 批次) | viewer_count, peak_count | 顶部小数字 |
| `live.vote.started` | 主播发起新投票 | vote_id, title, ends_at_ms, options[] | 渲染投票卡 + 倒计时 |
| `live.vote.tick` | 有人投票后 | vote_id, option_id, votes_count, total_votes | **用 votes_count 覆盖**(别 +1) |
| `live.vote.ended` | 投票到期 / 主播下播 | vote_id, winner_option_id, options[] | 显示最终结果;winner=null 表示平票 |
| `live.crowdfund.progress` | 每次有人送礼后 | cumulative_diamond, next_stage? | 用 cumulative_diamond 覆盖进度条 |
| `live.crowdfund.stage_unlocked` | 累计第一次达到某阶段 | stage{name, action_text}, amount_at_achieved | "🎉 主播 X 已解锁" toast |
| `room.status.ended` | 主播下播 / 后端自动下播 | room_id, status, reason? | 沿用原有关播兜底逻辑；C 端不需要上报心跳，`reason=streamer_heartbeat_timeout` 只用于可选文案区分 |
| `room.banned` | 房间被封禁 | — | 显示「房间已封禁」+ 踢出 |

**每条 WS 消息的外层包装**:

```
{
  "type": "live.vote.tick",          // 上表里的 type
  "msg_id": "uuid",
  "ts": 1717252384000,                // 服务端时间
  "trace_id": "uuid",
  "data": { ...上表里的 data 字段... } // 你关心的就这个
}
```

## ⑤ 错误处理 / 重连

### 视频流(Zego 自己重连,不用管)

```
engine.on('playerStateUpdate', (state) => {
  // state.state: NO_PLAY / PLAY_REQUESTING / PLAYING
  // Zego SDK 内部已经做断线重连,你只需要监听 UI 显示状态
  if (state.state === 'PLAY_REQUESTING') showLoading();
  else if (state.state === 'PLAYING') hideLoading();
});
```

### WS 重连(自己实现指数退避)

```
function connectWS(roomId, token, attempt = 0) {
  const ws = new WebSocket(WS + (token ? `?敏感凭据：[已脱敏] : ''));
  ws.onclose = () => {
    const delay = Math.min(1000 * 2 ** attempt, 30000); // 1s, 2s, 4s, ... 30s 封顶
    setTimeout(() => connectWS(roomId, token, attempt + 1), delay);
  };
  ws.onopen = () => {
    attempt = 0;
    ws.send(JSON.stringify({ type: 'client.subscribe', data: { channels: [`room:${roomId}`] } }));
  };
  return ws;
}
```

### HTTP 错误码

| code | 含义 | 处理 |
| --- | --- | --- |
| 0 | 成功 | data 一定有值 |
| 10001 ~ 19999 | 参数 / 系统类 | 显示 message,可重试 |
| 20001 | 资源冲突(如:已投过 / 投票已结束) | 提示并停留,别再调 |
| 20003 | 直播未开始 | 显示「主播未开播」 |
| 10004 | 资源不存在(如:没有 ongoing 投票) | 隐藏对应 UI,正常情况 |
| 30001 ~ 39999 | 权限 / 未登录 | 跳登录 |

## ⑦ 常见疑问

### Q1: 为什么 play-url 不再返 flv_url / hls_url / m3u8?

那是 SRS 自建 CDN 时代的产物,**已经不用了**。Zego WebRTC 拉流延迟 < 500ms,多档自动协商,前端只需要 ZegoExpressEngine.startPlayingStream(streamID) 一句话。

### Q2: 主播怎么推流?需要 OBS 吗?

**不要 OBS**。主播也是浏览器开页面,用同一个 ZegoExpressEngine.startPublishingStream(streamID) 推流。后端 `POST /streamer/rooms/:room_id/start` 返回主播版 Zego 参数(token Privilege = Login+Publish)。

### Q3: WS 上看不到 vote_tick / crowdfund.progress?

1. 检查 WS URL 是否 `/ws/v1/client`,并已发送 `client.subscribe` 订阅 `room:{room_id}`
2. 主播必须真的在直播中(房间 status=LIVE + 有 active session)
3. 触发条件:vote_tick 需要有人投票;crowdfund.progress 需要有人送礼。空闲房间不会推

### Q4: 未登录用户能看视频但不能发弹幕/投票?

对。视频 + WS 订阅匿名可见;弹幕 / 打赏 / 投票必须登录。`play-url` 接口未登录会返 guest_ Zego userID,登录后是 viewer_{user_id}。

### Q5: zego_token 多久过期?要不要主动续?

默认 2 小时。Zego SDK 会在过期前回调 `tokenWillExpire`,你只需在该回调里调 `POST /live/room/:room_id/refresh-token` 再 `engine.renewToken()`,看上面 §3.2 示例。

### Q6: 投票为什么 cast 之后没收到 vote_tick?

WS 是给"房间里其他人"的同步通道,你自己投完成功后端会返回成功,但 vote_tick 是广播事件,理论上你也收得到。如果没收到检查 WS 连接是否 alive。
