## 数据库公网白名单收敛

变更前 GCP 防火墙：

```text
mysql-3306          tcp:3306  sourceRanges=203.0.113.1/0
mysql-replica-3309  tcp:3309  sourceRanges=203.0.113.1/0
```

变更后 GCP 防火墙：

```text
mysql-3306          tcp:3306  sourceRanges=203.0.113.1/32,203.0.113.1/32
mysql-replica-3309  tcp:3309  sourceRanges=203.0.113.1/32,203.0.113.1/32
```

验证命令读回结果：

```text
mysql-3306          tcp:3306  203.0.113.1/32,203.0.113.1/32  False
mysql-replica-3309  tcp:3309  203.0.113.1/32,203.0.113.1/32  False
```

结论：`3306` 主库入口和 `3309` 副本库入口均已移除 `203.0.113.1/0`，只保留开发确认的两个公网来源 IP。

## 回滚

本次只新增 4 个文件，如需回滚可删除：

```bash
rm -f /www/wwwroot/pp-static/gs2c/common/v5/games-html5/games/vs/vs10forwildly/desktop/game/soundspt.ogg.json
rm -f /www/wwwroot/pp-static/gs2c/common/v5/games-html5/games/vs/vs10forwildly/mobile/game/soundspt.ogg.json
rm -f /www/wwwroot/pp-static/gs2c/common/v5/games-html5/games/vs/vs5luckymly/desktop/game/soundspt.ogg.json
rm -f /www/wwwroot/pp-static/gs2c/common/v5/games-html5/games/vs/vs5luckymly/mobile/game/soundspt.ogg.json
```

也可从备份目录恢复整个子游戏目录：

```bash
cp -a /www/server/ops/pp-vs10forwildly-20260725/backup-before-sync/vs10forwildly-20260725-1055 /www/wwwroot/pp-static/gs2c/common/v5/games-html5/games/vs/vs10forwildly

```

回滚后需要同步 GCS live/backup，并再次刷新对应 CDN 路径。

### 数据库白名单回滚

如需临时恢复全开放：

```bash
gcloud compute firewall-rules update mysql-3306 --source-ranges=203.0.113.1/0 --quiet
gcloud compute firewall-rules update mysql-replica-3309 --source-ranges=203.0.113.1/0 --quiet
```

不建议长期恢复全开放；如后续还有新增访问方，优先追加 `/32` 固定出口 IP。
