## 背景

2026-08-20 磁盘自动清理在业务日志 100.2G >= 100G 时触发（500G 数据盘仅用约 20%）。
S3 归档仍失败（exit=2，403 未修复），本地兜底已关闭，未删除任何日志（安全）。
按 Ben 计划上调阈值，减少无意义触发。

## 调整内容

```text
业务日志阈值：100G -> 200G
（数据盘 492G 可用，日志约 10 天增长 90G，200G 约留 20+ 天余量）
调整项：
  root crontab：YOUDIANSE_DISK_CLEAN_APP_LOG_THRESHOLD_GB=200（已备份 crontab）
  cicd-web/config/settings.json：app_log_alert_gb=200（CICD 已重启生效）
  youdianse-disk-auto-clean.py：默认值 200
  README 同步
保留：根盘 75%、S3 保留 3 天、本地兜底关闭、每 10 分钟巡检
```

## 验证

```text
APP_LOG_ALERT_GB=200（CICD 重启后实测）
dry-run：skip: root=37.6%, app_logs=100.3G, threshold=75.0%/200.0G（不触发）
```

## 后续

```text
1. 业务日志接近 200G 前应修复 S3 写权限（403），恢复“上传成功再删除”闭环；
2. 观察日志增长速度，必要时再调整阈值或启动扩容/归档。
```
