## 任务来源

用户要求：

- 把域名维护脚本能力对接机器人按钮：增加域名、维护域名、检查 SSL、续签 SSL 等前端域名维护工作尽量按钮化。
- 对已迁移但未改 CDN 回源的域名，在机器人里分类标识（暂不做服务器 SSL）。
- 识别到域名已通过 AWS CDN 回源到服务器后，提醒运维对该域名点按钮做 SSL 证书。
- 每步操作都发群通知，完成后验证、汇总文档、发群并提交代码。

## 实现内容

### 机器人新增入口：`🧭 前端域名维护`

按钮功能：

- `🔄 快速检查（DNS/模式/证书到期）`：SSH 到 16.208.38.88 执行 `check --quick`。
- `🛡 SSL 续签`：执行 `renew`（续签全部证书并输出到期时间）。
- `📋 未切CDN回源域名`：列出 78 个 pending 域名（已迁移到新服务器但 CDN 回源未切换，暂不做服务器 SSL）。
- `➕ 增加H5域名 / 增加PC域名 / 增加跳转域名(www/@) / 增加UA适配老域名`：点击后机器人提示“直接回复主域名”，回复后自动调维护脚本 `add ... --cert`（改 conf+maps、签发证书、reload）。
- `✅ 标记已切换CDN回源`：点击后回复域名，把该域名状态改为 `switched`（之后可做服务器 SSL，并会从 pending 列表移除）。

### 域名状态分类（93 个主机）

- `new`（12 个）：新域名直连 16.208.38.88，无需 CDN 回源。
- `switched`（3 个）：AWS CDN 回源已切到新服务器（shouyek.com / shyssjt.com / syyhslzp.com），已制作服务器 SSL。
- `pending`（78 个）：已迁移到新服务器 H5 conf，但 AWS CDN 回源未切换，暂不做服务器 SSL；切换后点“标记已切换回源”再点“SSL 续签/制作”。

状态文件：`data/scripts/前端域名维护/frontend_domain_status.json`。

### 代码

- `data/scripts/前端域名维护/youdianse_domain_maint_client.py`：SSH 调用服务器维护脚本的客户端（quick/check/renew/pending/status/add/mark）。
- `data/scripts/前端域名维护/benbot_plugin.py`：按钮渲染与回调（含“点按钮→回复域名”交互）。
- `app/benbot/handlers/domain_maint.py` + `main.py`：文本消息钩子，接收回复的域名并执行增加/标记。
- 服务器维护脚本增加 `check --quick`。

## 追加：按钮点击无反应修复（2026-08-12）

- 根因：按钮菜单消息使用 MarkdownV2 解析，文案含 `16.208.38.88` 等特殊字符导致渲染失败；内部按钮回调缺少 `node.id`，`plugin:` 路由不到插件。
- 修复：`benbot_plugin.py` 消息改用 HTML 解析；按钮回调改为 `plugin:<node.id>:<action>`。
- 验证：回调格式断言通过，点击入口可正常弹出功能按钮。

## 追加：增加域名合并为单入口（2026-08-12）

- 四个“增加 XX 域名”按钮合并为“➕ 增加域名”一个入口。
- 输入格式：`域名 [类型]`，类型 h5/pc/redirect/ua（默认 h5）。
- 域名校验/规范化：去 `http(s)://`、路径、结尾点，转小写，去 `www.` 前缀；格式错误拒绝；已存在自动跳过；自动识别 `h5./pc./www.` 前缀。
- 服务器脚本 `add` 增加 `normalize_domain`；机器人文本钩子支持“域名 [类型]”。

## 追加：结果格式化与翻页（2026-08-12）

- 服务器脚本 `check` 增加 `--json`；客户端返回 JSON；插件按页渲染。
