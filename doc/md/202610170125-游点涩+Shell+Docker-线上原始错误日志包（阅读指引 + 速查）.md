## 建议排查顺序（配合《优化实施指南》）

1. **支付下单慢**：`02/slow.log` 搜 `sharkPayment` / `httpJson` / `curl_exec`；`01/` 里筛 `"route":"recharge/create"` → 对应指南 B5（支付 HTTP 加超时）。
2. **登录 502**：`06/` 里筛 `/api/v1/Login/account`，再对照 `05/` 的 `upstream prematurely closed`；同时看 `02/master-error.log` 的 `executing too slow`。
3. **Mongo 慢命令**：`02/slow.log` 搜 `MongoDbConnection` / `MongoModel` → 对应指南 B1/B2/B3（缓存、消除重复查询、投影）与 D1（profiling）。
4. **404 噪音**：`04/` 里的 `system/info`、`game/detail` 等，核对前端调用时机/App 版本。
5. **FPM 探活失败**：`02/master-error.log` 里 `curl: (7) ... 203.0.113.1 ... Connection refused` 与 `sh: 1: free: not found`（各 77 次）。
6. **Redis 阻塞**：本包不含 Redis 日志；见《优化实施指南》第六章（业务用 `KEYS` 每 153 秒阻塞 0.5 秒）。

> 需要更多原始数据时可直接找运维要：完整 `access.log`（后端 177 MB / 网关 848 MB）、`api_request`/`api_response`（含完整请求响应体，涉及用户数据，按需单独提供）。
