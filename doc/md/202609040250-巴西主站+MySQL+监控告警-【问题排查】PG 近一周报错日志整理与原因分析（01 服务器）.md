## 三、原因与处理建议

```text
1) 1146 缺表：t_network_latency_logs / t_plat_new_user_day*
   -> 代码已写新日志表但 MySQL 未建表，建议 DBA 补表或代码降级；
2) sp_upsert 1318：代码传参与存储过程签名不一致（11/9 vs 12/10），
   -> 对齐代码与 DB 存储过程；
3) 风控字段缺失（RISK_STRATEGY_INFO:...YYTYBRL）：策略未命中 fallback 告警，
   -> 确认是否应配置策略，无策略场景建议降 WARN；
4) 接口执行超时：偶发慢查询/高负载，量小，结合慢 SQL 再查；
5) IP 拦截/余额不足：地区规则与正常业务提示，非故障。
```
