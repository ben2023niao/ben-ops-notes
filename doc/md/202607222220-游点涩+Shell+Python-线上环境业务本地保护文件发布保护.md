# 线上环境业务本地保护文件发布保护

> 来源文件：`~/Projects/work/game/youdianse-docker/main/docker-youdianse-php/docs/2026-07-22-2220-【优化】线上环境业务本地密钥文件发布保护.md`

> 整理日期：2026-07-22 22:20｜日期依据：文件名日期

文档日期：2026-07-22 22:20
环境：游点涩线上环境（main 分支）
分类：优化

通知群：18GAME_ 上线群（正式環境）

## 背景

线上业务目录中的 `alb_white.txt` 和 `alb_white_secret.txt` 都需要在发布构建镜像前存在，否则容器内对应文件会缺失。其中 `alb_white.txt` 由业务仓库跟踪，`alb_white_secret.txt` 是服务器本地保护文件，不提交业务代码仓库。

## 策略

运维仓库新增发布保护清单：

```json
"protected_app_local_files": [
  "alb_white.txt",
  "alb_white_secret.txt"
]
```

保护备份目录：

```text
cicd-web/runtime/app-local-file-backups
```

发布流程：

1. 拉取/清理业务代码前，先检查并备份当前存在的保护文件。
2. 拉取/切换业务代码后，只检查保护文件是否存在，不按内容差异回滚。
3. 如果文件存在，发布流程不从备份覆盖，保留开发和运维手动维护后的当前文件。
4. 如果文件缺失，则从 `cicd-web/runtime/app-local-file-backups` 恢复。
5. 如果缺失且没有备份，则发布失败，避免构建出缺少保护文件的镜像。
6. 发布健康检查成功后，再用当前存在的保护文件刷新备份。

## 安全边界

- 不读取、不输出、不提交 `alb_white_secret.txt` 内容。
- 只记录文件名、存在性和大小。
- 保护文件路径必须是业务仓库内相对路径，禁止绝对路径和 `..`。
- 两份文件允许开发和运维手动维护更新；发布流程不会因为内容和备份不同而恢复旧备份。

## 容器内权限

web 和 cron 容器启动时会对两份保护文件执行权限修正：

```text
chgrp www-data alb_white.txt alb_white_secret.txt
chmod 0640 alb_white.txt alb_white_secret.txt
```

原因：PHP-FPM worker 使用 `www-data` 用户运行。文件如果是 `root:root 0600`，容器里虽然 `is_file=true`，但业务代码 `file()` 读取会失败，可能导致 `checkTokenV2` 无法读取平台私钥并返回 `4002 Service Error`。

## 验证命令

本地验证：

```bash
python3 -m compileall cicd-web cicd-web.py cicd-web-auto-update.py
bash -n cicd-web.sh
docker compose --profile cron config >/tmp/youdianse-main-compose-protected-files.yml
git diff --check
```

服务器发布后确认：

```bash
test -f /opt/docker-youdianse-php/src/youdianse-php/alb_white.txt
test -f /opt/docker-youdianse-php/src/youdianse-php/alb_white_secret.txt
test -f /opt/docker-youdianse-php/cicd-web/runtime/app-local-file-backups/alb_white.txt
test -f /opt/docker-youdianse-php/cicd-web/runtime/app-local-file-backups/alb_white_secret.txt
docker exec youdianse-main-php-web test -f /var/www/html/youdianse-php/alb_white.txt
docker exec youdianse-main-php-web test -f /var/www/html/youdianse-php/alb_white_secret.txt
docker exec youdianse-main-php-cron test -f /var/www/html/youdianse-php/alb_white.txt
docker exec youdianse-main-php-cron test -f /var/www/html/youdianse-php/alb_white_secret.txt
```

权限验证：

```bash
docker exec youdianse-main-php-web stat -c "%n owner=%U:%G mode=%a" /var/www/html/youdianse-php/alb_white.txt /var/www/html/youdianse-php/alb_white_secret.txt
docker exec -u www-data youdianse-main-php-web php -r 'foreach (["alb_white.txt","alb_white_secret.txt"] as $f) { $p="/var/www/html/youdianse-php/".$f; echo $f." readable=".(is_readable($p)?"yes":"no")." file=".(file($p) !== false ? "ok" : "fail").PHP_EOL; }'
docker exec youdianse-main-php-cron stat -c "%n owner=%U:%G mode=%a" /var/www/html/youdianse-php/alb_white.txt /var/www/html/youdianse-php/alb_white_secret.txt
docker exec -u www-data youdianse-main-php-cron php -r 'foreach (["alb_white.txt","alb_white_secret.txt"] as $f) { $p="/var/www/html/youdianse-php/".$f; echo $f." readable=".(is_readable($p)?"yes":"no")." file=".(file($p) !== false ? "ok" : "fail").PHP_EOL; }'
```
