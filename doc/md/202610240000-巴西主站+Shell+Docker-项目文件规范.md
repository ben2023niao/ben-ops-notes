## 顶层职责

| 目录 | 放什么 | 不放什么 |
| --- | --- | --- |
| `infrastructure/brazil/` | 巴西服务器、运行时脚本、域名、Nginx、计划任务快照 | 香港配置、历史长文 |
| `infrastructure/hongkong/` | 香港服务器、CloudFront/S3、域名、Nginx、AWS 索引 | 巴西专属配置 |
| `infrastructure/shared/` | 总架构、公共服务器索引、跨区参考 | 单区域临时文件 |
| `scripts/` | 可执行运维脚本、Worker 备份、工具 | 业务代码、运行结果 |
| `docs/history/` | 历史记录和审计证据 | 当前生产脚本 |
| `docs/guides/` | 长期规范、操作原则、上手说明 | 一次性日志 |
| `workbench/` | 当前状态、任务、决策、交接 | 大体积附件 |
| `build/` | 构建文件 | 运行日志、密钥 |

## 文件放置规则

新增巴西服务器或配置：

```text
infrastructure/brazil/
```

新增香港服务器或 AWS/CloudFront 配置：

```text
infrastructure/hongkong/
```

新增跨区域脚本：

```text
scripts/
```

新增香港云工具：

```text
scripts/hongkong/cloud/
```

线上配置快照必须带采集日期：

```text
domains/live-YYYYMMDD/
nginx/live-YYYYMMDD/
```

## 脚本规则

- 脚本文件保持平铺，因为线上运行路径是 `/opt/bizops-scripts/<file>`。
- cron 中引用文件名，不引用 `docker/scripts/`。
- 脚本依赖的共享函数使用 `scripts/ops_runtime.py`。
- 通知统一使用 `scripts/bizops_notify.py` 或同等的宿主机环境直连方式。
- 脚本头部必须说明目标区域、用途、输入、输出和风险级别。

## 文档命名

事件文档：

```text
YYYY-MM-DD-HHMM-【分类】标题.md
```

长期规范：

```text
【运维记录】标题.md
【模板】标题.md
```

历史文档不回写旧路径，新文档一律使用新目录。

## 安全规则

- 不提交 Token、密码、私钥正文、Access Key、Secret。
- 只记录凭据在服务器上的 root-only 路径。
- 不把带签名的 S3 URL 写入仓库。
- 不在群消息里发凭证。
- Worker 操作前先拉线上、备份、比较。
