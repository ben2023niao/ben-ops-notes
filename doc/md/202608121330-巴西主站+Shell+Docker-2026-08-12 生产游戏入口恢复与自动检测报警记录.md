## 一、根因（诊断确认）

```text
2026-08-11 发布回归部署了包含 docker/services 端口目标态的 master（PP 9099/PPK 9098/vendor_c 9020/PANDA 9018）；

pg（9091）、vendor_a（9096/8765）、api（9090）端口未变，故正常。
```

## 二、恢复

```text
1. 回退 docker/services 端口为生产旧值（b5bbfb16，HOST_PORT=9101/9103/9104/9102，容器内端口不变）并推送新 GitLab。
2. 机器人发布全部（latest=b5bbfb16），3/3 成功。
3. 验证：4 游戏宿主端口恢复 9101/9103/9104/9102；6 游戏入口 + api 全部 200。
```

## 三、自动检测
