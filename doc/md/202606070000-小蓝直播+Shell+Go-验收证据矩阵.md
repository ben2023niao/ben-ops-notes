本文件是需求、页面、接口和测试之间的唯一验收账本。任何功能不得只凭口头说明或冒烟测试标记完成。

状态定义：

- `未开始`：尚未进入实现。
- `进行中`：已有实现或验证，但证据不足，不能说完成。
- `阻塞`：等待 PRD、设计图、接口、第三方或数据。
- `已完成`：PRD、契约、实现、测试、验收证据和日志均完整。
- `不适用`：确认不在当前版本范围内。

完成规则：

1. `已完成` 必须有 PRD 来源、实现文件、自动化测试、手工/E2E 证据、Agent 日志和结论。
2. 页面类和后台类需求还必须有截图或录屏证据。
3. 冒烟测试只能写在手工/E2E 证据里，不能单独支撑 `已完成`。
4. 证据不足时必须写 `进行中`、`阻塞` 或 `未开始`。
