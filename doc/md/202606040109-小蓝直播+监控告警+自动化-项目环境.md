# 项目环境

> 整理日期：2026-06-04 01:09｜日期依据：文件创建/修改时间

项目环境必须和 `project.config.json.environments` 保持一致。

| 环境 | 用途 | 必填信息 |
| --- | --- | --- |
| local | 本地开发 | 启动命令、依赖、示例账号 |
| dev | 日常联调 | 域名、部署分支、数据库、日志入口 |
| staging | 预发布验收 | 域名、测试账号、回滚方式、数据策略 |
| production | 生产 | 域名、部署审批、监控、告警、备份 |

## 规则

1. 不允许把生产密钥写入仓库。
2. 测试环境必须能跑完整用户路径。
3. 发布前必须有 staging 验收记录。
4. 环境变量新增时，必须同步 `.env.example` 或对应环境说明。
5. 部署策略写入 `docs/operations/deployment-strategy.md`。
