1. 只做非破坏性检查，不做登录、支付、下单、上传、删除、清理、重启或发版操作。
2. 不要打印或发送密码、Git token、Telegram bot token、chat_id、私钥、证书私钥或含凭据的仓库 URL。
3. 如果日志里出现含凭据的 URL，汇报前必须脱敏。
4. 接口测试只使用已有轻量接口和固定占位参数，不要发真实用户 token。
5. 汇总发群使用普通文本，不用 Markdown/HTML，避免 Telegram 自动链接或格式转义。

第三步：后端轻量接口检查
使用固定 header，不要使用真实用户 token：
version: 2.1.1

- POST https://h5.youdianse-main.xyz/api/system/info，预期 HTTP 200 JSON
- POST https://www.youdianse.com/api/system/info，预期 HTTP 200 JSON
- POST https://www.youdianse.com/api/sdk/system/info，预期 HTTP 200 JSON
- POST https://www.youdianse.com/channel/auth/getCaptcha，预期 HTTP 200 JSON
- POST https://www.youdianse.com/customer/other/getback，预期 HTTP 200，返回 success 或业务正常响应

第四步：SDK/支付域名客服接口检查
对每个 SDK/支付域名执行：
POST https://<domain>/api/user/kf
headers:

deviceType: web
time: [敏感内容已脱敏]
debugKey: EDB8256D0FE21D97A54552A7D4D749F8

id=264

预期：
- HTTP 200
- 没有 403、502、超时
- 如果业务返回 “授权过期 errorCode=2002”，说明请求已到后端，不算运维链路异常

PY
