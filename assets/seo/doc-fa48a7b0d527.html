升级 todo（七夕后运维手动执行）

  1. 【高优先】线上后端 16.209.16.108：4C/8G → ≥8C/32G（当前单台后端，PHP 峰值 87.7%；按生产保底 8C+32G 标准）。
  2. 【高优先】线上老 H5 13.208.101.121：4C/8G → ≥8C/16G（建议直接 8C/32G）。
  3. 【中优先】测试数据库 103.207.68.124：内存 8G → 16G（当前可用仅 2.8G）。
  4. 【中优先】宝塔 nginx 16.208.5.147 / 新 H5+PC 16.208.38.88：8C 已达标，内存 20G → 32G（可选）。
  5. 【低优先】测试宝塔 38.92.8.34：磁盘 29G → 加大（当前 56%，已配置定时清理）。
  6. 【低优先】ben-bot 52.79.252.255：4C/8G → 8C/16G（可选）。

统一注意事项

  • 所有升级前先打快照（AWS 实例快照 / 云厂商快照）。
  • 升级需重启实例，错开业务高峰；七夕后分批执行并复核服务与监控（http://52.79.252.255:8090）。
  • 升级后复核各服务域名/接口/容器状态。
