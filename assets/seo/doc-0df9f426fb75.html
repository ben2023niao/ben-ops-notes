一、本轮做了什么

用户需求：给一批「带资源的 URL」，方便国内同学直接测速度和网络质量；
          站点生效后与 CF（hkcloudplay06/07）做对比。
1. 确认 m4q7z1.shop 已生效：解析到 EdgeOne 节点（192.0.2.45 / 192.0.2.46），
   pg-games.m4q7z1.shop/health = 200，静态 pg/pp/g759 /health.json = 200。
2. 源站新放「固定大小测速文件」（standby nginx）：/srv/bizops-speedtest/{1mb.bin,10mb.bin}
   通过 https://<任一>-static.m4q7z1.shop/speedtest/{1mb,10mb}.bin 访问（EdgeOne 按静态规则缓存 7 天）。
3. 申请 EdgeOne 免费证书（ModifyHostsCertificate Mode=eofreecert，22 个域名一起），
   目前 18 个 applying、2 个 failed（g759-games / vendor_c-games 已重新触发）。
   ⚠️ HTTPS 目前还没生效，测速先用 HTTP；证书签发完成后 https/wss 同样可用。

二、测速链接（HTTP 可用，HTTPS 等证书签发完）

2.1 大文件下载（走完整 CDN 链路：国内 → EdgeOne 节点 → 香港 nginx → 源站）

1 MB :  http://pg-static.m4q7z1.shop/speedtest/1mb.bin
10 MB:  http://pg-static.m4q7z1.shop/speedtest/10mb.bin
# 任一静态前缀都可以，规则/缓存一致（把 pg-static 换成 pp-static、g759-static、vendor_d-static…）
# 第二次请求会命中 EdgeOne 边缘缓存（TTFB 更低）

2.2 静态资源（各厂商真实对象，与 CF 同一份内容）

小文件（测首包/延迟）：
  http://pg-static.m4q7z1.shop/health.json       (73 B)
  http://pp-static.m4q7z1.shop/health.json       (73 B)
  http://g759-static.m4q7z1.shop/health.json     (73 B)
  （pg3/pg4/pg5/pg6/pg7/ppk/vendor_d/vendor_c/vendor_b-static* 同理）

真实资源（同一对象在 CF 上也有，便于 A/B 对比）：
  http://pp-static.m4q7z1.shop/favicon.ico       (15 KB)   对比 https://pp-static.hkcloudplay06.com/favicon.ico
  http://ppk-static.m4q7z1.shop/favicon.ico      (15 KB)
  http://vendor_c-static.m4q7z1.shop/favicon.ico  (15 KB)

三、怎么测（一条命令）

# 下载速度（含 TTFB 与平均速率）
curl -o /dev/null -w '%{http_code} %{size_download}B %{speed_download}B/s TTFB=%{time_starttransfer}s\n' \
  http://pg-static.m4q7z1.shop/speedtest/10mb.bin

# 连测 5 次看抖动（第 2 次起命中边缘缓存）
for i in 1 2 3 4 5; do curl -s -o /dev/null -w '%{speed_download} B/s  ttfb=%{time_starttransfer}\n' \
  http://pg-static.m4q7z1.shop/speedtest/10mb.bin; done

# A/B 对比 CF 与 EdgeOne 同一对象
curl -s -o /dev/null -w 'CF      %{speed_download} B/s ttfb=%{time_starttransfer}\n' https://pp-static.hkcloudplay06.com/favicon.ico
curl -s -o /dev/null -w 'EdgeOne %{speed_download} B/s ttfb=%{time_starttransfer}\n' http://pp-static.m4q7z1.shop/favicon.ico

四、本地实测（境外线路，仅作链路验证）

http://pg-static.m4q7z1.shop/speedtest/1mb.bin   -> 200  1.97 MB/s  TTFB 0.23s
http://pg-static.m4q7z1.shop/speedtest/10mb.bin  -> 200  5.50 MB/s  TTFB 0.22s（二次 5.94 MB/s）
https://pp-static.hkcloudplay06.com/favicon.ico  -> 200  15 KB（CF 链路正常）
http://pp-static.m4q7z1.shop/favicon.ico         -> 200  15 KB（EdgeOne 链路正常）
注：以上是菲律宾/境外出口，国内各省要按运营商分别测；重点看 TTFB 与速率抖动。

五、注意事项

1. HTTPS/wss 依赖 EdgeOne 免费证书签发（当前 18 applying + 2 重新触发），
   证书就绪前请用 http:// 测静态与动态 GET，wss 用在线工具连源站 8765 验证握手。
2. 静态域名在 EdgeOne 命中缓存后速度会明显变快（第 2 次请求开始）；
   若要看"冷链路"表现，可加随机 query（?t=时间戳）绕过缓存。
3. 源站 nginx 443 是自签证书（CN=hkcloudplay06.com），直接访问源站 IP 会有证书告警，
   走 EdgeOne 域名时由 EdgeOne 侧证书负责，不受影响。
4. 测速文件是我们临时放的随机数据（1MB/10MB），仅用于压测，不参与业务。
