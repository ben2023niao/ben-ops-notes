游戏定位

欲女梦工厂：
  _id：618
  en_title：ynmgc
  发行方：蜜桃游戏（独家代理）
  平台：Android（无 H5 包）
  版本：V1.0.1，构建 2026-08-14
  Android 包：https://d391me9s8n5j5s.cloudfront.net//20260814/6a7f2065bb5760.73622859-1.0.2-pro.apk
  登录方式：App 内 SDK 调平台 API（老 18Game 用户使用 18GXXX 平台 ID）

现象与判断

现象：App 内登录报错（“网络连接失败”类）。
平台侧核验：后端登录接口全 status:"y"（08-20 全天 2.3 万+ 无失败）；网关无错误；CORS 全开放。
判断：App 内 SDK 调平台 API 的域名失效——
  api.18h.game      NXDOMAIN（无 DNS）
  sdk.18h.game      NXDOMAIN（无 DNS）
  api.youdianse.com 有 A 记录指向宝塔，但直连 https 返回 000（无匹配证书/站点）
老 SDK 无论配置以上哪个域名，登录请求都在 DNS/TLS 层失败。

恢复执行方案（DNS 先行）

第 1 步：GoDaddy 添加 DNS 记录（需域名管理员手动操作）

区域：18h.game（NS：ns01/02.domaincontrol.com）
api.18h.game  A  16.208.5.147  TTL 600
sdk.18h.game  A  16.208.5.147  TTL 600
若老包使用 api.youdianse.com：youdianse.com 区域确认/补齐 api A 16.208.5.147。

第 2 步：宝塔申请证书（DNS 生效后）

宝塔面板 -> 网站 -> 新建站点（或使用系统证书）-> SSL -> Let's Encrypt
域名：api.18h.game、sdk.18h.game（HTTP-01 验证，解析到宝塔即可通过）

第 3 步：宝塔独立 vhost（代理到后端）

server {
    listen 80;
    listen 443 ssl http2;
    server_name api.18h.game sdk.18h.game;

    ssl_certificate     /www/server/panel/vhost/cert/api.18h.game/fullchain.pem;
    ssl_certificate_key /www/server/panel/vhost/cert/api.18h.game/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;

    location ~ ^/(api|channel|customer)(/|$) {
        proxy_pass http://203.0.113.1:8088;
        proxy_set_header Host www.youdianse.com;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_connect_timeout 60s;
        proxy_send_timeout 600s;
        proxy_read_timeout 600s;
    }
    location / { return 404; }
}

第 4 步：验证

curl -X POST https://api.18h.game/api/sdk/system/info -H 'Content-Type: application/json' -d '{}' -> 200
欲女梦工厂 App 重试登录/进入游戏。

执行分工

DNS 记录：域名管理员（Ben/发行）在 GoDaddy 控制台添加。
证书 + vhost：DNS 生效后由运维在宝塔侧执行（本文档为就绪模板）。
