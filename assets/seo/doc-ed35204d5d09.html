整理日期：2026-10-02 14:46｜日期依据：文件名日期

一、需求

用户：腾讯云 CDN 新加了域名 k8x2v9.shop，参考 m4q7z1.shop 配置；解析配置为游戏的动态 + 静态二级域名；
      然后把香港 01/02 后端容器里的生效域名改成 k8x2v9.shop。
本轮按要求不发送飞机群通知。

二、现状核对（开始前）

· 本地/远程：cn 分支工作区干净，HEAD = cdac4bdc（领先 origin/cn 115，未 Push）
· EdgeOne：k8x2v9.shop 站点 zone-3vm7ccg417yf 状态 active、已绑 plan-basic（用户已开套餐）
  NS 已是 ns1/ns2.teodns.com（注册局委派已完成）
· 参照站点 m4q7z1.shop：22 个加速域名 + 25 条规则 + 免费证书，二级域名与 hkcloudplay06/07 同名

三、nginx 侧（standby 192.0.2.37）

文件：/etc/nginx/sites-available/bizops-hk-standby.conf
备份：/etc/nginx/sites-available/bizops-hk-standby.conf.bak-20261002-k8x2v9
仓库：docker/deploy/hongkong/nginx-standby.conf（尾部追加 k8x2v9 段，口径完全复制 m4q7z1 段）
新增：7 个动态 server 块（pg-games+api 合一、vendor_b-games 含 WebSocket、pp/ppk/vendor_d/vendor_c/g759）
      + 1 个静态块（正则捕获前缀 -> bizops-s3-<前缀>.s3.ap-northeast-3.amazonaws.com，目录 302、CORS *、OPTIONS 204）
      + 两个 /speedtest 测速文件 location（与 m4q7z1 一致）
动作：nginx -t 通过 -> systemctl reload nginx

直连验证（Host 头模拟，未过 CDN）：

动态 8/8 = 200：pg-games / api / vendor_b-games / pp-games / ppk-games / vendor_d-games / vendor_c-games / g759-games
静态      = 200：pg-static / pp-static / g759-static（vendor_b-static 403 = 桶里暂无对象，与 m4q7z1 一致）
测速文件  = 200：http://<前缀>-static.k8x2v9.shop/speedtest/1mb.bin（1 MB）

四、EdgeOne 侧（zone-3vm7ccg417yf）

工具：docker/deploy/hongkong/edgeone_apply.py（本轮新增，幂等；--dry-run 可预演）
      python3 edgeone_apply.py --domain k8x2v9.shop --zone zone-3vm7ccg417yf
执行结果：
  · 加速域名 22 个（14 静态 + 8 动态），源站统一 192.0.2.37:80 HTTP
  · 规则 25 条：static-cache-7d（7 天缓存）、dynamic-nocache（不缓存）、vendor_b-websocket（WS 开、超时 120s）、
    hostheader-<子域> x22（显式把回源 Host 改写成该子域，不依赖默认行为）
  · 启用 EdgeOne 自动创建的 22 条 CNAME（默认是禁用状态，必须显式启用）
  · 触发免费证书申请（eofreecert，自动验证 + 部署）：18 个 applying，2 个 failed
    （g759-games / vendor_c-games 已重新触发，与 m4q7z1 当时完全同现象）

五、香港 01/02 后端域名切换

目标机器：bizops-hongkong-sanic-prod-01（192.0.2.16）/ prod-02（192.0.2.17）
文件：/data/server-runtime/conf/domains/*.json，共改 34 处 host：
      m4q7z1.shop -> k8x2v9.shop（静态 14 个前缀 + 动态 8 个子域；api_hosts 仍是 socket.hk-socket.com 不动）
备份：/data/server-runtime/conf/domains.bak-20261002-k8x2v9（两台都有）
校验：10 个文件 JSON 全部解析通过；grep 确认已无 m4q7z1 残留，k8x2v9 出现在 8 个文件
生效方式：conf/domains 以 bind mount 挂到容器 /app/config/domains，
          platform-api 的 game_domains_manager 每次请求读文件 -> 热更新，**不需要重启容器**
容器内确认：docker exec game-service-api-prod 读 pg.json 已是
          pg-games.k8x2v9.shop / pg-static.k8x2v9.shop / pg3~pg7-static.k8x2v9.shop
配置快照：docker/deploy/hongkong/hk-domains-k8x2v9/

六、当前状态与待办

· EdgeOne 加速域名状态：22 个 DomainStatus=process（腾讯云侧还在配置下发），
  *.k8x2v9.shop.eo.dnse3.com 尚未解析出节点 IP —— 与 m4q7z1 首次接入时一致，等它跑完即可。
· 证书：18 applying + 2 已重试；证书就绪前客户端请用 http:// 测，wss 需等证书。
· 生效后验收命令：
    dig +short pg-static.k8x2v9.shop            # 应返回 EdgeOne 节点 IP
    curl -s -o /dev/null -w '%{http_code}\n' http://pg-games.k8x2v9.shop/health
    curl -s -o /dev/null -w '%{http_code}\n' http://pg-static.k8x2v9.shop/health.json
    curl -o /dev/null -w '%{speed_download}\n' http://pg-static.k8x2v9.shop/speedtest/10mb.bin

七、回滚

nginx  ：cp /etc/nginx/sites-available/bizops-hk-standby.conf.bak-20261002-k8x2v9 \
           /etc/nginx/sites-available/bizops-hk-standby.conf && nginx -t && systemctl reload nginx
后端配置：mv /data/server-runtime/conf/domains /data/server-runtime/conf/domains.k8x2v9-broken
         mv /data/server-runtime/conf/domains.bak-20261002-k8x2v9 /data/server-runtime/conf/domains
         （两台都执行；热读文件，回滚同样即时生效，无需重启容器）
EdgeOne ：用 edgeone_apply.py 幂等脚本再跑一次 m4q7z1 配置即可；不需要的加速域名可在控制台/API 删除
