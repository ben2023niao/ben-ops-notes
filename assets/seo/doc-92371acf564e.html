三、脱敏处理

交付页面已移除：

  • 服务器 SSH 密码；
  • GitLab URL 内嵌账号密码；
  • Telegram Bot Token；
  • Telegram Chat ID；
  • 当前生产 share.so MD5。

替换方式：

sshpass -p <password>  -> sshpass -e
GitLab embedded URL    -> ${GIT_PULL_URL}
Telegram Token         -> 空
Telegram Chat IDs      -> 空数组
默认 share.so MD5      -> 空

命令区顶部增加交付说明，要求由受控后端注入凭据。
