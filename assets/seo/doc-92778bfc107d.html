1. 模块目标

赛程页是用户查看完整赛事日历的全局视图，承担：

  1. 赛事时序：按天展示全部 64 场比赛，含状态与跳转入口
  2. 赛事结构：通过"阶段视图"展示小组赛 8 组 + 淘汰赛 Bracket
  3. CTA 分发：每场比赛根据状态提供不同 CTA（进入直播间 / 开赛前竞猜 / 竞猜未开）

2. 用户角色

角色 说明
已登录用户 完整赛程；点击 CTA 进入对应页面
未登录用户 同样可看；点击 CTA 跳登录

4. 业务规则

4.1 比赛状态

状态 触发 UI 表现 CTA
未开赛-竞猜未开 比赛存在但运营未配置开赛前竞猜活动 灰色"竞猜未开" 不可点击
未开赛-竞猜进行中 运营已配置开赛前竞猜活动且未封盘 "开赛前竞猜 →" 跳赛事详情
进行中 主播已开播 + 比赛已到开赛时间 "LIVE NN'" + 红点 + 进度时间 "进入直播间 →"
已结束 全场结束 + 比分写入 灰色"已结束" 可点击查看赛事详情

4.2 日期视图

  1. 按天分组，组内按开赛时间正序。
  2. 同一天分组的标题：2026 年 07 月 15 日 + 副标题 周三 · 共 4 场 · 1 LIVE / 3 待开赛。
  3. 已结束日期：行整体半透明灰；副标题显示"已结束 · 共 N 场"。
  4. 单行包含：时间、阶段、球队 vs 球队、比分（或 VS）、状态指示、操作按钮。
  5. 进行中场次：左边红色 LIVE 条 + 当前进行分钟。
  6. GET /api/v1/schedule/days 不传 from/to 时返回 2026 年后台已配置赛事，供 H5 构建完整日期视图；传入 from/to 时仅返回指定日期范围。

4.3 阶段视图 - 小组赛

  1. 8 组卡片：GROUP A - GROUP H 横向 strip。
  2. 每组结构： - 头部：组名 + "已结束/进行中"状态 - 4 队积分：晋级者前面带 ★，按积分倒序，同分按净胜球 - 6 场比赛：每场显示时间、双方、比分、胜者着色
  3. 积分计算：胜 3 分，平 1 分，负 0 分。
  4. 晋级标识：每组前 2 名 + 4 个最佳第 3 名（按 FIFA 规则）→ 16 强。

4.4 阶段视图 - 淘汰赛 Bracket

  1. 7 列横向布局：左 16 强 → 左 8 强 → 左半决 → 决赛 → 右半决 → 右 8 强 → 右 16 强。
  2. 每个 br-match 卡：含时间、双方、比分；胜者高亮；败者灰。
  3. 状态着色：已结束（黑）/ 进行中（红 LIVE）/ 待赛（虚线灰）。
  4. 决赛卡：居中放大；含奖杯 emoji；显示决赛时间和地点。
  5. 数据来源：服务端按 64 场比赛聚合后输出 bracket 树状结构。

4.5 数据刷新

  1. 进入页面拉取一次。
  2. 进行中场次比分：30s 轮询（共享首页 / 时间线缓存）。
  3. 当某场比赛结束 → 服务端推送 WS event match.ended → 前端局部刷新该场。

5. 边界与异常

场景 系统行为 提示/状态
当日无比赛 显示空白卡 "当日无比赛"
主播未上线但比赛已开赛 CTA 显示"等待主播上线" 不允许进入直播间
小组赛刚结束、积分接口延迟 显示上次缓存积分 顶部提示"积分更新中..."
Bracket 树有空位（决赛未定） 用 ❓ 占位 "待定 VS 待定"
接口失败 整页 skeleton 重试按钮

6. 权限与风控

  1. 仅读，无写操作。
  2. 不涉及资金。
  3. 不涉及审计日志。

7. 数据对象

对象 Owner 说明
match services/go-app 比赛主表
match_event services/go-app 比赛事件（进球/红黄牌/换人），用于实时进度推送
match_stats services/go-app 比赛实时统计快照
group_standing services/go-app 小组积分榜（衍生）
tournament_bracket services/go-app 淘汰赛 Bracket 配置与状态（衍生）

9. 验收标准

需求 ID 验收标准
SCHED-001 进入页面默认显示今日，往上滑可看已结束、往下滑可看未来
SCHED-002 三种状态的比赛行 UI 与 CTA 全部正确
SCHED-003 8 组卡片完整；每组积分按 3-1-0 规则正确；前 2 名带 ★
SCHED-004 Bracket 7 列完整；进行中场次显示 LIVE；决赛卡居中放大显示奖杯
SCHED-005 在日期视图与阶段视图之间切换；用户刷新后保持上次选择
SCHED-010 一场小组赛结束并写入比分后，对应组积分 60s 内更新
SCHED-011 Bracket 中已结束场次为黑色 winner / 灰色 loser；进行中红色 LIVE；待赛虚线灰

10. 测试要求

  1. 单元测试：积分计算、净胜球排序、Bracket 树构建
  2. 集成测试：写入比赛结果 → 触发积分重算 → 接口返回正确
  3. E2E：在线观看 1 场结束 → 切到赛程页 → 看到对应组积分变化
  4. 截图：日期视图 / 小组赛 strip / Bracket / 切换 tab
