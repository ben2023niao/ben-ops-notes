背景

测试服务器健康告警：根盘 86.9% >= 80%（可用仅 4.2G）。要求清理磁盘并新增不影响代码/镜像构建发布的定时清理任务。

占用定位（清理前）

项目 大小 说明
Docker 镜像 10.3G 可回收 4.4G（旧版 youdianse-php dev-a3fb5d07 4.68G、旧 h5 client 400M 均未使用）
Docker 构建缓存 900M 可回收 670M
/var/log/journal 3.0G systemd 日志
/var/log/btmp* 400M 登录失败记录
/www/wwwlogs 421M 访问日志（h5 活动日志 270M）
/tmp 270M 旧发布临时目录、测试文件
/www/swap 1.1G swap 文件，在用（不动）
/www/server/data 1.1G 本机 MySQL 数据（不动）

清理执行（一次性）

  1. Docker：删除未使用镜像 youdianse-php:dev-a3fb5d07ce8d（4.68G）、youdianse_test_f2955a5_18game_h5_client_3003:latest（400M）；悬空镜像 prune。
  2. journalctl --vacuum-size=200M（释放 2.6G）。
  3. btmp / btmp.1 截断清零。
  4. 删除 7 天前轮转日志（/var/log、/www/wwwlogs）。
  5. 清理 /tmp 7 天前旧文件与旧发布临时目录。
  6. h5 大访问日志（270M）截断并 kill -USR1 nginx.pid reopen。

结果：根盘 86% → 60%，可用 4.2G → 12G（释放约 7.8G）。

定时任务（不影响构建发布）

  • 脚本：/usr/local/bin/youdianse-test-disk-clean.sh（仓库副本：devops/scripts/youdianse-test-disk-clean.sh）
  • crontab：30 4 * * * /usr/local/bin/youdianse-test-disk-clean.sh（每天 04:30，root）
  • 日志：/var/log/youdianse-disk-clean.log（记录清理前后用量）
  • 安全设计：
  • 检测到 docker buildx bake / docker compose build 进行中时，跳过 docker 清理（其余照常）；
  • 只删除未被运行容器使用的 youdianse-php 旧镜像（保留当前 + 上一版，便于回滚）与未使用 h5/pc client 镜像；
  • 只清理 24h 前的构建缓存（保留近期缓存保证发布速度）；
  • 只删 7 天前轮转日志；活动日志 >200M 才截断并 reopen nginx；
  • /tmp 只删 7 天前文件与 3 天前发布临时目录。
  • 已试运行 rc=0，无报错。

验证

  • web/nginx/cron 容器正常（youdianse-php:dev-0b3ca19ed7fa）。
  • admin / h5 接口 200，0.1s。
  • 清理后 docker system df：镜像 6.1G（0B 可回收），构建缓存 900M。

通知与提交

  • 每步已发 18game运维 群（步骤 1-2）。
  • 本地 Git 已提交（不 Push），commit 信息见提交结果通知。
