目标 账号 说明

宝塔 16.208.5.147 ubuntu + 私钥 sudo 需要密码

私钥不随包分发，找运维要。

3. 第一次排查，按这个顺序

hostname; date
docker ps --format '{{.Names}} {{.Status}}' | grep youdianse
curl -s -o /dev/null -w '%{http_code}\n' http://203.0.113.1:8088/
sudo tail -200 /opt/docker-youdianse-php/runtime/app-logs/error-$(date +%F).log
sudo docker exec youdianse-main-php-nginx tail -100 /var/log/nginx/error.log
