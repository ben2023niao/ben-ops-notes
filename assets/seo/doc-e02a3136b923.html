背景

2026-08-25 首轮对比结论：我方入口 HTML 更快，但静态源单一在巴西；竞品 Cloudflare 全球边缘 + 菲律宾源站。 2026-08-28 完成改造：static_hosts 并列写入圣保罗桶（-sa）与东京桶，launcher 前端并发测速自动选快。 本次复测验证改造效果。

结论：两地视角完全对称——本地桶快（0.05-0.14s）、远端桶慢（1.7-1.9s）， 测速选优会稳定把用户导向本地桶。

二、真实浏览器（Playwright）

巴西视角（备用机，PG 麻将胡了）

入口 ind-h5.dbqpplus999.com/pgbronline/ -> 点击游戏 -> 打开到加载完成 3.3s（旧记录约 4s）
游戏 URL 携带 or=dbqp-gcs-pg4-static-sa.storage.googleapis.com  <- 巴西自动选圣保罗桶
通过 1/1，无关键错误、图片 4xx=0

马尼拉视角（本地，PG 第一张游戏卡）

入口 TTFB 433ms / DCL 38ms，113 张游戏封面图
点击 -> launcher 2.6s -> 游戏可用约 8.2s（含游戏启动，冷缓存）
资源请求统计：dbqp-gcs-pg4-static.storage.googleapis.com（东京桶）=4
              dbqp-gcs-pg4-static-sa.storage.googleapis.com（圣保罗桶）=1（仅测速探测）
              <- 亚洲自动选东京桶

竞品大厅（马尼拉视角，m6kk678n.com/main/inicio）

TTFB 1.67s（我方入口 0.43s 更快）；Ionic 应用
资源分布：m6kk678n.com=47、upload-us.f-1-g-h.com=22、api4.a-b-c-8.com=15、
          game-logo.6-q-r-s.com=8、o.alicdn.com=1（多 CDN 域名分散加载）

三、结论

  1. 双桶测速选优已生效：巴西走圣保罗桶、亚洲走东京桶，两侧静态 TTFB 均降到 0.05-0.14s； 亚洲侧不再受圣保罗桶 1.9s 慢链路影响。
  2. 我方入口/客户端 TTFB 仍快于竞品（马尼拉 0.43s vs 1.67s；圣保罗 0.09s vs 0.07s 基本持平）。
  3. 剩余差异与 2026-08-25 一致：我方大厅预加载 image.prod-br.com 100+ 封面图、 首次点击可能有 APP 推广弹窗，属前端优化项（懒加载/压缩/弹窗可跳过），不在本次范围。
