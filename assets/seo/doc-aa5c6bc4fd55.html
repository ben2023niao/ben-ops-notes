# 优化项 执行 验证
1 nginx 源站 proxy_cache（静态域） 宝塔+备用机 12+12 vhost 加 static_cache（1h + 失效重试） X-Proxy-Cache MISS→HIT
2 CF CacheRule：静态 HTML 全缓存 Agent Lee 3 zone Page Rule（*-static.* Cache Everything，Edge TTL 1d） 静态 HTML cf-cache-status MISS→HIT
3 Brotli Agent Lee 3 zone 开启 content-encoding: br
4 Early Hints Agent Lee 3 zone 开启 -

nginx cache 配置：proxy_cache_path ... keys_zone=static_cache:512m ... + proxy_cache static_cache; proxy_cache_valid 200 301 302 1h;（宝塔 proxy.conf / 备用机 /etc/nginx/proxy.conf， 均备份 .bak-20260829-2）；生成脚本模板已固化。
