二、需求

原验证输出只有容器名和状态：

docker ps --format 'table {{.Names}}    {{.Status}}' | grep game-service

问题：

  • 看不到实际镜像版本；
  • 巴西和香港命令格式重复；
  • 主机和查询时间不够醒目；
  • 未严格按发布页勾选厂家过滤。

三、调整结果

新增统一 verifyHostCmd 生成器，每台主机输出：

━━━━━━ 主机名 · IP · 北京时间 ━━━━━━
NAMES                       STATUS           IMAGE
game-service-api-prod       Up 6 minutes     203.0.113.1:5000/game-service-api:20261028-ben
...

具体变化：

  1. 巴西 01/02、香港 01/02 共用一套格式。
  2. 横幅包含主机名、IP、北京时间。
  3. docker ps 增加 {{.Image}}，直接显示镜像 tag。
  4. 使用发布页当前勾选的厂家过滤，不再固定显示全部容器。
  5. 容器状态保持 Docker 原生对齐表格，便于复制和人工核对。

四、验证

页面原命令实跑：

巴西 01：9 个容器 Up，镜像 20261028-ben
巴西 02：9 个容器 Up，镜像 20261028-ben
香港 01：9 个容器 Up，镜像 20261028-ben
香港 02：9 个容器 Up，镜像 20261028-ben

Brazil registry：

203.0.113.1:5000

Hong Kong registry：

34.39.180.82:5000

Chrome 实际渲染通过。

五、变更范围

本轮只修改发布页验证输出和文档，未重启生产容器，未修改镜像、业务数据、域名或 crontab。
