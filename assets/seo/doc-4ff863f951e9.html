一、需求

  1. 静态域名 CNAME 到对应 GCS 桶域名，巴西/香港都回源，开启黄云用 CF CDN；
  2. 接口（api/game）域名开通 Argo Smart Routing；
  3. 出明细发群（含费用与续费提醒）。

二、验证结论（重要）

  1. 黄云 CNAME 直指 GCS 桶不可行（实测）：pg-static.xqv9m8.icu 改 CNAME → dbqp-gcs-pg-static-sa.storage.googleapis.com + 黄云后返回 404， GCS 校验 Host 头必须等于桶域名；
  2. CF Free 无法改写 Host：Origin Rules 的 Host 改写仅 Enterprise （官方文档 Availability 表确认），Transform Rules/Snippets Free 不可用；
  3. 测试记录已还原（A 8.233.83.48 灰云 → 恢复 200），无副作用。

三、落地：nginx 改 Host 方案（巴西）

架构：CF(黄云) -> 宝塔/备用 nginx -> GCS 桶（nginx 改写 Host + SNI）

1. nginx vhost（宝塔 + 备用机 34.151.249.53，各 12 个静态 vhost）

location / 由本地目录直出改为 GCS proxy：

location / {
    resolver 8.8.8.8 1.1.1.1 ipv6=off valid=300s;   # 强制 IPv4（GCS AAAA 在 GCP 无 IPv6 导致 502）
    set $gcs_upstream dbqp-gcs-<prefix>-sa.storage.googleapis.com;
    proxy_pass https://$gcs_upstream;
    proxy_set_header Host dbqp-gcs-<prefix>-sa.storage.googleapis.com;
    proxy_ssl_server_name on;
    proxy_ssl_name dbqp-gcs-<prefix>-sa.storage.googleapis.com;
    ...
}

12 前缀 → 圣保罗 -sa 桶（g759-static 本就在圣保罗，无 -sa）： pg-static/pg3/pg4/pg5、tada-statics/1/2、pp-static、ppk-static、 playson-static、panda-static、g759-static。

2. 生成脚本模板

sync_all_game_domains_to_baota.py（宝塔 /www/server/panel/script/ 与仓库一致）： 静态 spec 增加 static_prefix，static_server_conf 按 STATIC_BUCKET_HOSTS[prefix][0] （-sa 桶）输出 proxy 模板；已重新生成并 reload，后续 cron 不会回退。 备份：/root/all_game_domain_sync_backup_20260829_191818。

3. btwaf cookie 跳过（关键）

宝塔 WAF 注入 server_name_session cookie 导致 CF 不缓存（DYNAMIC）。 /www/server/btwaf/header.lua 第 194 行追加：

and not string.match(ngx.var.host or "", "%-statics?%.")

即 -static. / -statics. 域名跳过 cookie 注入（备份 .bak-20260829）。 备用机无 WAF，天然无 cookie。

4. Cloudflare DNS（巴西）

241 条静态记录（A 8.233.83.48 灰云）全部改为：A 35.247.205.6 + 黄云(proxied)， API 批量 PATCH，0 失败；验证无残留 A 8.233.83.48 记录。

5. 验证结果

  • 公网：pg-static/126/ 200、pg4-static/126/ 200、g759-static 游戏页 200、 panda-static 游戏页 200（各厂商桶路径不同，缺失路径 404 属正常）；
  • .js 静态资源 cf-cache-status: HIT（CF CDN 缓存生效，age 递增）；
  • HTML 页面默认 DYNAMIC（CF 默认只缓存静态扩展名；如需全缓存可加 Cache Rule， 需 Zone Config 权限，待办）。

四、香港（待协调）

香港域名（hkcloudplay01-05 / hkplaycore）当前走 AWS CloudFront（DNS-only CNAME）， 由 cn 分支管理。切到 CF 黄云 + 东京桶需与 cn 分支协调后实施， 本记录预留：香港 nginx 34.92.13.108 相同 proxy 模板 → 东京桶 （STATIC_BUCKET_HOSTS[prefix][1]，g759 用 dbqp-gcs-g759-static-asia）。

五、Argo Smart Routing 评估

现状与结论

  • 42 个 zone 全部 Free 套餐；Argo 需付费套餐（Pro 及以上）+ 按 zone 计费；
  • 现有 DNS token 调 PUT /zones/{id}/argo/smart_routing → Authentication error （无 Zone Settings 权限），需新 token 或 CF 面板 Agent Lee 执行；
  • 动态域名盘点：199 条黄云 A → 35.247.205.6 （api.<22根域> 22、<6厂商>-games.<22根域> 132、通配/www/socket 等 45）。

费用估算（Argo 按 zone，非按 hostname）

Pro 套餐：$20/zone/月（Argo 前置条件）
Argo Smart Routing：$5/zone/月
若开 22 个巴西根域：($20+$5)×22 = $550/月
若开 20 个：$500/月 ≈ 500U（1 个月试跑）

待办

  1. 确认开通 zone 清单（建议：22 巴西根域或缩到实际在用的 ~20 个）；
  2. 充值/扣费确认（500U，亨利侧信用卡）；
  3. 升级套餐 + 开 Argo：用 Agent Lee 指令或提供 Zone Settings 权限 token；
  4. 续费提醒：Argo/Pro 按月计费，每月需预充值，否则下月停服。
