一、任务

聚焦一款双方同款游戏（Fortune Tiger：我方 PG id 126 / 竞品 id 2196）， 只测「点击游戏图标那一刻 → 游戏完整加载完毕（画布 + 过设备检测 + 网络稳定）」， 录屏裁切到点击开始，带水印发群。

二、方法

  • docker 浏览器方案：备用机（巴西）Playwright Chromium，手机 UA（iPhone 390x844）；
  • 新脚本 game_click_to_loaded_compare.py：分侧记录 canvas_after_click_ms（点击→画布）与 click_to_loaded_ms（点击→完整加载）；
  • 视频用 ffmpeg 裁切 [点击前1s, 完整加载后6s]，突出点击→加载阶段。

三、结果

侧    入口                               画布出现   点击→完整加载   状态
我方  ind-h5.bizopsplus999.com/pgbronline/  4.4s      15.9s        ✅（真实点击图标）
竞品  m6kk678n.com（登录）                 2.0s      12.8s        ✅（点击卡片后跳转URL计时）

我方静态走圣保罗桶（or=pg4-static-sa），无跨洲瓶颈。

四、重要发现/限制

  1. 竞品大厅自动化点击不响应：m6kk678n.com 为 Ionic（shadow DOM）+ 懒加载， .game-card 文本在 shadow root 内取不到、force 点击卡片/图片均不跳转 （elementFromPoint 被"Baixe Nosso APP"安装横幅层遮挡嫌疑，多轮验证未突破）。 竞品侧改用「点击卡片后的跳转 URL」（game/action/2196，即卡片点击的目标页）计时， 口径近似但非字面图标点击，已在群内说明。
  2. 我方点击→完整加载比竞品慢约 3.1s（15.9 vs 12.8），差距集中在画布出现前 （4.4s vs 2.0s，含 SPA 跳转/launcher 测速）与加载后半段。

五、其他修复

  • probe_ff789_open.py：支持新标签页/iframe 画布检测（原只扫主页面，游戏新开页时 误报 CLOSED）；canvas_sig 逐 frame 取画布。

六、产物

  • /tmp/bizops-click-loaded-20260828_1142/：2 条裁切 MP4 + PNG + results.json；
  • 2 条视频已带水印（域名/账号/服务器/分阶段耗时/★点击图标→完整加载）发群。
