origin/ben 新增的 domains-hk = 香港配置源
旧 origin/ben 的 domains 仍混有香港内容，不能直接用于巴西构建

二、目标

巴西：platform-api/conf/domains/ 覆盖 /data/server-runtime/conf/domains/
香港：platform-api/conf/domains-hk/ 覆盖 /data/server-runtime-hk/conf/domains/

域名、默认 hosts 和特殊组 game_ids 均按环境分别维护，禁止交叉复制。

三、ben 分支代码整理

1. 域名目录

将 03 当前巴西配置正式提交到：

platform-api/conf/domains/

保留开发新增的香港配置：

platform-api/conf/domains-hk/

校验后的配置规模：

环境 文件数 特殊组游戏 ID 数 静态 hosts 动态 hosts
巴西 10 258 38 38
香港 10 258 96 96

2. 域名校验器

新增 scripts/validate_domains.py：

  • JSON 可解析；
  • default.static_hosts / default.game_hosts 非空且数量一致；
  • special_games[].game_ids 为正整数且组内不重复；
  • hosts 格式统一、无重复；
  • 巴西和香港配置文件集合一致；
  • 巴西目录禁止 hkcloudplayNN.com；
  • 香港目录禁止巴西 xqv9m8.icu / vendor_a-cdn-2026.icu。
  • 巴西 vendor_a SPECIAL_GAMES_v2 固定为 [664, 598]，防止 598 再次被旧工作区覆盖。

负向测试将 pg-static.hkcloudplay01.com 放入巴西目录，校验器按预期拒绝。 另将 vendor_a v2 临时退回 [598] 做负向测试，校验器同样按预期拒绝。

3. CI/CD

新增 .gitlab-ci.yml，在 ben 分支执行域名校验。

build.sh 增加：

  • 打包前强制执行 validate_domains.py；
  • Docker 镜像写入当前 Git 短提交号 VCS_REF；
  • 巴西 runtime 从 domains 同步；
  • 香港 runtime 从 domains-hk 同步；
  • 两个域名目录均使用 rsync --delete --checksum，保证旧文件被清除；
  • 两个 runtime 分别同步 configs-*.py 和公共运行时文件；
  • server_configs、version.json 只更新巴西 runtime；香港保留自己的独立文件；
  • 构建前后对香港 server_configs / version.json 做 SHA256 比对；
  • 分别生成 domains.sha256、md5sum.txt；
  • 支持 RUNTIME_DIR / RUNTIME_HK_DIR 覆盖目录做离线验证。

同时重写 build.md，移除旧明文密码和过期发布说明，统一使用环境变量或发布机凭据。

五、03 域名目录覆盖

执行：

rsync -a --delete --checksum platform-api/conf/domains/ /data/server-runtime/conf/domains/
rsync -a --delete --checksum platform-api/conf/domains-hk/ /data/server-runtime-hk/conf/domains/

结果：

巴西源与巴西 runtime：逐文件一致
香港源与香港 runtime：逐文件一致
香港 runtime 覆盖前 10 个文件与新 domains-hk 均不同，覆盖后全部一致
巴西 runtime 覆盖前已与巴西源一致，覆盖后保持一致
巴西 runtime 未发现 hkcloudplayNN.com
香港 runtime 未发现 xqv9m8.icu / vendor_a-cdn-2026.icu
源和 runtime 的巴西 vendor_a SPECIAL_GAMES_v2 均为 [664, 598]
香港 server_configs / version.json 在域名覆盖前后 SHA256 不变

本地离线构建测试分别确认：

  • 巴西 runtime 包含巴西 domains，不包含 hkcloudplayNN.com；
  • 香港 runtime 包含 domains-hk，不包含 xqv9m8.icu；
  • 两边均生成对应的 configs-*.py、domains.sha256、md5sum.txt。
  • 香港预置的 server_configs / version.json 哨兵文件在构建后字节不变；
  • 构建输出 HK_MEvendor_aTA_PRESERVED=OK。

七、运维发布页

运维发布页.html 增加：

  • 巴西 / 香港域名源目录和 03 runtime 映射表；
  • “两目录不能互相复制”的显式警示；
  • 独立“域名全量覆盖”命令，直接使用 rsync --delete --checksum；
  • 独立“仅更新巴西 server_configs / version.json”命令，并对香港文件做前后 SHA256 比对；
  • 打包命令先执行域名校验；
  • 打包后对两个 runtime 分别执行 diff -qr；
  • 巴西 runtime 搜索香港域名、香港 runtime 搜索巴西域名；
  • 检查步骤同时展示巴西与香港 g759.json；
  • 自动输出检查新增 DOMAIN_CONFIG_OK、DOMAIN_SYNC=OK、 DOMAIN_ENV_ISOLATED=OK、BRAZIL_RUNTIME_MEvendor_aTA_OK、 HK_MEvendor_aTA_PRESERVED=OK 门禁；
  • 版本日期和页脚更新至 2026-11-02。
