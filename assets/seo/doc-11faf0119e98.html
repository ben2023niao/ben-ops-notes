时间：2026-10-20 19:26（北京）｜2026-10-20 08:26（巴西圣保罗） 反馈：测试人员在 g759-static.xqv9m8.icu 打开 slocashmania 时， slocashmania_lang/native 下 4 个 png/jpg 返回 404；test/uat 正常。

一、结论

资源没有丢，源站和 CDN 都是 200。 4 个文件在 GCS 桶 newgg2-bizops-gcs-g759-static 里都存在，直连 GCS 与走 g759-static.xqv9m8.icu / g759-static.vendor_a-cdn-2026.icu 均返回 HTTP 200。

最可能的原因是测试人员浏览器/边缘还留着旧缓存里的 404： 2026-10-20 13:54 之前 Worker 会把 404 也缓存 7 天， 当天 13:54 已通过给 g759 加缓存版本键 v1 整体失效，但用户本地浏览器的 404 需要清缓存或无痕窗口才会消失。

三、建议测试方式

  1. 先用无痕窗口打开上面 4 条 URL，确认返回图片；
  2. 如果无痕可以、正常窗口不行 → 是本地缓存，清站点缓存即可；
  3. 如果无痕仍然 404，请把完整 URL + 请求时间 + 所在地区/VPN发出来， 再按具体节点查边缘缓存。

四、复核命令

curl -sI "https://newgg2-bizops-gcs-g759-static.storage.googleapis.com/games/slocashmania/assets/slocashmania_lang/native/1e/1ea965735.fb801.png"

# 走 CDN
curl -sI "https://g759-static.xqv9m8.icu/games/slocashmania/assets/slocashmania_lang/native/1e/1ea965735.fb801.png"
