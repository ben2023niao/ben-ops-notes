1. 问题现象

PC 游戏列表页重新出现裸图片链接：

https://test-img.hbabaxb.cn/uploads/2026-06-30/597ccfb4d69f67da6bc850bae87a371f.png

正常规则应该是后端返回：

https://test-img.hbabaxb.cn/uploads/...png?敏感凭据：[已脱敏]

裸链只允许看到默认占位图，不能直接看到原图。

2. 排查结论

测试服务器 .env.dev 里的签名配置还在：

[cdn.test_img_auth]
enabled=1
hosts=test-img.hbabaxb.cn
prefixes=/uploads/
ttl=2592000
[敏感内容已脱敏]
time_param=t
key=仅 env 保存，文档不记录明文
key_file=

但 PHP 容器实际运行的 CommonService.php 已经没有 signCdnUrlIfNeeded()。

结论：

  • Nginx 图片兜底规则没有丢。
  • env 签名配置没有丢。
  • 后端代码里的签名出口被后续发布覆盖/还原了。
  • 页面出现裸图，是后端没有再给 test-img.hbabaxb.cn/uploads/* 追加 token/t。

3. 本次修复

3.1 恢复后端签名出口

修改文件：

/Users/ben/Documents/ben/自动化发布/dev/18game_php/app/Services/Common/CommonService.php

热同步到测试容器：

/var/www/html/youdianse-php/app/Services/Common/CommonService.php

改动点：

  • getCdnUrl() 返回 URL 前统一经过 signCdnUrlIfNeeded()。
  • signCdnUrlIfNeeded() 只处理 env 配置命中的 host 和 path prefix。
  • 当前只命中：
host: test-img.hbabaxb.cn
path: /uploads/*
  • AWS CloudFront 绝对 URL、其他域名、其他路径全部原样返回。
  • 不改上传逻辑。
  • 不改 AWS S3。
  • 不改前端打包资源。
  • 不把密钥写死在代码里。

签名方式：

敏感凭据：[已脱敏] + uri_path + timestamp)
t = 当前时间戳

说明：

  • t 是签名生成时间，不是过期时间。
  • 过期窗口由边缘/Nginx/后续强校验规则控制。

3.2 刷新广告缓存

代码恢复后，PC 游戏列表页仍残留一张裸图：

https://test-img.hbabaxb.cn/uploads/2026-07-28/569aa7aa389e0d95742b02dec89511b5.png

定位结果：

  • 这张图来自 PC 游戏列表页顶部推荐/广告 banner。
  • 页面里因为 preload、img、Nuxt payload 重复出现 3 次。
  • 后端代码路径本身会走 AdvService::getAll()。
  • 但游戏列表页先读 CacheKey::ADV . 'game-top' 广告缓存。
  • 缓存里还保留了后端代码被还原期间生成的裸 URL。

处理：

AdvService::refreshCache()

刷新后广告缓存重新经过 CommonService::getCdnUrl()，裸图恢复为带 token/t。

6. 影响说明

对测试 PC：

  • 页面里后端 uploads 图片恢复带 token/t。
  • 正常页面展示原图。
  • 复制裸图片 URL 直开仍显示默认占位图。

对测试 H5：

  • H5 页面验证为 107/107 带 token/t。
  • 本次没有改 H5 前端代码。

对上传：

  • 不影响后台上传。
  • 上传仍走原 AWS S3 逻辑。

对 AWS 原链路：

  • 不改 AWS S3。
  • 不改 CloudFront。
  • 只有配置命中的 test-img.hbabaxb.cn/uploads/* 才签名。

7. 回滚方式

如需要回滚本次测试容器热修：

docker exec youdianse-dev-php-web sh -lc '
cp /var/www/html/youdianse-php/runtime/logs/CommonService.php.bak.restore_sign_20260730_1518 \
   /var/www/html/youdianse-php/app/Services/Common/CommonService.php &&
chown www-data:www-data /var/www/html/youdianse-php/app/Services/Common/CommonService.php &&
php -l /var/www/html/youdianse-php/app/Services/Common/CommonService.php
'

回滚影响：

  • 后端会重新返回裸 test-img URL。
  • Nginx 裸链兜底仍会返回默认图。
  • 页面可能再次出现默认图，需要恢复代码或关闭兜底规则。

8. 后续注意

这次问题的根因是后端签名代码没有固化进后端代码仓库，后续发布会覆盖临时热修。

本次已同步修改本地后端代码仓库：

/Users/ben/Documents/ben/自动化发布/dev/18game_php
branch: dev

后续需要确保该提交进入测试后端发布链路，否则下次后端发布仍可能把签名出口覆盖掉。
