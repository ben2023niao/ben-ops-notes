一、需求

用户：
  1. 三个域名都设置到期自动续费：m4q7z1.shop / k8x2v9.shop / p3w9n5.shop
  2. m4q7z1.shop、k8x2v9.shop 是游戏域名；p3w9n5.shop 是商户域名，参考 CF 的商户域名 hk-socket.com
  3. 把这 3 个域名写进香港 01/02 的配置并生效
本轮按要求不发送飞机群通知。

二、三个域名的注册与续费（需要注册商侧操作）

RDAP 查询（rdap.gmoregistry.net，.shop 注册局已停用 whois）：
  注册商：GNAME.COM PTE. LTD.
  注册时间：2026-09-29
  到期时间：2027-09-29（三个域名一致）
  域名状态：clientTransferProhibited（正常，禁止转移）

⚠️ 自动续费我这边做不了：当前的腾讯云密钥只有 EdgeOne（TEO）权限，
   而域名的续费在注册商 GNAME 侧，腾讯云控制台管不到。
   需要在 GNAME（gname.com）后台操作：我的域名 -> 域名管理 -> 选择域名 -> 开启「自动续费」。
   说明：.shop 是按年计费（1 年一个周期），所以能开的是「到期自动续费（1 年）」；
   如果 GNAME 支持按月分期扣款，在同一个续费设置里选周期即可。
   把 GNAME 的账号或 API 凭据给我，我可以代做。

三、p3w9n5.shop 商户域名接入（参考 CF 的 hk-socket.com）

对照 CF 的 hk-socket.com 现网配置：
  DNS：hk-socket.com + socket.hk-socket.com 橙云 A -> 192.0.2.37（无 Worker、无缓存规则）
  nginx：server_name hk-socket.com socket.hk-socket.com -> platform-api（9090）
  platform-api 的 api_hosts = socket.hk-socket.com

本轮按同一口径落地（EdgeOne 渠道）：
1) nginx（standby 192.0.2.37）
   新增 server 块：server_name p3w9n5.shop socket.p3w9n5.shop -> bizops_hk_standby_platform_api，
   带 /healthz 探针；备份 *.bak-20261002-p3w9n5；nginx -t + reload 通过。
   直连验证（Host 头）：p3w9n5.shop / socket.p3w9n5.shop / hk-socket.com / socket.hk-socket.com
   的 /healthz 全部 200（新旧域名并存，旧的 CF 渠道未受影响）。

2) EdgeOne（zone-3vm7chzbxkcb，站点已 active + plan-basic）
   用 edgeone_apply.py 的 merchant 模式：2 个加速域名（p3w9n5.shop 根域 + socket.p3w9n5.shop），
   源站 192.0.2.37:80 HTTP；规则 3 条（merchant-nocache 不缓存 + 2 条回源 Host 重写）；
   启用 2 条 CNAME；触发免费证书申请。

四、香港 01/02 写入三个域名

目标机器：prod-01（192.0.2.16）/ prod-02（192.0.2.17）
文件：/data/server-runtime/conf/domains/*.json
改动（共 68 条 host + 1 处 api_hosts）：
  · static_hosts / game_hosts：每个前缀同时列出两个游戏域名（原来只有 k8x2v9）
        ["pg-static.m4q7z1.shop", "pg-static.k8x2v9.shop"] 等
        顺序：m4q7z1 在前（已在服务），k8x2v9 在后（正在上线）
  · api_hosts（pg.json）：["socket.p3w9n5.shop", "socket.hk-socket.com"]
        新商户域名在前，旧的 CF 渠道保留为第二条
  · vendor_a.json 的 game_hosts（vendor_a-games.hkcloudplay06/07.com）保持原样：EdgeOne 无对应域名，
    在 CF 上也是 404 的历史遗留项
备份：/data/server-runtime/conf/domains.bak-20261002-3domains（两台）
校验：10 个文件 JSON 全部通过；m4q7z1 / k8x2v9 各出现在 8 个文件，p3w9n5 出现在 pg.json
生效：conf/domains 以 bind mount 挂到容器 /app/config/domains，platform-api 每次请求读文件，
      热更新，**不需要重启容器**；已用 docker exec 读容器内 pg.json 确认三处 host 列表都是新值
配置快照：docker/deploy/hongkong/hk-domains-3domains/

五、当前生效状态与验收

k8x2v9.shop（zone-3vm7ccg417yf）：22 个加速域名陆续从 process 转 online
  实测 2026-10-02 14:50：pg-static.k8x2v9.shop 已解析到 EdgeOne 节点（192.0.2.46），2/22 online，其余在跑
p3w9n5.shop（zone-3vm7chzbxkcb）：2 个加速域名仍在 process（刚提交，等腾讯云下发）
m4q7z1.shop：线上正常（pg-games.m4q7z1.shop/health = 200），作为第一条游戏域名不受影响

完全生效后验收：
  dig +short pg-games.k8x2v9.shop            # 应为 EdgeOne 节点 IP
  curl -s -o /dev/null -w '%{http_code}\n' http://pg-games.k8x2v9.shop/health
  curl -s -o /dev/null -w '%{http_code}\n' http://pg-static.k8x2v9.shop/health.json
  curl -s -o /dev/null -w '%{http_code}\n' http://socket.p3w9n5.shop/healthz
  curl -s -o /dev/null -w '%{http_code}\n' http://p3w9n5.shop/healthz
证书：k8x2v9 / p3w9n5 各有一批在签发（k8x2v9 有 2 个失败已重试），https/wss 等证书就绪后再测。

六、回滚

后端配置（两台，热读即时生效）：
  mv /data/server-runtime/conf/domains /data/server-runtime/conf/domains.3domains-broken
  mv /data/server-runtime/conf/domains.bak-20261002-3domains /data/server-runtime/conf/domains
nginx：
  cp /etc/nginx/sites-available/bizops-hk-standby.conf.bak-20261002-p3w9n5 \
     /etc/nginx/sites-available/bizops-hk-standby.conf && nginx -t && systemctl reload nginx
EdgeOne：不需要的加速域名可在控制台删除；重新配置用
  python3 edgeone_apply.py --domain <域名> --zone <zoneId> [--profile merchant]

八、复查结论（2026-10-02 15:20 追加）

1) 香港 01/02 配置文件（两台一致，容器内可见）
   pg.json default : static=['pg-static.m4q7z1.shop','pg-static.k8x2v9.shop']
                     game  =['pg-games.m4q7z1.shop','pg-games.k8x2v9.shop']
                     api   =['socket.p3w9n5.shop','socket.hk-socket.com']
   三个域名字符串出现次数：m4q7z1 = 34、k8x2v9 = 34、p3w9n5 = 1（api_hosts 一处）
   容器内 docker exec 读 pg.json 与宿主机一致（热读，不需要重启）

2) EdgeOne 上线进度
   k8x2v9.shop（zone-3vm7ccg417yf）：19/22 online，剩 3 个在 process
   p3w9n5.shop（zone-3vm7chzbxkcb）：2/2 online
   两个站点解析均指向 EdgeOne 节点 192.0.2.46

3) 链路实测（--resolve 直打节点，绕开本地 DNS 缓存）
   http://pg-games.k8x2v9.shop/health      -> 200
   http://pg-static.k8x2v9.shop/health.json -> 200
   http://socket.p3w9n5.shop/healthz        -> 200
   http://p3w9n5.shop/healthz               -> 200
   http://p3w9n5.shop/ （根路径）            -> 404（与 CF 的 hk-socket.com 同为 platform-api 形态，符合预期）

4) 仍未完成：三个域名的「到期自动续费」
   注册商 GNAME.COM PTE. LTD.，到期 2027-09-29；仓库与香港机器上都没有 GNAME 凭据，
   当前腾讯云密钥仅有 EdgeOne 权限 -> 需要人工在 gname.com 后台开启（或提供 GNAME 凭据由本侧代做）。
