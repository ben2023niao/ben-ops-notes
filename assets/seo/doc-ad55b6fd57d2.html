一、现象

在浏览器打开 https://h5.game-app543.com/：

您的连接不是私密连接
授权安全测试者可能会试图从 h5.game-app543.com 窃取您的信息
net::ERR_CERT_AUTHORITY_INVALID
您目前无法访问 h5.game-app543.com，因为此网站使用了 HSTS

二、结论

不是我方证书或服务器问题。该域名被菲律宾政府 CICC （Cybercrime Investigation and Coordinating Center）列入封锁名单： ISP 把域名解析到封锁页服务器，该服务器使用不受信任的证书， 浏览器因此报 ERR_CERT_AUTHORITY_INVALID；叠加 HSTS 后用户无法跳过。

三、证据链

# 证据 结果
1 本机/运营商 DNS（2405:b800:fef:ff00::5、::4、路由器 203.0.113.1）解析 121.54.78.47（PH Smart Broadband，AS10139，非我方 IP）
2 该 IP 的 80 端口 302 → https://blocked.sbmd.cicc.gov.ph/?url=http%3A%2F%2Fh5.game-app543.com%2F&query_type=1
3 该 IP 的 443 证书 不受信任（unable to get local issuer certificate）→ 浏览器报错根因
4 权威 NS a.share-dns.com / b.share-dns.net 正确返回 dh7bz4ezbakb.cloudfront.net
5 7 个公共 DNS（1.1.1.1 / 8.8.8.8 / 9.9.9.9 / OpenDNS / 223.5.5.5 / 119.29.29.29 / 114） 全部返回正确 CloudFront CNAME
6 用干净 DNS 访问站点 HTTP 200（CloudFront，server: nginx/1.18.0）
7 证书 ACM 证书，CN=h5.game-app543.com，issuer Amazon RSA 2048 M01，有效期 2025-12-04 ~ 2027-01-02，验证通过

封锁页基础设施：blocked.sbmd.cicc.gov.ph → alb-blocked-sbmd-cicc-1864385455.ap-southeast-1.elb.amazonaws.com （菲律宾政府 URL 封锁系统，托管在 AWS ELB）。

四、影响面（扫描 12 个自有域名）

  • 被封锁：h5.game-app543.com
  • 正常：www.game-app543.com、kf.game-app543.com、www.youdianse.com、h5.youdianse.com、 youdianse.com、yds-pc-h5-01.cc、h5./pc.yds-pc-h5-01.cc、18h.game、sdk.youdianse.com、youdianse.vip

→ 属于对该域名的定向封锁，不是整段 IP 或整域封禁。

五、处置建议

  1. 自测/验证：DNS 换成 1.1.1.1 / 8.8.8.8，或使用手机流量 / VPN 即可正常访问（已验证）
  2. 产品侧：该域名对菲律宾用户基本不可用 → 建议此接入改用未被封的域名 （如 www.game-app543.com 正常），或通过 gov.ph 渠道向 CICC 申请解封
  3. 排查习惯：域名带 HSTS 时，地区封锁会表现为"证书错误"这种误导性提示； 遇到类似报错先换公共 DNS 复核，再判断是否证书问题
  4. 与 1game 反馈的 502 区分开：那次是我们的拦截规则误封了 CloudFront 边缘 IP（已修复）； 本次是政府/ISP 层封锁，不在我们控制范围内
