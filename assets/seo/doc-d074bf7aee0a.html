三、三次失败与处置

3.1 业务仓库 dirty，发布在切换代码前中止

首次发布日志：

业务代码存在本地未提交修改，默认拒绝发布。
M  alb_white.txt
?? alb_white.txt.bak.20261018-151446-alb
?? alb_white_secret.txt.bak.20261018-151446-alb

核对结果：

  • src/youdianse-php/alb_white.txt 与配置仓库权威文件 cicd-web/runtime/app-local-files/alb_white.txt 的 SHA256 完全相同。
  • 两个 .bak 文件是 10-18 事故遗留备份，业务代码本身没有待发布修改。
  • 发布脚本先同步受保护文件，再检查业务仓库；受保护文件路径可由脚本恢复， 但两个任意命名的未跟踪备份文件会触发 dirty 保护。

处置：

  • 将两个备份移动到：

text /opt/docker-youdianse-php/cicd-web/runtime/manual-backups/business-repo-dirty-20261020-2212/

  • 保留原始文件，不删除。
  • 业务目录仅剩受保护文件状态，发布脚本按既有策略恢复 Git 工作区。

3.2 Debian Bullseye apt 包 404

代码已正确切换到 688f43568c2e，但镜像构建在基础依赖层失败：

E: Failed to fetch http://deb.debian.org/debian-security/... 404  Not Found

根因：

  • php:7.4-fpm 使用 Debian 11 Bullseye。
  • 当前 deb.debian.org 仍返回部分旧安全包索引，但对应 deb 文件已经从镜像站移除。
  • apt-get install 按旧索引下载时批量返回 404。

修复：

  • 在 php-web.Dockerfile 的 apt 安装层执行前，将 Bullseye 源切换到：
  • archive.debian.org/debian
  • archive.debian.org/debian-security
  • 使用 Acquire::Check-Valid-Until=false 和 Acquire::Check-Date=false 兼容归档 Release 文件。
  • 原 Dockerfile 已留档在：

text /opt/docker-youdianse-php/cicd-web/runtime/manual-backups/dockerfile-bullseye-archive-20261020-2213/php-web.Dockerfile.before

构建验证：

  • 镜像：youdianse-php:main-688f43568c2e
  • PHP：7.4.33
  • 扩展：Phalcon、Redis、MongoDB 均加载
  • Composer：2.5.8

3.3 compose 重建命中 Created 残留

业务镜像构建成功后，compose 重建报错：

No such container: 80fd05764278_youdianse-main-php-cron

现场状态：

  • youdianse-main-php-web：Created
  • 2e92ae75a705_youdianse-main-php-cron：Created
  • dc26c47969c6_youdianse-main-php-nginx：Created
  • 原 nginx 已退出，8088 暂时不可访问

根因：

  • compose 重建过程中断后留下带 hash 前缀的 Created 容器。
  • 下一次 up 引用了已经消失的中间容器 ID。
  • 仓库主分支已有 cleanup_created_containers() 修复，但正式机正在运行的 CICD 版本早于该修复，所以本次仍被触发。

处置：

  • 只清理本次确认属于 youdianse-main-php-* 且状态为 Created 的 3 个容器。
  • 不删除任何 running 业务容器。
  • 重新执行：

bash docker compose --env-file .ops-build.env --profile cron \ up -d --force-recreate --remove-orphans web nginx cron

结果：三个正式容器全部启动。

五、后续防复发要求

  1. 业务仓库内禁止保留任意 .bak、临时副本或未跟踪文件；备份必须放到 cicd-web/runtime/manual-backups/ 等仓库外运行目录。
