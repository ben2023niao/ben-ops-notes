需求

开发要求在 Nginx 反向代理链中透传：

proxy_set_header CF-IPCountry $http_cf_ipcountry;

同时将 Cloudflare 全部 zone 的 IP Geolocation 开启。该功能会把访问者国家/地区代码写入 CF-IPCountry 请求头。

使用说明

在 Cloudflare 代理的动态请求中，Nginx 会向后端发送：

CF-IPCountry: <ISO 3166-1 alpha-2 国家代码>

后端可通过 CF-IPCountry 获取 Cloudflare 判定的访问者国家/地区。静态资源由 Worker 直接读取 request.cf.country，不经过这层 Nginx。

注意：如果源站可被绕过 Cloudflare 直接访问，客户端可以伪造该请求头；业务侧若把该值 用于安全决策，应同时限制源站只接受 Cloudflare 回源或校验 Cloudflare IP 段。
