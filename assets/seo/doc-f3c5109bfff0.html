一、背景与口径

用户要求：多选游戏与竞品比较“真实点击游戏 -> 完整渲染出开始页面”速度，
覆盖巴西 GRU / 马尼拉 / 东京；录屏 MP4 发群（可自动播放）；最后汇总报告。
同一会话插叙：Ben(C++) 问“分层缓存 Tiered Cache 服务打开没有，我访问还是很慢”；
要求操作一步通知一步、尽可能详细。

计时口径（沿用历史 2026-08-28/29）：打开大厅 -> 输入/直达游戏 -> 出画(canvas)
-> 点击“继续” -> 网络/画面稳定（可玩/开始页完整渲染）。
指标：canvas_ms（点击后到画布出现）、stable_ms（点击到稳定，总时长含画布前）。

游戏对照（game_load_video_compare.py GAMES）：
  Fortune Tiger 126/2196、Mahjong Ways 65/2223、Aztec Gold 87/2218、
  Wild Bounty Showdown 135/2215、Dragon Hatch 57/2201（我方/竞品 ID）。

三、CDN 分层缓存（Tiered Cache）核查（插叙请求）

查询：Cloudflare API 逐个 zone GET /zones/{id}/cache/tiered_cache_smart_topology_enable
（旧 /zones/{zid}/argo/tiered_cache 已废弃，返回 400）
范围：账号全部 42 个 zone（含 CDN 池 20 + 其他业务域）

开启 ON（3 个）：
  xqv9m8.icu（Pro，8-31 05:14 UTC 开）—— platform-api 单 Argo 域名，当前唯一承载
  cdn-tokyo-bizops.icu（Pro，8-31 开）
  m6xv8q.cyou（Free，8-29 开）
其余 39 个 OFF（含 Pro：q7m9v8.icu / t6qv8m.icu(已下架) / vendor_a-cdn-2026.icu）

结论：Ben(C++) 问“Tiered Cache 开没开” -> 当前实际承载域名 xqv9m8.icu = ON；
发布后“最初几次慢”的静态部分已由多区预热解决（东京昨晚已全量暖 NRT），
动态回源部分仍受地理距离约束（东京 api/health ~0.33s 恒定），见第四节对比。
