一、范围与方法

服务器：dbqp-saopaulo-sanic-prod-01（dbqp-pg-release-01）
日志：/opt/pgserver/logs/dbqp-pg-release-01（08-28 ~ 09-04，UTC）
方法：抽取 ERROR/Exception/Traceback/Timeout/rcode1110/接口超时/
      SQL Error/sp_upsert/风控字段缺失/IP 拦截等，按 UTC 日期分文件
产物：pg-week-errors-20260904.tar.gz（5 个日期 .err + analysis.md）

二、按天结论

08-30（442 行）：缺表 plat3rd_games_log.t_network_latency_logs(1146)
08-31（2043 行）：同上缺表（另 IP 拦截 1）
09-01（956 行）：缺表为主 + 风控缺失 11 + 接口超时 2
09-02（320 行）：缺表(含新用户表) + 风控缺失 32 + 超时 7 + IP 拦截 6
09-03（2598 行）：sp_upsert 1318 参数不匹配 1364 + 风控缺失 341
                  + IP 拦截 20 + 超时 19

三、原因与处理建议

1) 1146 缺表：t_network_latency_logs / t_plat_new_user_day*
   -> 代码已写新日志表但 MySQL 未建表，建议 DBA 补表或代码降级；
2) sp_upsert 1318：代码传参与存储过程签名不一致（11/9 vs 12/10），
   -> 对齐代码与 DB 存储过程；
3) 风控字段缺失（RISK_STRATEGY_INFO:...YYTYBRL）：策略未命中 fallback 告警，
   -> 确认是否应配置策略，无策略场景建议降 WARN；
4) 接口执行超时：偶发慢查询/高负载，量小，结合慢 SQL 再查；
5) IP 拦截/余额不足：地区规则与正常业务提示，非故障。
