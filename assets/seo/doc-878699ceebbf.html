三、配置与代码变更

3.1 data/scripts/运维值班表/weekend_duty.json

· by_date["2026-09-19"]  → {"group": "group2"}（由 group1 顺延为二组，按群内确认）
· by_date["2026-09-20"]  → {"type": "workday", "label": "补班出勤"}
· by_date["2026-10-10"]  → {"type": "workday", "label": "补班出勤"}
· by_date["2026-09-25/26/27"] → 增加 "shift": "early" 与 "extra_members": ["@Ben_Bird"]
· big_small_weeks 扩展 10 月：10-05 小、10-12 大、10-19 小、10-26 大
· note 补充中秋口径

3.2 data/scripts/运维值班表/duty_schedule.py

· 新增 _by_date_entry / _date_shift_key / _extra_duty_users / workday_override_label
· get_shift_users / get_day_duty_users：支持按日期统一班次（early/late）与加派人员；
  补班日按工作日“全员上班”处理，不生成值班组
· 周排班/当日详情：无人班次不再显示班次时间；补班日口径显示“补班出勤（全员上班）”
· 新增 SHIFT_META["makeup"]🟡 与 SHIFT_META["holiday"]🎑；
  get_shift_key 优先识别 补班 → 节日 → 周末 → 工作日

3.3 app/benbot/duty_status.py（机器人侧，独立实现）

· 同步实现 _by_date_entry / _date_shift_key / _extra_duty_users / workday_override_label
· _weekend_duty_usernames：支持统一班次与加派人员（中秋 3 天含 Ben）
· should_send_duty_event：补班日不触发值班事件
· build_duty_panel / build_duty_panel_html：补班日显示“补班出勤 · 全员上班”，不再显示空值班组
· _format_weekend_day：补班日显示“补班出勤（全员上班）”
