一、本轮做了什么

需求：把 k8x2v9.shop / r2v8k4.shop / p3w9n5.shop 也加入腾讯云 EdgeOne。
执行（API，机器 = 香港 standby 34.150.1.185）：
  CreateZone x3（Type=full NS 接入、Area=overseas）→ 全部创建成功
  k8x2v9.shop  zone-3vm7ccg417yf   status=initializing
  r2v8k4.shop  zone-3vm7cf444lhw   status=initializing
  p3w9n5.shop  zone-3vm7chzbxkcb   status=initializing
三个域名当前 NS：a.share-dns.com / b.share-dns.net（与 m4q7z1.shop 换 NS 前一致），
  还没有 A 记录，需要把 NS 改到 ns1.teodns.com / ns2.teodns.com 才会接入。

二、卡点：一个套餐只能绑一个站点

建站点成功，但紧接着建加速域名/规则被拒：
  CreateAccelerationDomain -> OperationDenied.ZoneNotActive「站点未启用」
  CreateL7AccRules         -> LimitExceeded「超过配额上限」
根因：这三个站点的 PlanType=None（没有套餐）。DescribePlans 显示账号里只有 1 个套餐：
  edgeone-3vm5ef7nqk96 / plan-basic / ZoneNumber=1 / Bindable=false（已被 m4q7z1.shop 占用）
也就是说：**EdgeOne（国际版）1 个套餐 = 1 个站点名额**，套餐到位前站点是 initializing，
任何加速配置都做不了。

三、可选套餐（DescribeAvailablePlans 实测，Currency=USD/月，SiteNumber 都是 1）

PlanType 站点数 流量 请求数 API Price
personal / personal_cm / personal_global 1 50 GB 300,000,000 420,000,000
basic / basic_cm / basic_global 1 500 GB 20,000,000 5,700,000,000
sta / sta_cm / sta_global（含 with_bot 变体） 1 3000 GB 50,000,000 59,000,000,000 
说明：Price 字段的货币单位 API 未标注，按 Tencent 惯例推算（1e-8 USD）大约是
personal ≈ $4.2/月/站点、basic ≈ $57/月/站点、sta ≈ $590/月/站点 —— **以控制台账单为准**，
下单前请在 EdgeOne 控制台确认价格与流量口径（尤其是个人版是否够测试用）。
三个测试站点若都用 personal，约 $12.6/月。

    - 4 个站点都要能跑：需要 4 个套餐名额（现有 1 + 新购 3）
