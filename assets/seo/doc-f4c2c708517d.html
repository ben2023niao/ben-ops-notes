文件 说明
error-2026-10-13.log.gz ~ error-2026-10-15.log.gz 10-13 ~ 10-15 的压缩错误日志
error-2026-10-16.log 10-16 全天：1,865 条 ERROR，其中 type=slow_api 1,792 条

字段：{"logId":..., "level":"ERROR", "data":{"type":"slow_api", "route":"...", "elapsed":"...", "request":{...}}}

速查结论：错误量 99% 是「慢接口」记录，route 集中在 recharge/create（10-16 共 1,532 条）与 spend/create2（232 条），另有 check_host_sign_failed 11 条。

02-php-fpm错误与慢日志/

文件 说明
master-error.log（6.1 MB） FPM 主进程日志。含 executing too slow（例：POST /index.php?_url=/api/v1/User/password）；另有各 77 次的 curl: (7) Failed to connect to 203.0.113.1 port N: Connection refused 与 sh: 1: free: not found —— 说明容器内有个探活脚本既连不上本地端口、又缺少 free 命令，建议一并排查
worker-error.log 业务 error_log() 输出，例：[BlindBoxPool::delete] findFirst by ObjectId: null 等调试行
slow.log（26.8 MB） PHP-FPM 慢日志，以调用栈输出。高频栈：curl_exec（CommonUtil.php:278 → PaymentService.php:954/1021）、MongoDbConnection::executeCommand（MongoDbConnection.php:68）、MongoModel::executeCommand（:490/:513）、后台报表 SystemController::getNewReportData
access.log 该文件为 0 字节（FPM 未启用 access 日志，保留占位）

03-nginx错误日志/error.log（后端，18.5 MB）

近 3 MB 聚合：an upstream response is buffered to a temporary file 6,942 次（响应体过大）、recv() failed (104: Connection reset by peer) 642 次、connect() failed (111: Connection refused) 302 次、FastCGI sent in stderr: "Primary script unknown" 270 次（扫描器探测）、upstream timed out 15 次。

04-非200请求明细/backend-access-non200.log

后端 access.log 中所有非 200/204 的原始行（最新 2 万行截取）：404 2,117、499 65、444 18。 404 TOP：/api/v1/system/info 393、/api/sdk/system/info 160、/api/v1/game/detail 135、/api/v1/AppVersion/latestVersion 121、/api/v1/message/unreadCount 89 —— 建议前端核对调用时机与版本兼容。

05-网关nginx错误日志/error.log（15.5 MB）

limiting connections by zone "perip_ssr" 11,606 次（SSR 连接区被打满触发限流，与网关负载 11~15 一致）、upstream prematurely closed connection 59 次、recv() failed 36 次。

06-网关5xx请求明细/gateway-access-5xx.log

网关 access.log 中状态码 ≥ 500 的原始行（28 行）：502 共 22、500 共 6。 其中 /api/v1/Login/account 出现 8 次，另有 /tag-code-detail/*、/api/v1/game/topPromotion —— 登录 502 建议优先看。

建议排查顺序（配合《优化实施指南》）

  1. 支付下单慢：02/slow.log 搜 sharkPayment / httpJson / curl_exec；01/ 里筛 "route":"recharge/create" → 对应指南 B5（支付 HTTP 加超时）。
  2. 登录 502：06/ 里筛 /api/v1/Login/account，再对照 05/ 的 upstream prematurely closed；同时看 02/master-error.log 的 executing too slow。
  3. Mongo 慢命令：02/slow.log 搜 MongoDbConnection / MongoModel → 对应指南 B1/B2/B3（缓存、消除重复查询、投影）与 D1（profiling）。
  4. 404 噪音：04/ 里的 system/info、game/detail 等，核对前端调用时机/App 版本。
  5. FPM 探活失败：02/master-error.log 里 curl: (7) ... 203.0.113.1 ... Connection refused 与 sh: 1: free: not found（各 77 次）。
  6. Redis 阻塞：本包不含 Redis 日志；见《优化实施指南》第六章（业务用 KEYS 每 153 秒阻塞 0.5 秒）。

需要更多原始数据时可直接找运维要：完整 access.log（后端 177 MB / 网关 848 MB）、api_request/api_response（含完整请求响应体，涉及用户数据，按需单独提供）。
