本文记录 TADA 新版完整静态资源包 tadaallstatic.zip 的下载、结构核对、宝塔增量合并、GCS live/backup 同步、Cloud CDN 刷新、全量文件验证和飞机群通知结果。

任务背景

开发提供了包含 PT（葡萄牙语）内容的 TADA 静态资源完整包：

https://ind-h5.dbqpplus999.com/tadaallstatic.zip

本次目标：

1. 解压并核对资源包结构。
2. 补齐宝塔 TADA 静态资源。
3. 同步 GCS live 和 backup。
4. 验证公开 CDN、CORS 和 TADA 入口。
5. 验证通过后发送飞机群通知。

历史文档确认

操作前读取了 docker/doc 和 docker/线上服务器信息 下的静态资源历史记录，确认当前链路为：

宝塔静态目录
  -> GCS live bucket
  -> Google HTTPS Load Balancer / Cloud CDN

宝塔静态目录
  -> GCS backup bucket

TADA 当前有三套静态目录：

/www/wwwroot/tada-statics
/www/wwwroot/tada-statics1
/www/wwwroot/tada-statics2

本次 ZIP 只有一个顶层目录 tadaallstatic/，其游戏目录和文件结构与主目录 /www/wwwroot/tada-statics 对应，不是 tada-statics1/2 的资源包。因此本次只合并和同步 TADA 主静态目录，未修改 tada-statics1/2。

已有且一致：

smallicon/lang/pt-BR/strings.json
