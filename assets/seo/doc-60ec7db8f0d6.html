任务边界

用户要求：

cn 分支增加厂家 g759；
静态前端代码从 gitlab.zg-qptest.com/platgames/client.git master 分支 G759static 拉取；
后端端口 9019；
按标准工作流：workbench、逐步群通知、验证、汇总文档发群、合并提交本地代码。

账号密码仅用于拉取 client 仓库，未写入仓库/文档/群通知。

一、前置情况

静态源：client.git master=97a3c2dc，G759static 目录
  - 文件数：35,689；大小：约 980MB；12 个游戏目录（slorio/slotaco/slocashmania 等）
  - 结构：根目录 favicon.ico、cdn-cgi/、games/<game>/、reso.slo888.com/
香港现状：g759 DNS / S3 前缀 / CloudFront 分配 / nginx 规则均为空（干净接入）
后端端口：9019（用户确认；192.0.2.18 / 192.0.2.19）

二、执行

1. 静态源拉取：git clone --depth 1 --branch master --sparse client.git，sparse-checkout G759static。
2. 本地配置：
   - 新增 docker/conf/domains/g759.json（static/games 各 5 域名）；
   - nginx-bizops.conf 新增 bizops_hk_g759 upstream（9019）+ g759-games/g759-api server block；
   - 工具脚本加入 g759：create_cloudfront_static_distributions.py、
     create_cloudfront_dynamic.py、cloudflare_aws_cutover.py、validate_cloudfront_static.py
     （validate 增加本地源对比支持：source_bucket=None 时读 G759_STATIC_SOURCE_DIR）；
   - docker/README.md、docker/conf/README.md 更新；
   - python3 docker/ci/check.py 通过。
3. 香港入口机部署（备份 /root/bizops-hk-g759-20260812/backup-20260812T073138Z）：
   - nginx-bizops.conf 安装，nginx -t 通过并 reload；
   - 工具脚本更新到 /opt/bizops-hk-ops/。
4. CloudFront：
   - 静态分配 E2GEOW3X246399 / d3pivpq6yx8cfn.cloudfront.net（g759-static.hkcloudplay01-05，OriginPath /g759-static，OAC）→ Deployed；
   - 动态分配 E3QV4VIGTRVCVD 增加 g759-games×5 + g759-api（AliasCount 44→50）→ Deployed。
5. 静态同步：
   - tar 打包本地 G759static（990MB）→ scp 香港机 → /root/g759static-source 解包；
   - AWS_PROFILE=bizops-hk aws s3 sync → s3://bizops-h5-hk-517506432530/g759-static/
     （35,689 对象 / 979,858,675 字节，与源目录一致）；
   - CloudFront invalidation：E2GEOW3X246399 /*（IBF9N9BOLQWLXX2V4DT8NAESXX）。
6. Cloudflare DNS（DNS-only，TTL 60，备份 20260812T074757Z / 20260812T074809Z）：
   - g759-static.hkcloudplay01-05.com -> d3pivpq6yx8cfn.cloudfront.net
   - g759-games.hkcloudplay01-05.com -> d1n4qfcp941cy6.cloudfront.net
   - g759-api.hkplaycore.com -> d1n4qfcp941cy6.cloudfront.net

三、验证

静态公开链路 10/10 OK：
  5 域名 × favicon.ico + games/slorio/index.html
  HTTP 200、CORS *、CloudFront x-cache 正常、SHA256 与源一致
  （favicon.ico=b403e6f6…、games/slorio/index.html=d569e31a…）
S3 私有直连：g759-static/favicon.ico -> 403
动态链路：g759-games 01-05 -> 502/504、g759-api -> 502（DNS/TLS/CloudFront/Nginx 已就位）
后端 9019：192.0.2.18:9019、192.0.2.19:9019 TCP timeout（尚未监听）
nginx：nginx -T 含 g759 upstream/server block；reload 完成
