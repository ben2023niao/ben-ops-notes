一、任务

用户确认：目前要按「只跑一台后端 01」的单机模式运行。
用户追问：域名解析下，流量是不是跑在备用 nginx 上？
要求：分析一步、发群一步，完成后验证、更新文档、提交本地 Git。

二、核查结论

1. 运行态已是单机 01

节点 容器数 负载 说明
后端 01 203.0.113.1 8（dbqp-*） 0.04 / 0.13 / 0.21 唯一承载业务
后端 02 203.0.113.1 0 0.00 / 0.00 / 0.00 停用
后端 03 203.0.113.1 0 1.00 / 1.02 / 1.00 停用

两台 nginx 的 00.vendor-upstreams.conf 均为：01 生效、02/03 显式 down（各 18 条）。

2. 动态流量实际跑在备用入口（用户判断正确）

Cloudflare DNS 全量核对（39 个 zone）：
  指向备用入口 34.151.249.53：199 条（api / 6 厂家 games / 通配符 / www / socket / verify）
  指向宝塔 35.247.205.6  ：0 条
  切换来源：doc/2026-09-01-1430 流量切换记录（当日 199/199 成功）

实流量证据（pg-games 访问日志）：
  备用入口 34.151.249.53：持续在跑，17:00(UTC) 当分钟仍有 26-69 请求/分钟
  宝塔 35.247.205.6     ：最后一条真实玩家请求停在 09-01 14:32，之后仅本机 curl

结论：
  备用入口 34.151.249.53 = 线上唯一动态入口
  宝塔 35.247.205.6      = 运维/同步机（静态同步、证书签发下发、结果数据同步 cron 仍在宝塔）

architecture.md 原先仍写「宝塔是入口、备用机被动备援」，与 09-01 之后的真实状态相反，本次一并更正。

三、发现并修复的隐患

隐患

sync_all_game_domains_to_baota.py 的 MANAGED_UPSTREAMS 硬编码三台后端且不带 down。 该脚本是「新增根域名时一键展开所有厂家域名」的生成器，一旦被人工重跑， 会重写 upstream 把 02/03 拉回负载均衡；而 02/03 没有容器，约 2/3 请求会超时/502 （表现为游戏卡在加载进度条）。

当时的爆炸半径评估：
  - crontab 中已无 all_game_domain_sync（最后运行 08-31 01:40），不是正在发生的故障
  - sync_certs_to_standby.sh 只同步证书、不碰 conf，不存在自动扩散通路
  - 风险为「人工重跑生成器」时的静默退化

修复

改为单机模式生成：
  01 生效；02/03 自动追加 down
  保留显式开关 GAME_SINGLE_NODE_MODE=0，用于将来显式恢复多机
本次文件：
  docker/线上服务器信息/baota/scheduled-tasks/sanitized/sync_all_game_domains_to_baota.py

部署（均先备份 .bak-20260912-single-node，md5 三处一致 6f2174c61dfdc3c6f72deb3b08465634）：
  宝塔 /www/server/panel/script/sync_all_game_domains_to_baota.py
  宝塔 /root/sync_all_game_domains_to_baota.py
  备用入口 /opt/pgserver/docker/线上服务器信息/baota/scheduled-tasks/sanitized/sync_all_game_domains_to_baota.py

四、验证

1) 生成结果 vs 线上实际配置（逐字节比对）
   宝塔 9 个 upstream、备用入口 9 个 upstream → 差异 0
2) 真机等价性测试（把 live 配置复制到临时文件后重跑生成函数）
   SINGLE_NODE_MODE = True，重跑后「无变化（等价，安全）」
3) 语法检查：宝塔 pyenv python3 / 备用入口 python3 均 OK
4) 公网实测 8/8 = 200
   pg / tada / pp / ppk / playson / panda / g759 / api

五、留下的可复用脚本

docker/scripts/vendor_single_node_check.py   单机 01 模式体检（只读，漂移退出码 1）
docker/scripts/dbqp_notify.py                命令行发飞机群（经宝塔跳板调用 bot 容器）

体检项：两台 nginx upstream → 后端 01/02/03 容器数 → Cloudflare DNS 指向 → 公网 8 入口健康。
