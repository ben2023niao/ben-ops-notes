一、改的是哪份配置

位置：/data/server-runtime/conf/domains/*.json
  （容器内挂载为 /app/config/domains）
读取方：platform-api 的 /app/platform-api/game_domains_manager.py
  · GameDomainManager.get_hosts_by_provider(provider, game_id)
  · **每次调用都会重新 open/read 配置文件**（load_provider_config）
  → 改文件立即生效，**不需要重启任何容器** ✓

改前：每个厂家的 static_hosts / game_hosts（以及 pg 的 api_hosts、各 special_games 组）
      都是 2 个域名：
        *.xqv9m8.icu
        *.vendor_a-cdn-2026.icu
改后：只保留 *.xqv9m8.icu（主域名，CF 上的 Worker 规则也在这个 zone）。

二、改动明细

涉及 7 个厂家文件（每台机器）：
  g759.json / vendor_d.json / pg.json / vendor_c.json / popok.json / pp.json / vendor_a.json
  · default.static_hosts / default.game_hosts（pg 还有 default.api_hosts）各从 2 → 1
  · special_games 组同样处理：
      pg3/pg4/pg5/pg6/pg7 的 static_hosts / game_hosts
      vendor_a SPECIAL_GAMES_v1~v5 的 static_hosts / game_hosts
  （共 7 个文件被改写；fc/jdb/vendor_b 未变）

明确**没有动**的：
  · fc.json / jdb.json：测试用配置，本来就各只有 1 个域名（bxgjnet / repair127）
  · vendor_b.json：配的是 3 个**不同厂商线路**的域名（cxkerui / shangdefu / nuvastone），
    不是 xqv9m8 + vendor_a-cdn 这一对，按原样保留。如果 vendor_b 也要收敛成单线路，需要单独确认保留哪一条。
  · 旧域名 vendor_a-cdn-2026.icu 的 DNS、证书、Worker、nginx 全部保留
    → 已在用旧域名的客户端不受影响，也方便回滚。

工具：docker/scripts/domain_config_single.py（可复用）

# 预演
python3 /opt/bizops-scripts/domain_config_single.py \
  --dir /data/server-runtime/conf/domains --drop-substring vendor_a-cdn-2026.icu --dry-run
# 真改
python3 /opt/bizops-scripts/domain_config_single.py \
  --dir /data/server-runtime/conf/domains --drop-substring vendor_a-cdn-2026.icu

三、备份（改动前）

机器 目录备份 打包备份
01 /data/server-runtime/conf/domains.bak-20261019-094923 /root/domains.bak-20261019-094923.tar.gz
02 /data/server-runtime/conf/domains.bak-20261019-094929 /root/domains.bak-20261019-094929.tar.gz 
备份前后两台 10 个 json 的 md5 完全一致（改动前两台配置本来就一致）。

四、验证（改完实测）

1) 配置文件：10 个 json 全部可正常解析（无损坏）；
   生效目录 domains/ 里 "vendor_a-cdn-2026.icu" 残留文件数 = **0**（两台）；
   server_configs、conf/configs-*.py 里也均无该域名（排除漏改）。

2) 用 platform-api 的真实读取逻辑验证（在容器内调用 GameDomainManager）：
   01：pp → 1 个静态 + 1 个游戏域名；vendor_a(gid=540, special_v1) → vendor_a-statics1 + vendor_a-games；
       vendor_d / pg(gid=540 默认) / pg(gid=65 → pg4 special) / g759 / popok 全部 = 1 个域名
   02：同上（pp / vendor_a(540) / vendor_d / pg(65) / g759 / popok 均为 1 个域名）

3) 两个域名都仍可访问（回滚/在途客户端安全）：
   https://vendor_a-games.xqv9m8.icu/health            → 200
   https://vendor_a-games.vendor_a-cdn-2026.icu/health     → 200

五、回滚（有问题立即执行，无需重启）

# 方式一：用目录备份覆盖回去（推荐）
cd /data/server-runtime/conf
rm -rf domains                     # 只在确认要回滚时执行
cp -a domains.bak-20261019-094923 domains      # 01 用 094923；02 用 094929

# 方式二：用打包备份恢复
cd /data/server-runtime/conf
tar -xzf /root/domains.bak-20261019-094923.tar.gz   # 01
tar -xzf /root/domains.bak-20261019-094929.tar.gz   # 02

恢复后同样**不需要重启**（platform-api 每次请求重新读文件）。
验证：用上面的 GameDomainManager 调用应恢复成 2 个域名。
