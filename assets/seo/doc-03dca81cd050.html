背景

上一轮（2026-08-31 01:40）三台服务器清理后，后端 16.209.16.108 根盘仍为 70% （可用 15G）。用户要求：再清理这台服务器的垃圾、老旧日志，或把根盘垃圾输出到挂载盘 /data。按固定流程：分析一步、操作一步、群通知一步；只本地提交不推送。

巡检根因（步骤 3）

根盘 49G 已用 35.2G（70%）；/var/lib/docker/containers 占 24G = 容器 stdout json 日志：
  youdianse-main-php-nginx  json.log 17.4G（官方 nginx 镜像把 access_log 软链到 /dev/stdout）
  youdianse-main-php-web     json.log 6.5G
无 /etc/docker/daemon.json（容器 json 日志无上限，持续涨满根盘）
journald 536M；atop 220M；mssql 服务运行中占 1G（非垃圾，保留）

立即清理（步骤 5）

- 截断 5 个容器 *-json.log（nginx 17.4G、web 6.5G 清零；容器日志追加写入，截断安全）
- journald 压缩至 200M（536M -> 280M）
- atop 保留 14 天，删除 5 个旧日快照
- 根盘 70%（可用 15G）-> 20%（可用 40G），释放约 25G

根治方案（步骤 6-7）

1. nginx 日志落盘 /data

docker-compose.yml nginx 服务新增：
  - ${YOUDIANSE_RUNTIME_NGINX_LOG_DIR:-./runtime/nginx-logs}:/var/log/nginx
fstab 新增 bind（已备份 /root/fstab.before-youdianse-nginx-logs.*）：
  /data/docker-youdianse-php/nginx-logs /opt/docker-youdianse-php/runtime/nginx-logs none bind,nofail,x-systemd.requires-mounts-for=/data 0 0
目录属主 chown 101:101（nginx 容器 uid），容器内 access.log/error.log 直接写数据盘。

2. 全容器日志上限

新增 /etc/docker/daemon.json（无旧文件，未覆盖）：
  log-driver = json-file，log-opts = max-size 100m / max-file 3
重建后的 web/nginx 实测 LogConfig=json-file max-size=100m max-file=3。

3. 自动清理脚本加固

youdianse-disk-auto-clean.py 新增 truncate_oversized_container_logs：
  触发清理时把 /var/lib/docker/containers/*/*-json.log 中 >512M 的日志截断；
  通知文本新增“容器日志截断”字段。

4. 线上应用

同步 compose/脚本 -> 配置 fstab/daemon.json/bind -> systemctl restart docker（5 容器自动恢复）
-> docker compose --env-file .ops-build.env up -d --force-recreate --no-build web nginx

验证（步骤 8）

- nginx LogConfig=json-file max-size=100m max-file=3；web 相同
- nginx access.log 落 /data（428KB -> 1.24MB 持续增长）；容器 json.log 最大 0.6M
- 根盘 20%（可用 40G）；数据盘 5%（468G 可用）
- 自动清理 dry-run=skip；--force dry-run：容器日志截断=0、S3 exit=0、失败步骤=0
- CICD 200、后台 200

后续事项

1. nginx access/error 日志改由数据盘承担（447G+ 可用），不再涨根盘；
2. cron/logbus/beszel 容器下次重建时自动带上 daemon.json 日志上限；
3. /data 上的 nginx 日志如需长期保留，可后续加 logrotate；如需清理需单独确认；
4. 本地提交未推送；线上工作区手工同步后保持 dirty，待推送后自动更新恢复。

回滚

1. fstab：恢复 /root/fstab.before-youdianse-nginx-logs.* 后 mount -a；
2. daemon.json：删除或恢复备份后重启 docker；
3. compose/脚本：git revert 本次提交并同步线上后重建 web/nginx。
