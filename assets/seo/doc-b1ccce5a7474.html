一、入口页 30 次循环（冷缓存，每轮新建浏览器上下文）

我方：https://ind-h5.bizopsplus999.com/pgbronline/ 竞品：https://m6kk678n.com/main/inicio

指标          我方         竞品        差异
TTFB 中位     386 ms      1484 ms     我方快 3.8 倍
TTFB p95      764 ms      2144 ms
TTFB max      1173 ms     3008 ms
DCL 中位      385 ms      1482 ms     我方快 3.8 倍
资源数中位     116         110         基本持平
字节中位       5.48 MB     1.37 MB     我方大 4 倍（大厅预加载封面图）
成功率         30/30       30/30

结论：我方入口 HTML/DCL 显著更快；我方首屏传输字节更大， 原因是大厅初始化预加载 image.prod-br.com 100+ 张游戏封面图（与 08-25 结论一致）。

二、静态桶 / 竞品 CDN 延迟 30 次采样（马尼拉，TTFB）

目标                        min    med    p95    max
我方静态-东京桶              45     49     66     1614 ms
我方静态-圣保罗桶            47     51     1949   1955 ms
竞品图 CDN game-logo        91     105    119    400 ms
竞品上传 CDN upload-us      0      0      0      0 ms（即时响应/拒绝）

说明：我方两个桶 med 都很低（Google 边缘就近），但圣保罗桶 p95≈1.95s 存在跨洲慢尾巴； 东京桶 p95=66ms 稳定。测速选优会让亚洲用户稳定选东京桶，避开圣保罗慢尾巴。

三、游戏启动级（真实浏览器点击）

我方（马尼拉，H5 入口点击第一张 PG 卡，试玩）

轮次  打开到游戏可用   静态桶选择
1     4.1s           东京桶（or=bizops-gcs-pg4-static...）
2     4.1s           东京桶
3     4.8s           东京桶
4     4.1s           东京桶
平均 ≈4.3s

（巴西视角备用机另测：PG 麻将胡了 3.3s，选圣保罗桶。）

竞品（马尼拉，账号 11955336688 登录成功）

登录流程可自动化（Telefone+Senha 弹窗），大厅 Perfil/Saque 可见、登录成功； 但游戏卡片为 Ionic SPA 懒加载结构，headless 自动点击命中促销容器/不稳定， 本轮未取得可靠的竞品"进游戏"计时样本。竞品大厅资源分布： m6kk678n.com=47、upload-us=22、api4=15、game-logo=8、o.alicdn.com=1。

竞品游戏级对比建议后续用人工/录屏或抓其 GameEntry API 计时。

四、结论

  1. 入口加载：我方 TTFB 中位 386ms vs 竞品 1484ms，30 次循环稳定快约 4 倍；
  2. 静态链路：双桶 + 测速选优后，亚洲侧稳定走东京桶（p95 66ms），不再受圣保罗桶跨洲慢尾巴影响；
  3. 竞品优势仅在首屏体积（懒加载 1.4MB vs 我方 5.5MB），对应我方 image.prod-br.com 封面图预加载策略，属前端优化项（压缩/WebP/懒加载）可继续跟进。
