1. 模块目标

单场比赛的详情页，承担：

  1. 赛前转化：未开赛状态下提供"开赛前竞猜" + 球队表现对比，刺激押注
  2. 赛中分流：进行中状态下提供"相关直播"入口 + 实时比分（运营录入）
  3. 赛后回顾：已结束状态下提供 MVP + 关键事件回放（运营事后录入） + 竞猜结算汇总

v1 砍掉：实时比赛事件流（控球/射门/角球/黄牌/越位/换人等）+ 6 项实时数据卡 + 6 项最终数据卡。原型评审版含完整数据卡，v1 因无第三方体育数据 API 接入能力统一删除。

2. 用户角色

角色 说明
已登录用户 完整查看 + 押注 / 进入直播间
未登录用户 同样可看，CTA 跳登录

4. 业务规则

4.1 三态对应

状态 比赛实际状态 默认展开 tab
未开始 距开赛 > 0；开赛前竞猜开盘 "未开始"
进行中 已开赛、未结束 "进行中"
已结束 全场结束（含加时点球） "已结束"

用户可手动切换 tab（场景：已结束比赛也可以看赛前竞猜历史，仅作历史回顾）。

4.2 未开始 - 表现对比

数据维度（基于本届当前阶段累计）：

  1. 战绩 W/D/L
  2. 累计进球数
  3. 累计失球数
  4. 最佳射手 + 进球数
  5. 平均控球率
  6. 场均黄牌数

数据来源：聚合本届截至上场比赛的 match_stats。

4.3 进行中 - 事件类型

icon 类型 文案模板
⚽ 进球 <球队> · <球员> <方式描述> <(比分)>
🟨 黄牌 <球队> · <球员> <犯规描述>
🟥 红牌 <球队> · <球员> <犯规描述>（红牌）
🔄 换人 <球队> · <上场球员> ↑ / <下场球员> ↓
🚩 越位 <球队> · <球员> 越位判罚
🟢 点球判罚 <球队> · <球员> 主罚 <进/扑>
📋 半场/全场 <阶段> 结束

事件流按时间倒序或正序皆可（默认按发生时间正序，新事件追加到底部）。

4.4 进行中 - 相关直播

  1. 数据来源：所有"已开播 + 关联本场比赛"的直播间。
  2. 排序：按当前观看人数倒序。
  3. 卡片信息：封面、LIVE 徽章、观看人数、播放图标、房间标题、主播、热度。
  4. 点击卡片 → 跳直播间。

4.5 已结束 - MVP

  1. 由运营在后台手动选定（v1）；后续可基于数据自动评选（v2）。
  2. 显示：球员（含国旗 + 球衣号）+ 关键数据（进球、助攻、射门、过人、控球时间）。

4.6 已结束 - 竞猜结算汇总

三类典型市场：

市场 显示内容
胜平负 实际结果（XX 胜）+ 押中人数 + 派彩金额 + 命中率
比分 实际比分 + 押中人数 + 派彩 + 高赔率倍数
总进球 实际进球 + 押中人数 + 派彩 + 命中率

4.7 数据刷新

  1. 进入页面拉一次。
  2. 进行中状态：比分 + 进球事件 30s 轮询；运营在后台改动后推 WS match.score.updated / match.goal.added。
  3. 状态切换瞬间（开赛、结束）：服务端推 WS 提醒前端切 tab。

5. 边界与异常

场景 系统行为 提示/状态
比赛存在但开赛前竞猜未开盘 "未开始" tab CTA 替换为"竞猜未开" 不可点击
比赛进行中无相关直播 "相关直播" 卡片显示空状态 "暂无相关直播 · 等待主播上线"
已结束但竞猜尚未开奖 "竞猜结算汇总"显示"待开奖" 24h 内自动开奖
MVP 未选 卡片显示"MVP 待评选" 24h 内补
表现对比无历史数据（首场） 仅显示双方 FIFA 排名 "暂无对比数据，首场登场"

6. 权限与风控

  1. 仅读，无写操作（押注通过共享 push push modal 走 kickoff-predict 流程）。
  2. 不涉及资金、审计。

7. 数据对象

对象 Owner 说明
match services/go-app 比赛主表
match_event services/go-app 比赛事件流
match_stats services/go-app 实时统计快照 + 最终统计
match_mvp services/go-app MVP 配置（运营手选）
team_tournament_stats services/go-app（衍生） 本届球队累计统计（用于赛前对比）
predict_activity + predict_bet services/go-app 竞猜数据（结算汇总聚合）

7.1 比赛阶段枚举（v0.3.1 新增 match.phase）

取值 说明 前端展示文案
pre_match 未开赛（含开赛前热身、入场） 未开赛
first_half 上半场（含补时） 上半场 N'（含 +M 补时）
half_time 中场休息 中场休息
second_half 下半场（含补时） 下半场 N'（含 +M 补时）
et_first 加时上半 加时上半 N'
et_break 加时中场 加时中场
et_second 加时下半 加时下半 N'
penalty 点球大战 点球 home_pen-away_pen
finished 比赛结束 完场

驱动方：admin 后台手动切换（v1 无第三方数据源）；切换时服务端推 WS match.phase.changed 事件。

与 match.status 关系：match.status 是粗粒度状态（未开始 / 进行中 / 已结束），match.phase 是细粒度阶段。status 由 phase 驱动派生： - phase ∈ {pre_match} → status=未开始 - phase ∈ {first_half, half_time, second_half, et_first, et_break, et_second, penalty} → status=进行中 - phase=finished → status=已结束
