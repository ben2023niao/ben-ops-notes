For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: 立起 pnpm monorepo + 两个空白 Next.js app(web 3000、admin 3100)+ docker-compose Postgres + 极简 GitHub Actions CI(lint/typecheck/build,P0 不需要 Postgres service)。

Architecture: pnpm workspaces 单仓多包。apps/web 与 apps/admin 各为独立 Next.js 15(App Router)应用。packages/db 是 Prisma client 的占位包(P1 才填 schema)。Postgres 仅通过 docker-compose 起,P0 不连接。

Tech Stack: - Node.js 20 LTS - pnpm 9.x - TypeScript 5.x - Next.js 15.x(App Router) - React 19.x - Prisma 5.x(P0 仅安装客户端依赖) - PostgreSQL 16(Docker) - GitHub Actions

Spec 引用: docs/superpowers/specs/2026-05-08-ghome-product-shape-design.md §1、§5 P0。

Task 8 — GitHub Actions CI(极简版,P0 不需要 Postgres service)

Files: - Create: .github/workflows/ci.yml

  • [ ] Step 1: 写 .github/workflows/ci.yml
name: CI

on:
  push:
    branches: [main]
  pull_request:

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  ci:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version-file: .nvmrc

      - name: Setup pnpm
        uses: pnpm/action-setup@v4
        with:
          version: 9.12.0
          run_install: false

      - name: Get pnpm store directory
        id: pnpm-cache
        run: echo "STORE_PATH=$(pnpm store path --silent)" >> $GITHUB_OUTPUT

      - name: Setup pnpm cache
        uses: actions/cache@v4
        with:
          path: ${{ steps.pnpm-cache.outputs.STORE_PATH }}
          key: ${{ runner.os }}-pnpm-store-${{ hashFiles('**/pnpm-lock.yaml') }}
          restore-keys: |
            ${{ runner.os }}-pnpm-store-

      - name: Install
        run: pnpm install --frozen-lockfile

      - name: Lint
        run: pnpm lint

      - name: Typecheck
        run: pnpm typecheck

      - name: Build
        run: pnpm build

注意:P0 的 CI 不包含 postgres:16 service、不跑 prisma migrate / db seed。 因为页面是空白的,pnpm build 不会查 DB。详见 spec §4.1 的 "CI 含义(分阶段)" 部分。 P1 任务里会把这个 ci.yml 整体重写加上 Postgres service。

  • [ ] Step 2: 提交
