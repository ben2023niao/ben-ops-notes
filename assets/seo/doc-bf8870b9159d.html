服务器

当前测试环境是单机部署，反向代理、后端 PHP、前端 H5 都在同一台测试服务器上。

测试服务器：38.92.8.34
SSH：root@38.92.8.34
运维目录：/opt/docker-youdianse-php
角色：测试服务器（包含宝塔 Nginx 反向代理、后端 Docker、前端 3003 服务）

Telegram

测试环境健康监控统一发送到 Telegram 飞机群：运维监控报警群。

敏感配置只放服务器本地，不写入 Git：

cd /opt/docker-youdianse-php
mkdir -p cicd-web/runtime && chmod 700 cicd-web/runtime
vi cicd-web/runtime/secrets.env
chmod 600 cicd-web/runtime/secrets.env

secrets.env 至少需要维护：

[敏感内容已脱敏]
YOUDIANSE_HEALTH_TG_CHAT_ID=...
YOUDIANSE_OPS_MENTIONS=@Ben_Bird @jett_yunwei @Kermit0824 @melo_sre @Daviea2

必须单独写 YOUDIANSE_HEALTH_TG_CHAT_ID，避免健康监控发到发布通知群。如果确认现有 TG_CHAT_ID 本来就是“运维监控报警群”，可以临时用 YOUDIANSE_HEALTH_USE_TG_CHAT_ID=1 bash ops/test/install-health-monitor.sh 复用。

脚本路径

仓库脚本：

ops/test/scripts/youdianse-server-health-alert.py
ops/test/scripts/youdianse-health-hourly-summary.py
ops/test/install-health-monitor.sh

服务器安装后路径：

/usr/local/sbin/youdianse-server-health-alert.py
/usr/local/sbin/youdianse-health-hourly-summary.py
/etc/youdianse-health-alert.json

/etc/youdianse-health-alert.json 权限必须是 600，里面包含 Telegram token/chat_id，不要打印，不要提交。

检查项

每 5 分钟本机检查：

磁盘：根盘、数据盘（存在才检查）
资源：CPU、内存、1 分钟负载 / CPU 核数
Docker：docker stats 容器 CPU、内存
阈值：磁盘80% 内存70% CPU80% 负载200%
冷却：同一批告警 1800 秒内不重复刷屏

每小时 03 分采集一次测试环境汇总。健康正常时只写日志，不发送 Telegram；只有发现异常才发群：

测试服务器整体资源
Docker 容器资源
Mongo/Redis TCP 连通性

Mongo/Redis 地址来自 env/.env.dev：

Mongo主：103.207.68.124:27017
Mongo从1：103.207.68.124:27017
Mongo从2：103.207.68.124:27017
Redis：103.207.68.124:6379

安装

ssh root@38.92.8.34
cd /opt/docker-youdianse-php
git pull --ff-only origin dev

# 确认 secrets.env 有 TG_BOT_TOKEN 和 YOUDIANSE_HEALTH_TG_CHAT_ID
test -f cicd-web/runtime/secrets.env && ls -l cicd-web/runtime/secrets.env

bash ops/test/install-health-monitor.sh

安装脚本会：

1. 复制脚本到 /usr/local/sbin
2. 从 cicd-web/runtime/secrets.env 读取 Telegram 配置
3. 从 env/.env.dev 读取 Mongo/Redis 地址
4. 写入 /etc/youdianse-health-alert.json 并 chmod 600
5. 备份 root crontab 到 /root/crontab.youdianse-health.<时间>.bak
6. 用 BEGIN/END 标记安装健康检查和小时汇总 crontab
7. 执行一次本机 JSON 采集到 /tmp/youdianse-health-alert.json

Crontab

# BEGIN YOUDIANSE_HEALTH_ALERT
*/5 * * * * /usr/bin/flock -xn /var/run/youdianse-health-alert.lock /usr/bin/python3 /usr/local/sbin/youdianse-server-health-alert.py >> /var/log/youdianse-health-alert.cron.log 2>&1
# END YOUDIANSE_HEALTH_ALERT
# BEGIN YOUDIANSE_HEALTH_SUMMARY
3 * * * * /usr/bin/flock -xn /var/run/youdianse-health-summary.lock /usr/bin/python3 /usr/local/sbin/youdianse-health-hourly-summary.py >> /var/log/youdianse-health-summary.log 2>&1
# END YOUDIANSE_HEALTH_SUMMARY

手动验证

python3 -m py_compile /usr/local/sbin/youdianse-server-health-alert.py /usr/local/sbin/youdianse-health-hourly-summary.py
sudo /usr/bin/python3 /usr/local/sbin/youdianse-server-health-alert.py --json
sudo /usr/bin/python3 /usr/local/sbin/youdianse-health-hourly-summary.py --dry-run
sudo /usr/bin/flock -xn /var/run/youdianse-health-summary.lock /usr/bin/python3 /usr/local/sbin/youdianse-health-hourly-summary.py
# 健康正常时上一条不会发群；需要测试 Telegram 发送时临时加 --force-send
sudo crontab -l | grep -A3 YOUDIANSE_HEALTH
sudo tail -100 /var/log/youdianse-health-alert.cron.log
sudo tail -100 /var/log/youdianse-health-summary.log
