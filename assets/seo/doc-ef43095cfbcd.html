通道：本地 -> 巴西宝塔 192.0.2.8（私钥）-> ben-bot 容器（PGSERVER_DEPLOY_PASS）-> 香港机。

二、执行内容

1. 本地代码/工具更新（docker/ci/check.py 通过）

- docker/conf/domains/pg.json：新增 pg6（1834850/1935269）、pg7（1897678/1903012/1971587）
  特殊分组，static_hosts 指向 S3 公开地址 pg6-static/pg7-static，动态域名沿用 pg-games×5；
- create_cloudfront_static_distributions.py：注册 ("pg6-static","pg6-static")、("pg7-static","pg7-static")；
  新建分配 IsIPV6Enabled=False（与 DEC-20260827-HK-CF-IPV4-ONLY 一致）；
- validate_cloudfront_static.py：新增 pg6/pg7 本地源校验（LOCAL_SOURCE_DIRS=/root/pg6static-source、
  /root/pg7static-source，样例 1834850/index.html、1897678/index.html）；
- cloudflare_aws_cutover.py：TARGETS 增加 pg6-static -> d1zgha56h8g72c.cloudfront.net、
  pg7-static -> d4m63juakwye2.cloudfront.net。

2. 香港机部署

脚本更新 /opt/bizops-hk-ops/（create_cloudfront_static_distributions.py、validate_cloudfront_static.py、
cloudflare_aws_cutover.py），原文件备份 /root/bizops-hk-pg67-20260902/backup-*，编译通过。
静态源：/root/pg6static-source（684 文件/46MB）、/root/pg7static-source（1053 文件/83MB）。

3. AppleDouble 残留处理

首次 macOS bsdtar 打包含 xattr，香港机 GNU tar 解包把扩展属性物化为 ._ 文件
（pg6 1071 个、pg7 1649 个）。已用 COPYFILE_DISABLE=1 tar --no-xattrs 重新打包、
重传并二次清理（find -name '._*' -delete），最终 ._ / .DS_Store 均为 0。

4. 静态同步（增量不删除）

AWS_PROFILE=bizops-hk aws s3 sync /root/pg6static-source -> s3://bizops-h5-hk-517506432530/pg6-static/
  684 对象 / 46MB；抽查 index.html 等 ETag 与本地 md5 一致（774b312a…、1f56867f…）。
AWS_PROFILE=bizops-hk aws s3 sync /root/pg7static-source -> s3://bizops-h5-hk-517506432530/pg7-static/
  1053 对象 / 83MB；抽查 index.html 等 ETag 与本地 md5 一致（6f3f2dcd…、8b1678b0…）。

5. CloudFront / S3 桶策略 / DNS

CloudFront 静态分配（OAC、IPv6 关闭、OriginPath /pg6-static、/pg7-static）：
  pg6-static = E15XCV4FBAA5UB / d1zgha56h8g72c.cloudfront.net（pg6-static.hkcloudplay01-05.com）
  pg7-static = E1U930PIP4PPW1 / d4m63juakwye2.cloudfront.net（pg7-static.hkcloudplay01-05.com）
S3 桶策略：新增 PublicReadpg6static / PublicReadpg7static（s3:GetObject，Principal *），
  原有 29 条语句全部保留，共 31 条。
Cloudflare DNS（DNS-only CNAME，TTL 60）：pg6-static/pg7-static × hkcloudplay01-05 共 10 条
  已创建，备份 /root/bizops-cloudflare-dns-backups/20260902T041118Z。
