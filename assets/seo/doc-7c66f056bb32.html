线上后端日志 S3 归档与三天保留

背景

线上健康告警显示后端服务器 ip-172-31-31-108 根盘超过 80%。排查发现主要占用来自：

/opt/docker-youdianse-php/runtime/app-logs

其中 api_request-YYYY-MM-DD.log 和 api_response-YYYY-MM-DD.log 是大头。

结论

后端服务器当前没有独立 /data 挂载，只有 50G 根盘；宝塔入口服务器有 /data 数据盘，但不承载后端 PHP 容器日志。

因此当前不把后端日志迁到 /data 目录。若只在后端根盘创建 /data 目录，仍然占用根盘，不能解决告警。

改造

新增脚本：

ops/production/scripts/youdianse-log-s3-retention.py
ops/production/scripts/youdianse-disk-auto-clean.py

策略：

  • 读取 env/.env.prod 的 AWS S3 配置。
  • 按北京时间自然日保留最近 3 天本地日志。
  • 3 天外日志先 gzip，再用 rclone copyto 上传到 S3。
  • 上传成功且源文件未变化后，才删除本地日志。
  • 真实归档前先做 S3 写权限 preflight；失败则整批停止，不删除本地日志。
  • 每次执行写 JSONL manifest 到 runtime/log-s3-retention/manifests。

S3 对象前缀：

ops/server-logs/<hostname>/app-logs/YYYY/MM/DD/...

后续 /data 方案

后端服务器后续如挂载独立数据盘，推荐热日志目录：

/data/docker-youdianse-php/app-logs

迁移步骤：

  1. 确认 /data 是独立挂载，不是根盘普通目录。
  2. 停止或重建相关容器前同步旧日志。
  3. 设置 YOUDIANSE_APP_LOG_DIR=/data/docker-youdianse-php/app-logs。
  4. 重建 web 和 cron 容器。
  5. 确认容器内 /var/www/html/youdianse-php/runtime/logs 挂载源已切换。

验证命令

python3 -m py_compile cicd-web/core.py ops/production/scripts/youdianse-log-s3-retention.py
sudo python3 /opt/docker-youdianse-php/ops/production/scripts/youdianse-log-s3-retention.py --dry-run
sudo tail -80 /var/log/youdianse-log-s3-retention.log
sudo df -hT /
sudo du -sh /opt/docker-youdianse-php/runtime/app-logs

2026-07-31 执行结果

  • 后端当前没有独立 /data 挂载；未做 /data 迁移。
  • S3 写入 preflight 使用当前 AWS 配置返回 403 Forbidden，因此未安装依赖“先上传再删除”的立即批量归档。
  • 按用户确认“旧日志已上传 S3”的前提，已一次性删除本地 2026-07-29 前旧日志 110 个，释放约 17.4G。
  • Docker builder cache 另回收约 1.685G。
  • 后端根盘从约 82% 降到约 46%，runtime/app-logs 降到约 12G。
  • 新增磁盘自动清理守护：根盘达到 75% 或业务日志达到 20G 时触发，先清 Docker 构建/悬空镜像缓存，再执行日志三天保留；S3 写入失败且线上明确启用本地兜底时，按“旧日志已上传 S3”前提清理 3 天外本地日志。

线上 root crontab 安装每日任务：

22 4 * * * cd /opt/docker-youdianse-php && /usr/bin/flock -n /var/lock/youdianse-log-s3-retention.lock /usr/bin/env YOUDIANSE_LOG_S3_RETENTION_DAYS=3 /usr/bin/python3 ops/production/scripts/youdianse-log-s3-retention.py >> /var/log/youdianse-log-s3-retention.log 2>&1

磁盘自动清理 crontab：

*/10 * * * * cd /opt/docker-youdianse-php && /usr/bin/flock -n /var/lock/youdianse-disk-auto-clean.lock /usr/bin/env YOUDIANSE_DISK_CLEAN_THRESHOLD_PERCENT=75 YOUDIANSE_DISK_CLEAN_APP_LOG_THRESHOLD_GB=20 YOUDIANSE_LOG_S3_RETENTION_DAYS=3 YOUDIANSE_DISK_CLEAN_LOCAL_DELETE_FALLBACK=1 /usr/bin/python3 ops/production/scripts/youdianse-disk-auto-clean.py >> /var/log/youdianse-disk-auto-clean.log 2>&1
