一、流量切换至备用 nginx（14:30，提交 345b4ee8）

目标：宝塔 nginx 全量同步备用机并切换域名，全厂家全游戏测试。
执行：
1. 勘察：宝塔 52 conf/78 证书 vs 备用机 25 conf；10 个共享配置有差异
2. 同步：25 站点配置 + 78 证书目录 + 静态目录 29GB（rsync 排除 game_results_data）
3. 发现并修复：g759 根路径 200 线路探测（宝塔被每日生成脚本覆盖丢失）
   → 修复写入 sync_all_game_domains_to_baota.py 生成模板（key==g759 注入 location = /）
   → 宝塔重跑生成器 + 同步备用机，两台根路径均 200
4. DNS 切换：199 条 A 记录 35.247.205.6 → 34.151.249.53（api/games/通配/www/socket/verify）
   工具：docker/scripts/dns_cutover.py（--to-standby / --to-baota 回滚，快照可恢复）
5. 验证：直连 IP 对比一致；切换后动态 /health 153/157（4 个 410 待确认）；
   全厂家入口 200；静态 health 200；备用机日志见真实流量
回滚：python3 docker/scripts/dns_cutover.py --to-baota

二、证书同步 cron（14:45，提交 b7a387c7）

脚本：docker/scripts/sync_certs_to_standby.sh（宝塔 /opt/dbqp-scripts/）
逻辑：rsync --checksum 检测内容变更 → 同步 /www/server/panel/vhost/cert →
      备用机 nginx -t + reload（无变更跳过）
cron：40 4,10,16,22 * * *（紧跟 acme 续签 03 分后）
实测：测试文件触发同步+reload OK

三、全量域名检查 + 410 修复（15:21，提交 322cca17）

背景：用户报 pg-games.6qv8m.icu/health 不通，要求全部厂家全部域名检查。
结果：动态 /health 181 域名 177 正常 + 4 个 410；静态 242/242 OK
根因：nginx all-games-proxy.conf 故意访问策略验证
      (pg-games|api).(t6qv8m|6qv8m).icu（含 /health）
处理：移除两条访问策略验证（备份 .bak-20260901-410block）→ 181/181 全绿

四、m. 前缀 bug 域名下掉 + api_hosts 接入（15:30，提交 8ed401fc）

历史（2026-07-06）：前端把 hostname 里 "m." 替换成 "api."，
  pg-games.t6qv8m.icu 会被拼成 pg-games.t6qv8api.icu。
用户决定：t6qv8m.icu / 6qv8m.icu（m.icu 结尾）下掉。
执行：
1. nginx 410 访问策略验证规则加回宝塔+备用机（4 域名验证 410，cache-buster/直连均 410）
2. platform-api 6 厂商移除 t6qv8m/6qv8m（game+static hosts）
3. pg.json 新增 api_hosts：20 条 api.<zone>（含 3 条 Argo：
   api.xqv9m8 / api.tada-cdn-2026 / api.cdn-tokyo-dbqp）
4. game_launcher.py 注入 params_dict["api_hosts"]（增量，不破坏现有逻辑）
5. 3 台后端容器热更新 + 重启；验证 api 域名 200 / t6qv8m、6qv8m 410

五、厂商配置清理 + g759 线上化（17:00，提交 049e209b）

1. 删除测试厂商配置：fc.json / jili.json / jdb.json（master+宝塔+3 后端容器）
2. g759.json 由测试配置（g759-test.bxgjnet.com / g759-api.repair127.com）
   改为线上配置（镜像 panda 结构）：
   static_hosts 20 条 g759-static.<zone> + game_hosts 20 条 g759-games.<zone>
   （排除 t6qv8m/6qv8m）
3. 3 容器热更新；验证 g759 游戏 /health 200、静态页 200、静态 health.json 200
备注：agent_apis.py 仍 import jili/jdb 模块（仅删域名配置）
