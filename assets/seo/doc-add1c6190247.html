视频详情页差异基准

视频详情页差异基准。本文属于业务系统运维 / GHOME，对比范围：产品原型 docs/ghome-20260522.html 的 /video/v01 ，以及当前本地 test 分支视频详情页 /video/:slug 。

对比范围：产品原型 docs/ghome-20260522.html 的 /video/v01，以及当前本地 test 分支视频详情页 /video/:slug。

状态约定：

  • 待确认：需要产品/负责人确认是否按原型调整。
  • 按原型改：后续进入开发任务。
  • 保留当前：明确不改。
  • 已确认无差异：当前实现已与原型一致或可接受。

1. 全局与页面结构

编号 模块 差异点 原型表现 当前表现 当前来源类型 建议状态
VD-001 页面模块标识 原型模块带 data-spec video-detail-player、video-detail-info、video-detail-related、video-detail-aside 当前详情 Hero、信息区、推荐区、侧栏未完整设置对应标识 代码属性；非内容配置 按原型改；只作为 QA/验收/自动化扫描辅助属性
VD-002 路由 原型使用 /video/:id 当前项目使用 /video/:slug 代码路由 保留当前；项目真实路由是 slug
VD-003 数据来源 原型使用静态 VIDEOS 当前使用数据库 getVideoBySlug / getPublishedVideos 内容配置 保留当前；数据库内容更符合真实业务

2. 封面与观看入口

编号 模块 差异点 原型表现 当前表现 当前来源类型 建议状态
VD-004 播放 Hero 模块标识 <section class="vdx-hero" data-spec="video-detail-player"> 当前仅 .vdx-hero 代码属性；非内容配置 按原型改
VD-005 封面 左侧 16:9 封面 + 右下时长 当前一致，使用真实封面 URL，缺省用占位图 内容配置 + 代码结构 已确认无差异
VD-006 标题与 meta 标题、播放数、点赞、上传日期、时长、分类 当前一致 内容配置 + 代码结构 已确认无差异
VD-007 分类链接 分类 link 目标 /videos/list?cat={cat} 当前跳 /category/{slug} 代码链接；非内容配置 按原型改；统一落到视频列表筛选页
VD-008 观看入口侧卡 只显示观看入口说明与两个按钮 当前侧卡还包含 视频简介 代码结构；非内容配置 按原型改；简介移动到下方 video-detail-info
VD-009 观看按钮 前往合作方观看 当前有真实 /r/:id 跳转和 disabled 兜底 跳转配置 保留当前；真实跳转优先
VD-010 更多同类视频 跳同分类列表 原型 /videos/list?cat={cat} 当前跳 /videos 代码链接；非内容配置 按原型改

3. 标签与简介

编号 模块 差异点 原型表现 当前表现 当前来源类型 建议状态
VD-011 信息卡 模块容器 独立 .adx，data-spec=video-detail-info 当前没有独立信息卡，标签在 Hero 下方，简介在观看侧卡 代码结构；非内容配置 按原型改
VD-012 视频标签 标签展示 信息卡内 视频标签 + chips 当前 Hero 内和侧栏各展示一次 内容配置 + 代码结构 按原型改；主信息卡展示，侧栏标签保留当前业务增强
VD-013 视频简介 多段简介 原型用静态文案拼接标签、分类、时长 当前使用数据库 video.detail 一段 内容配置 保留当前；真实内容详情优先，不生成长假文案

4. 相关推荐

编号 模块 差异点 原型表现 当前表现 当前来源类型 建议状态
VD-014 相关推荐 模块标识 外层 data-spec=video-detail-related 当前无 data-spec 代码属性；非内容配置 按原型改
VD-015 推荐数据 同分类视频 4 条 当前同分类视频最多 4 条 数据库查询 已确认无差异
VD-016 同标签视频 原型没有额外同标签视频模块 当前额外展示同标签视频 内容配置 + 查询逻辑 保留当前；提升真实内容发现能力

5. 右侧栏

编号 模块 差异点 原型表现 当前表现 当前来源类型 建议状态
VD-017 右侧栏 模块标识 <aside data-spec="video-detail-aside"> 当前 <aside> 无 data-spec 代码属性；非内容配置 按原型改
VD-018 所属分类 分类卡 显示所属分类，跳 /videos/list?cat={cat} 当前有分类卡，但跳 /category/{slug} 代码链接 按原型改
VD-019 推荐 App 推荐 3 个 App 当前使用数据库 App 前 3 个 内容配置 已确认无差异
VD-020 相关专题 推荐 3 个专题 当前查询包含当前视频的专题，最多 3 条 内容配置 + 查询逻辑 保留当前；数据库关联更准确
VD-021 创作者卡 原型右侧栏没有创作者卡 当前展示创作者卡和关注按钮 fixture + 代码结构 保留当前；属于当前版本业务增强
