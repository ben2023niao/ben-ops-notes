① 关键 URL(dev 环境)

用途 URL
REST API 根路径 https://api-dev.54-151-131-132.sslip.io/api/v1
主播端 WebSocket 统一入口 `wss://api-dev.54-151-131-132.sslip.io/ws/v1/streamer?敏感凭据：[已脱敏]
REST API 文档 /docs/

主播端必须使用 streamerBearer。不要用 C 端用户 token，也不要接 /ws/v1/client。

② 主播端主流程

步骤 接口 / SDK 说明
登录 POST /api/v1/streamer/auth/login 拿主播 access token。文档：streamerLogin
获取我的房间 GET /api/v1/streamer/me/rooms 文档：streamerMyRooms
开播 POST /api/v1/streamer/rooms/{room_id}/start 返回 ZEGO 推流参数。文档：streamerStartLive
ZEGO 推主播流 startPublishingStream(stream_no) 主播摄像头 / 麦克风走 ZEGO Web SDK，不走 OBS。
订阅房间事件 WS /ws/v1/streamer 订阅 room:{room_id}，接收弹幕、打赏、话术回显、投票/众筹事件。
直播业务心跳 streamer.live.heartbeat 开播成功后每 15s 发送一次。60s 未收到时后端自动下播并广播 room.status.ended。
下播 POST /api/v1/streamer/rooms/{room_id}/stop 文档：streamerStopLive

③ 主播端 WS 接法

const API = 'https://api-dev.54-151-131-132.sslip.io/api/v1';
const WS = 'wss://api-dev.54-151-131-132.sslip.io/ws/v1/streamer';

function connectStreamerWS(roomId, streamerToken, startLiveData) {
  const ws = new WebSocket(`${WS}?敏感凭据：[已脱敏]
  let liveHeartbeatTimer = null;

  ws.onopen = () => {
    ws.send(JSON.stringify({
      type: 'client.subscribe',
      data: { channels: [`room:${roomId}`] }
    }));

    // client.ping 是 WS 连接保活；streamer.live.heartbeat 是直播业务心跳。
    const sendLiveHeartbeat = () => ws.send(JSON.stringify({
      type: 'streamer.live.heartbeat',
      data: {
        room_id: String(roomId),
        session_id: startLiveData.session_id,
        zego_room_id: startLiveData.zego_room_id,
        zego_stream_id: startLiveData.stream_no
      }
    }));
    sendLiveHeartbeat();
    liveHeartbeatTimer = setInterval(sendLiveHeartbeat, 15000);
  };

  ws.onmessage = (ev) => {
    const msg = JSON.parse(ev.data);
    switch (msg.type) {
      case 'live.danmaku.received':
        appendDanmaku(msg.data);
        break;
      case 'live.tip.combo':
        refreshTipRank();
        playGiftEffect(msg.data);
        break;
      case 'live.system.notice':
        showNotice(msg.data.text);
        break;
      case 'room.status.ended':
        if (msg.data.reason === 'streamer_heartbeat_timeout') {
          showEndedNotice('直播心跳超时,房间已自动下播');
        }
        break;
    }
  };

  ws.onclose = () => {
    if (liveHeartbeatTimer) clearInterval(liveHeartbeatTimer);
  };

  return ws;
}

主播端 WS 只订阅 room:* / match:*。钱包个人频道 user:* 是 C 端登录用户专用，主播端不能订阅。

开播接口返回的 session_id、stream_no、zego_room_id 要原样放到 streamer.live.heartbeat。

⑤ 体育节目流 / 混流

能力 接口 说明
获取房间节目配置 GET /api/v1/streamer/rooms/{room_id}/program 返回节目流配置和 ZEGO 云播放器相关流 ID。文档：streamerRoomProgram
回写混流输出 POST /api/v1/streamer/rooms/{room_id}/mixed-stream 回写 mixed_stream_id，普通直播和赛事混流都传 mixed_stream_id = host_stream_id = start.stream_no 保证 C 端不切流；普通直播仅做校验和审计。文档：streamerRoomMixedStreamReport
体育直播源列表 GET /api/v1/streamer/sports-live 文档：streamerSportsLiveSearch

⑥ 和 C 端的区别

项目 C 端 主播端
鉴权 C 端用户 JWT，可游客 主播 JWT，必须登录
WS /ws/v1/client /ws/v1/streamer
视频 ZEGO 拉稳定 zego_stream_id，混流前后不切换 ZEGO 推 start.stream_no，必要时将赛事源混到同一个输出流
操作 发弹幕、送礼、投票 开播/下播、发话术、发起投票、看实时榜
