一、Beszel（主机监控）

地址：http://52.79.252.255:8090
镜像：beszel-zh:v0.18.7（中文告警版）
数据：/var/lib/docker/volumes/beszel_data/_data/data.db
  • 告警中文：X 高于阈值 / 低于阈值、最近 N 分钟平均 …
  • 每条告警末尾自动 @ 全部运维
  • 阈值按近 7 天 p95：CPU=p95+10（≥60）、内存=p95+8（≥70）、磁盘=p95+5（≥60）、带宽=p95×1.5（≥30）

新增一台监控

docker run -d --name beszel-agent-52 --restart unless-stopped \
  -e LISTEN=61208 -e 敏感凭据：[已脱敏] -e HUB_URL=http://52.79.252.255:8090 \
  -e KEY="ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAII+xVa2O3blyab23CN5RnMD8uY6xLDCbIV+zTPw+PtB0" \
  -p 61208:61208 henrygd/beszel-agent

无 Docker 的机器用 deb + systemd（见历史文档《用 Spug 密钥补接监控》）。

二、内网数据库探测

脚本：后端 /usr/local/sbin/yds-db-probe.py
配置：/etc/youdianse/db-probe.env
日志：/var/log/yds-db-probe.log
频率：cron 每 2 分钟

探测主库/从库01/从库02 的 27017（Mongo hello）+ 从库01 的 6379（Redis PING），连续失败 2 次且状态变化才告警。

三、CC 守卫

代码：监控机 /opt/telegram/18game_devops/devops/scripts/cc_guard/
频率：cron 每 10 秒（flock 串行）
状态：state/guard.log、blocked_ips.txt、static_block_prefixes.txt
  • 默认放行 + 黑名单（UA/前缀/IP）
  • 夜间盯盘 night_watch.py（到次日 06:00，异常自动触发守卫）

四、日志位置

日志 位置
业务错误 runtime/app-logs/error-YYYY-MM-DD.log
请求/响应 runtime/app-logs/api_request/api_response-*
php-fpm runtime/app-logs/php-fpm/
后端 nginx runtime/nginx-logs/
网关 nginx /var/log/nginx/

S3 归档桶：youdianse-prod-gateway-logs。

五、告警来了怎么办

  1. Beszel 看趋势
  2. 上机器 docker stats / df -h / du -sh /*
  3. 查 docs/05-常见故障处置.md
  4. 处置后回群说明
