App 详情页差异基准

App 详情页差异基准。本文属于业务系统运维 / GHOME，对比范围：产品原型 docs/ghome-20260522.html 的 /app/broconnect ，以及当前本地 test 分支 App 详情页 /app/:slug 。

整理日期：2026-06-12 03:49｜日期依据：文件创建/修改时间

对比范围：产品原型 docs/ghome-20260522.html 的 /app/broconnect，以及当前本地 test 分支 App 详情页 /app/:slug。

状态约定：

  • 待确认：需要产品/负责人确认是否按原型调整。
  • 按原型改：后续进入开发任务。
  • 保留当前：明确不改。
  • 已确认无差异：当前实现已与原型一致或可接受。

1. 全局与页面结构

编号 模块 差异点 原型表现 当前表现 当前来源类型 建议状态
D-001 页面模块标识 原型模块带 data-spec，便于需求对照 app-detail-card、app-detail-reviews、app-detail-related、app-detail-aside 当前详情页未设置这些 data-spec 代码属性；非内容配置 按原型改；只作为 QA/验收/自动化扫描辅助属性
D-002 页面顶部结构 原型先显示面包屑，再进入详情主体 面包屑在主详情卡之前 当前先显示彩色 AppHero，再显示面包屑 代码结构；非内容配置 按原型改
D-003 App 顶部 Hero 原型没有独立全宽 AppHero 顶部信息放在 .adx 主信息卡内 当前有独立 .app-hero，含下载 CTA 代码结构/样式；非内容配置 按原型改；移除详情页独立 AppHero
D-004 页面布局 原型主体为左内容 + 右侧栏 .container.two-col 当前也使用 .container.two-col 代码结构；非内容配置 已确认无差异

2. 主信息卡

编号 模块 差异点 原型表现 当前表现 当前来源类型 建议状态
D-005 主信息卡 主体容器 一个 .adx 卡承载顶部信息、扫码、安装 tabs、产品介绍、亮点、App 信息 当前内容散落在 AppHero、AppInfoGrid、正文、AppInstallTips 等多个区块 代码结构；非内容配置 按原型改
D-006 顶部信息 图标尺寸与位置 大图标 + 名称 + 官方徽章 + 一句话介绍 当前 AppHero 内显示标题/短描述，图标不在详情主体顶部 内容配置 + 代码结构 按原型改
D-007 顶部信息 官方徽章 显示 ✓ 官方 当前没有官方徽章 代码静态文案；非内容配置 按原型改
D-008 顶部信息 4 行 info 版本 / 更新时间 / 支持 / 来源 当前没有独立 4 行 info；部分信息在 AppInfoGrid 中 内容配置 + 卡片结构 按原型改
D-009 顶部信息 来源字段 固定 官方安装包 当前无来源字段 代码静态文案；非内容配置 按原型改
D-010 下载入口 PC 扫码安装区 .pc-dl：标题、QR、提示文案 当前顶部 CTA 使用 AppDownloadCTA，桌面扫码在按钮 hover 中出现 代码结构；非内容配置 按原型改
D-011 移动 CTA 移动端在扫码提示下显示 iOS / Android 两个占位入口 原型移动端 .mobile-cta 当前由 AppDownloadCTA 按 OS 显示不同按钮 代码结构/客户端状态；非内容配置 按原型改
D-012 安装说明 iOS / Android tabs 一张卡内两 tab，默认按系统推断 当前是普通 AppInstallTips，无 tabs 代码结构；非内容配置 按原型改
D-013 安装说明 iOS 安装步骤 6 步企业签名流程 + note 当前为通用 3 步安装说明 代码静态文案；非内容配置 按原型改
D-014 安装说明 Android 安装步骤 5 步 APK 下载流程 + 安全 note 当前为通用注意事项 代码静态文案；非内容配置 按原型改
D-015 产品介绍 标题命名 产品介绍 当前为 应用详解 代码静态文案；非内容配置 按原型改
D-016 核心亮点 列表展示 feature-list，每条 ✓ 前缀 当前也使用 feature-list 内容配置 + 样式 已确认无差异
D-017 适合人群/主要功能/标签 是否单独展示 原型主信息卡内不单独展示这三段 当前单独展示 适合人群、主要功能、标签 内容配置 + 代码结构 按原型改；避免详情页信息重复
D-018 App 信息 信息卡数量 5 cell：评分 / 年龄 / 开发者 / 语言 / 大小 当前 6 cell：评分 / 用户量 / 平台 / 大小 / 年龄分级 / 语言 内容配置 + 卡片结构 按原型改
D-019 App 信息 开发者字段 显示开发者，缺省为 ${app.name} Team 当前注释说明 dev 为 admin-only，不展示 内容配置 + 卡片结构 按原型改
D-020 App 信息 用户量字段 原型用户量作为评分 cell 的副信息 当前用户量单独占一个 cell 内容配置 + 卡片结构 按原型改
D-021 App 信息 平台字段 原型平台作为大小 cell 的副信息 当前平台单独占一个 cell 内容配置 + 卡片结构 按原型改

3. 用户评价

编号 模块 差异点 原型表现 当前表现 当前来源类型 建议状态
D-022 用户评价 模块容器 独立 .adx 卡，带 data-spec=app-detail-reviews 当前是普通内容区，不在 .adx 卡内 代码结构；非内容配置 按原型改
D-023 用户评价 示例评价说明 必须显示 ⚠ 以下为示例评价，仅供页面展示参考，非真实用户反馈 当前已显示同等警示文案 代码静态文案；合规提示 已确认无差异
D-024 用户评价 评价数据 固定 3 条 SAMPLE_REVIEWS mock 当前使用同一份 SAMPLE_REVIEWS 代码常量；非内容配置 已确认无差异
D-025 用户评价 底部补充说明 原型没有额外 P5 后接入真实评价系统 说明 当前评价后有 * 评价示例，P5 后接入真实评价系统 代码静态文案；非内容配置 按原型改；删除内部研发阶段说明

4. 同类推荐

编号 模块 差异点 原型表现 当前表现 当前来源类型 建议状态
D-026 同类推荐 模块标识 外层有 data-spec=app-detail-related 当前无 data-spec 代码属性；非内容配置 按原型改；只作为 QA/验收/自动化扫描辅助属性
D-027 同类推荐 推荐数量 3 张卡，同分类不足时 fallback 全局前 3 当前同分类最多 4 张，无全局 fallback 内容配置 + 查询逻辑 按原型改
D-028 同类推荐 卡片结构 复用 App 卡 当前复用 AppCard 代码结构；非内容配置 已确认无差异
D-029 同类推荐 更多入口 浏览全部 → 跳 /apps 当前一致 代码静态链接；非内容配置 已确认无差异

5. 右侧栏

编号 模块 差异点 原型表现 当前表现 当前来源类型 建议状态
D-030 右侧栏 模块标识 <aside data-spec="app-detail-aside"> 当前 <aside> 无 data-spec 代码属性；非内容配置 按原型改；只作为 QA/验收/自动化扫描辅助属性
D-031 相关专题 数据来源 固定 3 条：/topic/platform、/guide/choose-app、/guide/privacy 当前查询包含当前 App 的专题，最多 3 条 内容配置 + 查询逻辑 保留当前；使用数据库关联更符合真实业务
D-032 热门标签 展示范围 全站 ALL_TAGS.slice(0,10) 当前展示当前 App 自身标签 内容配置 + 查询逻辑 保留当前；详情页展示当前 App 标签更精准
D-033 使用指南 展示数量 4 条指南 当前查询热门/最新指南 3 条 内容配置 + 查询逻辑 按原型改；展示 4 条
D-034 右侧栏 视觉结构 3 张 side-card：相关专题 / 热门标签 / 使用指南 当前也使用 SideCard 分组 代码结构/样式 已确认无差异

6. 数据与路由边界

编号 模块 差异点 原型表现 当前表现 当前来源类型 建议状态
D-035 路由 原型使用 /app/:id 当前项目使用 /app/:slug 代码路由；非内容配置 保留当前
D-036 数据来源 原型使用内置 APPS 静态数组 当前使用数据库 getAppBySlug / getPublishedApps 内容配置 保留当前
D-037 QR 生成 原型使用 genQR(a.id) 伪二维码 当前使用 qrcode-svg 生成真实 QR 代码逻辑；非内容配置 保留当前
