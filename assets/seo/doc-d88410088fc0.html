一、任务与背景

使用 docker 浏览器方案（Playwright Chromium，备用机巴西本地），手机 UA 模拟， 完成「登录 → 点击同游戏 → 点击继续 → 等游戏完整加载」的分阶段计时录屏对比：

  • 我方：ff789p3.com（接 API 包网）；若游戏未开，直测 7 个 H5 入口 （PG/vendor_a/PP/PPK/vendor_c/PANDA/G759，ind-h5.bizopsplus999.com/<厂家>bronline*）；
  • 竞品：m6kk678n.com；
  • 账号/密码：11955336688 / 11955336688。

二、执行过程与发现

1. ff789p3 状态（实测）

  • probe_ff789_open.py 返回 OPEN：该 probe 实际探测的是 PG H5 入口（可视为 平台游戏可用性），不是 ff789p3 站点本身；
  • ff789p3.com 实测：大厅可登录（R$ 109.35 余额），但点击任意游戏卡 （article.game-card）不跳转、无画布 → 游戏确实未开放（站点侧问题）。

按用户预案切换：我方直测 7 个 H5 入口；竞品正常登录对比。

2. 脚本修复（新标签页 + 卡片点击）

  • 游戏可能新开标签页打开：wait_visible_canvas 原只扫当前页 frames， Fortune Tiger 被误判为打不开；改为扫描 context 全部页面 + iframe；
  • ff789p3 大厅按文本点击无效：open_our 改为点击 article.game-card（含标题）卡片本体；
  • label_game_videos.py：results.json 匹配键改为支持 file 字段， 使 H5 多厂家视频的水印描述能正确带上分阶段耗时。

3. 我方 7 个 H5 入口实测（手机 UA 390x844，点卡→画布→继续→可玩）

4. 竞品 m6kk678n.com 实测（登录→同游戏→继续→可玩）

  • rendered_ok 启发式返回 False（120s 窗口末画面静止），但帧分析证明是 真实完整渲染的游戏画面（与对标游戏色彩统计一致），静止只是停在待开始界面；
  • 全部视频已抽帧验证（avg/std/unique colors 与已渲染画面一致）。

三、结论

  1. docker 浏览器方案（备用机巴西 + Playwright Chromium + 手机 UA）可以完整跑通 「点卡→画布→继续→可玩」并产出带水印 MP4，无需 CF token；
  2. 我方 7 厂家 H5 入口全部可用（画布 8-13s，点继续→可玩 3-9.7s）；
  3. 竞品登录+进游戏链路稳定（登录 16-20s，画布 20-29s，继续→可玩 7.0-7.6s）；
  4. ff789p3 站点未开放是站点侧问题，cron（每 30 分钟）探测到开放后自动跑 登录版完整对比（game_login_compare_mobile.py --side both --mobile）。 （注：该 cron 已于 2026-08-29 取消，见【运维】取消ff789p3定时探测任务记录）

四、变更文件

  • docker/scripts/game_load_video_compare.py：新标签页画布识别；
  • docker/scripts/game_login_compare_mobile.py：新标签页识别 + ff789p3 卡片点击；
  • docker/scripts/h5_vendor_full_render_test.py：新增 7 厂家 H5 完整加载测试脚本 （手机 UA + 水印 field）；
  • docker/scripts/label_game_videos.py：results 匹配支持 file 字段；
  • 备用机 /opt/pgserver/docker/scripts/ 已同步。
