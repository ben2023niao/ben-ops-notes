一、现象

开发（C++）反馈：「线上吉利进不去了」，要求处理；用户补充：这次是**腾讯云（EdgeOne）那条线**，
并提示两个方向：① 看代码里配置的域名；② 怀疑 nginx 把 https 转发成了 http。

二、排查

1) 先做整体健康检查（都正常，排除了服务挂掉）：
   · 四套动态域名 /health 全 200：vendor_b-games.m4q7z1.shop / .k8x2v9.shop / .hkcloudplay06.com / .hkcloudplay07.com
   · 静态页与资源 200：vendor_b-static1.<新域名>/lj500/index.html（97,383B）、/commom_v3_1.0.9.js、/lj500/src/*.bundle.js
   · 香港 01/02：9 个业务容器 Up、磁盘 40%、负载 <1；ws 容器日志显示真实客户端消息正常收发
   · nginx 错误日志只有扫描器的 SSL handshake 噪音
2) 配置核对（用户提示①）：线上 conf/domains/vendor_b.json 的 default/v1/v2 用的都是腾讯域名
   （vendor_b-static{,1,2}.m4q7z1.shop / .k8x2v9.shop，DNS 与 nginx 都正常）；
   v3/v4/v5 仍写的是 vendor_b-static{3,4,5}-aws.hkcloudplay0[67].com（CF 侧命名），本机 nginx 没有这些 server_name
   → 命中默认站点返回平台页/404。**这条单独记，等开发确认这几个分组的目标域名**（不属本次 https→http 问题）。
3) 抓包对账（用户提示②，决定性证据）：在 prod-01 上 tcpdump 9093/8765，看后端实际收到的头：

   修复前
     Host: vendor_b-games.m4q7z1.shop        X-Forwarded-Proto: http     ← 腾讯 EdgeOne 链路
     Host: vendor_b-games.hkcloudplay06.com  X-Forwarded-Proto: https    ← Cloudflare 链路

   即：**EdgeOne 回源到本机用的是 HTTP**，而 nginx 片段里写的是
   `proxy_set_header X-Forwarded-Proto $scheme;` → `$scheme` 取的是「边缘→本机」这一跳的协议（http），
   后端据此认为客户端在 http 上 → 生成 http:// 链接 → 浏览器按混合内容/协议不一致拦掉 → 游戏进不去。
   CF 链路回源是 HTTPS，所以只有腾讯线出问题，这也解释了「为什么只有腾讯云这条线进不去」。

三、修复（两台 nginx 入口）

原则：对外（EdgeOne / Cloudflare / 浏览器）实际都是 HTTPS，边缘→源站那一跳用什么协议不代表客户端协议；
      统一告诉后端 https，和 Cloudflare 链路的行为对齐。

· standby 192.0.2.37（腾讯域名 + 06/07 都在这台）
    /etc/nginx/snippets/bizops-hk-standby-proxy.conf   X-Forwarded-Proto: $scheme →  https；新增 X-Forwarded-Port 443
    /etc/nginx/snippets/bizops-hk-standby-ws.conf      X-Forwarded-Proto: $scheme →  https；X-Forwarded-Port: $server_port → 443
· 入口机 192.0.2.14（老域名 01-05）
    /etc/nginx/snippets/bizops-hongkong-proxy.conf     同上（避免 CF 那条线哪天回源走 HTTP 时重演）
· 只改「告诉后端的协议」，不动任何业务口径（动态 CORS 仍归开发、静态 CORS 仍 ACAO *），静态域名不受影响。
· nginx -t 通过后才 reload。

四、验证

· 抓包（修复后）：腾讯线 vendor_b-games.m4q7z1.shop 与 CF 线 vendor_b-games.hkcloudplay06.com 的后端请求头均为
  `X-Forwarded-Proto: https` + `X-Forwarded-Port: 443`；ws 升级请求（8765）同样带上 https/443。
· 四套动态域名 /health 全 200；静态资源 200；ws 容器继续正常收发包。
· 请开发在腾讯线重新进一次游戏确认（群里已同步）。
