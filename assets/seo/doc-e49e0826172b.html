时间：2026-08-07 19:10（Asia/Manila） 项目：DBQP / PGServer master 范围：巴西生产新增备用流量入口（GCP 新实例 + Docker + Nginx） 执行人：Codex（本地工作区 + 宝塔 gcloud/SSH）

任务边界

用户要求：

目前只有 1 台宝塔服务器是 nginx 流量入口服务器（典型单节点）。
参考宝塔服务器的 nginx 和前端客户端资源；
使用谷歌云 API 开一台同内网的服务器；
只需要部署 docker 环境和 nginx，搭建为备用的流量入口服务器；
域名参考宝塔服务器配置；证书直接复制粘贴宝塔的。
同时按标准工作流：workbench、逐步群通知、完成后验证、汇总文档发群、最后合并提交本地代码。

前置勘察（只读）

宝塔 nginx：1.28.0，配置含 quic/http2（站点配置由 all_game_domain_sync 生成）。
证书：/www/server/panel/vhost/cert 共 78 个域名目录（约 1.2M）。
前端客户端静态资源：/www/wwwroot 下 12 个目录，合计约 27GB
  （pg-static/pg3-static/pg4-static/pg5-static/tada-statics*/pp-static/ppk-static/
   playson-static/panda-static/verify.pgofficialbx.com；game_results_data 134G 为结果数据，未复制）。
GCP：内网可用 IP 203.0.113.1；镜像 ubuntu-2204-jammy-v20260731；pd-balanced 可用。

云资源创建（gcloud）

静态公网 IP：dbqp-saopaulo-nginx-standby-01 = 34.151.249.53（southamerica-east1）
实例：dbqp-saopaulo-nginx-standby-01
  zone：southamerica-east1-a
  规格：e2-custom-4-8192（4C/8G）
  内网：203.0.113.1（同 VPC dbqp-saopaulo-slotsapi-network-v2 / 203.0.113.1/20）
  系统盘：200GB pd-balanced（Ubuntu 22.04.5 LTS，已自动扩容到 194G）
  标签：http-server,https-server；删除保护：开启
  快照策略：default-schedule-1（14 天）
  SSH：注入运维公钥（root）

部署内容

Docker：29.7.2（docker-ce 官方源，docker daemon 正常，hello 容器验证通过）。
Nginx：1.30.4（nginx.org 源，含 http_ssl/http_v2/http_v3，支持配置中的 quic/http2）。
复制自宝塔（内网 rsync）：
  - 证书：/www/server/panel/vhost/cert（78 个域名目录，fullchain.pem + privkey.pem）
  - nginx 引用目录：common / extension / well-known / tcp / rewrite / proxy.conf
  - 活跃站点配置 45 个 -> /etc/nginx/conf.d/
    （动态：pg/tada/pp/ppk/playson/panda games + socket；静态：各 static 站点；
     排除 btwaf/lua/php/fastcgi/ssl.<root> 等宝塔面板专属配置）
  - 前端静态资源 12 个目录（26GB）-> /www/wwwroot/
主配置：/etc/nginx/nginx.conf（user www，include conf.d/*.conf，保持宝塔目录引用路径）。

验证结果（与宝塔直连对比）

nginx：syntax ok，active，监听 80/443（含 IPv6:80）。
Docker：daemon OK，hello 容器运行成功。
源站直连（-k 对比 baota 35.247.205.6 vs standby 34.151.249.53）：
  pg-games=200/200、api=200/200、tada=403/403、pp=403/403、
  ppk=404/404、playson=404/404、panda=404/404、socket=404/404 —— 完全一致。
静态文件：pg-static 抽检 baota=200、standby=200。
TLS：按 SNI 下发证书与宝塔一致（pg-games -> *.q7m9v8.icu，socket -> xtmpz.com）。
后端可达：standby -> 203.0.113.1/.4/.11 八端口响应与宝塔一致（9091=200、8765=426 等）。
线上 DNS：未切换，公网仍指向宝塔 35.247.205.6。

备用切换说明（未执行，仅供运维参考）

切换前：确认备用机 nginx active、upstream 三台健康、静态资源为最新（必要时先 rsync）。
切换步骤：
  1. Cloudflare 动态域名 A 记录从 35.247.205.6 改为 34.151.249.53
     （* -games.<root> / api.<root> / socket.xtmpz.com 等所有橙云记录）。
  2. 静态域名走 Google CDN 不受影响，无需切换。
  3. 如宝塔短暂不可用，先手工改 Cloudflare 记录；恢复后切回。
  4. 证书续签仍在宝塔；备用机证书为复制副本，长期运行需定期 rsync 刷新。
