3. 现象和根因

用户截图中的主要异常分两类：

  1. API 请求失败或 404 前置 Nginx 曾把 /api/v1/... 代理到 admin.youdianse.com，实测该域名对应路径返回 404；线上可用前端 API 入口为 www.youdianse.com，同类接口返回 200。

  2. 静态资源 403 H5/PC 前端页面中的部分 /images/...、根路径静态图被代理到了错误源或缺少兼容映射。H5 历史缺图 email.png、pwd.png、sms.png、game-controller-icon.png 在此前补资源文档中已记录为“源码引用但 public/images 中不存在”，本轮前置服务器和本地仓库均未找到真实文件。

补充观察：

  • business.svg 在本轮页面 bundle 反查中未发现当前首页真实引用；线上 CloudFront 和前置 S3 对该路径也返回 403，判断不是当前首页主要报错路径。
  • 本机 in-app Browser 插件不可用，无法直接接管当前 Chrome DevTools；本轮使用 HTTP 状态、Content-Type、页面静态引用和接口抽样替代验证。

4. 执行改动

4.1 前置 Nginx

文件：

  • devops/python/ben-bot/data/scripts/线上前置-游点涩-前端配置/nginx/youdianse-preprod-frontends.conf

改动：

  • H5/PC 的 /api|/channel|/customer 代理源改为 www.youdianse.com。
  • H5 /images|/image|/video|/videos|/media 代理到 18game-nuxt-static-preprod-h5.s3.ap-southeast-1.amazonaws.com。
  • PC /images|/image|/video|/videos|/media 代理到 18game-nuxt-static-preprod-pc.s3.ap-southeast-1.amazonaws.com。
  • /uploads/ 保持代理线上后台 AWS CloudFront 资源源 d391me9s8n5j5s.cloudfront.net。
  • PC 根路径兼容：
  • /footer-logo.webp -> /images/footer/footer-logo.webp
  • /placeholder.webp -> /images/placeholder.webp
  • H5/PC 对历史缺图路径增加透明图片兜底：
  • /images/email.png
  • /images/pwd.png
  • /images/sms.png
