日期：2026-06-02 Agent：Codex 任务：将上传能力改为 C 端、主播端、后台共用底层 service 的通用上传接口。

输入资料

  • 需求 ID：UPLOAD-001
  • 接口/契约：docs/api/openapi.yaml、packages/contracts/openapi/v1.yaml
  • AI/工具控制文件：AGENTS.md

本次目标

  1. 移除 C 端头像专用上传接口。
  2. C 端、主播端和未登录客服附件统一使用 /api/v1/upload。
  3. 后台上传与新入口共用同一套 scene、MIME、大小和存储规则。

修改文件

文件 说明
services/go-app/internal/service/admin/upload.go 上传 service 增加 actor/action 入口，扩展 scene。
services/go-app/internal/http/public/upload.go 新增 C 端、主播端通用上传 handler。
services/go-app/internal/http/public/upload_test.go 覆盖 C 端和主播端上传。
services/go-app/internal/http/router/public.go 注册统一入口 /api/v1/upload。
services/go-app/internal/http/public/member.go 删除头像专用上传 handler。
services/go-app/internal/service/member/avatar_upload.go 删除头像专用上传 service。
docs/api/openapi.yaml 新增统一上传 userUpload，更新上传 schema。
packages/contracts/openapi/v1.yaml 同步契约。

核心决策

  1. C 端和主播端采用同一个 /api/v1/upload，通过 JWT sub_type 区分审计主体；未登录仅允许客服附件 scene=support。
  2. 后台仍位于 admin 服务命名空间内，前端相对路径仍是 /upload。
  3. 通用上传只返回 URL/key，不自动写用户头像、主播资料或客服业务字段。

工程规范

项目 内容

规范例外与原因 无

回滚 回滚本次 commit 即可；/api/v1/admin/upload 未删除

风险与待办

  1. C 端和主播端统一接 /api/v1/upload，未登录客服附件也接该接口但必须传 scene=support；后台继续用后台请求客户端的 /upload。
  2. 如后续支持视频/大文件，应新增 scene 和大小策略，不应直接放开当前图片接口。
