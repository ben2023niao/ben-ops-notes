一、来由

团队讨论后定下来的方向：不要在机器人里堆堡垒机相关的功能（"就是个堡垒机，不用搞这么多花里胡哨"、"一定要安全"）。改成：

  1. 堡垒机域名用 nginx 加访问密码（已做，见同目录另一篇记录）；
  2. 做一个运维工作台页面，把常用入口集中到一个 https 页面，团队成员收藏一个网址就够。

二、页面来源与改造

来源：团队原有的静态导航页 devops/work.youdianse.com（Bootstrap + jQuery，icons 数组定义按钮，双击打开）。

改造后的按钮（按本项目重写）：

管 堡垒机 https://manage.evercare.id 新窗口打开；需要再输一次 nginx 访问密码

改动：标题改成「BKL UAT 运维工作台」，加了一行使用提示；图标沿用原页面的内联 SVG 彩色圆点风格，没引入新依赖。

打开方式（openInNewWindow 字段，双击图标生效）：

打开方式 按钮 原因
内嵌面板（false） 监控、文档 双击后在工作台页面里弹一个可拖动/缩放的窗口，不跳走
新窗口（true） 堡垒机、运维机器人、报警群、Cloudflare 堡垒机要输访问密码 + 跳转，放新窗口体验更好（实测后定的）；Telegram 和 Cloudflare 是外部服务，发 X-Frame-Options 禁止被 iframe 嵌入，只能新窗口

其中监控（Beszel）原本也禁止内嵌（响应头 X-Frame-Options: SAMEORIGIN），在 nginx 里用 proxy_hide_header X-Frame-Options; 去掉后才允许（文档站的反代配置里也预先加了这一行）。堡垒机的响应头本来就不限制内嵌，改成新窗口是按使用体验定的。

项 值
文件夹 ID 1_jl0zo_lQahhZunI-rieO9UABs5dOZt0（2026-10-16 从上一个文件夹换过来）
内嵌地址（按钮用） https://drive.google.com/embeddedfolderview?id=<文件夹ID>#list
普通地址（浏览器打开） https://drive.google.com/drive/folders/<文件夹ID>

为什么不用普通链接：普通 Drive 链接返回 X-Frame-Options: SAMEORIGIN，iframe 会被浏览器拦；Google 专门提供了 embeddedfolderview 这个可内嵌的文件夹视图，所以按钮用它。

限制：内嵌视图要求浏览器里已登录有权限的 Google 账号（匿名请求会返回 401 登录页）。如果面板里显示登录提示或空白，直接用上面的普通地址打开即可。

原来指向的 Confluence 文档站（wendang.evercare.id）等 DNS 解析 + SVD 部署好之后，可以再单独加一个入口，两者不冲突。

三、代码位置

code/work-console-运维工作台页面/          # 工作台静态页面
├── index.html              # 按钮定义在这里（icons 数组）

服务器上对应 /opt/nginx/www/work/（nginx 容器挂载 ./www:/var/www）。

去掉了原目录里两个十几 M 的 README 预览 GIF，本地 1.5M。

四、部署步骤

  1. 上传静态文件到 /opt/nginx/www/work/。
  2. 新增 nginx 站点 conf.d/40-work.conf（HTTP 版先上，方便签证书）：静态根 /var/www/work + 与堡垒机同一套 Basic 认证 + ACME 路径免密。
  3. 签证书：certbot certonly --webroot -w /var/www -d work.evercare.id（DNS 已由 Mark 解析到 Cloudflare）。
  4. 换成带 443 的正式配置，nginx -t + reload。

五、验证结果

检查 结果
不带密码访问 https://work.evercare.id/ 401（带 www-authenticate: Basic realm="BKL UAT"）
带账号密码访问 200，页面标题 BKL UAT 运维工作台
6 个按钮链接 解析正确（见上表）
静态资源（css / js / 背景图 / 图标 / jquery） 全部 200
证书 Let's Encrypt 已签，写入 /opt/nginx/certs/live/work.evercare.id/，跟原有续期任务共用（certbot renew 覆盖全部证书）

六、踩的坑

  1. 配置没生效前会落到默认站点：刚开始测公网时返回 302 —— 因为 work.evercare.id 还没匹配到站点，落到 99-default.conf（跳转到堡垒机域名）。配置生效后再测就是 401/200，属于正常现象，别误判成配置错误。
  2. 证书要在 HTTP 配置下签：带 listen 443 ssl 的配置在证书不存在时 nginx -t 会失败，所以先上 HTTP 版、签完证书再切 443。
  3. Basic 认证要放行 ACME 路径：否则证书 90 天自动续期会失败（auth_basic off）。
  4. 用 cp 目录/* 同步会漏掉隐藏文件（这次是 .user.ini / .well-known，不影响），同步整目录更稳。

七、后续

  1. 文档域名（wendang）解析 + Confluence 部署完成后，「文档」按钮即可用，无需改页面（链接已写好）。
  2. 想加新入口：编辑 code/work-console-运维工作台页面/index.html 的 icons 数组，重新传 /opt/nginx/www/work/ 即可，不用动 nginx。
  3. 以后如果做「集中运维后台」（SVD 提的），可以把这个页面当成入口页，逐步把功能收进来。
