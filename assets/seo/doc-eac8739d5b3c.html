For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to execute this plan task-by-task.

Goal: P10 路线图选项 A —— 完成 A 档 5 项纯代码 + B 档 3 项本地桩。共 8 项工作,涵盖 P10 完整范围 80%,不依赖外部凭证(R2 / SES / Resend 等),不触发产品方向决策。

完成后 Ghome 在以下方面到位: - 视频/App 有真实 numeric 计数(views_count likes_count users_count),榜单按计数自动重排 - 每个 detail 页有动态 og:image(brand-hero gradient + 标题 + Ghome logo)+ JSON-LD 结构化数据 + Twitter Cards - Playwright E2E 覆盖关键流程(20+ 用例) - redirect 列表支持批量勾选 + 批量切 disabled,APK URL 加严校验(白名单域名) - i18n 脚手架就绪(next-intl,中文默认,英文/日文等留扩展点) - 视频封面图可在 admin 上传(本地 /public/uploads/videos/,生产换 R2 即可) - 联系页表单提交到 contact_submissions 表,admin 列表查看 + 状态管理

Architecture

  • 数据层一次性迁移:T1 一个手写 migration 加 3 处变更: 1. videos.views_count + videos.likes_count int(从 views_label likes_label 解析回填) 2. apps.users_count int(从 users_label 解析回填) 3. 新表 contact_submissions(id / email / name / subject / body / status enum / created_at / replied_at / replied_by)

  • 自动榜单重排:扩展 P7 已有的 aggregateClickEvents cron 任务,改名 runScheduledJobs,增加 recomputeRankings() 步骤 —— 按 numeric 列重排 collection_items 的 position(沿用 P1 的 DEFERRABLE UNIQUE 约束保证中间态)

  • og:image 用 @vercel/og:Edge runtime,SSR 时给每个 detail 路由暴露 opengraph-image.tsx(Next 15 约定)。SVG 渲染品牌 gradient + 大标题 + Ghome 字标。不接外部图片服务

  • JSON-LD:每个 detail 页加 <script type="application/ld+json">(server component 直渲),按 schema.org 类型:Article / VideoObject / SoftwareApplication / WebPage

  • Playwright:配 pnpm --filter @ghome/web add -D @playwright/test;新建 apps/web/e2e/;CI 加 playwright test --project=chromium 步骤

  • redirect 批量:/redirects 页加 client component <RedirectBulkBar> (checkbox 选区 + Disable/Enable 按钮);后端 PATCH /api/redirects/bulk 走 prisma.$transaction 批量 update

  • APK 加严:packages/db/src/lib/url-policy.ts 加可选选项 requireApk?: boolean,启用时检查 URL 末尾 .apk 或来自白名单(Google Play / App Store / Galaxy Store)

  • i18n 脚手架:next-intl v4,改 apps/web/app/[locale]/... 路由结构,默认 zh-CN,留 en / ja 占位空文件;不真实翻译,P11+ 决定语种再补译文

  • 视频封面上传:admin video 编辑器加 <input type="file" accept="image/*">;server action 写到 apps/web/public/uploads/videos/{slug}.{ext}(本地 dev 走文件系统);新增 videos.cover_image_url text? 字段;web VideoCard/VideoHero 优先用真实图,fallback 现有 coverKey gradient

  • APK URL 加严(无文件托管):redirect 编辑器在 validateForWrite(url, { requireApk: true }) 时强校验 — 不通过则 throw

  • 联系表单:/contact 表单 → server action → prisma.contactSubmission.create;admin 加 /contact-submissions 列表 + 详情页 + 状态切换(pending → read → replied → spam)。不发邮件,运营在 admin 看板处理

Tech Stack

新依赖: - @vercel/og ^0.6 (web) - next-intl ^4 (web) - @playwright/test ^1.49 (web devDep) - negotiator + @formatjs/intl-localematcher (web,i18n locale 协商)

不新增任何后端服务 / 邮件 / 对象存储依赖。

Conventions

  • migrations 一次性:T1 一个 migration 包含 3 处变更(添加列 + 添加表),手写 SQL 避开 Prisma 自动 drop 生成列的坑(P1/P7/P9 都踩过)
  • Auto-rank 仅重排现有 6 条 ranking collections,不新建:沿用 P1/P9 seed 时已落地的 weekly-hot-videos 等 slug
  • og:image runtime = "edge":Next.js 限制(@vercel/og 只在 edge 跑)
  • JSON-LD 渲染时机:server component,<script> 直接写在 page 顶部
  • i18n 默认 locale = zh-CN;URL 不带前缀(/ 默认 zh-CN,/en/... 才显示英文 — 等真有翻译再启用)
  • 视频封面上传文件路径:/uploads/videos/{slug}.{ext};数据库存 URL 路径 /uploads/videos/abc.jpg(相对路径,生产换 R2 时只改 lib/upload.ts)
  • contact_submissions 是 admin 独占资源,不暴露给 web
  • APK 加严策略:白名单域名(apps.apple.com play.google.com samsung.com huawei.com)+ 拒绝 raw .apk 链接(避免被引导托管)
  • Playwright 测试在 dev 跑:测试时启动 next dev + Postgres,不依赖 prod build。CI 用 service container
  • 提交风格:Conventional Commits;每 task commit。permission 阻塞→DONE_WITH_CONCERNS

Task 1 — 数据基建:迁移 + seed 回填

Files: - Modify: packages/db/prisma/schema.prisma - Create: packages/db/prisma/migrations/20260511010000_p10a_extensions/migration.sql - Modify: packages/db/seed/data/videos.ts + apps.ts(parseLabelNumber + 写入 numeric) - Modify: packages/db/prisma/seed.ts

改动

  1. schema.prisma: ```prisma model Video { // ... existing viewsCount Int @default(0) @map("views_count") likesCount Int @default(0) @map("likes_count") coverImageUrl String? @map("cover_image_url") // T4 用 } model App { // ... existing usersCount Int @default(0) @map("users_count") } model ContactSubmission { id String @id @default(uuid()) @db.Uuid email String name String? subject String body String // markdown ok status ContactSubmissionStatus @default(pending) createdAt DateTime @default(now()) @map("created_at") @db.Timestamptz(6) repliedAt DateTime? @map("replied_at") @db.Timestamptz(6) repliedBy String? @map("replied_by") @db.Uuid // 关联 admin_users adminUser AdminUser? @relation(fields: [repliedBy], references: [id])

    @@index([status, createdAt(sort: Desc)]) @@map("contact_submissions") } enum ContactSubmissionStatus { pending read replied spam } ```

  2. migration.sql(手写): ```sql ALTER TABLE "videos" ADD COLUMN "views_count" INT NOT NULL DEFAULT 0; ALTER TABLE "videos" ADD COLUMN "likes_count" INT NOT NULL DEFAULT 0; ALTER TABLE "videos" ADD COLUMN "cover_image_url" TEXT; ALTER TABLE "apps" ADD COLUMN "users_count" INT NOT NULL DEFAULT 0;

CREATE TYPE "ContactSubmissionStatus" AS ENUM ('pending', 'read', 'replied', 'spam');

CREATE TABLE "contact_submissions" ( "id" UUID PRIMARY KEY DEFAULT gen_random_uuid(), "email" TEXT NOT NULL, "name" TEXT, "subject" TEXT NOT NULL, "body" TEXT NOT NULL, "status" "ContactSubmissionStatus" NOT NULL DEFAULT 'pending', "created_at" TIMESTAMPTZ(6) NOT NULL DEFAULT now(), "replied_at" TIMESTAMPTZ(6), "replied_by" UUID REFERENCES "admin_users"("id") ); CREATE INDEX "idx_cs_status_created" ON "contact_submissions"("status", "created_at" DESC); ```

  1. seed.ts:在 videos.upsert 和 apps.upsert 中加 numeric 字段,从 views_label likes_label users_label 用 parseLabelNumber(P9.5 T1 已有同名 helper,可复用或共享到 seed/helpers/parse-label.ts)

Steps

  1. 改 schema + 写 migration
  2. 跑 migrate:pnpm --filter @ghome/db db:migrate:deploy
  3. 改 seed → 跑 pnpm --filter @ghome/db db:seed
  4. 验证:docker exec ghome-postgres psql -U ghome -d ghome -c "SELECT slug, views_count, likes_count FROM videos LIMIT 3;"(应非零)
  5. typecheck + commit

Tricky Bits

  • 不要让 Prisma 自动生成 migration(会 drop category_kind 生成列)
  • gen_random_uuid() 需要 pgcrypto,Postgres 16 默认有
  • seed 是 idempotent upsert,跑两次结果一致
  • parseLabelNumber 与 P9.5 T1 重复,抽到 packages/db/seed/helpers/parse-label.ts 共享

Task 2 — Auto-rank cron 扩展

Files: - Modify: packages/db/src/lib/click-aggregate.ts → 改名 scheduled-jobs.ts,加 recomputeRankings() - Modify: apps/admin/app/api/cron/aggregate-clicks/route.ts → 调用新 wrapper(或新建 /api/cron/run/route.ts)

Steps

  1. 抽 recomputeRankings(prisma):对 6 条 ranking collections 各自重新计算 items 顺序: - weekly-hot-videos / latest-videos / top-liked-videos:按 views_count desc / published_date desc / likes_count desc 分别重排前 8 条 video items - weekly-hot-apps / top-rated-apps:按 users_count desc / rating desc 重排前 8 条 app items - hot-tags:按各 tag 关联 video 数 desc 重排前 10 条 tag items - 用 prisma.$transaction + DEFERRABLE UNIQUE 约束允许中间态冲突
  2. 新 export runScheduledJobs(prisma) = aggregateClickEvents + recomputeRankings
  3. cron route 调 runScheduledJobs
  4. 测试:跑一次 → 看 ranking_items.position 重排
  5. commit

Tricky Bits

  • 6 条 ranking 每条 items 数量不同,要先 deleteMany({ collectionId: r.id }) 再 batch create —— 比 in-place update 简单
  • DEFERRABLE INITIALLY DEFERRED 约束确保事务内 position 重排不冲突
  • 不动 aggregateClickEvents 的现有逻辑(advisory lock 仍生效)

Task 3 — Redirect 批量 + APK URL 加严

Files: - Create: apps/admin/components/RedirectBulkBar.tsx (client) - Modify: apps/admin/app/(admin)/redirects/page.tsx(加 checkbox 列 + bulk bar) - Create: apps/admin/app/api/redirects/bulk/route.ts - Modify: packages/db/src/lib/url-policy.ts (加 requireApkSafe 选项)

Steps

  1. URL 校验加严: ts // url-policy.ts const APK_SAFE_HOSTS = new Set([ "apps.apple.com", "play.google.com", "galaxy.store", // Samsung "appgallery.huawei.com", // Huawei "www.apple.com", ]); export async function validateForWrite(url, opts = {}) { // ... existing checks if (opts.requireApkSafe) { const u = new URL(url); if (!APK_SAFE_HOSTS.has(u.hostname)) { return { ok: false, reason: `host '${u.hostname}' 不在 APK 白名单。仅允许官方应用商店。` }; } } return { ok: true }; }
  2. RedirectBulkBar:勾选状态用 useState<Set<string>>,顶部 toolbar 显示选中数 + 「批量启用 / 批量禁用」按钮

Task 4 — 视频封面图上传(本地桩)

Steps

  1. lib/upload.ts:saveImageToLocal(file: File, slug: string): Promise<string>,返回 URL 路径 - 验证:文件类型 image/*,大小 ≤ 5MB,扩展名 jpg/png/webp - 写到 apps/web/public/uploads/videos/{slug}.{ext}
