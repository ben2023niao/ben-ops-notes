一、结论

核对开始时，新游戏在 open_game_list 中已经齐全，但域名分组没有完整登记：

PP：0/3 显式登记
vendor_a：4/12 显式登记，缺 8 款
G759：0/18 个唯一 ID 显式登记

完成修复后：

巴西：PP 3/3，vendor_a 12/12，G759 18/18
香港：PP 3/3，vendor_a 12/12，G759 18/18
六台 API 容器：open_game_list 与 GameDomainManager 全部通过

五、双层校验

scripts/validate_domains.py 新增 20261105 批次门禁：

  1. 检查 ID 是否在 platform-api/configs.py 的 open_game_list；
  2. 检查 ID 是否位于正确域名分组；
  3. 对巴西、香港两套目录同时执行；
  4. 6144 按唯一 ID 校验，不因通知重复而重复写入。
