本次目标

  3. 不恢复任何等级特权；后台隐藏竞猜活动菜单入口。

核心决策

  1. 新增 user_level_configs，不复用历史 level_configs 的 privilege / limit / chat color 字段。
  2. 等级只表示升级门槛，不影响 C 端权限、限额、颜色、进场、排序或投注。
  3. 礼物 effect_type 先固定为 1-5 枚举，避免提前绑定具体动画实现。
