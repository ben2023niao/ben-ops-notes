背景

新增服务器 162.211.181.13，用于测试环境腾讯 CDN 回源和前端备案域名反向代理。 用户已确认备案域名迁移到该新服务器，本文同步更新为迁移后的运行事实。

本次只处理测试环境，不触碰正式环境。用户提供的 SSH 密码只用于当前操作，不写入 Git、workbench、docs、通知或最终回复。

新服务器核验

公网 IP：162.211.181.13
hostname：youdianse-test-cdn-proxy
系统：Ubuntu 24.04.1 LTS
Nginx：1.24.0
Docker：29.1.3
docker-compose：1.29.2
服务状态：nginx active，docker active
监听端口：80、22

首次安装时，docker-compose-plugin 在当前 Ubuntu 源不可用，因此改用 docker-compose 包安装。

Nginx 配置

配置文件：

/etc/nginx/conf.d/youdianse-test-record-domains.conf

当前是 HTTP 回源/反代配置：

test-h5.* -> 38.92.8.34:3003
test-pc.* -> 38.92.8.34:3004
/(api|channel|customer) -> 38.92.8.34:8088
test-h5-s3.hbabaxb.cn -> AWS S3 H5 静态桶
test-pc-s3.hbabaxb.cn -> AWS S3 PC 静态桶
test-img.* /uploads/ 带 token/t -> CloudFront uploads
test-img.* /uploads/ 缺 token/t -> 固定占位图

域名配置明细：

域名 新 Nginx 规则 上游
test-h5.hbabaxb.cn H5 页面；API 路径分流到后端 页面 38.92.8.34:3003，API 38.92.8.34:8088
test-h5.hbazuua.cn H5 页面；API 路径分流到后端 页面 38.92.8.34:3003，API 38.92.8.34:8088
test-pc.hbabaxb.cn PC 页面；API 路径分流到后端 页面 38.92.8.34:3004，API 38.92.8.34:8088
test-pc.hbazuua.cn PC 页面；API 路径分流到后端 页面 38.92.8.34:3004，API 38.92.8.34:8088
test-h5-s3.hbabaxb.cn H5 静态资源代理 AWS S3 H5 静态桶
test-pc-s3.hbabaxb.cn PC 静态资源代理 AWS S3 PC 静态桶
test-img.hbabaxb.cn /uploads/ 必须带 token/t；裸链固定图 CloudFront uploads / 固定图
test-img.hbazuua.cn /uploads/ 必须带 token/t；裸链固定图 CloudFront uploads / 固定图

HTTPS 说明：

当前新服务器未配置 443 证书。
域名由 EdgeOne/CDN 接入，HTTPS 在 EdgeOne/CDN 终止，回源到 162.211.181.13:80。
不要把 EdgeOne/CDN 回源协议设置为 HTTPS，除非后续给新服务器补 443 证书。

使用 curl --resolve 临时将域名指向 162.211.181.13，未修改 DNS，未影响当前入口。

当前结论

162.211.181.13 / youdianse-test-cdn-proxy 作为备案域名 HTTP 回源/反代服务器。
页面、前端静态资源、uploads 裸链固定图、uploads 签名原图、页面输出 token/t 均正常。
旧测试服务器 38.92.8.34 继续作为 H5/PC/API/后端业务服务源站。
旧测试服务器上的备案域名配置是否清理，需等多地公网验证和新服务器 access log 命中稳定后再执行。

18game运维 群状态

用户要求新增 18game运维 群接收所有操作通知。

当前结果：

18game运维 群已加入测试服务器 runtime 通知配置。
当前 runtime secrets 可解析 2 个群。
步骤 60-80 的关键文字通知和相关文档附件已补发到 18game运维 群。

后续处理：

后续测试环境操作继续复用测试服务器 runtime secrets 发送通知。
默认同时覆盖原运维监控报警群和 18game运维 群。
不要在文档、日志或最终回复中输出 token/chat_id。

后续动作

1. 从多地公网 HTTPS 重新验证 H5/PC/静态/uploads。
2. 使用唯一 no_cache 参数访问，并在 youdianse-test-cdn-proxy 的 /var/log/nginx/*.record.access.log 中确认命中。
3. 确认稳定后，再按用户明确指令备份并清理旧测试服务器备案域名配置。
