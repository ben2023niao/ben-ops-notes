同步过程

工作目录：

/root/bizops-hk-client-update-20260729-vendor_d

同步命令：

AWS_PROFILE=bizops-hk /usr/local/bin/bizops-sync-gcs-to-s3 vendor_d-static

同步结果：

sync_start source=gs://bizops-gcs-vendor_d-static destination=s3://bizops-h5-hk-517506432530/vendor_d-static
marker_scan_complete prefix=vendor_d-static markers=51 changed=0
sync_verify prefix=vendor_d-static source_count=79232 destination_count=79283 adjusted_destination_count=79232 source_bytes=1349189083 destination_bytes=1409567144 adjusted_destination_bytes=1349189083 marker_count=51 marker_bytes=60378061
sync_complete prefix=vendor_d-static

说明：

  • destination_count 比源端多 51，是目录入口 marker 对象。
  • adjusted_destination_count 与 source_count 一致。
  • adjusted_destination_bytes 与 source_bytes 一致。
  • 本次未使用 --delete，不会删除香港 S3 已有额外对象。
