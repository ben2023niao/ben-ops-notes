uiautomator2 自动化封装

uiautomator2 自动化封装。本文属于DevOps 与 SRE / 高效运维，u2 现在google 官方使用的是apk的形式来实现的，有大神封装了python来实现u2的功能的使用。 github 的地址： https://github.com/openatx/uiautomator2 可以具体的了解相…

发布于 2023-04-14 作者 BEN 5,683 字 17 分钟阅读

u2 现在google 官方使用的是apk的形式来实现的，有大神封装了python来实现u2的功能的使用。 github 的地址：https://github.com/openatx/uiautomator2 可以具体的了解相关的功能和实现的原理，

一、uiautomator2是什么？有什么作用？ 1、实现安卓系统自动化测试的工具，让手机可以自动点击相关元素，坐标点。或者手机的相关元素的信息，来判断操作过程有没有异常出现 2、如果是针对于单个app 来说的，在app相对于稳定的ui情况下，可以做一些压测。以及一些变动比较少的UI 页面检查 3、如果是用于安卓系统的自动化测试的话（UI层面），可以在一些系统常用的场景，以及一些第三方应用场景，系统应用的压力测试等（非monkey） 4、对于一些高频，繁琐的操作，可以使用自动化来实现。 二、使用步骤 1.引入库 安装库： pip install --upgrade --pre uiautomator2 1 安装元素查看工具 或者ui页面的元素信息，可以使用weditor，（大致的原理是adb dump 当前tree为xml 文件在读取出来，显示在web 页面。元素的点击应该是基于元素坐标来点击）

如果按照出错的话，可以尝试 git clone https://github.com/openatx/weditor 然后在 安装 pip install -e weditor

pip3 install --pre weditor

python -m uiautomator2 init

python -m weditor

然后会自动打开浏览器（建议安装chrome 浏览器），如下图： 点击页面的元素，就可以具体的查看该元素的信息。然后通过该元素的信息来做相对应的操作

2.开始使用U2 python

（1）连接设备

多种设备的连接方式，当然 usb 调试方式是最稳定的，根据自己的需求选择连接的方式

import uiautomator2 as u2
# 一个设备的情况下，默认连接
d = u2.connect()
print(d.info)
# 多个设备
d = u2.connect('device_id')
# 通过wifi 连接的话，电脑同设备在同一个网络里面
d = u2.connect('wifi ip ')
# 1、先adb tcpip 5555 设置断开
# 2、adb connect 203.0.113.1:5555 (设备的ip地址加上端口)
# 3、这个时候可以断开
d = u2.connect_adb_wifi('203.0.113.1:5555')

return self.driver.find_element_by_id(selector)

selector_value = selector.split(",")[1]

elif selector_by == "t" or selector_by == "text":
element_txt = "text={}".format("'" + selector_value + "'")
elif selector_by == "x" or selector_by == "xpath":
element_txt = selector_value
elif selector_by == "c" or selector_by == "className":
element_txt = "className={}".format('"' + selector_value + '"')
elif selector_by == "d" or selector_by == "description":
element_txt = "description={}".format("'" + selector_value + "'")
else:
self.logger.save_log("auto_d:{}".format("没有返回到元素文本_" + selector))
return element_txt
