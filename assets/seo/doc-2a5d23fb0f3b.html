本次目标

  1. 在管理员账号列表为 super_admin 增加修改管理员密码入口。
  2. 后端提供管理员密码修改接口，写入 bcrypt 哈希并撤销目标管理员旧 token。
  3. 同步 OpenAPI / contracts，并补充测试和工作日志。

数据链路

入口页面：apps/admin/src/views/admins/list.vue 管理员账号列表 API：PUT /api/v1/admin/admins/{id}/password DTO：dto.AdminAccountPasswordUpdateRequest Service：AdminAccountService.UpdatePassword 数据表 / Redis：admins.password_hash、admin:revoked_before:{id} 返回字段：空成功响应 前端消费字段：不新增列表返回字段，仅新增请求体 password

核心决策

  1. 仅 super_admin 可修改管理员密码，沿用管理员账号管理权限边界。
  2. 改密成功后写 admin:revoked_before:{id}，目标管理员旧 token 立即失效。
  3. DB 更新和 Redis 撤销写入放在同一 service 事务流程内；Redis 不可用时回滚 DB 更新并返回依赖错误。
