三、监控改造内容（critical_restart_watch.py v3）

1. 取消调试期静默：/opt/dbqp-hk-ops/container-watch.env 里 DBQP_MONITOR_MAX_ALERTS 3 → **0（不限）**，
   并删除容器监控静默文件 —— 与巴西生产口径一致：**任何变化都发群**。
2. 全量容器清单比对（新增能力）：每分钟不仅看 9 个厂家容器，还把两台**所有容器**
   （含 beszel-agent、以及任何新出现的容器）做快照比对，命中任一项立即报警：
     ➕ 新增容器（名、镜像、状态、端口）
     ➖ 容器消失（业务容器由厂家检查负责，非业务容器由清单检查负责，避免重复）
     🔄 镜像/版本变化（例如 20261003-ben → 20261005-ben，等价于发版信号）
     🔀 端口映射变化 ｜ ⚙️ 重启策略变化 ｜ 🔁 状态/重启次数变化（非业务容器）
3. 发版窗口内的变化也逐批通知：原来同一窗口只发一条（后续变化只写日志），
   现在按批次内容签名去重 —— 内容变了就再发一条，保证「有变化就有通知」。
4. 宿主机负载预警：load1 > 1.5 × CPU 核数（新增），内存（默认 3000MB）、根盘（默认 85%）保留。
5. 修复误报：发布动作检测正则原为 `[r]sync|…|[s]ync`，其中 `[r]sync` 文本本身含 "sync"，
   pgrep -f 会匹配到携带该模式串的命令行自身 → 每轮都误判「发版窗口」，导致报警被标成预期变化。
   已改为全括号写法 `[r][s]ync|[s][t]art\.sh|[s][t]op\.sh|[b]uild\.sh|[s][y][n]c`
   （既能匹配 rsync/start.sh/stop.sh/build.sh/sync，又不会自匹配）。
6. 保留：重启循环标注 + 容器最近 3 行日志、SSH 重试 + 连续 2 轮失败才报、持续告警冷却 30 分钟、
   --baseline / --show / --dry-run / --reset-alerts、日志 4MB 轮转。

四、部署与验证

部署（prod-01 34.92.83.132）
  · 脚本 /opt/dbqp-scripts/critical_restart_watch.py（v3）
  · env /opt/dbqp-hk-ops/container-watch.env：MAX_ALERTS=0（备份 container-watch.env.bak-20261005）
  · 静默文件 /opt/dbqp-hk-ops/container-monitor-quiet 已删除
  · systemd dbqp-container-watch.timer 每分钟一次，active

验证
  · 桩数据自测：新增容器 / 容器消失 / 镜像版本变化 三类都能识别并生成告警文案
  · 发版动作检测：修正后空闲时不再误判（meta 里不再出现 last_release_ts）
  · 基线重铺：18 个厂家容器 + 两台全量清单（inv:203.0.113.1 / inv:203.0.113.1，各 10 个容器）+ load 键
  · 正常巡检一轮：心跳「18 个厂家容器，18 个 running，本轮无新增异常」，无告警
  · --dry-run：alerts=0 recovers=0
  · 容器快照：18 个容器全部 running、端口监听，uptime 1 天 17~18 小时

五、日常使用

set -a; . /opt/dbqp-hk-ops/container-watch.env; set +a
python3 /opt/dbqp-scripts/critical_restart_watch.py --show         # 容器快照
python3 /opt/dbqp-scripts/critical_restart_watch.py --dry-run      # 只检查不写状态不发群
python3 /opt/dbqp-scripts/critical_restart_watch.py --baseline     # 变更后重铺基线（不发告警）
python3 /opt/dbqp-scripts/critical_restart_watch.py --reset-alerts # 复位告警计数（当前不限条数，一般用不到）
journalctl -u dbqp-container-watch.service -n 50 ; tail -f /var/log/dbqp-hk-restart-watch.log

# 如果某段时间不想收告警（例如大改版维护窗口）：
touch /opt/dbqp-hk-ops/container-monitor-quiet && rm /opt/dbqp-hk-ops/container-monitor-quiet
