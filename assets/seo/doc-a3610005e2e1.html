附带发现与修复：nginx 证书 map 回归（16.208.38.88）

现象

发布验证时发现公网 https://h5.yds-pc-h5-01.cc 返回证书 CN=youdianse.com（SAN 不匹配，curl 报 SSL 证书错误），而目标机本机 3003 内容正确。

根因

  • 16.208.38.88 nginx 统一入口 20-youdianse-prod-unified.conf 的 ssl_certificate 使用变量 $youdianse_cert_dir。
  • 10-youdianse-prod-maps.conf 中 map $ssl_server_name $youdianse_cert_dir 只剩 default /etc/letsencrypt/live/www.youdianse.com，无按 SNI 的映射条目（8-20 现场改动引入，8-27 域名维护重写后仍未修复）。
  • 后果：所有非 youdianse.com 域名（含 yds-pc-h5-01.cc、118acs2.com、18game.app、taokju.com、shouyek.com、ydsgames.com 等）的 HTTPS 都错误返回 www.youdianse.com 证书，SAN 不匹配。
  • 本次发布本身不受影响，但线上 HTTPS 访问存在证书错误风险。

修复

  • 备份：/root/.codex-backup/10-youdianse-prod-maps.conf.bak-fix-certmap-20260901085608。
  • 修复 $youdianse_cert_dir map：按 SNI 选择 live/<sni>/，保留无 SNI 时回退 www.youdianse.com。
  • nginx -t 通过，systemctl reload nginx 成功。
  • 验证：
  • h5/pc.yds-pc-h5-01.cc → CN=yds-pc-h5-01.cc（SAN 含 h5/pc/www/根域）
  • www.youdianse.com → CN=youdianse.com（SAN 含 *.youdianse.com）
  • 抽查 118acs2.com / 18game.app / taokju.com / shouyek.com / ydsgames.com 均返回各自正确证书，公网 HTTPS 200。
  • 建议：后续域名维护/nginx 变更后增加证书 SAN 抽查，避免同类回归。
