背景

Jay 反馈 PP 两个子游戏缺少巴西语音资源，资源包已下载到本地 MacBook：

/Users/ben/Downloads/vs10forwildly.zip
/Users/ben/Downloads/vs5luckymly.zip

目标静态路径：

gs2c/common/v5/games-html5/games/vs/

同时开发要求把昨天新增的数据库公网入口 3306、3309 从全开放收敛为只允许两个外网 IP：

56.125.151.37    后台系统
47.244.103.104   多租户测试服

说明：pp-test.bxgjnet.com 是测试环境参考域名；本次资源最终按线上实际 PP 静态链路处理，发布到线上 pp-static.* 使用的 GCS live/backup 和 Google Cloud CDN。

数据库公网白名单收敛

变更前 GCP 防火墙：

mysql-3306          tcp:3306  sourceRanges=0.0.0.0/0
mysql-replica-3309  tcp:3309  sourceRanges=0.0.0.0/0

变更后 GCP 防火墙：

mysql-3306          tcp:3306  sourceRanges=56.125.151.37/32,47.244.103.104/32
mysql-replica-3309  tcp:3309  sourceRanges=56.125.151.37/32,47.244.103.104/32

验证命令读回结果：

mysql-3306          tcp:3306  56.125.151.37/32,47.244.103.104/32  False
mysql-replica-3309  tcp:3309  56.125.151.37/32,47.244.103.104/32  False

结论：3306 主库入口和 3309 副本库入口均已移除 0.0.0.0/0，只保留开发确认的两个公网来源 IP。

回滚

静态资源回滚

本次只新增 4 个文件，如需回滚可删除：

rm -f /www/wwwroot/pp-static/gs2c/common/v5/games-html5/games/vs/vs10forwildly/desktop/game/soundspt.ogg.json
rm -f /www/wwwroot/pp-static/gs2c/common/v5/games-html5/games/vs/vs10forwildly/mobile/game/soundspt.ogg.json
rm -f /www/wwwroot/pp-static/gs2c/common/v5/games-html5/games/vs/vs5luckymly/desktop/game/soundspt.ogg.json
rm -f /www/wwwroot/pp-static/gs2c/common/v5/games-html5/games/vs/vs5luckymly/mobile/game/soundspt.ogg.json

也可从备份目录恢复整个子游戏目录：

cp -a /www/server/ops/pp-vs10forwildly-20260725/backup-before-sync/vs10forwildly-20260725-1055 /www/wwwroot/pp-static/gs2c/common/v5/games-html5/games/vs/vs10forwildly
cp -a /www/server/ops/pp-vs5luckymly-20260725/backup-before-sync/vs5luckymly-20260725-1058 /www/wwwroot/pp-static/gs2c/common/v5/games-html5/games/vs/vs5luckymly

回滚后需要同步 GCS live/backup，并再次刷新对应 CDN 路径。

数据库白名单回滚

如需临时恢复全开放：

gcloud compute firewall-rules update mysql-3306 --source-ranges=0.0.0.0/0 --quiet
gcloud compute firewall-rules update mysql-replica-3309 --source-ranges=0.0.0.0/0 --quiet

不建议长期恢复全开放；如后续还有新增访问方，优先追加 /32 固定出口 IP。
