汇总结论

本记录通过 Google Cloud gcloud 和六台服务器 SSH 实时采集生成。

  • Google Cloud 项目：infra-alc-20260511
  • 巴西：3 台，合计 18 vCPU、68GB 内存、1500GB 系统盘。
  • 香港：3 台，合计 18 vCPU、68GB 内存、1500GB 系统盘。
  • 两地合计：6 台、36 vCPU、136GB 内存、3000GB 系统盘。
  • 六台实例当前状态均为 RUNNING。
  • 巴西继续承载现网；香港独立环境不影响巴西流量。

巴西环境

区域：southamerica-east1

VPC：bizops-saopaulo-slotsapi-network-v2

子网：bizops-saopaulo-slotsapi-network-v2 / 192.0.2.1/20

路由模式：REGIONAL

角色 hostname 可用区 规格 CPU/内存 内网 IP 公网 IP 系统盘 根分区使用
入口/Nginx/资源源站 bizops-saopaulo-game-results-data-bt southamerica-east1-a e2-medium 2 vCPU / 4GB 192.0.2.1 192.0.2.8 500GB pd-balanced 220GB / 485GB，46%
后端 01 bizops-saopaulo-sanic-prod-01 southamerica-east1-a e2-standard-8 8 vCPU / 32GB 192.0.2.1 192.0.2.10 500GB pd-ssd 260GB / 484GB，54%
后端 02 bizops-saopaulo-sanic-prod-02 southamerica-east1-a e2-standard-8 8 vCPU / 32GB 192.0.2.1 192.0.2.11 500GB pd-standard 254GB / 484GB，53%

系统：入口机为 Ubuntu 22.04 LTS；两台后端为 Ubuntu Minimal 26.04 LTS。

香港环境

区域：asia-east2

VPC：bizops-hongkong-slotsapi-network-v2

子网：bizops-hongkong-slotsapi-subnet-v2 / 192.0.2.1/20

路由模式：REGIONAL

角色 hostname 可用区 规格 CPU/内存 内网 IP 公网 IP 系统盘 根分区使用
入口/Nginx/资源源站 bizops-hongkong-game-results-data-bt asia-east2-a e2-medium 2 vCPU / 4GB 192.0.2.1 192.0.2.14 500GB pd-balanced 5.9GB / 485GB，2%
后端 01 bizops-hongkong-sanic-prod-01 asia-east2-b e2-standard-8 8 vCPU / 32GB 192.0.2.1 192.0.2.16 500GB pd-balanced 2.6GB / 484GB，1%
后端 02 bizops-hongkong-sanic-prod-02 asia-east2-c e2-standard-8 8 vCPU / 32GB 192.0.2.1 192.0.2.17 500GB pd-balanced 2.6GB / 484GB，1%

系统：入口机为 Ubuntu 22.04 LTS；两台后端为 Ubuntu Minimal 26.04 LTS。

香港三台服务器已配置 root SSH 公钥和密码登录；密码继续使用现有 PGSERVER_DEPLOY_PASS，文档不保存明文。

香港当前建设状态

  • 入口机只安装 Docker、Docker Compose、Nginx 和同步工具，没有安装宝塔。
  • 两台后端只安装 SSH、Docker、Docker Compose 和发布必需工具，当前业务容器数为 0。
  • 香港 Nginx /healthz 公网检查返回 200 ok。
  • 香港三台 beszel-agent 均为 running，重启策略为 unless-stopped，公网 TCP 45876 实测连通。
  • 香港结果资源一次性后台同步正在运行：bizops-hk-results-bootstrap.service。
  • 静态资源继续复用 Google HTTPS Load Balancer、Cloud CDN 和 GCS 全球链路。
  • 远程 cn 分支尚未创建，因此香港业务代码、容器、域名和正式 Nginx upstream 尚未部署。
  • 未修改数据库、Redis、巴西 DNS 和巴西现网流量。

网络隔离说明

  • 巴西和香港分别使用独立自定义 VPC 与独立 /20 子网。
  • 香港入口到后端业务端口只允许来源 192.0.2.1 访问 TCP 8765、9090-9104。
  • Beszel 使用规则 bizops-hk-allow-beszel-agent 对带 hk-baota、hk-backend 标签的三台香港实例放行 TCP 45876。
  • 香港没有复制巴西网络中面向公网的 MySQL、Redis、Docker API 和大范围游戏端口规则。
  • 当前六台服务器 SSH 端口均可用于堡垒机接入；堡垒机录入完成后可进一步收紧公网 SSH 来源地址。
