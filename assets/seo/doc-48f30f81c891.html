清理明细

middleware

  • Docker build cache：5.393G → 150.9M
  • journal：253M → 75M
  • apt cache：已清
  • 磁盘：83% → 78%
  • 未删除 tagged images（10.68G）和 Jenkins 备份/workspace

堡垒机

  • Docker build cache：2.649G → 534M
  • journal：225M → 97M
  • 磁盘：27% → 24%

manager / worker01 / worker02

  • journal：267M/350M/288M → 97M/68M/60M
  • build cache 均为 0
  • 只清 dangling images，没有删除运行容器或 tagged images

项目 大小 原因
