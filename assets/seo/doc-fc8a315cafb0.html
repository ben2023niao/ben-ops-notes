整理日期：2026-08-31 16:30｜日期依据：文件名日期

一、背景

  • 群内反馈：“修改完了 env 咋没自动更新配置”（@melo_sre / @Kermit-ops），Vesperd 之前也遇到过同类现象。
  • 后端发布需求（@波特）：平台 youdianse / 正式环境 / git id c444b6c82b3cfc069df624d0671c94a694ea5357（main）
  • 新增腾讯 CDN 域名（eep-apking.zkifae.cn / eepk-apking.zkifae.cn）
  • 批量站内信发送支持用户名和用户 ID
  • 需求附带新增 .env 配置两段（[cdn.tencent.eep-apking.zkifae.cn]、[cdn.tencent.eepk-apking.zkifae.cn]）

二、根因（只读核验，2026-08-31 16:00-16:20）

  1. 新腾讯 CDN env 段根本没写进发布源文件 - 宿主机发布源 /opt/docker-youdianse-php/env/.env.prod（mtime 2026-08-20）只有 5 段旧 cdn.tencent，缺少需求里的两段新配置。 - web / cron 容器内 /var/www/html/youdianse-php/.env 与宿主机一致，同样缺失。 - 结论：不是“改了没生效”，而是“改的位置不对 / 没写进发布源”，发布自然不带新配置。
  2. 服务器运维仓库自动 pull 被跳过 - /opt/docker-youdianse-php 工作区有未提交改动（env/.env.prod、nginx/default.conf、php/dev.ini、cicd-web/core.py、docker-compose.yml、ops 脚本等）。 - cicd-web-auto-update.py 每分钟因“工作区有未提交改动，跳过自动 pull”而停止拉取，导致即使有人在 GitLab 改了 env 也同步不下来。
  3. 当天 3 次 c444b6c 发布尝试均未生效 - CICD 日志 16:00:20 / 16:01:55 / 16:13:47 三次记录均停在“CICD 配置校验”之后；无发布锁、无新镜像。 - web/cron 仍运行 08-27 的 youdianse-php:main-1aff98b78dca（Up 15h）。 - 疑似网页会话不可用（历史上同款 web-session-lost）导致 PyWebIO 确认流程中断。
  4. 发布源确认：main 分支发布读取 env/.env.prod（无 .env.main），改该文件即可生效。

三、处理（C1/P2，逐步通知线上群）

  1. 备份：env/.env.prod.bak.20260831-162123
  2. 补齐 env：在 env/.env.prod 追加需求两段（格式与现有段一致，key 值只写服务器文件）： - [cdn.tencent.eep-apking.zkifae.cn] - [cdn.tencent.eepk-apking.zkifae.cn] - 校验后共 7 段 cdn.tencent，原有 5 段与 pay.callback 等本地改动保持不动。
  3. 确认生效机制：env 为 bind mount（env/.env.prod → /var/www/html/youdianse-php/.env），宿主机文件修改后容器内立即可见，无需单独同步。
  4. 正式发布：CLI 发布（绕过 UI 会话确认）： cicd-web.py deploy --branch main --git-id c444b6c82b3cfc069df624d0671c94a694ea5357 --with-cron - 构建镜像 youdianse-php:main-c444b6c82b3c 成功 - web / nginx / cron 重建启动，全部 running

四、验证

  • 镜像/容器：web、nginx、cron = youdianse-php:main-c444b6c82b3c，main，dirty=false
  • 健康检查：HTTP /admin1866/login 200、Session writable、Redis open 1ms、MongoDB open 0ms、bigDataJob 队列守护 ok
  • env 生效：web 容器 .env 内 7 段 cdn.tencent，含新增 eep-apking / eepk-apking（key 不落文档）
  • 公网：https://admin.youdianse-main.xyz/admin1866/login → 200（0.19s）

五、遗留与建议

  1. 运维仓库工作区清理：/opt/docker-youdianse-php 未提交改动需由 Ben 统一梳理后提交/推送，恢复自动 pull（否则 GitLab 侧 env/nginx/php 变更无法自动同步到服务器）。
  2. CICD UI 发布卡住：今天 3 次网页发布停在配置校验（疑似网页会话不可用）；可优先使用 CLI 发布，或由操作人在 UI 重新确认。
  3. 功能复测：批量站内信用户名/用户 ID、新增腾讯 CDN 域名（eep-apking / eepk-apking）由开发/测试复测。
  4. env 提交：本次 env 变更（新增两段 + 原有 pay.callback 未提交改动）尚未提交服务器运维仓库，后续随工作区清理一并处理。

六、敏感信息

  • 文档/群通知未写入 key 值、token、密码、私钥、完整连接串；仅记录配置段名与路径。
