4. 后端 CICD（cicd-web）迁移

4.1 操作

  1. 新机安装 python3-pip 并安装 requirements.txt（pywebio）+ tornado；import 验证通过。
  2. 从老机同步 cicd-web/runtime 关键内容到新机：secrets.env、app-local-files、env-backups、manual-backups、config-backups、sync-artifact-backups、tencent-cdn-auth.key 等（排除超大日志）；保持 root 属主。
  3. 新增 nginx 路由 /etc/nginx/conf.d/11-youdianse-test-cicd.conf：cicd.youdianse-test.xyz → 203.0.113.1:18090（HTTP 301 + HTTPS + WebSocket 升级 + 200M 上传限制）；nginx -t 通过并 reload。
  4. sudo ./cicd-web.sh start 启动（PID 196817，root 运行，与老机一致）。
  5. 安装 cronie 并添加每分钟 cicd-web-auto-update.py 自动更新 cron（工作区 dirty 时脚本安全跳过 pull）。

4.2 验证

  • https://cicd.youdianse-test.xyz/ 200（PyWebIO 页面）。
  • /auto-deploy/<错误token> 返回 401，端点与 token 校验生效。
