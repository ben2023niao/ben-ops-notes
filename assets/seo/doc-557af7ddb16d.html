域名与空间

域名，domain name，它是企业、政府、组织机构或个人在域名注册商上注册的名称，是访问互联网上的企业、机构或其他网站时所用的网络地址。

空间也叫网站空间或主机，主要用于存放网站内容，包括各种形式的文件和资料，比如说网站的页面、文档、图片、音影、数据库等。

http://www.sohu.com | | | | 网络协议 网络名 域名主体 域名后缀

常见的域名注册商：

| 注册商 | 地址 | 国内国外 |

| --- | --- | --- |

| 中国万网 | <http://www.net.cn> | 国内 |

| 新网 | <http://www.xinnet.com> | 国内 |

| 西部数码 | <http://www.west263.com> | 国内 |

| GoDaddy | <http://www.godaddy.com> | 国外 |

常见后缀的含义：

| 后缀 | 全称 | 描述 |

| --- | --- | --- |

| .com | company 的缩写 | 商业公司或组织，国际通用域名 |

| .cn | china 的缩写 | 中国境内 |

| .net | network 的缩写 | 提供网络业务服务 |

| .org | organization 的缩写 | 组织类,通常具有权威性 |

| .edu | education 的缩写 | 教育专用，权威教育机构 |

| .com.cn | com 和 cn 域名 | 中国境内的商业公司或组织 |

| .gov | government 的缩写 | 政府部门 |

后缀的选择，建议使用 .com 的，因为使用的人多，搜索引擎赋予的权重高，有利于后续优化。

常见的空间提供商和常见的域名注册商是一样的。IDC(Internet Data Center)即互联网数据中心，上面提到的常见域名注册商就是 IDC。

常见的空间类型：

| 空间类型 | 描述 |

| --- | --- |

| 虚拟主机 | 使用技术手段，将一台服务器划分成多个空间，提供给多个网站使用 |

| VPS 主机 | 虚拟主机的升级版，但可以远程登录服务器进行维护 |

| 独享主机 | 一个网站独享一台服务器，可以任意进行操作 |

| 云主机 | 新兴的高端空间类型，费用昂贵 |

购买空间需要考虑的问题：

  1. 预算和技术水平、操作系统和 web 服务器、数据库和开发语言、空间容量、月流量、接入方式(双线，多线)
  2. 月流量：如果你的月流量是 50G，你提供的下载文件是 1G，那么下载 50 次之后就不能继续下载了
  3. 接入方式：如果是双线的话就是电信和网通（解决了电信用户访问网通慢和网通用户访问电信慢的问题），多线就增加了比如，教育网，联通，移动等的网络，提高用户的访问速度。

空间的购买流程：

  1. 注册会员
  2. 挑选空间
  3. 购买空间
  4. 域名备案
  5. 域名解析

域名备案，在国外购买的空间无需备案，只有国内买的才需要，备案是为了防止有人进行非法活动。备案大概需要 20 个工作日。

域名解析：将域名解析到空间上。

用户体验

| 用户体验 | 影响因素 |

| --- | --- |

| 访问速度 | 网页大小，服务器稳定性，多线路由访问 |

| 网站结构 | 导航栏清晰，网站结构符合营销需求 |

| 网站内容 | 企业优势、产品优势、服务优势 |

| 网站设计 | 色彩搭配协调，用户习惯良好 |

| 购物流程 | 简化购物流程，丰富结算模式 |

| 网站诚信 | 资格认证，荣誉证书，第三方论证 |

| 联系方式 | 企业邮箱，客服热线 |

SEO优化

  1. 标题优化：搜索引擎在抓取网页的时，首先就抓取标题。需要优化首页标题，产品页标题，新闻页标题
  2. 内容优化：关键词密度（5%-8%），内容更新频率，内容原创性
  3. 关键词优化：使用第三方工具挖掘关键词
  4. 链接优化：外链(友情链接，博客论坛外链，购买外链)和内链（锚文本，tags 标签）
  5. 营销功能：在线客服，企业邮箱，广告促销，电子地图

网站结构

物理结构

物理结构可以分为扁平结构和树形结构，扁平结构是所有网页文件都放在根目录下：

| 特点 | 描述 |

| --- | --- |

| 适用 | 简单垂直的中小型网站 |

| 优点 | 内容易被搜索引擎抓取 |

| 缺点 | 内容杂乱，用户体验不好 |

树形结构是根目录下分为多个栏目或者频道，网站内容按照类别分为不同的栏目：

| 特点 | 描述 |

| --- | --- |

| 适用 | 类别多，内容量大的网站 |

| 优点 | 内分类详细，信息方便查找 |

| 缺点 | 不利于搜索引擎抓取 |

| 注意 | 避免分类路径过深，分类目录不超过三级 |

逻辑结构

逻辑结构是指通过连接，将网站内部的各页面组织起来的结构图。推荐做法：

首页 ----------> 栏目页1 /\ | 链| | 互连 接| | 内容页 栏目页2

网站的结构也是影响 SEO 的重要的一个要素，搜索引擎是模仿人来浏览网站的，网站结构混乱，搜索引擎也不会收录。

首页的权重一般是最高的，搜索引擎给其的排名也是在最前面的。

网站页面与布局

网站页面类型：

  • 网站首页
  • 频道页\栏目页
  • 列表页
  • 内容页
  • 其他页面（注册页，登陆页）

网页结构：

  • 头部 head 区（LOGO，Banner，导航栏）
  • 主体 body 区(页面正文内容，文字，图片，动画等)
  • 底部 footer 区（友情链接，招贤纳士）

导航类型：

  • 主导航（一般位于网站的顶部）
  • 次导航（一般位于网站的两侧）
  • 面包屑导航（一般是位置导航，可以让用户知道自己目前所处的位置）
  • 网站地图（主要是为了给搜索引擎指引道路，一般会包含所有的频道和网站的路径）

网页布局，一般是由左到右，由上到下（左边的重要性大于右边的，上面的重要性大于下面的）。
