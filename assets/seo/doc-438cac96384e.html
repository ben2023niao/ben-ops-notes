用途

这份文档给 AI、运维和发布人员在操作线上环境前阅读，用来确认每台服务器的连接方式、认证材料、部署内容、运行进程、关键路径和风险边界。

本页只记录“需要用哪个账号和哪个密钥文件连接”，不记录密码、token、私钥内容、证书私钥、Git 凭据或 Telegram chat_id。

操作前必读

  1. 当前仓库 main 分支对应游点涩线上环境，执行前必须确认不要误用测试环境配置。
  2. 所有服务器操作优先只读核对，再决定是否修改。
  3. 需要发布、重启、改 Nginx、改 crontab、改密钥文件、改 Docker 配置前，先说明影响范围和回滚方式。
  4. 不要在终端、文档、提交或 Telegram 中输出任何密码、token、私钥内容、证书私钥、Git 凭据。
  5. 线上后端服务器的 Telegram 运行密钥在 /opt/docker-youdianse-php/cicd-web/runtime/secrets.env，只允许程序读取后发送通知，不允许打印内容。

后端 游点涩-后端 16.209.16.108 203.0.113.1 / ip-172-31-31-108 ssh -i id_rsa ubuntu@16.209.16.108 仓库根目录 id_rsa PHP 后端、后端 Nginx、php-cron 队列、CICD Web、Beszel Agent、SQL Server

补充说明：

  • 宝塔也保留 ssh -i id_rsa ubuntu@16.208.5.147 作为备用连接方式，但常规 Nginx/宝塔配置操作使用 root 和 16.208.5.147_id_ed25519。
  • ubuntu 登录后涉及 Docker、crontab、系统服务通常需要 sudo。本文不记录 sudo 密码；若实际提示密码，应通过既有安全渠道确认。
  • 宝塔面板、CICD Web、数据库等业务密码不写入文档。

3 * * * * /usr/bin/flock -xn /var/run/youdianse-health-summary.lock /usr/bin/python3 /usr/local/sbin/youdianse-health-hourly-summary.py >> /var/log/youdianse-health-summary.log 2>&1

AI 操作建议

发布或排障前，AI 应按这个顺序读取资料：

  1. AGENTS.md：确认线上环境通知规则。
  2. README.md：确认发布主流程和固定信息。
  3. ops/production/2026-07-06-1608-【运维记录】线上环境服务器速查.md：快速确认服务器和流量入口。
  4. ops/production/2026-07-29-1430-【运维记录】线上环境服务器详细信息与AI操作参考.md：确认连接账号、密钥文件、部署内容和运行状态。
  5. 涉及宝塔/Nginx 时，再读 docs/2026-06-16-2204-【网络调整】线上环境宝塔反向代理固定配置运维手册.md。

若当前服务器状态和本文不一致，以实时只读核对结果为准，并在操作结束后补充本文或服务器速查文档。
