背景

用户计划不续费 162.211.181.13（youdianse-test-cdn-proxy），要求盘点该机部署/运行内容，并分析关停对测试环境的影响。本次登录机内盘点使用用户临时提供的凭据，密码不写入任何文档/Git。

服务器角色

162.211.181.13 = youdianse-test-cdn-proxy（Ubuntu 24.04.1 LTS）
角色：测试环境备案域名（腾讯 EdgeOne/CDN）HTTP 回源 + 反向代理 Nginx 服务器
部署：本机 Nginx + Docker + docker-compose；无业务后端/数据库/队列

机内盘点（2026-08-25 登录确认）

系统：Ubuntu 24.04.1 LTS；运行 6 天；内存 1.9Gi（用 468Mi）；磁盘 99G（用 7%）
运行服务：nginx / docker / ssh / cron / rsyslog / systemd-resolve
监听端口：22(ssh)、80(nginx)、61208(beszel-agent)；443 未开（TLS 由 EdgeOne 终止）

Nginx：/etc/nginx/conf.d/youdianse-test-record-domains.conf（8 个 server 块，仅监听 80）
  upstream 指向：
    youdianse_test_h5_app  -> 38.92.8.34:3003
    youdianse_test_pc_app  -> 38.92.8.34:3004
    youdianse_test_php_api -> 38.92.8.34:8088
  server 块：
    test-h5.hbabaxb.cn / test-h5.hbazuua.cn -> H5(3003) + API(8088)
    test-pc.hbabaxb.cn / test-pc.hbazuua.cn -> PC(3004) + API(8088)
    test-h5-s3.hbabaxb.cn -> S3 18game-nuxt-static-test-h5
    test-pc-s3.hbabaxb.cn -> S3 18game-nuxt-static-test-pc
    test-img.hbabaxb.cn / test-img.hbazuua.cn -> CloudFront d1rct3ku9n07y3（token/t）

Docker：仅 1 个容器 beszel-agent（henrygd/beszel-agent，restart=unless-stopped，端口 61208），
  上报到 beszel hub（HUB_URL=http://localhost:8090，hub 在其它机器）。

定时任务：仅系统默认（sysstat/apt/motd/tmpfiles），无自定义 cron。

公网链路现状（DNS 探针）

test-h5 / test-pc / test-img（hbabaxb.cn 与 hbazuua.cn 共 6 个）
  -> CNAME 指向腾讯 EdgeOne（*.eo.dnse4.com）-> 回源 162.211.181.13:80
test-h5-s3 / test-pc-s3
  -> 公网 A 记录指向 138.252.248.139（非本机），不走 162.211.181.13 的公网路径；
     本机仍配置了这两个域名的反代兜底。
主入口 admin/h5/pc/cicd/cron 的 *.youdianse-test.xyz -> 直连 38.92.8.34，不经过本机。

关停影响分析

直接影响（会断）：
  1. test-h5.hbabaxb.cn / test-h5.hbazuua.cn（H5 备案入口）
  2. test-pc.hbabaxb.cn / test-pc.hbazuua.cn（PC 备案入口）
  3. test-img.hbabaxb.cn / test-img.hbazuua.cn（uploads 图片 token/t 链路）
  表现：EdgeOne 回源 502；未命中缓存时页面/图片打不开或回退固定图。

不受影响：
  1. admin/h5/pc/cicd/cron 的 *.youdianse-test.xyz 主入口（直连 38.92.8.34）
  2. 后端 API、容器、数据库、Redis、队列（都在 38.92.8.34 / 远端）
  3. test-h5-s3 / test-pc-s3 公网路径（指向 138.252.248.139）
  4. 测试环境日常开发/发布（不经本机）

其它：
  beszel 对该机的监控会失联（不影响 38.92.8.34 的 beszel agent）。
  本机无业务数据，关停无需迁移数据；仅需在 EdgeOne 侧处理 6 个备案域名回源。

建议

1. 若确定不续费：先在腾讯 EdgeOne 控制台把 6 个备案域名的回源地址从 162.211.181.13
   改为 38.92.8.34（H5/PC/API 直接回源 38.92.8.34:3003/3004/8088；
   test-img 回源需按 token/t 链路的可用源调整，或改为直接回源可用 CloudFront/S3 网关），
   验证 200 后再关停，避免备案域名访问中断。
2. 关停前：保留本机 nginx 配置备份（已在 /etc/nginx/conf.d/ 留有多份 .bak），
   并把 youdianse-test-record-domains.conf 归档到本仓库 docs/workbench 记录。
3. beszel-agent 容器无需迁移（仅监控本机）。
4. 若只是暂停备案域名测试，可仅停 EdgeOne 域名回源，不急着关服务器。
