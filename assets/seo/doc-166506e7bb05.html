dbqp-saopaulo-sanic-prod-03 Python 修复

参考版本

prod-01 / prod-02 的业务容器 Python 版本一致：

  • dbqp-panda-release-01 / 02：Python 3.11.15
  • dbqp-pg-release-01 / 02：Python 3.11.15
  • dbqp-platform-api-release-01 / 02：Python 3.11.15
  • dbqp-playson-release-01 / 02：Python 3.11.15
  • dbqp-popok-release-01 / 02：Python 3.11.15
  • dbqp-pp-release-01 / 02：Python 3.11.15
  • dbqp-tada-release-01 / 02：Python 3.11.15

prod-03 修复前

  • 系统：Ubuntu 26.04 LTS
  • python：Python 3.14.4
  • python3：Python 3.14.4
  • python3.11：不存在

已执行修复

由于 Ubuntu 26.04 默认仓库未提供 python3.11 包，为避免替换系统 Python 影响系统组件，已在 prod-03 独立编译安装 Python 3.11.15：

  • 安装目录：/opt/python-3.11.15
  • 开发入口：/usr/local/bin/python
  • 版本入口：/usr/local/bin/python3.11
  • pip 入口：/usr/local/bin/pip3.11
  • 系统入口：/usr/bin/python3 保持 Ubuntu 默认 Python 3.14.4

修复后验证

在 dbqp-saopaulo-sanic-prod-03 上验证：

python --version
# Python 3.11.15

python3.11 --version
# Python 3.11.15

pip3.11 --version
# pip 24.0 from /opt/python-3.11.15/lib/python3.11/site-packages/pip (python 3.11)

/usr/bin/python3 --version
# Python 3.14.4

开发在 prod-03 上做内网测试/压测时，建议使用 python 或 python3.11 创建虚拟环境，例如：

python3.11 -m venv .venv
source .venv/bin/activate
python --version
