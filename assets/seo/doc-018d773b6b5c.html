一、用户口径（本轮指令）

动态域名不要做任何跨域处理；开发代码来做跨域处理。
运维只做静态域名的跨域处理。
本轮按要求不通知飞机群。

二、执行：撤销上一轮在动态域名的 CORS 兜底

撤销内容（2026-10-05 12:50 那次改动，见 docker/doc/2026-10-05-1250）：
  /etc/nginx/snippets/bizops-hk-standby-proxy.conf 里新增的三行：
    proxy_hide_header Access-Control-Allow-Origin;
    add_header Access-Control-Allow-Origin $http_origin always;
    add_header Vary "Origin" always;
执行：
  1. 服务器片段已还原为原始内容（grep Access-Control-Allow-Origin / Vary = 0 行），
     原始文件仍留备份 /etc/nginx/snippets/bizops-hk-standby-proxy.conf.bak-20261005
  2. 仓库同步还原：docker/deploy/hongkong/nginx-standby-proxy.conf（回到 10 行原始版本）
  3. nginx -t 通过 -> systemctl reload nginx

三、验证（撤销后两侧行为）

动态域名（CORS 头完全来自后端，nginx 不加工）：
  https://vendor_b-games.k8x2v9.shop/health（带 Origin）
    -> 200 + access-control-allow-origin: <回显 Origin> + allow-credentials: true
       + allow-methods / allow-headers / max-age=86400（全部由后端 Sanic 输出）
  https://vendor_b-games.k8x2v9.shop/nope-xyz（404，带 Origin）
    -> 404 + access-control-allow-origin（后端对错误响应也带）
  已确认响应里没有 nginx 添加的 Vary: Origin（撤销生效）。

静态域名（运维负责，稳定输出 ACAO *）：
  vendor_b-static.k8x2v9.shop/ifff/index.html -> 200 + ACAO: * + allow-methods/headers
  pg-static.k8x2v9.shop/health.json       -> 200 + ACAO: *
  pp-static.m4q7z1.shop/favicon.ico       -> 200 + ACAO: *
  实现位置：通用静态块的 proxy_hide_header + add_header（见 nginx-standby.conf 与
  snippets/bizops-hk-standby-static-extra.conf），以及静态桶自身的 CORS 配置。

四、职责划分（长期口径）

| 层 | 谁负责 | 具体内容 |
| --- | --- | --- |
| 动态域名（*-games / api / socket 等） | **开发代码**（后端 Sanic CORS 中间件） | 回显 Origin、allow-credentials、允许的方法/头、OPTIONS 预检；运维不改这类响应头 |
| 静态域名（*-static） | **运维**（nginx + 桶 CORS） | 统一 ACAO *、GET/HEAD/OPTIONS、OPTIONS 204、customizations.info 与 .js 等特殊规则 |

备注：nginx 自产 502/503/504 不带 CORS 头属于「动态域名」范畴，按本口径**也不由运维补**；
若后端不可用导致浏览器把网关错误显示成跨域，请先确认后端容器状态（容器监控会报警）。
