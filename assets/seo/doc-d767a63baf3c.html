三、结果集权限问题（第二次同类）

现象：vendor_a 日志 “建立只读连接失败 vendor_a_540: attempt to write a readonly
database”（4 次，08:23:49 UTC，V20260909 重启后）。
根因：昨日结果集 rsync 后 /opt/game_results_datas/pp、vendor_a 等目录属主
root:root、755；容器 appuser(uid1000) 无法创建 SQLite WAL/-shm。
修复：01/02/03 对 pg/vendor_a/pp/ppk/vendor_c/vendor_d/g759 统一
  chown -R 1000:1000 + chmod -R u+rwX,go+rX。
验证：三台逐容器 os.access 检查 readbad=0、目录写测试通过、uid=1000；
  vendor_a_540/pp_5708 quick_check=ok；08:31 后无新增 readonly/no such。
防复发：docker/scripts/sync_game_results_data.py 增加
  rsync --chown=1000:1000 与同步后 fix_target_permissions
  （自动 chown/chmod uid1000）；README 固化“禁止裸 rsync 不带 chown”规则。
